Level 2 · C140·M4

Kernel trick

Your goalCalculate a dot product in a feature space using a kernel function applied to the input points, check the equality on an example, then classify a new point using the dual form.

Before you start

✿01 See the idea

Two fictional signals, centered and without units, are read four times. The label y is +1 when the two signals have the same sign, and −1 when they have opposite signs. The four readings are plotted as A, B, C and D in the first diagram. All values on this page are fictional.

No straight line in the plane separates them. At the midpoint of two points, an affine score takes the average of its values at those two points. The midpoint of A and B is the origin; so is the midpoint of C and D. A score that is positive at A and B would therefore be positive at the origin, and a score that is negative at C and D would be negative at the same place: this is a contradiction.

Add a calculated coordinate: the product x1x2 of the two signals. It is +1 for A and B, and −1 for C and D; in this richer space, a simple threshold is enough. The cost is that we have to build a list of coordinates for each point, and this list grows quickly as we add signals and products.

The kernel trick uses a fact from the unit on the dual, repeated here without a new proof: in the hard-margin dual problem, the points appear only through their pairwise dot products, and the same holds for the decision function. If we can calculate the dot product of two lists of coordinates using only the two original points, we never need to write out those lists.

Here are the objects involved. The feature map φ sends a point in the plane to a list of coordinates; the dot product ⟨·, ·⟩ adds the products of corresponding coordinates; the kernel k is the function that gives this dot product directly. In the decision function, the dual weights α are positive or 0, one per training point, the y values are the labels, the x values are the training points and b is the bias.

k(a,b)=⟨φ(a),φ(b)⟩
f(x)=∑iαiyik(xi,x)+b

Assumptions and limits. The data are fictional, the margin is hard (no errors allowed) and the points are separable in the feature space. The trick is valid only if k really is a dot product in a feature space; here we check this using an explicit map φ, and we do not cover a general criterion.

The rule to remember

Calculate k(a, b) directly from the input points rather than calculating ⟨φ(a), φ(b)⟩ coordinate by coordinate, then replace the dot product with k in the dual and in the decision function, provided that k really is a dot product in a feature space.

✿02 Follow an example

Worked example

Four fictional readings and a new point

The four fictional readings are A = (1, 1) and B = (−1, −1) with label +1, then C = (1, −1) and D = (−1, 1) with label −1; the coordinates have no units. A new point U = (3, 1) arrives. We want its label using the kernel k(a, b) equal to the square of ⟨a, b⟩, without ever writing φ(U) in the decision calculation, then we check using explicit calculations.

  1. Set out the points and check that a straight line fails

    A point is written x = (x1, x2). At the midpoint of two points, an affine score g(x) = w1x1 + w2x2 + b takes the average of its values at those points. For A and B, the sum of each coordinate is 1 + (−1) = 0: the midpoint is the origin. For C and D, the result is the same. Separation would require g(origin) > 0 from A and B, and g(origin) < 0 from C and D. A straight line therefore cannot work.

  2. Build the map φ

    Choose the following map. The coordinate x1x2 is written twice: the usual version of this kernel includes it just once with an irrational factor, giving the same dot product; we repeat it to stay within the rational numbers.

    φ(x)=(x12,x1x2,x1x2,x22)

    For A = (1, 1), φ(A) = (1, 1, 1, 1). B = (−1, −1) gives the same four numbers, because the product of two numbers with the same sign is positive. For C = (1, −1), φ(C) = (1, −1, −1, 1), and D = (−1, 1) has the same image.

  3. Separate in the feature space

    Take the weight vector w = (0, 1/2, 1/2, 0) and b = 0. Then w·φ(A) = 0×1 + 1/2×1 + 1/2×1 + 0×1 = 1, and w·φ(C) = 1/2×(−1) + 1/2×(−1) = −1. All four points therefore have exactly y(w·φ(x) + b) = 1: they all lie on the functional margin boundary.

    In the original plane, this score is f(x) = 1·x1x2, the product of the two signals. The separator is linear in the space of φ; viewed in the plane, it is nonlinear.

  4. The trick: the same number without building φ

    Expand the square of the dot product in the plane. The four terms on the right are, in order, the four products of corresponding coordinates of φ(a) and φ(b).

    k(a,b)=⟨a,b⟩2=(a1b1+a2b2)2
    (a1b1+a2b2)2=a12b12+a1a2b1b2+a1a2b1b2+a22b22

    So k(a, b) = ⟨φ(a), φ(b)⟩. Test this on C = (1, −1) and U = (3, 1). Short path: ⟨C, U⟩ = 1×3 + (−1)×1 = 3 − 1 = 2, giving k(C, U) = 2 × 2 = 4.

    k(C,U)=(3−1)2=22=4

    Long path: φ(U) = (9, 3, 3, 1) and ⟨φ(C), φ(U)⟩ = 9 − 3 − 3 + 1; we calculate 9 − 3 = 6, then 6 − 3 = 3, then 3 + 1 = 4. Both paths give 4, and the first handled only two numbers per point.

  5. Build the Gram matrix

    The Gram matrix K stores k(x, x′) for all pairs of training points, in the order A, B, C, D. For A with itself, ⟨A, A⟩ = 1 + 1 = 2 and k = 2 × 2 = 4. For A and B, since B = −A, the dot product changes sign and squaring removes that change: k(A, B) = 4. The kernel is therefore even, k(−a, b) = k(a, b). For A and C, ⟨A, C⟩ = 1 − 1 = 0, giving k = 0.

    K=(4400440000440044)

    The other entries follow from symmetry or evenness. Between a + point and a − point, the kernel is 0; between points with the same label, it is 4. This matrix was calculated entirely in the plane.

  6. Classify point U using the dual

    We use the dual solution for these four points: all four weights are α = 1/8 and b = 0. This is given as a starting point and checked in the next step. Between each training point and U: ⟨A, U⟩ = 3 + 1 = 4, so k(A, U) = 4 × 4 = 16; k(B, U) = 16 by evenness; k(C, U) = k(D, U) = 4 from the previous step.

    Add the signed contributions: 16 + 16 = 32 for the + points, and 4 + 4 = 8 for the − points.

    f(U)=1/8×(32−8)=1/8×24=3

    The sign is positive: U receives the label +1. Also, f(U) = 3 exceeds 1, so U is beyond the margin boundary. No list of coordinates of φ(U) was used in this decision.

  7. Check by three other routes

    Direct route: w·φ(U) = 1/2×3 + 1/2×3 = 1×3 = 3, and x1x2 is 3×1 = 3: three ways, one number 3.

    Reconstructed weights: w = the sum of α·y·φ(x) over the points. In the second coordinate, φ(A) and φ(C) are 1 and −1, with a difference of 1 − (−1) = 2; with two points per class, this gives 2 × 2 = 4, then 1/8 × 4 = 1/2, which is indeed the value 1/2 in w. The third coordinate gives the same value, and the first and last coordinates cancel because φ(A) and φ(C) coincide there.

    Sum of signed weights: each class has 1/8 + 1/8 = 1/4, and the difference between the classes is 0.

    These equalities — positive weights, a signed sum of 0, w reconstructed from the weights, and the margin reached at points with nonzero weight — are the dual conditions from the previous unit. We check them here without proving optimality again or drawing a conclusion for other data.

Explain it in your own words

Explain why calculating f(U) never needed φ(U), and why we nevertheless needed to know that k is a dot product of features. What would happen to the result if each product of coordinates were squared separately?

✿03 Common mistakes

  • “The kernel trick calculates φ faster.”

    It avoids building φ: the dual needs only the dot product of the two lists. The exercise counts 101 multiplications versus 30000 for a fictional case; this is an operation count rather than a measured time.

    Repeat the operation count

  • “The kernel is the sum of the squares of the products of coordinates.”

    The square applies to the entire sum. For C and U, the sum of squares gives 10, whereas the kernel is 4: the two cross terms a₁a₂b₁b₂ are missing from the incorrect formula.

    Review the expansion of the square

  • “If a hyperplane separates the points after φ, a straight line would already have been enough in the plane.”

    The hyperplane lies in the feature space. In the original plane, f(x) = x₁x₂ is 0 on both axes, and the midpoints of A, B and of C, D coincide: no straight line works, although a separator exists in the space of φ.

Exercise 1 · Direct application

Two paths for a new pair

Using the fictional points a = (2, 1) and b = (1, −3), calculate k(a, b) by the short path, then ⟨φ(a), φ(b)⟩ by the long path, and compare.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Keep the sign of ⟨a, b⟩ before squaring it.

Hint 2

First write φ(a) and φ(b), each with its four coordinates (square of the first, product of the two coordinates twice, square of the second).

Compare with the solution

Short path: ⟨a, b⟩ = 2×1 + 1×(−3) = 2 − 3 = −1, so k(a, b) = (−1) × (−1) = 1.

Long path: φ(a) = (4, 2, 2, 1) and φ(b) = (1, −3, −3, 9). The dot product is 4×1 + 2×(−3) + 2×(−3) + 1×9, giving 4 − 6 − 6 + 9. Regrouping: 4 + 9 = 13, then 13 − 6 = 7, then 7 − 6 = 1.

Both paths give 1. The original dot product was negative, while the kernel is positive because it is a square: there is no contradiction, because k is the dot product of the images under φ rather than of a and b.

Check your reasoning

  • The sign of ⟨a, b⟩ is kept before squaring.
  • All four coordinates of φ(a) and φ(b) are written out.
  • Both paths give the same number.

Exercise 2 · Application with explanation

Classify a second point

Use the weights α = 1/8 and b = 0 from the example. Determine the label of the fictional point V = (3, −1) using the four kernel values, then check with f(x) = x₁x₂.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

V is obtained from U by changing the sign of one coordinate: look at what this does to ⟨A, V⟩ and ⟨C, V⟩.

Hint 2

The kernel is even: k(B, V) = k(A, V) and k(D, V) = k(C, V). The contributions have now swapped roles.

Compare with the solution

⟨A, V⟩ = 3 − 1 = 2, so k(A, V) = k(B, V) = 4. ⟨C, V⟩ = 3 + 1 = 4, so k(C, V) = k(D, V) = 16.

f(V) = 1/8 × (8 − 32) = −1/8 × 24 = −3: point V receives the label −1, and its absolute score exceeds 1, so V is beyond the margin.

Check: x1x2 = 3×(−1) = −3. The two routes agree.

Check your reasoning

  • All four kernel values are calculated, using evenness.
  • The sign and magnitude of f(V) are interpreted.
  • The check using the product of the signals is carried out.

Exercise 3 · Transfer

Count without drawing conclusions too quickly

Fictional case: each point has n = 100 signals, and φ lists all products of two signals taken in order (signal i then signal j), giving n squared coordinates. For a pair a, b, count only the multiplications in the long path (build φ(a), build φ(b), then take their dot product) and in the short path (⟨a, b⟩ then its square). State what this count does not prove, and how many entries the Gram matrix of 4 points has.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Each coordinate of φ costs one multiplication to build; the dot product of two lists of the same length costs as many multiplications as that length.

Hint 2

For ⟨a, b⟩: one multiplication per signal, then one for the square. For Gram: one entry per ordered pair of points.

Compare with the solution

The square of n is 10000. Long path: 10000 multiplications for φ(a), as many for φ(b), and as many for the dot product, so 3 × 10000 = 30000. Even when reusing lists already built, the dot product alone costs 10000.

Short path: 100 multiplications for ⟨a, b⟩, plus one for the square, giving 100 + 1 = 101.

This count ignores additions, memory, reads and any time measurement; it proves neither an actual improvement in a program nor that a kernel suits a dataset. The Gram matrix of 4 points has 4 × 4 = 16 entries, with somewhat fewer to store thanks to symmetry: it grows with the number of points rather than with the dimension of φ.

Check your reasoning

  • Multiplications are counted for each path using the same conventions.
  • The limit of the count (no measured time, no guarantee about the model) is stated.
  • The size of the Gram matrix depends on the number of points.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What does a kernel k(a, b) calculate in this unit?

The dot product ⟨φ(a), φ(b)⟩ of two lists of coordinates, obtained directly from a and b; here, the square of ⟨a, b⟩.

Recall 2What does the kernel trick replace in the dual and in the decision function?

It replaces each dot product of the input points with k(x, x′); the decision becomes the sum, over the training points, of α·y·k(point, x), plus b.

Recall 3What equality links the short and long paths for the pair C and U?

k(C, U) = ⟨C, U⟩ squared = ⟨φ(C), φ(U)⟩: 2 squared gives 4, and the sum of the four products of corresponding coordinates of φ also gives 4.

Recall 4What does the success of this example fail to guarantee?

It guarantees neither that a kernel suits other data, nor a general criterion for kernel validity, nor good performance: the example is fictional, with a hard margin and an explicit φ.

Reconstruct the reasoning

Set out the points and labels; use the midpoints to show that a straight line fails; choose φ and separate in its space; see that the dual uses only dot products; replace each one with k(a, b) calculated from the input points, checking the equality on a pair; build the Gram matrix and classify U using the signed sum of α·y·k; check using w, the weights and their sum; keep the limits in mind: a valid kernel, fictional data, and an operation count without measured time.
