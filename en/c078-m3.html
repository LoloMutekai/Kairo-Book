Level 2 · C078·M3

Degenerate geometry and missing results

Your goalDecide whether an angle is defined before calculating it, then pass on a missing result without replacing it with a 0 angle.

Before you start
c027-m5 : complex numbers · c040-m5 : least squares · c036-m5 : annotated graphs · c022-m5 : untrusted inputs and injection · c078-m1 : pixels, coordinates and normalization · c078-m2 : landmarks, segments and angles

✿01 See the idea

On an image of a hinge, you mark A at the end of one arm, B at the pivot and C at the end of the other arm. The opening at B compares the directions from B to A and from B to C. As long as each drawn arm has a length, you can talk about this opening.

Now move A exactly onto B. Where does arm BA point? There is no displacement to determine a direction. The coordinates still exist, but the construction needed for this angle has collapsed: this is degenerate geometry. An angle of 0° would instead mean that the nonzero arms point in the same direction.

If C has not been recorded, the problem occurs even earlier: the second arm cannot even be constructed. “Missing landmark” and “0-length segment” are therefore distinct reasons for an unavailable angle. A missing measurement does not mean that the hinge does not exist.

The hinge, its images and all the coordinates are fictional. We study only the geometry of the drawing in the plane; we do not infer any physical opening outside the image. The axes use the same scale, and the pixels are assumed to be square.

The rule to remember

Check the landmarks, then the lengths; calculate the angle only if its directions exist. Keep a value together with its status: a 0 angle can be valid, and a missing result must keep its reason.

✿02 Follow an example

Worked example

Measure the hinge, then know when to stop

We receive A = (2 ; 1), B = (2 ; 4) and C = (6 ; 4), in pixels, in the same coordinate system. Let us calculate the angle at pivot B. We will then examine the same set of recorded positions with A moved onto B, then with C missing.

  1. Establish what the input lets us say

    Here, a landmark is a named position given by its x and y coordinates. For a point P, xp and yp are these coordinates, in pixels, abbreviated px. A, B and C denote the points; B is the vertex of the angle. All 3 points must be present with finite coordinates, meaning numbers without infinity or an undefined numeric value.

    We treat the fictional coordinates as exact and the plane as Euclidean: the axes have the same unit and scale. Different normalization in width and height does not generally preserve angles; a common metric would have to be restored before this calculation. The presence of a number does not prove that a landmark has been correctly placed.

  2. Form the directions from the pivot

    u = A − B and v = C − B are the vectors from the pivot to the endpoints; their components ux, uᵧ, vx and vᵧ are in pixels. Subtraction removes the position of the pivot, leaving only the displacement.

    u=(xA−xB;yA−yB)

    Thus u = (2 − 2 ; 1 − 4) = (0 ; -3) px, and v = (6 − 2 ; 4 − 4) = (4 ; 0) px. Both directions start at B; following A towards B for the first vector would change the angle being studied.

  3. Check that each direction exists

    The norm of a vector is its length. Lᵤ = ‖u‖ and Lᵥ = ‖v‖ are in pixels; U and V denote their squares, in square pixels. Using the squares avoids taking a square root when deciding whether a length is 0.

    U=ux2+uy2;V=vx2+vy2

    U = 0 × 0 + (-3) × (-3) = 0 + 9 = 9 square pixels; V = 4 × 4 + 0 × 0 = 16 + 0 = 16 square pixels. Both are strictly positive. Lᵤ = √U = 3 px and Lᵥ = √V = 4 px. Here the segments are vertical and horizontal: their lengths are also 0 − (-3) = 3 px and 4 = 4 px. This shortcut depends on this arrangement.

  4. Divide only after checking

    p = u·v is the dot product: multiply the corresponding components, then add the products. It is in square pixels. D = LᵤLᵥ is the denominator, in the same unit. Their ratio r is dimensionless: it is the cosine of the angle θ, the Greek letter theta.

    p=uxvx+uyvy;D=LuLv;r=pD

    p = 0 × 4 + (-3) × 0 = 0 + 0 = 0 square pixels. D = 3 × 4 = 12 square pixels, which is strictly positive: division is allowed. r = 0/12 = 0. The arccos function, the inverse of cosine over the interval of angles from 0° to 180°, gives θ = 90° here.

    In exact geometry, r belongs to [-1 ; 1]. After validating the data, a program can clamp it to this interval to correct a tiny overshoot caused by rounding. This clamping never restores the direction of a 0-length segment.

  5. Check using another geometric relationship

    Let us calculate the side joining A to C, without reusing the ratio r. C − A = (4 ; 3) px. Its squared length is 16 + 9 = 25 square pixels. Now U + V = 9 + 16 = 25 square pixels: the converse of the Pythagorean theorem confirms the right angle at B.

    The result is therefore “valid; 90°” for the drawing and the stated assumptions. It tells us neither the depth of the scene nor the quality of any automatic landmark detection.

  6. Repeat with A coinciding with B

    Replace only A with (2 ; 4). The new u is (0 ; 0) px. Its squared length is 0 + 0 = 0 square pixels; its norm is therefore 0 px. The denominator would be 0 × 4 = 0 square pixels.

    Stop before division: the quotient 0/0 does not define a cosine. Returning 0° or arbitrarily adding a small quantity to the denominator would invent a direction. The output to pass on is “unavailable; 0-length segment BA”, with no angle value. Even if the program returned a number, the mathematical construction would remain invalid.

  7. Repeat with C missing and preserve the cause

    This time A and B keep their initial positions, but no recorded position is provided for C. Neither v nor V can be calculated. Return “unavailable; missing landmark C”, without substituting coordinates (0 ; 0), silently reusing an old C or calling arccos.

    The recipient must look at the status before reading the value. For a valid output, the recipient can display the angle, including 0°. For an unavailable output, the recipient keeps the reason and leaves a gap in the measurement. A very short but nonzero segment passes our exact check; this is not enough to establish its reliability. Any additional rejection rule would need a justified threshold in the units of the coordinate system.

Explain it in your own words

Hide the calculation. Why must you check presence before lengths, and lengths before division? Explain why “missing direction” does not mean “0 opening”.

✿03 Common mistakes

  • “If a point is missing, I set the angle to 0°.”

    A 0 angle is a real opening between nonzero segments pointing in the same direction. Without C, the second segment is unknown. Pass on an unavailable status and the reason; the first exercise shows a 0 angle that is actually defined.

    Compare with the collinear case in the exercises

  • “I clamp the cosine, so division becomes safe.”

    Clamping comes after a defined quotient. If a length is 0, the denominator is 0: you must stop before division. Adding a small constant does not repair the missing direction.

    Review the length checks and the repeated case A = B

  • “As soon as the points are collinear, the angle no longer exists.”

    For this angle at vertex B, BA and BC must be nonzero. Two collinear directions can give 0° or 180°. The triangle can be flattened while the angle remains defined. Identify which object the calculation requires.

    Return to the directions from the pivot

Compare with the solution

Initial configuration: “valid; 90°”. C = A: “valid; 0°”. A = B: “unavailable; no value; 0-length segment BA”. C missing: “unavailable; no value; missing landmark C”.

The report therefore keeps 2 defined angles. It must consult the status to allow display, then display the value even if it is 0. For the other inputs, it displays the reason for unavailability and keeps a gap: replacing them with zeros would create openings that have not been measured.

The absence of C does not prove the absence of the hinge. It says only what this set of recorded positions does not allow us to measure. Likewise, being able to calculate the geometry in the image does not by itself guarantee that the landmarks are correctly located.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1In what order should you check an angle obtained from landmarks A, B and C?

Check that the coordinates are present and numerically valid in a common coordinate system; form A − B and C − B; check that their lengths are nonzero; only then calculate the quotient and the angle.

Recall 2Why does A = B not simply give a 0 angle at pivot B?

The vector A − B has 0 length, so it has no defined direction. The cosine denominator becomes 0: no angle is obtained. A 0 angle instead requires two nonzero vectors pointing in the same direction.

Recall 3In our hinge, does C = A always make the angle at B unavailable?

No: if A is distinct from B, the two vectors starting at B are equal and nonzero. Their cosine is 1 and their angle is 0°. The flattened triangle is not enough to invalidate this angle.

Recall 4What should you pass on if C is missing, and what can you conclude?

Pass on an unavailable angle, with no value and with the reason missing landmark C. The recorded positions do not allow the measurement; they do not demonstrate that the real object or point does not exist.

Recall 5Why does clamping the cosine not repair degenerate geometry?

Clamping can correct a small rounding overshoot after a defined division. It creates neither a missing coordinate nor a direction for a 0-length segment. The status and the cause must reach the recipient.
