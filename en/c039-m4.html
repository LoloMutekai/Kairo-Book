Level 1 · C039·M4

Linear maps

Your goalRecognize a linear map, calculate its effects from a basis, and describe the displacements it erases or can produce.

Before you start
c032-m5 : computational rank · c014-m5 : invariants · c039-m1 : subspaces · c039-m2 : independence · c039-m3 : bases

✿01 See the idea

A drawing plotter receives a horizontal displacement and a vertical displacement. In our fictional setting, it adds them, then draws this sum horizontally and twice this sum vertically. The command u = (2 ; 1) cm therefore becomes (3 ; 6) cm. The signs indicate directions: a negative component commands movement in the opposite direction.

Now imagine combining commands before sending them. A linear rule gives the same output if you first transform each command, then add the drawn displacements. It also preserves scaling: reducing or reversing the entire command reduces or reverses the entire output by the same factor.

We track displacements, starting at the origin. No constant displacement is added. The model accepts all real components, without rounding, mechanical limits, or noise. The numbers are fictional; this page does not describe measurements of a real device.

The second diagram reveals a feature of this setting: all outputs stay on the same line. A linear map can lose information. Linear therefore does not mean reversible, or that each component stays separate.

The rule to remember

Transforming a sum gives the sum of the images; transforming a multiple gives the image multiplied by the same scalar. These equalities must hold for all vectors and all scalars in the stated domain.

✿02 Follow an example

Worked example

Combine commands without changing the resulting drawing

The setting is T(x, y) = (x + y, 2(x + y)). Send u = (2 ; 1) cm and v = (-1 ; 2) cm. We will prove linearity, calculate their images, check addition, and determine what the plotter erases.

  1. State the domain, symbols, and units

    E is the plane of commands and F the plane of drawn displacements. Each is a real vector space: ordered pairs are added component by component and multiplied by a real number. A map T : E → F assigns a unique output to each command; T(u) is called the image of u.

    x and y are the numerical values of the input components, expressed in centimetres. Let s = x + y be their sum, also in centimetres. X = s and Y = 2s are the output components. The coefficient 2 is dimensionless. A scalar, denoted by λ, is here a dimensionless real number that multiplies the entire pair.

    The domain is the entire real plane: negative and fractional values are allowed. The setting stays fixed throughout all calculations. Rounding or clamping would be part of a different rule, to be examined separately.

  2. State and prove the general criterion

    T is linear when the following equalities hold for all u and v in E and every real scalar λ. The + signs on the left add inputs in E; those on the right add outputs in F.

    T(u+v)=T(u)+T(v)
    T(λu)=λT(u)

    To prove these properties together, now take arbitrary u = (x, y), v = (h, k). h and k are the components of v in centimetres; a and b are dimensionless real scalars. The command au + bv is (ax + bh, ay + bk). Applying our setting and then regrouping the terms gives:

    T(au+bv)=(a(x+y)+b(h+k)2a(x+y)+2b(h+k))
    T(au+bv)=aT(u)+bT(v)

    This is preservation of a linear combination. Taking a = b = 1 gives addition; taking a = λ and b = 0 gives scaling. The proof uses arbitrary components and the distributive law, rather than a few chosen commands.

  3. Calculate the images of the commands separately

    Return to the values in the problem. For u, adding the components gives s = 2 + 1 = 3 cm. The horizontal output is therefore 3 cm, and the vertical output is 2 × 3 = 6 cm: T(u) = (3 ; 6) cm.

    For v, the horizontal component is negative: s = (-1) + 2 = 1 cm. The vertical output is 2 × 1 = 2 cm. Therefore T(v) = (1 ; 2) cm. Keep the signs of the components when adding them.

  4. Add before and after: a check by two routes

    Input route: u + v = (2 + (-1) ; 1 + 2) = (1 ; 3) cm. The internal sum is 1 + 3 = 4 cm; therefore T(u + v) = (4 ; 8) cm.

    Output route: T(u) + T(v) = (3 + 1 ; 6 + 2) = (4 ; 8) cm. The results agree component by component. This check can reveal a calculation error; the general proof comes from the previous step.

  5. Recover the rule from the columns of its matrix

    The command basis consists of a horizontal displacement of 1 cm and a vertical displacement of 1 cm, denoted by p = (1 ; 0) cm and q = (0 ; 1) cm. Their images are identical: (1 ; 2) cm. Since T is linear, these images determine all the others.

    In F, we also use the horizontal and vertical unit displacements as a basis. In these fixed bases, A denotes the matrix of coefficients of T. Its first column contains the coordinates of T(p), and the second those of T(q). The coefficients are dimensionless: they express ratios of lengths, and both spaces use centimetres. The following multiplication acts on the numerical coordinate values; the output is read in centimetres.

    T(x,y)=A(xy)=[1122](xy)=(x+y2x+2y)

    The identical columns are not independent: different commands can have the same image. Changes of basis belong to the next unit; here we keep the same axes.

  6. Find the kernel: the erased commands

    The kernel of T, denoted by ker(T), is the set of inputs mapped to the 0 vector of F. Here, solving T(x, y) = (0 ; 0) amounts to solving x + y = 0. The second component is already 0 when the first is 0. Therefore y = −x.

    Every command in the kernel can be written as (t ; −t) cm, for real t. This is the line spanned by n = (1 ; -1) cm. Check its direction: 1 + (-1) = 0 cm; the output is (0 ; 0) cm. A nonzero command can therefore disappear.

    The word kernel refers to inputs, not outputs. It is a subspace: sums and multiples of erased commands remain erased, which follows directly from linearity.

  7. Find the image and check its description

    The image of the map, denoted by Im(T), is the set of all possible outputs. Every output has the form (s ; 2s) cm, so it lies on the line Y = 2X. Conversely, every point on this line is reached: for any real value s, the command (s ; 0) cm gives exactly (s ; 2s) cm. Both directions are needed to describe the entire image.

    Thus Im(T) is the line spanned by (1 ; 2) cm. The kernel and image are both lines here, but in different planes: the first contains the lost commands, and the second the attainable drawings. Their directions play different roles.

    Final checks: the calculated outputs do satisfy Y = 2X; T(0, 0) = (0 ; 0); and n, although nonzero, is erased. To guarantee this equality at the origin, linearity requires T(0u) = 0T(u). Adding a constant displacement to the output would violate this condition; the final exercise tests this.

Explain it in your own words

Without looking at the calculations, explain why the images of the basis vectors are sufficient, then give a nonzero command that is erased and an impossible output. Distinguish the general proof from the check on u and v.

✿03 Common mistakes

  • “The calculations on u and v agree, so I have proved linearity.”

    An equality for chosen values checks one case. Take arbitrary u = (x, y) and v = (h, k) again, then expand T(au + bv). Keep both scalars to cover addition and scaling.

    Review the general criterion and its proof

  • “If T is linear, I can always recover the command.”

    Here the kernel contains n = (1 ; -1) cm, which is nonzero. Adding a multiple of n to a command does not change its output. The identical columns of A explain this loss; the image covers only a line.

    Review the kernel, then the image

  • “Adding the same fixed displacement to every output still gives a linear map.”

    Test the 0 command. A horizontal offset of 1 cm would give (1 ; 0) cm instead of (0 ; 0) cm. This single counterexample is enough to reject linearity; then calculate where addition fails.

    Test the offset in the final exercise

Exercise 1 · Direct application

Reconstruct a command from the basis

The setting T stays unchanged. For w = (3 ; -2) cm, calculate T(w) by combining the images of p and q. Then check using the sum of the components. Give the units and the sign of each contribution.

Exercise 2 · Exact calculation and justification

Reduce and reverse a command

Take dimensionless λ = -1/2 and the command u from the example. Calculate λu, then T(λu) directly. Compare with λT(u). Keep the exact fractions and also give the outputs as decimals in centimetres.

Assisted answer: try this exercise without help later.

Hint 1

Multiplying the entire command by λ changes both its components. A negative factor reverses their directions.

Hint 2

Apply T to the new pair before comparing with the known output (3 ; 6) cm.

Compare with the solution

The input becomes λu = (-1/2 × 2 ; -1/2 × 1) = (-1 ; -1/2) cm. The sum of these components is -1 + (-1/2) = -3/2 cm.

Direct calculation gives T(λu) = (-3/2 ; -3) cm. Transforming and then multiplying gives: λT(u) = (-1/2 × 3 ; -1/2 × 6) = (-3/2 ; -3) cm. The pairs are exactly equal.

Decimal form: (-1.50 ; -3.00) cm. The fractions establish equality before any decimal display. This check practises scaling; the proof for every λ has already been given using arbitrary components.

  • I compared T(λu) with λT(u), keeping the steps distinct.

Exercise 3 · Counterexample and transfer

The plotter adds a fixed displacement

Another setting of the same plotter applies G(x, y) = T(x, y) + (1 ; 0) cm. Can it be linear? First calculate G(0, 0), then compare G(u + v) with G(u) + G(v). Explain the cause of the difference. A few favourable trials are not a proof: look for a decisive counterexample.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

A linear map must send the 0 vector to the 0 vector.

Hint 2

The offset is added every time G is applied: count how often it appears on each side of the addition equality.

Compare with the solution

G(0, 0) = (1 ; 0) cm, which is nonzero. The necessary condition at the origin fails: G is not linear. This rule is called affine because it is the sum of a linear map and a constant vector.

Calculating from the sum gives G(u + v) = (4 + 1 ; 8) = (5 ; 8) cm. Applying the map separately gives G(u) = (4 ; 6) cm and G(v) = (2 ; 2) cm. Their sum is (6 ; 8) cm.

The horizontal difference is 6 − 5 = 1 cm. Transforming separately adds the fixed displacement to each command; transforming the sum adds it only once. A single failure is enough to refute a property claimed for all inputs.

Check your reasoning

  • I used the value at the origin to reach an unambiguous conclusion.
  • I calculated both sides and located the horizontal difference.
  • I explained how often the offset is added, without attributing the difference to rounding.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1Which equalities must be established, and for which inputs?

For all u and v in the domain and every real scalar λ: T(u + v) = T(u) + T(v) and T(λu) = λT(u). Numerical examples do not replace this general proof.

Recall 2What do the columns of the matrix of a linear map contain?

In fixed bases, the column associated with a basis vector contains the coordinates of its image. Linearity then allows these columns to be combined using the coordinates of any input.

Recall 3What does the kernel of the setting T describe?

The commands sent to the 0 output: here, the pairs (t ; −t) cm. The direction (1 ; -1) cm is erased, so the output does not allow a unique command to be recovered.

Recall 4How can you establish that the image is an entire line?

Show that every output satisfies Y = 2X, then that every pair (s ; 2s) cm is reached, for example from (s ; 0) cm. Inclusion alone does not prove that the entire line is reached.

Recall 5What does a nonzero output at the origin prove?

It refutes linearity, since T(0u) must equal 0T(u). A nonzero constant offset causes this failure. Conversely, passing the test at the origin alone is not enough to establish linearity.

Reconstruct the reasoning

Reconstruct the reasoning: state the spaces and units; prove preservation of linear combinations using arbitrary components; calculate the images of the basis vectors and read them as columns; find the erased inputs in the kernel and all attainable outputs in the image; check a calculation by another route; test the effect of a constant displacement at the origin.

What you understand
A step that multiplies an input by a fixed coefficient preserves linear combinations. This property must be attributed to a precisely defined map and precisely defined inputs; it does not automatically extend to all the surrounding processing.
