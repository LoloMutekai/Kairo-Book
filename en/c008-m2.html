Expressions

Your goalWrite and evaluate the calculation for the rice to weigh, choose the correct grouping, and explain when a stored value needs to be recalculated.

Before you start

✿01 See the idea

You are preparing rice for 3 portions. The chosen amount is 75 g of uncooked rice per portion, and the bag contains 500 g. Before weighing anything, you can already predict the mass to take out of the bag: repeat the amount for each portion, then subtract that mass from the supply.

This small calculation is an expression: a written form that produces a value from numbers, names, and operations. In dose * portions, Python reads the values associated with dose and portions, then multiplies them. The asterisk * serves the same purpose as the sign × on paper.

The assignment besoin = dose * portions adds an action to the calculation: it associates the name besoin with the result obtained. It does not store a recipe that would update itself. If the number of portions required changes later, you will need to run the calculation again.

The masses and requests on this page are fictional, chosen for this exercise. The amount per portion is not nutritional advice. We assume identical portions, a known stock, no losses, and no other withdrawals. The calculation predicts a weighing; it does not prove that the rice has been weighed.

The rule to remember

Read the current values, calculate according to operator precedence and parentheses, then store the result if the line contains an assignment. Next, check the unit and whether the result makes sense.

✿02 Follow an example

Worked example

Predict the mass to weigh and the remaining supply

For 3 portions of 75 g each, with an initial stock of 500 g, let us calculate the amount needed, the amount left, and the mass per portion. Take a pencil: for each line, predict the result before continuing.

  1. Set out the data and their units

    The initial assignments are dose = 75, portions = 3, and stock = 500. Each name must already have been assigned its value before it is used. Here the values have type int, meaning integers, as in the previous unit.

    dose is the number of grams planned per portion; portions is an integer count, with no physical unit. stock, besoin, and reste represent masses in grams. Python stores only the numbers: the letter g belongs in our explanations, not in these program lines. Keeping the units consistent is our responsibility.

    In a Python assignment, the sign = asks for the right-hand side to be evaluated, then for the value to be associated with the name on the left. On paper, the sign = between calculations expresses equality of values.

  2. Represent repetition with a product

    The line besoin = dose * portions evaluates the expression dose * portions. Each of the 3 portions requires the same mass: multiplication counts the repeated amounts, whereas adding dose + portions would mix a mass per portion with a count.

    75×3=225 g

    We therefore associate besoin with 225, interpreted in grams. Check by another method: 75 + 75 + 75 = 225 g. This check corresponds to the packets in the diagram.

  3. Subtract the amount needed and check the stock

    The line reste = stock - besoin reads the current numbers associated with stock and besoin. The sign - subtracts: the entire mass requested is removed from the initial supply.

    500−225=275 g

    The value associated with reste is 275. Reverse check: besoin + reste gives 225 + 275 = 500 g, exactly reconstructing the initial stock. Here the sign + adds masses with the same unit.

    The name stock still has the value 500: reading stock in a subtraction does not change it. Only a new assignment to that name would change its value. The calculation does not take any rice out of the actual bag either.

  4. Read the order of operations

    We can write reste = stock - dose * portions directly. For the operations on this page, * and / take precedence over + and -. Parentheses specify a grouping; operations at the same precedence level group from left to right.

    Here, stock - dose * portions means stock - (dose * portions). We calculate the product 75 × 3 = 225, then the difference 500 − 225 = 275 g. Subtraction is the last operation in the diagram.

    Spaces make the line readable but do not change these rules. We write * in Python code and × in equations on paper.

  5. Moving the parentheses changes the question

    With (stock - dose) * portions, we first subtract the mass of a single portion: 500 − 75 = 425. We then multiply this entire reduced stock: 425 × 3 = 1275. This other calculation replicates the supply itself.

    The difference between the results is 1275 − 275 = 1000 g. These parentheses therefore have a specific effect. They do not simply mean “make the presentation tidy.”

    For the planned meal, a remaining supply greater than the initial 500 g, without any rice being added, contradicts the scene. This check of meaning complements the arithmetic. Python can correctly evaluate an expression that represents the question poorly.

  6. Divide to recover the amount per portion

    The line part = besoin / portions distributes the total mass among the identical portions. Here the name part represents grams per portion; the sign / performs division in Python.

    2253=75.0 g par portion

    The recovered amount is indeed 75.0 g per portion. Even with these integer inputs and an integer quotient, / produces a value of type float here, meaning a floating-point number. Type and value are two different pieces of information.

    This calculation assumes a number of portions strictly greater than 0. With 0 portions, the product gives 0 g needed and 500 g left. However, besoin / portions would require dividing 0 by 0: Python reports a division-by-0 error. You must not invent a 0 amount per portion in its place.

  7. Distinguish a new input from a new calculation

    After the calculations for the planned meal, run only portions = 5. besoin is still 225 and reste is still 275: these names retain the results of the previous lines. Their values do not automatically follow the value of portions.

    Run besoin = dose * portions again: the amount needed becomes 75 × 5 = 375 g. Then run reste = stock - besoin again: the amount left becomes 500 − 375 = 125 g. This order is necessary because the calculation of the amount left reads besoin.

    Check: 375 + 125 = 500 g. Rerunning only the line for the amount left would still have used the old amount needed, 225 g. Reevaluation means evaluating an expression again with the values available when it runs.

Explain it in your own words

Hide the results. Describe the path of the data through to the amount left, then explain why a new value of portions requires rerunning besoin before reste. What arithmetic check and what check of meaning can you repeat?

✿03 Common mistakes

  • “I always calculate from left to right, so I subtract before multiplying.”

    Identify the parentheses first, then operator precedence. In stock - dose * portions, the product gives the entire amount needed before the subtraction. Draw the inputs to each operation: moving the parentheses can cause the entire supply to be multiplied.

    Review the order of operations and moving parentheses

  • “Changing portions or calculating stock - besoin updates all the supplies.”

    An expression produces a value; an assignment changes the association of only the name on the left. stock stays unchanged when reste is assigned. After changing portions, rerun the calculation of the amount needed, then the amount left: the results already stored remain out of date until then.

    Review subtraction and reevaluation

  • “A negative amount left proves that Python made a mistake; I might as well replace it with 0.”

    A negative amount left can represent a request greater than the supply. Its sign and value indicate the shortfall. Keeping this information lets you check the calculation; deciding what to do next belongs to the unit on conditions.

Hint 1

In the first expression, multiplication comes first. In the second, start inside the parentheses.

Hint 2

Which grouping subtracts the entire amount needed from the stock? Which also multiplies the initial supply?

Compare with the solution

First grouping: the amount needed is 75 × 4 = 300 g. The amount left is therefore 500 − 300 = 200 g. Check: 300 + 200 = 500 g.

Second grouping: 500 − 75 = 425, then 425 × 4 = 1700. The difference is 1700 − 200 = 1500 g.

The first grouping represents the amount left that we want. The second subtracts the amount for a single portion, then multiplies the reduced stock by the number of portions: it would produce more rice than the 500 g available, without any being added. This arithmetic result is consistent with its own expression, but the expression represents the situation poorly.

Hint 1

Changing portions does not rerun the line that calculated besoin.

Compare with the solution

After changing portions and rerunning only the calculation of the amount left, besoin is still 225 and reste is 500 − 225 = 275. This amount left still corresponds to the old request; the line correctly used a value that had become out of date.

You must rerun besoin = dose * portions, then reste = stock - besoin. This gives 75 × 8 = 600 g requested, then 500 − 600 = -100 g. The negative sign indicates a shortfall of 100 g: it is not a negative mass actually in the bag. Replacing the result with 0 would hide the shortfall. stock is still 500.

With portions = 0, after the same recalculations, besoin is 0 and reste is 500 g. But besoin / portions would be 0 / 0: division by 0, hence an error in Python, with no numerical quotient to assign. The mass to prepare is 0; a mass per portion is undefined when there are no portions.

  • Give the order besoin, then reste, and recover 600 g, -100 g, and the shortfall of 100 g.
  • Keep the initial stock unchanged, explain the sign, and refuse to invent a quotient for division by 0.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What is the difference between dose * portions and besoin = dose * portions?

The expression dose * portions produces a value from the current data. The assignment evaluates this expression, then associates besoin with the result. It does not create an automatic update.

Recall 2How do you read stock - dose * portions? What would parentheses around stock - dose change?

The product first calculates the entire amount needed; this is then subtracted from the stock. Parentheses around stock - dose would cause the amount for a single portion to be subtracted, then the entire reduced stock to be multiplied.

Recall 3Why rerun besoin before reste after changing portions?

besoin retains the value calculated previously. Rerunning it uses the new number of portions; rerunning reste afterwards allows it to read this new amount needed. Calculating reste does not change stock.

Recall 4What does / do with our integer inputs? What precaution must you take?

Division produces a float here, even if the quotient has an integer value. The divisor must be nonzero. With no portions, the amount needed is 0, but the quotient besoin / portions is undefined.

Recall 5How can you check the calculation of the amount left, including when it is negative?

Check that besoin + reste reconstructs the stock and that the units match the scene. A negative amount left means that the amount needed exceeds the supply; its additive inverse gives the shortfall, not a mass present in the bag.
