Q-learning

Your goalApply a Q-learning update to a table of states and actions, justifying the target, the temporal-difference error, the maximum, the terminal case and the limitation of a table learned in simulation.

Before you start

✿01 See the idea

A fictional warehouse cart moves along a corridor with 3 cells: A, the entrance; B, the middle; C, the loading dock where the delivery ends. In A and B, it chooses between moving forward and waiting. Each action has a reward of -1 point, so it has a cost; reaching the dock adds 10 delivery points, so moving forward from B to C is worth 9 points. These numbers, like the discount factor 0.8, are invented for this scene.

The previous units provided the framework: states, actions, transitions, rewards, the value of a policy and the Bellman equation. Here, the cart does not have the transition table. It observes a single transition at a time, in the form (state, action, reward, next state), and must use each observation to improve a Q-table that records the estimated value of each (state, action) pair.

Q(s, a) estimates the sum of future discounted rewards if the agent takes action a in state s, then acts optimally. After a transition, we compare this estimate with a target: the reward received, plus the best known value in the next state, discounted by the factor γ. The difference between the target and the estimate is called the temporal-difference error here. We move the estimate by a fraction α of this difference, the learning rate, rather than by the whole difference: in a random environment, a transition is only a sample of the expectation in the Bellman equation.

One point may be surprising. The target takes the maximum of the values in the next state, even if the agent has chosen something else to explore. Q-learning therefore learns the value of greedy behavior while behaving differently; this is called off-policy learning. A simple exploration rule is ε-greedy action selection: with probability ε, the agent picks an action at random from all the actions; otherwise, it takes the action with the highest Q-value.

Assumptions in this course: finitely many states and actions, stored in a table; an unambiguously observed state; rewards and transitions that do not change over time; each pair visited often. Convergence guarantees also require conditions on the sequence of learning rates α; we do not prove them. Our scene is deterministic to keep the calculations easy to follow.

The rule to remember

After an observed transition (s, a, r, s′), replace Q(s, a) with Q(s, a) plus α times the difference between the target, r plus γ times the maximum Q-value in s′, and Q(s, a); if s′ is terminal, the target is r alone.

✿02 Follow an example

Worked example

A cart, 3 cells, 3 updates

The cart starts with a Q-table whose entries are all 0: 0 point for each of the 4 nonterminal (state, action) pairs. Its settings are α = 0.5 and γ = 0.8. It observes, in this order, (A, forward, -1, B), then (B, forward, 9, C), then (A, forward, -1, B) again. Let us calculate the table after each transition. All values are fictional.

  1. Define the symbols and assumptions

    s is the state before the action, a the chosen action, r the reward received in points, and s′ the next state. γ is the dimensionless discount factor, between 0 and 1: the weight of a reward a step further away is multiplied by γ. α is the dimensionless learning rate, strictly positive and at most 1. Q(s, a) is measured in points.

    Assumptions: a finite table, an unambiguously observed state, deterministic transitions in our scene, and a terminal state C, meaning that no continuation is possible. If any assumption fails, the following rule must be reconsidered.

  2. Write the update rule

    The target y summarizes what the transition suggests for Q(s, a). The maximum is taken over actions a′ in the next state; it is replaced by 0 if s′ is terminal.

    y=r+γmaxa′Q(s′,a′)

    The temporal-difference error is δ = y − Q(s, a). It is positive when the transition suggests more than the current estimate, and negative otherwise. The arrow means that the stored value is replaced.

    Q(s,a)←Q(s,a)+αδ

    An alternative form, useful for checking: Q becomes (one minus α) times the old Q plus α times y. The two weights add up to 1: this is a weighted mixture of the old value and the target.

  3. First transition: all table entries are 0

    In B, both values are 0, so their maximum is too. The future term is 0.8 × 0 = 0. The target is just the reward: y = -1 + 0 = -1.

    δ=-1−0=-1, et Q=0+0.5×-1=-0.5

    Q(A, forward) therefore changes from 0 to -0.5 point: the first action is seen as a cost, before anything is known about what follows.

  4. Second transition: the terminal dock

    Dock C is terminal: there is no continuation, so there is no future term. Adding γ times a maximum here would make the calculation incorrect. The target is y = 9 + 0 = 9, then δ = 9 − 0 = 9.

    Q(B, avancer)=0+0.5×9=4.5

    Q(B, forward) is now 4.5 points. Note: the estimate remains far from the target 9, because a single step moves Q by only the fraction α.

  5. Third transition: the value propagates back

    Back in A. This time, in B, Q(B, forward) = 4.5 is greater than Q(B, wait) = 0: the maximum is 4.5. The future term is 0.8 × 4.5 = 3.6 and the target is y = -1 + 3.6 = 2.6 (or 13/5 as a fraction).

    δ=2.6−(-0.5)=3.1, et Q=-0.5+0.5×3.1=1.05

    Q(A, forward) becomes 1.05 point. Its sign has changed: the information that the dock gives a large reward has propagated back from B to A, a step per visit.

  6. Check with the alternative form

    (1−0.5)×(-0.5)+0.5×2.6=-0.25+1.30=1.05

    We obtain 1.05 point again, as with the temporal-difference error. Sign check: the target is above the old estimate, so Q increases, and the new value stays between the old value and the target.

  7. Check against the optimal value

    Knowing the whole scene, we can solve the Bellman optimality equations by hand. This complete model is used for checking; the cart does not have it. Working back from the dock: Q*(B, forward) = 9 + 0 = 9. Then Q*(A, forward) = -1 + 0.8 × 9 = -1 + 7.2 = 6.2.

    Waiting in A returns to A: Q*(A, wait) = -1 + 0.8 × 6.2 = 3.96; waiting in B is worth 6.2. Moving forward is better in both cells. With these values, the target from a sample is 6.2, exactly Q*(A, forward): the temporal-difference error is 0, so the update no longer changes anything.

    The gap from Q*(A, forward) was 6.7 point after the first transition and 5.15 point after the third: it has decreased, but has not disappeared.

  8. Interpret the limitation of the resulting table

    Only 2 of the 4 pairs have been visited; both values for waiting are still 0 point, with no information. With ε-greedy action selection using ε = 0.1 and 2 actions, the action with the highest value is chosen with probability 0.95 and the other with probability 0.05. This rare but nonzero exploration makes it possible to try waiting eventually.

    This table describes what was observed in the scene’s simulator, with its declared rewards. It proves neither that the greedy policy is suitable elsewhere nor that the values are close to Q* in general.

Explain it in your own words

Why does the third update of Q(A, forward) use the value of B rather than a more distant reward? Also explain why the second update adds no future term.

✿03 Common mistakes

  • “The target uses the action that the agent will take next.”

    Q-learning takes the maximum of the values in the next state, even if the agent explores. In the target exercise, the value of the chosen action would give -1 instead of 2.6, and would learn the value of exploration rather than that of greedy behavior.

    Redo the target exercise

  • “In a terminal state, we still add γ times a maximum.”

    A terminal state has no continuation: the future term is 0 and the target reduces to the reward, 9 for the dock in the example. Adding a maximum would invent gains after the end.

    Review the transition to the dock

  • “A table learned in simulation proves that the policy is good in the real world.”

    The table only summarizes the declared simulator, with its transitions and rewards. Its value outside the simulator requires separate validation, introduced in unit C265·M5; the milestone reinforces the same distinction between what is read and what is proved.

    Reread the limitation in the milestone

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What is the Q-learning target for an observed transition?

The reward received plus γ times the maximum Q-value in the next state; if that state is terminal, the reward alone.

Recall 2Why is Q-learning called off-policy learning?

Because the target takes the maximum in the next state, corresponding to greedy behavior, even when the agent has explored with another action.

Recall 3What does the learning rate α do in the update?

It applies only a fraction α of the temporal-difference error: the new value mixes the old value, with weight one minus α, and the target, with weight α.

Recall 4What is the future term in a terminal state?

0: there is no continuation, so the target reduces to the reward received.

Recall 5What does a Q-table learned in a simulator prove?

It summarizes what was observed in that simulator, under its declared transitions and rewards; it does not prove the value of the policy outside the simulator.

Reconstruct the reasoning

Observe a transition; form the target with the reward and γ times the best Q-value in the next state, with that future term set to 0 if the state is terminal; measure the temporal-difference error; move Q by the fraction α of that error; explore without changing the target; check with an alternative form; never draw conclusions about the real world from the simulator alone.
