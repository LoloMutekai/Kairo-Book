Level 2 · C043·M1

Limited context and budgeting

Your goalCalculate the space available for excerpts by reserving space for the answer and counting the entire input, then decide whether a proposal fits within the stated budget.

Before you start

✿01 See the idea

You ask an assistant: “Explain how to wash the cover, using its care instructions.” The instructions are available in a folder, but the answer will be prepared from the text actually sent in this call. Imagine a work table: documents left on the shelf have not become sheets laid out on the table.

Context is everything supplied to the model for this call: instructions, the current request, retained conversation and any excerpts. A context window is a limit on quantity. A saved or retrieved document can exist without its text being included in this input. Here we examine only the content sent for this call.

The table must also leave space for the answer to be produced. Under our fictional contract, the input and answer share a capacity C of 1200 tokens. Reserving R = 300 tokens for the answer leaves at most 900 tokens for the entire input. This contract is an assumption of the exercise; a real interface may impose other limits, which must be checked separately.

A token is a unit produced by splitting text for the model; it does not necessarily correspond to a word or a character. The counts on this page are fictional and supplied with the contract. We will neither split the care instructions into tokens nor convert their characters into tokens. The budget counts a quantity of text; it does not measure answer quality.

The rule to remember

Reserve space for the output first, count all the input already planned, then compare the cost of the excerpts with the remaining space. Fitting within that space does not guarantee a correct answer.

✿02 Follow an example

Worked example

Do the care instructions fit alongside the request and answer?

In the fictional cover scenario, the proposal contains excerpts A and B from the same care instructions. The counts are: instructions 150 tokens, question 100 tokens, retained conversation 200 tokens, message envelope 50 tokens, A 250 tokens and B 200 tokens. The capacity is 1200 tokens and the output reserve is 300 tokens. Let us check this proposal without silently removing a passage.

  1. Define the symbols, units and contract

    C denotes the shared capacity; R, the answer limit for which we reserve space; I, the cost of the instructions; Q, the cost of the question; H, the cost of the retained conversation; E, the cost of the envelope. The envelope includes the role markers and separators counted by our contract. All these costs are nonnegative whole numbers of tokens.

    A and B are the costs of the excerpts bearing those letters. D will denote their total cost. F will denote all input excluding excerpts, and P the remaining space for those excerpts. Here the letter Q counts the question and has no other meaning. Every quantity symbol is expressed in tokens.

    Assumptions: the contract allows C to be shared between input and output; R also meets the output limit specific to this contract; the supplied costs are additive, with no overlap or hidden budget item. They are assigned to the blocks in their final form, including the envelope. In a real call, the complete message would have to be counted using its actual tokenization: adding separate estimates is not enough to establish this assumption.

    R is space kept for an answer that may reach this limit, rather than the definite length of that answer. An answer that turns out to be shorter does not justify using its reserve in advance.

  2. Subtract the output reserve

    To guarantee the stated space for the answer, subtract it before adding excerpts. The input limit is C − R = 1200 − 300 = 900 tokens. Counting only the documents against C would therefore already overlook the output.

    C−R=1200−300=900 jetons

  3. Add up what already occupies the input

    The instructions and question occupy I + Q = 150 + 100 = 250 tokens. The conversation and envelope occupy H + E = 200 + 50 = 250 tokens. These groups are disjoint, so their costs can be added.

    Thus F = I + Q + H + E = 250 + 250 = 500 tokens. “Excluding excerpts” does not mean free. F stays fixed while we examine this proposal; it is not a universal constant.

    F=I+Q+H+E

  4. Calculate the space for excerpts

    Subtract F from the input limit: P = 900 − 500 = 400 tokens. This is the excerpt budget; it is neither C nor C − R on its own.

    If this calculation gave P less than 0 tokens, even the input excluding excerpts would be too large: removing all excerpts would not be enough. If P is 0 tokens, no excerpt with a positive cost can be added without revising another budget item.

    P=C−R−F

  5. Compare the required space with the available space

    The proposed excerpts cost D = A + B = 250 + 200 = 450 tokens. The condition D ≤ P means “the cost of the excerpts is less than or equal to their budget.” Here 450 > 400, so the condition is not met.

    The overrun is D − P = 450 − 400 = 50 tokens. Having retrieved the excerpts does not create any extra space. This proposal fails the capacity check.

    The symbol ⇔ means that the conditions on either side are equivalent. Replacing P with C − R − F and adding R and F to both sides of the inequality gives the check using the total:

    D≤P⇔F+D+R≤C

  6. Check by rebuilding the total

    Let us check the other way, without starting again from budget P: the complete input costs F + D = 500 + 450 = 950 tokens. With the reserve, the required space is 950 + 300 = 1250 tokens, above the 1200 tokens available.

    The remaining margin is C − (F + D + R) = -50 tokens. Its negative sign represents a shortage of 50 tokens; it does not denote a negative quantity of text. Subtraction and rebuilding the total give the same rejection.

  7. State what the calculation lets us decide

    We can conclude that the proposal containing A and B does not meet the stated fictional budget. It must be revised and counted again before the call. Reducing a budget item changes the proposal; we will have to check that the information needed for the request about the cover remains available.

    We cannot conclude that a particular model would reject this exact call, remove a specific passage or produce a good answer with less text. We have neither made this call nor read the content of the fictional care instructions. The following units will examine how to retrieve, assemble and retain useful material.

✿03 Common mistakes

  • “The care instructions are in the folder, so the model is already reading them.”

    Distinguish the available document from the text sent in this call. Check what is actually included before saying that the model has the care instructions. Retrieving a document and including it require separate steps.

    Review the work table and the shelf

  • “I have 900 tokens left, so I can use all of them for excerpts.”

    The 900 tokens cover the entire input. The 500 tokens excluding excerpts still have to be subtracted: only 400 remain for excerpts. Forgetting the 50 envelope tokens would even give a reported total of 1200 tokens instead of 1250, wrongly accepting this proposal.

    Repeat the count and rebuild the total

  • “If the text fits, the answer must be supported.”

    The calculation checks only quantity under the stated contract. A necessary passage may be missing from a short input. Examine the content sent to judge what claims it supports; a positive margin does not prove this.

    Distinguish capacity from content in the last exercise

Exercise 1 · Applying the budget

Try the proposal with A only

Keep the initial settings and remove B from the proposal about the care instructions. A still costs 250 tokens. Calculate the input, the required space including the reserve, and the margin. What can you state about capacity? What still needs to be checked about the answer?

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

F does not change: removing B removes neither the question nor the envelope.

Hint 2

Compare F + A + R with C, then subtract this required space from C.

Compare with the solution

The input becomes 500 + 250 = 750 tokens. Adding the reserve of 300 tokens gives a required space of 1050 tokens. The margin is 1200 − 1050 = 150 tokens: this proposal passes the capacity check.

Check using the excerpt budget: 400 − 250 = 150 tokens, the same result. We have not established that A contains the necessary washing instructions. Here, removing B is a trial of quantity, without validating the content of the future answer.

Check your reasoning

  • Keep the 500 tokens excluding excerpts and the 300 tokens reserved for the answer.
  • Find the margin of 150 tokens by both methods.
  • Distinguish meeting the capacity limit from having sufficient content.

Exercise 2 · Predict, then calculate

Reserve a longer answer

Start again from the initial proposal with A and B. Only the reserve R changes to 400 tokens. Before calculating, predict whether the space for excerpts will increase or decrease. Then recalculate that space and the overrun; do not use the proposal with A only.

Assisted answer: try this exercise without help later.

Hint 1

C stays fixed: reserving more space for output leaves less space for input.

Hint 2

Calculate C − R with the new reserve, then subtract the same F as at the start.

Compare with the solution

The space for excerpts decreases. The new input limit is 1200 − 400 = 800 tokens. After the 500 tokens excluding excerpts, their budget is 800 − 500 = 300 tokens.

The excerpts still require 450 tokens. The overrun becomes 450 − 300 = 150 tokens. Direct check: the required space 950 + 400 exceeds capacity 1200 by the same 150 tokens. A larger reserve therefore does not add capacity.

Check your reasoning

  • Predict a decrease in available space before calculating.
  • Change neither F nor the cost of the excerpts.
  • Obtain 300 tokens available and an overrun of 150 tokens, then check directly.

Exercise 3 · Boundary case and objection

Fitting exactly is not enough to conclude

Return to the initial reserve of 300 tokens and keep A and B. The proposal is to reduce the retained conversation to 150 tokens, with all other budget items unchanged. Someone claims: “It fits exactly, so I can remove this passage from the conversation history without risking the answer.” First check the capacity, then discuss this conclusion if the removed passage identified which cover was meant.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Calculate the reduction in H and apply it only once to the total excluding excerpts.

Hint 2

Distinguish equality with the limit from information about the object of the request.

Compare with the solution

The reduction is 200 − 150 = 50 tokens. The new cost excluding excerpts is 500 − 50 = 450 tokens. The input then costs 450 + 450 = 900 tokens, and the required space including the reserve is 900 + 300 = 1200 tokens. The margin is 0 tokens.

Equality with the limit is allowed under our assumptions of exact and complete costs. Independent check: 150 + 100 + 150 + 50 + 250 + 200 + 300 = 1200 tokens. However, there is no margin for a forgotten budget item.

The conclusion about meaning is unjustified. If the removed passage identified the cover concerned and that information is not given elsewhere in the input, the request becomes ambiguous. Preserve this information or ask for clarification about the object, then count again. The calculation allows us to accept the quantity; it does not authorize any arbitrary deletion.

Check your reasoning

  • Apply the reduction of 50 tokens only once.
  • Establish equality at 1200 tokens and explain the margin of 0 tokens.
  • Name the information that might be lost and propose preserving or clarifying it before counting again.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1Why can saved care instructions be missing from the context of this call?

Context includes what is actually sent to the model for this call. The availability of a document does not prove that its text is included.

Recall 2How can you reconstruct the excerpt budget under our shared capacity contract?

Start from C, subtract the answer reserve R, then all input excluding excerpts F: P = C − R − F. F adds up the instructions, question, retained conversation and envelope. All these quantities are in tokens in the exercise.

Recall 3How can you check a proposal without starting again from the excerpt budget?

Add the input excluding excerpts F, the total excerpt cost D and the reserve R, then compare with C. The required space F + D + R must be less than or equal to C. A negative margin indicates an overrun.

Recall 4Why is a character count not enough to prove compliance with a token budget?

A token comes from tokenization specific to the model and is not necessarily a character or a word. You need the count corresponding to the final message and the contract used; these units cannot be treated as identical without justification.

Recall 5Does a positive or 0 margin establish that the answer will be supported?

No. It validates only quantity under the stated counting contract. You still need to check that the input contains the necessary material and that the answer uses it correctly.

Reconstruct the reasoning

Reconstruct without rereading: distinguish the available document from the context sent; state the capacity, unit and contract; reserve the output; count all input excluding excerpts; calculate the remaining space; compare, then rebuild the total.
