Level 2 · C143·M1

Rigorous continuity

Your goalMove from the idea of “a small change in input, a small change in output” to the definition of continuity at a point using ε and δ, construct an explicit δ for a given tolerance, and recognise when no δ exists.

Before you start
c142-m5 : Convergence criteria · c045-m5 : Introductory quadrature · c046-m5 : Approximation error

✿01 See the idea

A fictional machine cuts square slabs. The side length x is set in centimetres; the area A(x) = x² is expressed in square centimetres. All the values on this page are invented for the exercise: they describe neither an actual measurement nor a workshop setting.

The target is a side length of 3 cm, giving an area of 9 cm². The customer accepts a tolerance ε (epsilon) on the area: a difference strictly less than ε, expressed in cm². The continuity question then becomes: how far can the side length differ from 3 cm, at most, while keeping the area within the tolerance?

This margin on the side length is called δ (delta) and is measured in cm. The exchange has two stages: the requirement ε is given first, then you respond with a δ. The stricter the requirement, the smaller the response must be; δ can therefore depend on ε. If a response exists for every requirement, the function is continuous at the target point.

For comparison, a fictional indicator with no units displays 0 when the side length is less than 3 cm and 1 from 3 cm onwards. With a tolerance of 0.5, no margin works: just below the target, the indicator differs by 1. This indicator is not continuous at 3.

Continuity is assessed at a specific point. A function can be continuous at one point and not at another; this page covers only continuity at a point, leaving out sequences, compactness and integration.

The rule to remember

A function f is continuous at a if, for every output tolerance ε > 0, there is an input margin δ > 0 such that |x − a| < δ implies |f(x) − f(a)| < ε. The value of δ can depend on ε; it never depends on the x being tested.

✿02 Follow an example

Worked example

A margin on side length for a tolerance on area

Return to the fictional slab: target side length a = 3 cm, area A(x) = x² in cm², tolerance ε = 0.5 cm². Find a δ in cm such that |x − 3| < δ guarantees |A(x) − 9| < ε, then test the fictional indicator s, which equals 0 below a and 1 from a onwards.

  1. Introduce the symbols and the definition

    f is a real function; a, the point under study, belongs to its domain. |u| is the absolute value of u: the distance between u and 0, in the same units as u. ε is the output tolerance and δ the input margin, both strictly positive. The symbols ∀ and ∃ are read as “for all” and “there exists”; ⇒ is read as “implies”.

    ∀ε>0,∃δ>0,∀x,|x−a|<δ⇒|f(x)−f(a)|<ε

    The order matters: ε is fixed first, δ can be determined from it, and x is chosen last. Assumption: f is defined for all the x near a that we test. Here A(x) = x² is defined on the interval under study, where x stays positive.

  2. Factorise the output difference

    Expanding (x − a)(x + a) gives x² + xa − ax − a² = x² − a². The output difference can therefore be factorised, and the absolute value of a product is the product of the absolute values.

    |x2−a2|=|x−a|×|x+a|

    Using the numbers from the scene, this becomes:

    |x2−9|=|x−3|×|x+3|

    The first factor is the input difference, which δ controls directly. The second acts as an amplification coefficient in cm, which must be bounded before choosing δ.

  3. Bound the coefficient on an interval

    First require |x − a| < ρ, with ρ = 1 cm: x stays strictly between 3 − 1 and 3 + 1. Then x + 3 is positive and strictly less than 3 + 1 + 3; this upper bound, denoted L, is a constant in cm.

    |x+3|<3+1+3=7=L

    This step establishes that as long as |x − a| < ρ, we have |A(x) − 9| < L × |x − 3|, with L = 7 cm. This bound is guaranteed only within the interval of radius ρ.

  4. Choose δ and guarantee the tolerance

    We want L × δ ≤ ε, so take δ = ε ÷ L. Check the units: cm² divided by cm gives cm. The calculation gives δ = 1/14 cm, or approximately 0.071 cm.

    The bound from the previous step holds only if δ ≤ ρ. Here 1/14 is indeed less than 1: the minimum of ρ and ε ÷ L is therefore ε ÷ L. In the general case, set δ = min(ρ, ε ÷ L).

    δ=(0.5)÷7=1/14⇒|x2−9|<7×1/14=0.5

    For every x such that |x − 3| < δ, the area difference is strictly less than ε. This inequality, valid for all these x, is the proof; the checks that follow do not replace it.

  5. Check both endpoints of the interval

    The endpoints x = a − δ and x = a + δ are excluded from the open interval, but they show whether the chosen δ is consistent. Upper endpoint: x = 43/14 cm, A = 1849/196 cm², giving a difference of 85/196 cm². Lower endpoint: x = 41/14 cm, A = 1681/196 cm², giving a difference of 83/196 cm².

    43/142−9=85/196<0.5

    Both differences stay below ε = 0.5 cm², with margins of 13/196 and 15/196 cm². The chosen δ is conservative, because the bound L × δ replaces the exact difference with a slightly larger value. Testing two points proves nothing on its own.

  6. Look for a δ for the indicator: none exists

    The indicator equals s(x) = 0 for x < a and s(x) = 1 for x ≥ a. Keep ε = 0.5. For the δ from the previous step, the point x = a − δ ÷ 2 = 83/28 cm is at a distance δ ÷ 2 from a, so it lies inside the interval. Yet s(x) = 0 and s(a) = 1: the difference is 1, which exceeds ε.

    The same reasoning works for any δ > 0: the point a − δ ÷ 2 is always inside the interval and always on the branch that violates the tolerance. This is therefore an impossibility, rather than a poor choice of δ. Writing the negation of the definition means exhibiting an ε and, for every δ, an x:

    ∃ε>0,∀δ>0,∃x,|x−a|<δet|s(x)−s(a)|≥ε

✿03 Common mistakes

  • “We can choose δ first, then see what tolerance ε it guarantees.”

    The order in the definition is ε then δ: the requirement is given, and the margin is the response. A δ fixed in advance guarantees only certain tolerances. In the example, δ is calculated from ε.

    Review the step that chooses δ

  • “It is enough to take δ = ε ÷ L, with no further precaution.”

    The coefficient L is guaranteed only within the interval of radius ρ. For a large tolerance, ε ÷ L exceeds ρ and the guarantee is lost: take the minimum of ρ and ε ÷ L, as in the exercise on the minimum trap.

    Redo the exercise on the minimum

  • “A function that changes formula at a point, or forms a corner there, must be discontinuous.”

    Continuity rules out jumps, but allows corners. Clamping to an interval changes formula at an endpoint and remains continuous. Check with ε and a point on each side, as in the last exercise.

    Redo the exercise on clamping

Exercise 1 · Explained application

A stricter tolerance

Use the same fictional slab, the same interval of radius ρ = 1 cm and the same coefficient L = 7 cm, but change the area tolerance to ε = 0.01 cm². Give a valid δ, then check the upper endpoint of the interval.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Divide the tolerance by L and compare the result with ρ.

Hint 2

For the check, calculate the area at a + δ, subtract 9 cm² and compare with ε.

Compare with the solution

δ = ε ÷ L = 1/100 ÷ 7 = 1/700 cm. This number is less than ρ = 1 cm, so the minimum of ρ and ε ÷ L is indeed ε ÷ L, and the bound using L can be applied.

Upper endpoint check: x = 3 + 1/700 = 2101/700 cm, A = 4414201/490000 cm², difference = 4201/490000 cm², less than ε = 1/100 cm². The remaining margin is 699/490000 cm².

A requirement one hundred times stricter than the tolerance in the example gives a smaller δ: δ does indeed depend on ε. This endpoint check does not replace the inequality valid for every x.

Check your reasoning

  • Write δ = ε ÷ L with the units.
  • Compare δ with ρ before drawing a conclusion.
  • Check an endpoint without treating it as a proof.

Exercise 2 · Spot the trap

Why keep the minimum

Still using the slab, take a large tolerance: ε = 14 cm². Show that δ = ε ÷ L, without the minimum, is too large by testing x = 49/10 cm. Then propose a valid δ and check its upper endpoint.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

First calculate ε ÷ L and compare it with ρ.

Hint 2

Check that x = 49/10 cm is at a distance of 19/10 cm from a, so it lies inside the overly large interval, then calculate A(x) − 9.

Compare with the solution

Without the minimum, δ = 14 ÷ 7 = 2 cm, greater than ρ = 1 cm. The point x = 49/10 cm is 19/10 cm from a, so it lies inside this interval. Its area is 2401/100 cm²: the difference is 1501/100 cm², greater than ε = 14 cm² by 101/100 cm². The claimed guarantee is false.

Instead take δ = min(ρ, ε ÷ L) = min(1, 2) = 1 cm. Within the interval of radius ρ, the bound using L remains valid and L × δ = 7 cm² is less than ε.

Upper endpoint check: x = 4 cm, A = 16 cm², difference = 7 cm², less than ε = 14 cm² with a margin of 7 cm². The minimum is necessary: it guarantees both that L is valid and that L × δ does not exceed ε.

Check your reasoning

  • Compare ε ÷ L with ρ.
  • Exhibit an x inside the overly large interval that violates the tolerance.
  • Correct using the minimum and check the units.

Exercise 3 · Transfer

Continuous clamping

Let c be the function with no units defined below, which clamps a number to the interval from 0 to 1. The formula changes branch at t = 1. For ε = 0.1, take δ = ε. Test t = 1 − δ ÷ 2 and t = 1 + δ ÷ 2, then justify the case of every t in the interval. This function illustrates a form of clamping; it describes no measurement.

c(t)=max(0,min(1,t))
Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

First write c(1), then compare c(t) with c(1) on each side of 1.

Hint 2

For t < 1 inside the interval, check that t stays greater than 0 before removing the clamp.

Compare with the solution

We have c(1) = 1. With δ = ε = 0.1, δ ÷ 2 = 0.05. Lower point: t = 19/20 stays inside the clamping interval, so c(t) = t and the difference is 1/20, less than ε. Upper point: t = 21/20 exceeds 1, so c(t) = 1 and the difference is 0.

For every t with |t − 1| < δ, we have t > 1 − δ = 9/10 > 0. If t ≤ 1, then c(t) = t and the difference 1 − t is less than δ = ε. If t > 1, then c(t) = 1 and the difference is 0. Thus δ = ε works.

The graph forms a corner at t = 1 but does not jump: continuity does not require differentiability. The reasoning applies to real numbers, not to computer rounding.

Check your reasoning

  • Treat t ≤ 1 and t > 1 separately.
  • Check that t stays inside the clamping interval before concluding that c(t) = t.
  • Distinguish continuity from the absence of a corner.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What is the definition of continuity of f at a, using ε and δ?

For every tolerance ε > 0, there is a δ > 0 such that |x − a| < δ implies |f(x) − f(a)| < ε.

Recall 2Which is chosen first, ε or δ, and what can δ depend on?

ε comes first. δ can depend on ε and the point a, but never on the x being tested.

Recall 3Why write δ = min(ρ, ε ÷ L) in the slab example?

The constant L is guaranteed only within the interval of radius ρ; the minimum ensures both that we stay within this interval and that L × δ ≤ ε.

Recall 4How can you show that a function is not continuous at a?

Find an ε such that, for every δ > 0, an x with |x − a| < δ gives |f(x) − f(a)| ≥ ε. For the indicator, x = a − δ ÷ 2 works.

Recall 5What does calculating a few points close to a fail to prove?

It does not prove continuity: we need an inequality valid for every x in the interval, such as |A(x) − A(a)| < L × |x − a|.

Reconstruct the reasoning

Reconstruct without support: the definition with the order ε then δ; the factorisation of the output difference; the bound on a coefficient over an interval of radius ρ; the choice δ = min(ρ, ε ÷ L) with its units; endpoint checks, which do not constitute a proof; the negation of continuity using an ε and an x for every δ.

Milestone · recognise continuous clamping in code

What you understand
Clamping to an interval preserves the idea of a small change in input giving a small change in output: the tolerance carries through, so δ can be taken equal to ε. This reasoning concerns real numbers, not rounding or nonfinite values on a machine.
