Level 2 · C140·M5

Hyperparameter validation

Your goalChoose SVM settings through cross-validation, justify the score, and preserve a final test independent of the choice.

Before you start
c059-m6 : Deterministic discrete Bellman · c099-m5 : probability calibration · c040-m5 : least squares · c140-m1 : margin · c140-m2 : hinge loss · c140-m3 : dual · c140-m4 : kernel trick

✿01 See the idea

A workshop wants to classify washers as “acceptable” or “reject” using their diameter and the area of visible defects. Different settings for the same SVM produce different decision boundaries. Which should we choose before using it on new parts?

A hyperparameter is a setting fixed before fitting the model. The SVM then learns its boundary from the permitted examples. C sets the weight of the penalty for margin violations; γ, read as “gamma”, controls the range of the Gaussian kernel. Choosing these settings also uses data, so we need to set aside examples for this choice.

We have 80 fictional washers, already labelled by a reference inspection. We set aside 20 test washers. The remaining 60 form the development set, divided into 3 folds: disjoint groups of 20 washers. Each fold is used for validation while the others are used for fitting. This is cross-validation.

The sample sizes and errors on this page are invented for the calculations. The record directly provides the errors from fictional predictions; we do not claim to have trained an SVM. The exercise concerns making a decision from this record and does not demonstrate an industrial result.

The rule to remember

Fit within each round; compare on the same folds; fix the choice; refit on the entire development set; finally open the test set without repeating selection.

✿02 Follow an example

Worked example

Choose the settings for the washer inspector

Let us compare exactly 3 pairs (C, γ), decided on before the scores: A = (1, 0.1), B = (10, 0.1), C = (10, 1). The letter for setting C is a row label; C within each pair is the hyperparameter. Every other training option stays fixed.

  1. Fix what the protocol must represent

    We assume the washers are independent and come from the same population as future parts. Repeated photos of the same washer never cross group boundaries. Each fold contains 10 parts from each category; the test set contains 10 from each category. This balanced allocation is an assumption of the exercise.

    An error on an acceptable part and an error on a part to reject have the same cost here. Our criterion is therefore the overall proportion of misclassifications, which we minimize. If letting a defective part through cost more than rejecting an acceptable part, we would need to fix a suitable criterion before the comparison; this protocol does not solve that new problem.

    The split, candidate list and rule for ties are fixed before the results. In an exact tie, we prefer the smaller C, then the smaller γ. This convention makes the decision reproducible; it does not guarantee that this pair is better in the population.

  2. Separate the settings from what the model learns

    h denotes a candidate pair (C, γ). In our chosen convention, C multiplies the sum of margin losses in the training objective. A larger C gives more weight to this penalty relative to the regularization term. A larger γ makes Gaussian similarity more local. Neither change alone promises better validation results.

    Diameter is measured in mm and defect area in mm². Before each fit, we centre and scale each feature separately: subtract its training mean, then divide by its training standard deviation, assumed strictly positive. The mean and standard deviation have the unit of the feature; the transformed coordinate has no unit. The transformed coordinates, C and γ are therefore dimensionless in our convention.

    The means, standard deviations and SVM coefficients are learned only from the training washers in that round. We then apply the same transformations to the validation fold. Calculating means on the entire development set before validation would already pass on information from the held-out fold: this is data leakage, even without looking at its labels.

  3. Fit again in each round

    In round P, we fit on Q and R, then predict P without refitting on P. In round Q, we start from scratch on P and R. In round R, we start from scratch on P and Q. Each fit sees 60 − 20 = 40 parts; each evaluation sees the other 20.

    The same folds are used for A, B and C, so a score difference is not mixed with a change in the split. This comparison requires 3 × 3 = 9 fits. Keeping the model from the previous round instead of starting from scratch could leave it with information from the fold to be predicted.

    The fictional record gives, in order P, Q, R: A makes 3, 4, 5 errors; B makes 2, 3, 1 errors; C makes 4, 3, 5 errors. Each number counts misclassified parts among 20 parts kept separate from the corresponding model.

  4. Define the score before dividing

    K = 3 is the number of folds and n = 20 is their common size, in parts. The index j denotes a fold. mⱼ(h) is the number of errors made by candidate h on that fold, in parts. eⱼ(h) is the error proportion for the fold; E(h) is the mean of these proportions. Both scores are dimensionless and lie between 0 and 1.

    ej(h)=mj(h)n;E(h)=1K∑j=1Kej(h)

    The symbol ∑ means to add the terms for all folds. Each prediction used in mⱼ(h) comes from a model fitted without fold j. Since the folds have the same size, E(h) also equals the total number of errors divided by 60. With different sizes, we would need to specify whether the criterion gives equal weight to each fold or to each part.

  5. Calculate and select

    For B, the proportions are 2/20 = 0.10, 3/20 = 0.15 and 1/20 = 0.05. Add them: 0.10 + 0.15 = 0.25, then 0.25 + 0.05 = 0.30. Then divide by the number of folds to obtain a mean:

    E(B)=0.303=1/10=0.10

    Check by another route: 2 + 3 = 5, then 5 + 1 = 6 errors; 6/60 = 1/10, or 10 % fictional errors. We counted each development part only once in validation.

    For A: 3 + 4 = 7, then 7 + 5 = 12; E(A) = 12/60 = 0.20, or 20 %. For C: 4 + 3 = 7, then 7 + 5 = 12; E(C) = 12/60 = 0.20, or 20 %.

    B minimizes the score among the pairs tried: we select h★ = (10, 0.1). The star denotes the choice resulting from the comparison. We have not searched all possible pairs, and no statistical test here demonstrates superiority in the population.

  6. Freeze, refit, then evaluate on the test set

    We keep h★ and fit a new model on the 60 development parts, with new means and standard deviations learned from these parts alone. We do not arbitrarily reuse the model from the last fold. With this final fit, the protocol involves 9 + 1 = 10 fits.

    After this freeze, the fictional test record reports 3 errors on 20 parts. The proportion is 3/20 = 3/20, or 0.15, or 15 %. The test describes this new model trained on the entire development set. The validation score compared models trained on 40 parts; the results need not coincide.

    The validation minimum was used for selection: it benefits from that selection and is not sufficient as an independent final estimate. The held-out test set provides a separate view, under our sampling assumptions; its small size leaves uncertainty. If its score is disappointing, we report it. Going back to choose γ after reading it would turn this test set into development data and require a new independent evaluation.

    A random split is not automatically suitable for every use. If the aim became predicting tomorrow’s parts under manufacturing drift, we would need to preserve time order; if several images described the same part, we would need to keep that group together. These situations change the protocol, not just C or γ.

Explain it in your own words

Hide the scores and describe the path of a washer from fold Q. Which model may see it during fitting? Which model must ignore it to validate it? Then explain why the final test cannot be used to choose from a new list of settings.

✿03 Common mistakes

  • “I choose the C that best classifies its own training examples.”

    A boundary can adapt to the examples already used to fit it. Recalculate the score on the fold excluded from that fit; this held-out score compares settings in our protocol.

    Review the rounds and the score definition

  • “I normalize all the washers before making the folds; this does not change the labels.”

    The features of the held-out fold would already have changed the means and standard deviations. Start again with only the training parts in the round to learn these transformations, then apply them to validation without fitting again.

    Reread what is learned in each fit

  • “The test is worse: let us try another γ and keep the best test result.”

    The test would then influence the choice. Keep its result as the result of the frozen protocol. A new search may reassign it to development, but must plan another independent evaluation before claiming to have a final test.

    Repair the protocol in the last exercise

Compare with the solution

The mean is (3/20 + 4/20 + 5/20)/3 = (3 + 4 + 5)/(3 × 20). It equals 12/60 = 1/5, or 0.20, or 20 % fictional errors.

The second method counts the 12 errors among the 60 parts used for validation: the same result. Equality comes from the identical fold sizes, not from a general property of means. B has a smaller score, 0.10; under the fixed criterion, A does not replace it.

Exercise 3 · Repairing a protocol

The test has already been used for selection

For these same washers, a colleague learns the means and standard deviations from the 80 parts, compares the candidates on the development set, then changes γ after each reading of the test result. She reports the best test score as an independent evaluation. Identify the leaks and propose a repair, distinguishing what can be recalculated from what requires a new held-out set.

Assisted answer: try this exercise without help later.

Hint 1

First look for which parts contributed to the learned transformations.

Hint 2

Can the test still act as an unseen exam if its result changed γ?

Compare with the solution

The initial transformations used the held-out folds and the test set. Validation must be repeated: with the original split, each round learns its transformations from the 40 training parts, then applies them to its held-out fold. The same rounds and criterion are used for all candidates.

The test also influenced the choice through the changes to γ. Reading it again after correcting the normalization does not restore its independence. We document this use, and these data no longer serve as a final test. We plan a new independent held-out set suited to the same target population. Neither the size nor the score of this set is known here.

We then freeze the protocol and the choice, refit on the permitted development data, and evaluate on this new held-out set. Without it, we can provide a diagnosis and validation results, but cannot report an independent final evaluation.

Check your reasoning

  • I identify leakage through the transformations and through decisions made after reading the test result.
  • I put learning the transformations back inside the rounds.
  • I request a set that is still independent without assigning it an invented result.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What is the difference between the pair (C, γ) and the SVM’s learned coefficients?

The pair is fixed before each fit. The model coefficients are then learned from the permitted training examples. The validation scores choose the pair from the planned candidates.

Recall 2When validating on Q, which washers and transformations are used for fitting?

We fit the SVM and the transformations on P and R only. We apply these transformations to Q without learning them again. Q does not contribute to fitting the model that predicts it.

Recall 3Why can we divide the total errors by 60 here?

Each fold contains 20 parts, and each part is predicted once in validation. The mean of the proportions therefore equals the overall proportion. With different sample sizes, the choice of weights must be specified.

Recall 4Why does the validation minimum not replace the final test?

This minimum contributed to choosing the setting and may benefit from fluctuations in the folds. The held-out test set contributed neither to fitting nor to selection; it evaluates the final model, with the uncertainty of a finite sample.

Recall 5What should we do after choosing B, before opening the test set?

Freeze the settings and protocol, then refit the transformations and the SVM on the 60 development parts. Then evaluate on the test set without reusing it to choose another pair.
