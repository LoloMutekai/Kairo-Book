Transfer

Your goalReuse a rule in a new task, check its conditions and distinguish transfer, retention and an assisted answer.

Before you start

✿01 See the idea

In a fictional drawing workshop, Leah learns to prepare kits. Each pouch gets 2 pencils; for 4 pouches, she prepares 8 pencils. Later, she is asked for 7 pouches, presented differently. Can she work out what to do without looking at the solution again? Remembering 8 is no longer enough: the request has changed.

Transfer is the influence of previous learning on a new task. The source task is the task used for learning; the target task is the task in which we want to reuse that learning. Here, the useful link is “the same number of pencils in each pouch”. The colour of the pouches is a detail of presentation.

Retention concerns what remains available after a delay: doing the question already practised again without help provides information about retention. Transfer requires a new target. The two can be combined: a new request can be tested later. Successfully repeating the answer from the first day does not by itself show that you can adapt the rule.

To reason about transfer, distinguish recognising a relationship, retrieving the rule from memory, matching its elements to the new instructions, and then checking that it applies. This is a method for examining Leah’s approach; this diagram does not describe a sequence of brain regions or a measured neural mechanism.

Transfer is called near transfer when the tasks share many of their demands; it is called far transfer when reuse requires more changes in context or activity. This distance is described relative to a specific source. Changing only the colour of the pouches does not justify claiming far transfer.

All quantities on this page are fictional. They are preparation data, rather than experimental results about Leah or measures of improvement. A correct answer to the target provides evidence of reuse if the reasoning properly links source and target; by itself, it does not measure the effect of previous learning.

The rule to remember

Carry a relationship over with its conditions, then check it in the target. A memorised answer or a similarity in presentation is not enough.

✿02 Follow an example

Worked example

Move from a learned answer to a usable rule

At the source, Leah worked on 4 pouches containing 2 pencils each, making 8 pencils. The target, not previously practised, requires 7 pouches with the same quantity per pouch. Let us reconstruct the calculation and specify what a successful answer would allow us to conclude.

  1. Read the goal and the conditions

    We need to find the total number of pencils. We assume that each pouch gets exactly the stated quantity, that the pencils are counted only once and that no allowance for losses or extra reserve is required. For this target, only the number of pouches changes.

  2. Name the corresponding elements

    n denotes the number of pouches, in pouches; q denotes the quantity per pouch, in pencils per pouch; C denotes the total, in pencils. These numbers count whole objects. We have n greater than 0 and q greater than 0. The sign × means multiply: combine n groups containing q pencils each.

    At the source, n = 4 and q = 2; in the target, n = 7 and q = 2. Matching the tasks means identifying the same role for each quantity, even if their presentation changes.

    C=n×q

  3. Retrieve the rule behind the source answer

    At the source, the product 4 × 2 = 8 pencils counts the equal groups. The result 8 belongs to this order. What can be useful elsewhere is the relationship “number of pouches multiplied by pencils per pouch”. Retrieving this relationship allows another total to be reconstructed; reciting only 8 does not.

  4. Adapt and calculate in the target

    We replace n with the new request and keep q, because the instructions confirm that it stays the same. We multiply to count all the groups, because the relationship applies, rather than because the pouches look like those at the source. The units follow: pouches × pencils per pouch gives pencils.

    C=7×2=14 crayons

  5. Check the result in reverse

    Division shares the total among the pouches. 14 pencils ÷ 7 pouches = 2.0 pencils per pouch: we recover the required quantity. Another interpretation: 14 pencils ÷ 2 pencils per pouch = 7 pouches. We also recover the number of groups.

    The same relationship can therefore answer the reverse question: if C and q are known, n = C ÷ q. We then count how many complete groups of q pencils fit into the stock. Here, the chosen quantities give a whole number of pouches; a remainder would require the unused pencils to be handled separately.

  6. Distinguish a correct answer from evidence of transfer

    If Leah solves the target without seeing the solution and explains the correspondence, her approach is consistent with reusing the rule. If she has just been told “multiply”, her answer is an assisted answer: it tells us what she does with that help. After reading this passage, you also know the solution; doing it again immediately is no longer a test on an unfamiliar target.

    A retention test could repeat the source request later without support. A transfer test should set aside a new request and record the reasoning before any help. Attributing a difference in performance to learning on the source task would also require an appropriate comparison without that learning, under comparable conditions. This page conducts no such experiment.

  7. Examine the limits of the rule

    Transfer is called positive if previous learning helps with the target, and negative if it hinders it. These words describe an influence that must be established, rather than just the sign of a calculation. If the instructions change to 3 pencils per pouch, mechanically reusing the old quantity can hinder performance: the familiar name of the kits hides a relevant change.

    The relationship C = n × q still applies, but the value of q must be checked again. We can therefore keep a principle while revising a learned detail. The last exercise examines this limit; no general improvement in memory is inferred from successful preparation.

Explain it in your own words

Hide the calculations. Explain what carries over from the source to the target, what must be replaced and what division checks. Then say what observation would still be needed to attribute success to previous learning.

✿03 Common mistakes

  • “I retrieve the source answer, so I have transferred my learning.”

    Retrieving 8 provides information about the question already practised. For the target, identify the new request and reconstruct the total from the relationship. An assisted answer remains assisted, even if its result is correct.

    Revisit the distinction between calculation and evidence

  • “The pouches look alike, so I keep all the numbers.”

    Compare the requirements: the number of pouches and the pencils in each. A colour can change without changing the rule; a quantity per pouch can change without changing the appearance. The roles and conditions guide adaptation.

    Compare the changes in the diagrams

  • “An incorrect answer proves that all the learning has been lost.”

    First locate where the process broke down: a rule not retrieved, an incorrect correspondence, the old quantity kept or a calculation error. These errors call for different remedies. Then doing a request set aside for testing without support will allow the reasoning to be examined again, without awarding a level on the basis of the exercise solution.

Exercise 1 · Identify

What does each attempt test?

Stay in the workshop. First situation: later, Leah repeats the source request for 4 pouches without support. Second situation: before seeing any exercise solution, she encounters the request for 7 pouches and solves it on her own, explaining the rule. Third situation: she is shown the multiplication to perform for this new request. For each situation, name what is being tested and a conclusion that would go too far.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Ask yourself whether the task has already been practised, then whether help is visible.

Hint 2

An answer to a new task can be independent or assisted; the help does not disappear because the result is correct.

Compare with the solution

The first situation is a retention attempt: it checks what remains available for the request already practised. It is not enough to show adaptation to another request.

The second is a near transfer task: the number changes and the relationship still applies. The reasoning provides evidence of reuse. Without an appropriate comparison, it does not quantify a causal effect of learning on the source task.

The third is an assisted answer to a new task. It does not demonstrate the ability to retrieve the rule independently. In your own exercise, consulting these hints or this solution also counts as help.

Check your reasoning

  • Distinguish whether the task is new and whether help is present.
  • Associate retention with repeating the source request after a delay.
  • Limit each conclusion to what the attempt allows you to observe.

Exercise 2 · Adapt and calculate

The stock is given; the request works in reverse

The pouches still get 2 pencils each. You have 18 pencils, with no losses and no reserve to keep. How many complete pouches can you prepare? Define the roles of the quantities, calculate and check the result. Explain why copying the source total would not answer the question.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

You know the total C and the quantity q per pouch. The unknown is now the number of pouches n.

Hint 2

Count the groups of 2 pencils in the stock, then reconstruct the stock by multiplication.

Compare with the solution

C = 18 pencils and q = 2 pencils per pouch. n = C ÷ q = 18 ÷ 2 = 9 pouches. Division counts how many complete groups the stock contains; it does not produce a number of pencils.

Check: 9 pouches × 2 pencils per pouch gives 18 pencils again, with no remainder. The source total of 8 pencils answered a different request and expressed a different quantity from the current unknown.

The equal groups principle has been reused in reverse. This adaptation is more demanding than copying the multiplication, but it does not demonstrate far transfer to all workshop activities.

Check your reasoning

  • Name C, q and the unknown n with their units.
  • Obtain 9 pouches by division and check by multiplication.
  • Explain why an answer in pencils does not answer the new question.

Exercise 3 · Diagnose and prepare a test

The same pouches, a different quantity

The workshop now requires 3 pencils in each of the 7 pouches. Leah prepares 14 pencils by reusing the old quantity per pouch. Calculate what is needed and the shortfall; repair her approach. Then propose how to distinguish a retained rule from independent adaptation, without claiming a measured gain.

Assisted answer: try this exercise without help later.

Hint 1

The relationship between the quantities can remain correct even when the reused value of q is wrong.

Hint 2

Calculate the new requirement, then subtract the quantity prepared. For the test, set aside a request that has not been practised and keep the solution hidden.

Compare with the solution

The requirement is 7 × 3 = 21 pencils. The shortfall is 21 − 14 = 7 pencils. Independent check: each pouch must get 3 − 2 = 1 extra pencil; as many extra pencils are therefore needed as there are pouches, giving 7.

Leah kept q = 2 instead of checking q = 3 again. The correspondence with the new instructions must be revisited, then the calculation performed with the new value. The error does not establish that she has forgotten multiplication. It is consistent with an old habit that has become a hindrance; without a comparison, its negative effect is not measured.

To separate the questions, plan an attempt on the source request without support after a delay, and set aside another kit request that Leah has never solved for the transfer attempt. Record the answer and explanation before any hints; note all help. Once their solutions have been seen, the requests on this page can no longer serve as unfamiliar targets.

The first attempt examines retention; the second examines independent adaptation to the target set aside for testing. Measuring an effect of learning on the source task would still require an appropriate comparison. No attained level or actual gain follows from merely reading this procedure.

Check your reasoning

  • Obtain 21 pencils required and 7 missing, with a check.
  • Repair the value of q without abandoning the equal groups relationship.
  • Plan a target set aside for testing, an attempt before help and an explicit distinction between retention and transfer.
  • Keep the causal effect as a question that an isolated result does not resolve.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What is the difference between retention and transfer in the workshop?

Retention concerns what remains available after a delay from what has been learned. Transfer concerns the influence of that learning on a new task. Repeating the source request is not enough to show adaptation.

Recall 2What carries over from the source request to the target request?

The relationship C = n × q between the total number of pencils, the number of pouches and pencils per pouch. Identify the same roles and check the values and conditions again; the source total does not automatically carry over.

Recall 3Why do 18 pencils at 2 per pouch require division?

The unknown is the number of groups: n = C ÷ q. This gives 9 pouches; multiplying them by 2 pencils per pouch recovers the stock. It is the same relationship used in reverse.

Recall 4Why can an old answer hinder a new preparation task?

The familiar appearance can lead to reusing the old quantity per pouch despite different instructions. Check q again. An isolated error does not measure negative transfer or prove that the entire rule has been forgotten.

Recall 5What should be set aside and recorded before speaking of independent adaptation?

Set aside a target that has not been practised, hide the solution and record the reasoning before any help. Note the help consulted. An isolated success does not measure the causal effect of learning on the source task; an answer after a hint remains assisted.

Reconstruct the reasoning

Without rereading, describe the progression source → relationship → target → check. Then explain why retention is not enough to establish transfer, how a changed condition requires adaptation and what evidence an assisted answer lacks. Try again after 2 days, without support and with a request set aside for testing: this delay is a scheduled practice session, rather than an automatic threshold for mastery.
