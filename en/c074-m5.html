Level 2 · C074·M5

Identification assumptions

Your goalConnect an observed comparison to a causal effect by naming the assumptions required and the situations in which calculation alone is no longer enough.

Before you start
c066-m5 : standard errors and diagnostics · c073-m5 : interaction and repeated measurements · c009-m5 : reading notes · c074-m1 : causal effect · c074-m2 : randomization · c074-m3 : confounding · c074-m4 : selection

✿01 See the idea

To reach a workshop, people can cross a footbridge or follow the usual path. People carrying a heavy bag choose the footbridge more often, but also walk more slowly. If footbridge users take longer, have you demonstrated that this route slows them down?

You would like to compare the journey times the paths would produce for the same population of journeys. Yet you observe only one path per journey. An identification assumption explains how an observable quantity can replace the missing comparison. Here, identification means expressing the causal effect in terms of the distribution of observations, under stated assumptions.

The bag load is measured before the path is chosen. We will compare the paths separately for light and heavy bags, then combine these comparisons using the same distribution of loads. This adjusts for this difference in composition if load is enough to make the groups comparable; the calculation does not prove that it is enough.

The entire scene and all journey times are fictional. Each journey represents a different person, with no repeated journeys and no waiting caused by other people. The diagram proposes an explanation to examine; the drawing is not a causal discovery derived from the data.

The rule to remember

Define the paths being compared, justify comparability at a fixed load, check that each path remains possible, and only then calculate the comparison using a common composition.

✿02 Follow an example

Worked example

Compare the paths for a common population

The fictional dataset contains 20 journeys. For light bags, 2 footbridge journeys each take 2 min and 8 journeys on the usual path each take 4 min. For heavy bags, 8 footbridge journeys each take 8 min and 2 journeys on the usual path each take 10 min. Using identical journey times within each cell only serves to make the sums easy to check. The target distribution is that of the entire dataset: 10 light bags and 10 heavy bags.

  1. Define the effect before seeking its value

    A codes the path actually taken: A = 1 for the footbridge, A = 0 for the usual path. X is either “light” or “heavy”, according to a load rule set before the journeys. Y is the observed journey time between the same starting and finishing points, in minutes.

    For a given journey, Y(a) is the time it would take if path a were imposed, keeping the initial load unchanged. The letter a denotes a possible value of A. These potential journey times are in minutes; we do not observe the alternative paths for the same person at the same departure. E denotes the mean in the target population of journeys, of which we assume our dataset is a representative sample.

    τ=E[Y(1)−Y(0)]

    τ, the letter tau, is the average effect of interest in minutes: footbridge minus usual path. A negative effect would correspond to a shorter journey via the footbridge. It concerns this population and these precisely defined paths, rather than all journeys.

  2. State the conditions under which the replacement would be valid

    Consistency: if A = a, then Y = Y(a). “Taking the footbridge” denotes the same intervention for everyone: the same entry routes and the same measurement points. We also assume no interference: the path chosen by one person does not change other people’s journey times. A footbridge that created a queue would fall outside this model.

    Conditional exchangeability: at a fixed load X, potential journey times have the same distribution among people choosing each path. Here, this rules out a common cause of path choice and journey time that would remain unaccounted for after considering X, such as usual walking speed if it also governs path choice. It does not mean equal observed journey times across paths.

    Y(a)⟂A|X

    The symbol ⟂ means independence; the bar | means “at a fixed X”. This assumption concerns potential journey times that are partly unobserved. A balanced table or a well-fitted regression does not demonstrate it.

    Positivity: for every load present in the target population, each path must have a strictly positive probability of being chosen. P denotes a probability, which has no unit; x is a possible load and a is 0 or 1.

    0<P(A=a|X=x)<1

    Finally, we assume that time and load are measured correctly, all journeys in the dataset are retained, and the target population is represented. Selecting only fast arrivals or measuring X after the choice would change the problem. These are conditions of this analysis that must be documented, rather than results of the calculation.

  3. Connect the observed comparison to the causal effect

    Fix a load x. Exchangeability allows us to replace the mean potential journey time for this load with that of people who chose a. Consistency then allows us to use their observed journey time. Positivity ensures that this conditional mean refers to a group that can occur.

    E[Y(a)|X=x]=E[Y(a)|A=a,X=x]=E[Y|A=a,X=x]

    Let ma(x) denote this last mean in minutes and w(x) = P(X = x) the proportion with this load in the target population, which has no unit. The weights sum to 1. To obtain the average effect, average the differences by load using these same weights. The symbol Σ means to sum over the loads “light” and “heavy”.

    τ=Σxw(x)[m1(x)−m0(x)]

    This equality gives identification at the population level. In the finite dataset, we replace ma and w with observed means and frequencies. The result will be an estimate τ̂, tau with a hat. Even under the assumptions, sampling uncertainty remains; we do not evaluate it in this unit.

  4. Check the cells and calculate the weights

    Count by load: 2 + 8 = 10 light-bag journeys; 8 + 2 = 10 heavy-bag journeys; 10 + 10 = 20 journeys in total. The estimated weights are therefore 10/20 = 0.50 and 10/20 = 0.50, with no unit. Their sum is 1.

    Among light bags, the footbridge frequency is 2/10 = 0.20, and the usual-path frequency is 8/10 = 0.80. Among heavy bags, they are 8/10 = 0.80 and 2/10 = 0.20. Each frequency is strictly between 0 and 1: the required cells are filled in this dataset.

    This check detects observable gaps. A small dataset with no empty cells does not prove positivity throughout the population, and does not verify exchangeability. Here, the cell means are simply the given journey times, since times are identical within each cell.

  5. See why the crude difference answers a different question

    The footbridge group contains 10 journeys. The total journey time is 2 × 2 + 8 × 8 = 4 + 64 = 68 min; its mean is 68/10 = 6.8 min. For the usual path, 8 × 4 + 2 × 10 = 32 + 20 = 52 min, for 10 journeys, giving 5.2 min.

    The crude difference is 6.8 − 5.2 = 1.6 min. It compares the groups as they formed: mostly heavy bags for the footbridge, mostly light bags for the usual path. It does not compare interventions for the same load distribution. Its sign is therefore not enough to establish the direction of the causal effect.

  6. Calculate using a common composition

    Apply the target population weights to the means for each path. For the footbridge: 0.50 × 2 = 1 min for the light-bag contribution, then 0.50 × 8 = 4 min for the heavy-bag contribution. Sum: 1 + 4 = 5 min.

    For the usual path, the same weights give 0.50 × 4 = 2 min and 0.50 × 10 = 5 min. Sum: 2 + 5 = 7 min. Keeping the same weights makes the composition comparable.

    τ^=5−7=-2 min

    We have calculated an adjusted contrast of -2 min in the fictional data. Under the stated assumptions and sampling design, it estimates the average effect of the footbridge relative to the usual path. It is neither a real measurement nor a validation of the assumptions.

  7. Check another way and limit the conclusion

    Start again with the differences by load: light, 2 − 4 = -2 min; heavy, 8 − 10 = -2 min. Their weighted average is 0.50 × -2 + 0.50 × -2 = -1 + -1 = -2 min. The equal weights also allow us to divide the sum of the differences by 2. We recover the result by organizing the calculation another way.

    The adjusted means 5 min and 7 min do lie between their respective cell means. All weights are positive and their sum is 1; no time has been added to a proportion without multiplication.

    The arithmetic check does not replace the causal justification. If fast walkers choose the footbridge more often at the same load, exchangeability may fail and τ̂ may lose its causal interpretation. A regression reproducing the same means would not supply this missing information. Properly conducted random assignment can support comparability; it does not remove the need to define the intervention, measurements and follow-up.

Explain it in your own words

Without looking at the formulas, connect each replacement of a mean to its assumption. Why do the crude contrast and the adjusted contrast have different signs here? What additional fact would you need to justify before saying that the footbridge causes a shorter journey time?

✿03 Common mistakes

  • “I controlled for load, so the effect is causal.”

    Naming an adjustment variable does not prove that it is enough. At the same load, usual walking speed influencing both choice and time would leave confounding. Write down what justifies exchangeability, or retain the result as an adjusted descriptive contrast.

    Return to the conditions and the replacement of means

  • “An empty cell means a journey time of 0.”

    The absence of a journey is not an observation of journey time. A cell mean is then missing; setting it to 0 min would fabricate a comparison. Investigate whether the path is possible for this load and state the limitation on identification.

    Examine the transfer exercise on the closed path

  • “The calculation checks out, so the assumptions do too.”

    The second method confirms an arithmetic identity. It does not reveal the missing potential journey times. Check the path definition, comparability, possible choices, measurement and journey selection separately.

    Reread the check and its scope

The same name hides different routes

Hint 1

What must Y(a) denote for Y = Y(a) to make sense?

Hint 2

Is a path name enough to define a reproducible intervention?

Compare with the solution

Consistency with a well-defined intervention is at issue: here, the value A = 1 mixes versions that are not distinguished and may have different journey times. This mixture does not automatically define the effect of a specific entry route to the footbridge.

Fixing the entry routes, starting and finishing points and measurement rule, then recording the version actually used, makes the contrast interpretable. If the aim is to compare a policy that mixes entry routes, that policy and its mixture must be defined. Increasing the number of journeys without clarifying this choice does not resolve it.

Check your reasoning

  • Connect the difficulty to the definition of Y(a) and to consistency.
  • Propose a precise intervention and measurement points.
  • Do not claim that a larger sample size is enough.

Respond to the crude difference

A reader states: “6.8 min versus 5.2 min, so the footbridge slows people down.” Starting from the means by load, recover the contrast for the target composition, then the contrast for heavy bags alone. Justify the use of the weights and state a conditional conclusion.

Hint 1

The target population contains as many light bags as heavy bags. First compare the paths within each load.

Hint 2

For the full target population, use 0.50 and 0.50. For heavy bags alone, no mixture of loads is needed.

Compare with the solution

Light: 2 − 4 = -2 min; heavy: 8 − 10 = -2 min. For the full target population, 0.50 × -2 + 0.50 × -2 = -2 min. For heavy bags alone, the contrast is directly -2 min.

The weights describe the target composition, rather than separately reproducing the composition of each path group. The contrasts coincide here because the differences by load are equal; this is not a general rule.

Under consistency, no interference, exchangeability at a fixed load, positivity and representative observation, these calculations estimate the corresponding average effects. The crude difference of 1.6 min is descriptive; it does not by itself refute these conditional estimates, and the dataset is not enough to prove their assumptions.

Check your reasoning

  • Recover -2 min for the full population and -2 min for the heavy load.
  • Explain why the target weights are shared across paths.
  • Name the conditions for a causal interpretation and retain estimation uncertainty.

Exercise 3 · Critical transfer

A path becomes impossible for heavy bags

It is discovered that heavy bags were forbidden on the usual path throughout the period of interest. The 2 journeys previously classified in that cell came from another period and must be excluded from this comparison. There are 0 heavy-bag journeys on the usual path left. Can we keep the estimate for the full target population, or replace it with the estimate for light bags alone? Distinguish an impossible path from the absence of observations in a small sample.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Which mean potential journey time for heavy bags can no longer be connected to an observed mean from the period?

Hint 2

Changing the target population does not fill the missing cell: it changes the question.

Compare with the solution

For heavy bags, the probability of the usual path is 0 during this period. Positivity fails for the full target population. The heavy-bag mean of 10 min for the usual path in the old table can no longer be used; replacing it with 0 min would invent a journey time.

The contrast for light bags alone remains calculable: 2 − 4 = -2 min. Under the other assumptions for this subgroup, it estimates that subgroup’s effect, not the effect for all journeys. The numerical coincidence with the old result does not justify generalizing to heavy bags.

If there were simply no heavy-bag journeys on the usual path in a small sample even though this choice remained possible, the empty cell would not prove impossibility in the population. The possibilities would need to be better documented and relevant observations obtained; for the structural restriction described here, collecting more journeys under the same rule does not restore positivity. Changing the protocol or imposing an extrapolation would require a new, explicit justification.

Check your reasoning

  • Name positivity and the missing heavy-bag mean.
  • Refuse to confuse the absence of a journey time with a time of 0.
  • Distinguish the full target population from the light-bag target population, even if their old results coincide.
  • Separate an empty cell due to sampling chance from a choice made impossible.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What does it mean to identify the average effect of the paths?

Express the mean of the differences in potential journey times using the distribution of observations, under explicit assumptions. Estimating it in a finite dataset adds sampling uncertainty.

Recall 2What must be defined to connect observed and potential journey times?

A precise intervention: entry routes, departure, arrival, measurement. If A = a, consistency gives Y = Y(a). Here we also assume that one person’s path does not affect other people’s journey times.

Recall 3Why is knowing the bag load not enough to prove comparability?

Exchangeability requires potential journey times to be independent of path choice at a fixed load. Overlooked usual walking speed may still influence both. The observations do not show all potential journey times.

Recall 4What is missing if heavy bags can never take the usual path?

Positivity for that load: its potential journey time on the usual path can no longer be replaced by an observed mean from the period. The absence of a journey is not a journey time of 0 min.

Recall 5Why use the same load weights for the paths?

To compare interventions in the same target population. The compositions specific to the observed groups describe different populations. Checking the calculation does not demonstrate the assumptions that permit a causal interpretation.

Reconstruct the reasoning

Reconstruct the reasoning without support: define the target population, paths and potential journey time; connect each replacement to consistency, exchangeability and positivity; check measurements and selection; compare by load using the same weights; check the calculation and name the missing causal evidence.
