Level 3 · C105·M4

Encoder and decoder

Your goalFollow a rewording task from source to output, distinguish encoder and decoder attention, then identify answer leakage during training.

Before you start
c104-m5 : temporal validation · c102-m5 : finite difference checking · c050-m5 : conditioning · c105-m1 : queries, keys and values · c105-m2 : multi-head attention · c105-m3 : positions

✿01 See the idea

A small display receives the message “door open” and must reword it as “entry allowed”. In this fictional scene, the exercise convention associates these messages; an actually open door would not be enough to establish permission to enter. We follow only the production of the text.

Imagine someone reading the whole note and setting out notes in front of them, then writing the reworded message one word at a time. The encoder prepares the notes about the source. The decoder consults what it has already written and returns to those notes to choose what comes next. These are calculations on representations, with no human reader hidden inside the machine.

At the point we are studying, “entry” has already been produced. The decoder must now choose between “allowed” and “denied”. It can consult “door” and “open”, both received before it began. It cannot consult the output word it is supposed to predict.

Self-attention connects positions within the same sequence. In the encoder on this page, the entire source is visible. In the decoder, a causal mask prevents it from looking at future output positions. Cross-attention then connects the decoder to the source representations. This difference in visibility explains the roles of the blocks, even when their attention operations are similar.

The rule to remember

The encoder contextualizes the available source; the decoder combines the permitted output prefix and the encoded source to predict the next token.

✿02 Follow an example

Worked example

Produce the word after “entry” from “door open”

The data are entirely fictional. The chosen tokenization gives 2 source tokens, “door” and “open”. The available prefix is “start, entry”, where “start” is a technical marker with no displayed word. We calculate only the choice of the next word; the initial choice of “entry” is assumed to have already been made.

  1. Define the visibility rules

    x is the source sequence of length n; y is the output sequence. A token is an element of the text tokenization; here, each chosen word forms a token. t denotes the position to predict. y<t denotes the output words strictly before t, to which we add the start marker. In our calculation step, t = 2 and the only word already produced is “entry”.

    H is the array of contextualized source representations: n rows, each of width d. Each row retains a source position. The encoder in this architecture uses noncausal self-attention: “door” can incorporate “open”, and vice versa. The entire source is available before generation. Any padding positions added to align sequences must be excluded from attention.

    H=Encodeur(x);zt=Décodeur(y<t,H)

    zt denotes the decoder state used to predict at position t. The array H can be reused while generating this output; the decoder states depend on the growing prefix. This notation describes the encoder–decoder architecture being studied: some models use only an encoder or only a decoder, without this pair of blocks.

  2. State the simplifications and the data

    To follow the paths with pencil and paper, take d = 1 component per representation. ep = 2 represents “door”, eo = 6 represents “open”, e_b = 0 represents the start marker and ea = 4 represents “entry”. The letters p, o, b and a are only labels. All these representations, states and scores have no physical unit; the lengths n and d count tokens and components.

    Position information is assumed to be included in these inputs already. Over the visible positions, the attention weights are prescribed, positive and sum to 1: 1/2 and 1/2 in the encoder; 1/4 and 3/4 for self-attention over the prefix being studied, then the same weights for its cross-attention reading of the source. These last two pairs are chosen to be equal for this exercise; they come from separate calculations in a trained model.

    A residual addition adds the input of a sub-block to its output. We retain these additions and use identity value projections, which leave the numbers to be mixed unchanged. We omit normalization, intermediate transformation networks and the stacking of layers. The values are not learned parameters: this toy model isolates the flow of information and does not reproduce a complete Transformer.

  3. Encode the entire source without reducing it to a single number

    Our encoder self-attention takes the same average on each row. Multiply each source value by its weight: 1/2 × 2 = 1 and 1/2 × 6 = 3. The shared average is therefore 1 + 3 = 4, with no unit.

    hp=ep+4=6;ho=eo+4=10

    hp and ho are the final representations of these positions in the toy model. Adding the average to each input gives 2 + 4 = 6 and 6 + 4 = 10. H therefore retains the 2 rows, 6 then 10. It does not require the sentence to be compressed into a single vector.

    Check: the weights sum to 1 and the average 4 lies between 2 and 6. The states after residual addition can fall outside this interval: they are no longer simple averages of the inputs.

  4. Read only the permitted prefix in the decoder

    Here the decoder processes the inputs “start, entry” to predict the word after “entry”. Its self-attention uses queries, keys and values from this same prefix. The causal mask allows a row to consult its own input and previous inputs; shifting ensures that its own input is not the expected answer on that row.

    The prefix average is 1/4 × 0 + 3/4 × 4 = 0 + 3 = 3. Add the current input ea to obtain u, the state after this sub-block:

    u=ea+3=4+3=7

    Check: the weights sum to 1, and 3 lies between 0 and 4. The word “allowed” has supplied no input to this calculation. During generation, it is not yet known.

  5. Connect the decoder query to the source memory

    In cross-attention, the query comes from u; the keys and values come from H. A query indicates what the decoder is looking for, keys are used to compare source positions, and values carry what will be mixed. Learned projections normally transform these representations. Here the values remain hp and ho; the weights are provided, so we do not recalculate the comparisons between the query and keys.

    Consulting “door” contributes 1/4 × 6 = 3/2, or 1.50 with no unit. Consulting “open” contributes 3/4 × 10 = 15/2, or 7.50. Add them to obtain c, the source context for this step:

    c=1/4×6+3/4×10=9;z=u+c=16

    z denotes zt at the step being studied. The source and prefix meet through the addition 7 + 9 = 16. Independent check of the average: c = hp + 3/4 × (ho − hp), so 6 + 3/4 × (10 − 6) = 9. c does lie between 6 and 10.

    Consulting “open” does not violate causality: it is a word in the source already received. The causal mask concerns the future of the output. Confusing these two sequences would remove information that the task permits the model to consult.

  6. Go from the state to scores, then to the word

    An output head transforms the state into a score for each candidate. For this step alone, the vocabulary is deliberately limited to “allowed” and “denied”. We define sa = z − b and sᵣ = b − z, with b = 12, a constant with no unit. The subscripts a and r label the candidates here. This rule is chosen for the exercise; it is not a general rule for language decoding.

    sa=16−12=4;sr=12−16=-4

    Choose the candidate with the highest score: 4 exceeds -4, so the next word is “allowed”. The margin, defined as sa − sᵣ, is 8, with no unit. Check: the scores are opposites, as their definition requires. These are ranking scores, not probabilities or proof that the sentence is true.

    In a language model, normalization can convert scores into token probabilities. A selection rule then chooses a token, which joins the prefix for the next step. Here, producing the end marker would require another step and an output head that allows this marker; we have not calculated it.

  7. Distinguish parallel training from stepwise generation

    During training, the known target is “entry, allowed, end”. The decoder is given “start, entry, allowed” and is expected to produce “entry, allowed, end”, respectively. Providing the true preceding words is called teacher forcing. Shifting and masking must work together: on the row expecting “allowed”, the current input is “entry” and the future input “allowed” remains inaccessible.

    The rows of an example can then be calculated in parallel, because the reference inputs are known and each row has its own visibility restriction. The answers are not all available during generation: after each choice, the prefix grows. An incorrect word can therefore affect later steps. The mask does not replace an evaluation of the sequence actually generated.

    Final dependency check: if only the target word to predict changes, while the source, prefix and parameters stay fixed, the state z of this row must remain identical. The expected answer can change, but it must not enter the calculation that predicts it. The last exercise asks you to trace the path of a leak.

Explain it in your own words

Hide the calculations. Draw where queries, keys and values come from in each attention mechanism. Explain why “open” is visible while “allowed” is not yet visible. Then reconstruct the source representations, u, c and the final choice.

✿03 Common mistakes

  • “The encoder must produce a single vector, which the decoder then translates.”

    In the encoder–decoder Transformer being studied, H retains a row for each source position. The decoder can weight these rows differently at each step. In the toy model, rows 6 and 10 remain distinct despite the shared average.

    Revisit the construction of H and the cross-attention reading

  • “A causal decoder must also hide “open” to predict the next word.”

    The entire source has already been received. What must remain hidden is the rest of the output. First identify which sequence each position belongs to, then apply the permissions in the diagram.

    Review the paths and the visibility table

  • “During training, the target is known: the mask becomes unnecessary.”

    Without a mask, the row predicting “entry” could consult the future input “entry”. It would read its answer, information absent at the same point during generation. Shifting alone does not block this path; also check every self-attention layer in the decoder.

    Diagnose the leak in the last exercise

Exercise 1 · Reasoned identification

What does each block consult?

When completing “entry”, identify the sequence supplying keys and values in encoder self-attention, decoder self-attention and cross-attention. In each case, specify whether “open” and the target word “allowed” can contribute. Give more than just the block names.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Self-attention stays within a sequence; cross-attention changes sequence between the query and the keys and values.

Hint 2

Separate the source “door open” from the prefix “start, entry”. “Allowed” is still an expected answer.

Compare with the solution

Encoder: keys and values come from the source “door open”; “open” is visible, “allowed” is not an encoder input. Decoder self-attention: they come from the prefix “start, entry”; neither “open” nor the future output word “allowed” is an input to this sub-block.

Cross-attention: the query comes from the decoder state, the keys and values from H. “Open” can therefore influence the prediction through its encoded representation, while the target word “allowed” remains inaccessible. After this sub-block, the decoder state has indeed received source information.

Check your reasoning

  • Assign each attention mechanism its sequence of keys and values.
  • Place the cross-attention query on the decoder side.
  • Justify the permissions by the availability of information.

Exercise 2 · Calculation and checking

The decoder consults the same source differently

Keep H, u = 7 and the output head from the example. Change only the cross-attention weights: 3/4 for the “door” position, 1/4 for “open”. First predict the direction of the change in the source context, then calculate this context, the new state, the scores and the margin. Does the word choice change?

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The weight increases on the smaller of the representations 6 and 10. The context should therefore decrease.

Hint 2

Calculate the new source average before adding u. Then retain the rules z − b and b − z.

Compare with the solution

The contribution of “door” becomes 3/4 × 6 = 9/2, or 4.50 with no unit. The contribution of “open” becomes 1/4 × 10 = 5/2, or 2.50. The context is 9/2 + 5/2 = 7, less than 9 as predicted.

The state is 7 + 7 = 14. Score for “allowed”: 14 − 12 = 2; score for “denied”: 12 − 14 = -2. The margin is 2 − (-2) = 4. The scores have no unit; “allowed” remains the choice under the highest score rule, with a smaller margin.

Check using another expression: 10 + 3/4 × (6 − 10) = 7, between 6 and 10. H does not change: we have changed how it is consulted, not how it is encoded. The same chosen word can therefore conceal different states and margins.

Check your reasoning

  • Predict the decrease before calculating and retain the representations in H.
  • Recover 7, 14 and the opposite scores.
  • Explain why an unchanged choice does not mean an unchanged calculation.

Exercise 3 · Diagnosis and repair

Training that reads its own answer

For the same rewording task, a program receives “start, entry, allowed” and expects “entry, allowed, end”. It removes all causal masks from the decoder, claiming that shifting is enough. Describe a precise leakage path to the row predicting “entry”, repair the permissions, then propose a dependency check on the row predicting “allowed”. Explain what this check would establish and what would still need to be evaluated.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

An input on the next row already contains the word expected on the current row.

Hint 2

To test a forbidden dependency, keep the source and the permitted prefix; change only a future input. The parameters must remain fixed, with no randomness in the calculation.

Compare with the solution

On the “start” input row, “entry” is expected. Without a mask, its query can read the key and value of the next input, “entry”: the expected answer flows back into the state that must predict it. On the “entry” input row, “allowed” is expected and the next input already contains this word. Shifting has placed the answer elsewhere; it has not made it inaccessible.

Repair: each decoder self-attention row consults only its own input and previous inputs, in every layer. The “start” row sees only “start”; the “entry” row sees “start, entry”. Cross-attention keys and values still come from the source, without injecting the targets into it.

Proposed check: with fixed parameters and no randomness, keep “door open” and “start, entry”, then replace the future input “allowed” with “denied”. The scores on the “entry” input row must be identical before and after. In our toy model, the formulas always give z = 16, sa = 4 and sᵣ = -4, because this future input does not appear in them.

A difference would reveal a forbidden dependency in this case. A single equality would not be enough to prove that all masks work: some weights could cancel out the leak. It would also be necessary to inspect the dependencies of every layer and vary the cases. Finally, even correct masking does not prove the quality of the generated texts; that requires evaluation during generation, with the prefixes actually chosen. None of these tests on a real model is run on this page.

Check your reasoning

  • Name the row, the future input and the answer this input reveals.
  • Keep shifting and restore the mask in all affected layers.
  • Define what changes, what stays fixed and the expected invariance.
  • Distinguish a counterexample revealing leakage, a general proof of causality and a quality evaluation.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What does the encoder pass to the decoder in the architecture being studied?

An array H of contextualized representations, with a row for each source position. Cross-attention can consult these rows differently at each step. This array is not necessarily a single sentence vector.

Recall 2Where do queries, keys and values come from in cross-attention?

Queries come from the decoder states; keys and values are projections of the source representations H. Self-attention constructs these three objects from the same sequence.

Recall 3Why is “open” visible while “allowed” must remain hidden at the step being studied?

“Open” belongs to the source received in full before generation. “Allowed” is the output word to predict. The available prefix contains only the start marker and “entry”. Causality concerns the future of the output.

Recall 4Why must targets be shifted and the future masked during training?

Shifting pairs each input with the expected next word. Without a mask, this expected word remains readable in a future input. The mask prevents this leakage in every decoder self-attention layer. The rows can then be calculated in parallel over the reference prefixes.

Recall 5What check can reveal that a row is reading a future input?

With the source, permitted prefix and parameters fixed, and no randomness, change only a future input: the scores on the row must remain identical. A difference reveals a forbidden dependency; equality in a single case does not prove general causality or generation quality.

Reconstruct the reasoning

Without rereading, reconstruct the paths from “door open” to the choice after “entry”. Recall what H retains, what the prefix permits, then the origins of the cross-attention queries, keys and values. Finally, reconstruct the input–target pairs and explain why shifting and masking are both necessary. Reading or an assisted answer does not establish an attained level.
