Level 4 · C264·M1

Permutation

Your goalMeasure how much a fixed model depends on an input by permuting it, then define what the change in error allows us to conclude.

Before you start
c263-m5 : distribution shift · c074-m5 : identification assumptions · c220-m5 : numerical reproducibility · c017-m5 : reproduction protocol

✿01 See the idea

A workshop wants to predict the total energy consumed during a trial. It has an estimate for the machine and an estimate for other uses. Its model adds these inputs together. To find out how much it relies on the “machine” input, we give it the same values, but assign them to different trials.

Imagine swapping labels within a single column. The meter reading for each trial stays in place; so do the other uses. If the predictions get worse, the original association between this column and the trials helped this model predict. This measure is called permutation importance.

The entire scene and all its values are fictional. The 4 trials A, B, C and D are held out for evaluation: they were used neither to fit nor to select the model. All energies are expressed in kilowatt-hours, written kWh. The trial letters are labels, not dates.

We will evaluate the same rule before and after the swap. Retraining the rule after shuffling would answer a different question: could we build a different model with these modified inputs?

The rule to remember

Keep the model, targets and other columns fixed; permute an input; recalculate the predictions; measure the increase in the same error on the same trials.

✿02 Follow an example

Worked example

The cost of swapping the machine labels

Inputs a and b are the energy estimates for the machine and other uses; y is the total energy given by the meter. The rule, already fixed, is f(a,b) = a + b. The 4 triples (a ; b ; y), in kWh, are A (2 ; 1 ; 4), B (4 ; 1 ; 4), C (6 ; 2 ; 9), D (8 ; 2 ; 9). We reverse the order of a to make the calculation fully reproducible.

  1. Define the objects and the protocol

    i denotes a trial; n = 4 is the number of trials. aᵢ, bᵢ and yᵢ are energies in kWh. f is the fixed prediction function; ŷᵢ = f(aᵢ,bᵢ), where the hat denotes a prediction. No parameter or preprocessing is recalculated on these trials.

    The table is complete, with no missing values. We treat the trials as independent repetitions carried out under the same operating conditions. Their order has no physical role in this example. This assumption allows unrestricted shuffling here; it would need to be reconsidered for a time sequence or trials grouped by machine.

  2. Choose an error measure and its direction

    eᵢ is the distance between the prediction and the meter reading: the bars |…| denote the absolute value, which removes the sign of a difference. E is the mean absolute error: add these distances, then divide by the number of trials. The symbol Σ denotes this sum, from i = 1 to i = n. eᵢ and E are in kWh; n is a count with no physical unit. A smaller error is better.

    ei=|f(ai,bi)−yi|;E=1nΣi=1nei

    This choice penalizes each kWh of difference in the same way. Changing the error measure can change the resulting importance: the measure must therefore be specified before making comparisons.

  3. Calculate the baseline over all rows

    Initial predictions: A, 2 + 1 = 3 kWh; B, 4 + 1 = 5 kWh; C, 6 + 2 = 8 kWh; D, 8 + 2 = 10 kWh.

    Distances from the meter reading: A, |3 − 4| = 1 kWh; B, |5 − 4| = 1 kWh; C, |8 − 9| = 1 kWh; D, |10 − 9| = 1 kWh. Taking absolute values prevents overestimates from cancelling out underestimates.

    E=1+1+1+14=44=1.00 kWh

    Immediate check: all distances equal 1 kWh, so their mean must equal 1 kWh. Averaging the signed differences would have hidden the error.

  4. Define the permutation while keeping the targets in place

    π, read as “pi”, assigns each row a source row, which may be different or the same, using each source exactly once. It is a permutation of the indices and has no unit. Here π(A) = D, π(B) = C, π(C) = B and π(D) = A. The symbol aπ(i) denotes the value of a taken from that source; bᵢ and yᵢ remain those of row i.

    The new pairs (a ; b) are therefore A (8 ; 1), B (6 ; 1), C (4 ; 2), D (2 ; 2), still in kWh. We run f again on these inputs: moving only the predictions already calculated would not work, because b must remain associated with its row.

    Eπ=1nΣi=1n|f(aπ(i),bi)−yi|

    The superscript π labels the perturbed evaluation; it is not a numerical power. Eπ remains a mean in kWh. The reversal is a fixed permutation for calculation with pencil and paper, not a representative estimate of all possible shuffles.

  5. Recalculate the error after shuffling

    New predictions: A, 8 + 1 = 9 kWh; B, 6 + 1 = 7 kWh; C, 4 + 2 = 6 kWh; D, 2 + 2 = 4 kWh.

    New distances: A, |9 − 4| = 5 kWh; B, |7 − 4| = 3 kWh; C, |6 − 9| = 3 kWh; D, |4 − 9| = 5 kWh. The comparisons use the original meter readings, in their original order.

    Eπ=5+3+3+54=164=4.00 kWh

  6. Subtract the baseline, then check

    Iaπ denotes the observed importance of a for this permutation: the new error minus the initial error. It measures a loss of predictive performance, in the unit of the chosen error measure.

    Iaπ=Eπ−E=4.00−1.00=3.00 kWh

    Another route: the distances increase, row by row, by (5 − 1), (3 − 1), (3 − 1), (5 − 1) kWh. Their mean again gives 3.00 kWh. This is the same paired comparison, carried out before averaging.

    Protocol check: the set of values of a is preserved; b and y are unchanged. An identity permutation, which leaves everything in place, gives 0 kWh of importance. If the error decreased after shuffling, the importance would be negative: that would call for examining the model and the variability, without clipping the result to 0.

  7. Move from a single shuffle to an estimate from repeated shuffles

    For a study, draw several permutations according to a declared rule, rather than choosing the one that gives the largest increase. R is the number of draws; r is their index, from 1 to R; πᵣ is the permutation for draw r. These indices and this count have no physical unit. Keep f and E, then average the differences.

    Ia¯=1RΣr=1R(Eπr−E)

    The bar denotes this mean, still in kWh. Also retain the spread across draws and the permutations used, or the seed and procedure that reproduce them. Repetition reduces the variability due to shuffling; it does not remove the uncertainty associated with our small set of trials. We have not carried out these draws here: 3.00 kWh remains the result of the single reversal shown.

  8. Understand the scope before ranking the inputs

    The increase shows that f depends predictively on the original association of a with these trials, for this error measure and this perturbation. It measures neither a share of the energy consumed nor the effect of a real intervention on the machine. It is also not a permutation test providing a p-value.

    Here, large values of a occur with large values of b. Shuffling therefore creates pairs absent from the original table, such as (8 ; 1) kWh. If such pairs are physically impossible or very atypical, the increase also describes behaviour outside the usual combinations. These combinations must be examined before generalizing.

    More generally, closely related inputs can substitute for one another in a model: low importance is then insufficient to declare information useless. Restricting swaps to comparable trials or permuting a group of inputs asks a different question, which must be stated explicitly. For temporal data, preserving the relevant dependencies can also change the protocol. This unit stops at this diagnosis and does not teach these additional methods here.

Explain it in your own words

Hide the results. Describe what is kept, what is swapped and why f must be recalculated. Then reconstruct the unit and sign of the importance, and state a conclusion that this calculation supports and a conclusion that it does not support.

✿03 Common mistakes

  • “I will shuffle all the columns together; that will be fairer.”

    If you move a, b and y together, you merely reorder the trials: each pair keeps its meter reading and the mean does not change. To isolate the dependence on a, move only a and keep b and y associated with each row.

    Reread the columns in the first diagram

  • “The importance is the error after shuffling; I can also retrain.”

    The perturbed error is 4.00 kWh, but it includes the initial error of 1.00 kWh. The importance is their difference, 3.00 kWh. Retraining changes the model whose dependence you wanted to measure; keep its rule and preprocessing fixed.

    Revisit the subtraction and its check

  • “High importance proves a cause; 0 importance proves uselessness.”

    Shuffling perturbs a model’s inputs without intervening in the real workshop. Its effect also depends on the associations between columns, the trials and the error measure. The calculation for b in the exercises will even show 0 importance although f uses this input.

    Calculate for b, then discuss the conclusion

Predictions: A, 2 + 2 = 4 kWh; B, 4 + 2 = 6 kWh; C, 6 + 1 = 7 kWh; D, 8 + 1 = 9 kWh.

Distances: |4 − 4| = 0 kWh; |6 − 4| = 2 kWh; |7 − 9| = 2 kWh; |9 − 9| = 0 kWh. Their sum is 4 kWh.

The mean is 4/4 = 1.00 kWh. The importance for this shuffle is 1.00 − 1.00 = 0.00 kWh. Yet the predictions have changed: the distances decreased for A and D and increased for B and C. The cancellation concerns the changes in distances, after taking absolute values.

Exercise 3 · Discuss the protocol

Receive an overconfident report

A report on these trials concludes: “a causes consumption, b is never useful; we tried several shuffles and publish only the highest importance.” Rewrite its conclusion and propose a reproducible protocol that avoids this selection. Explain the role of unusual pairs of a and b.

Assisted answer: try this exercise without help later.

Hint 1

Does the model f(a,b) = a + b use b, even when the calculated importance is 0?

Hint 2

Separate an observed predictive dependence, a mean over shuffles specified in advance and a real effect on the workshop.

Compare with the solution

A defensible conclusion: for the fixed rule, the 4 trials and the mean absolute error, reversing a increases the error by 3.00 kWh; reversing b leaves it unchanged. The latter result does not establish that b is ignored: b appears in f and all the predictions in the previous exercise changed.

Before calculating, specify the held-out evaluation set, the version of the model and preprocessing, the error measure, the columns to permute, the sampling rule and the number of repetitions. Retain all the resulting differences, their mean and their spread, along with what is needed to reproduce the permutations. Keeping only the maximum would select the most unfavourable perturbation.

Examine the pairs created: the combination (8 ; 1) kWh is absent from the original table. If the protocol creates impossible situations, its scope must be reduced or the shuffling rule revised. This diagnosis proves no causal effect and provides no measurement of the real workshop. A delayed check without hints still needs to be done; an answer produced after consulting the solution is an assisted answer.

Check your reasoning

  • Replace the causal claim with a conclusion tied to the model, trials, error measure and shuffle.
  • Justify why 0 importance for b does not prove that it is unused.
  • Propose a procedure specified before the results and retain all draws.
  • Name the risk of unusual pairs without claiming that they are necessarily impossible.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What must be moved and kept to measure the dependence on a?

Permute the values of a between rows, using each source row once. Keep b, the targets, the model and the preprocessing fixed, then recalculate the predictions.

Recall 2Why is the importance 3.00 kWh rather than 4.00 kWh in the example?

The error after shuffling includes the baseline error. Subtract 1.00 kWh from 4.00 kWh: the increase is 3.00 kWh. For an error measure where smaller is better, an increase gives positive importance.

Recall 3How can b have 0 importance when f uses it?

In this shuffle, the predictions change, but the decreases and increases in distances from the meter readings cancel out on average. Importance describes a change in the error measure, not an inspection of the inputs used by the code.

Recall 4What must be retained when permutations are repeated?

The reproducible procedure and permutations, all differences, their mean and their spread. Variability between shuffles on a fixed set remains distinct from uncertainty due to the choice of trials.

Recall 5What limits must be stated before interpreting a large increase in error?

It concerns this model, this evaluation set, this error measure and this perturbation rule. Related inputs can create unusual pairs after shuffling. The increase establishes neither a real causal effect nor universal usefulness of the variable.

Reconstruct the reasoning

Reconstruct without reference material: draw a row before and after permuting a, name everything that stays fixed, write the mean error and then the difference in errors with its unit. Then explain the 0 result for b, the value of repetitions and the limitation of unusual pairs.
