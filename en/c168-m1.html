Level 3 · C168·M1

Measurable variables

Your goalDecide whether a quantity respects the information in a σ-algebra, calculate a preimage, and explain why its probability is then defined.

Before you start
c164-m5 : Fubini-Tonelli · c060-m5 : approximations and assumptions · c165-m5 : duality

✿01 See the idea

A workshop fills small bags. In our fictional model, the selected bag can be a, b, c, d, e, or f. The sensor distinguishes only the groups A = {a, b}, B = {c, d}, and C = {e, f}. Its reading X is 100 g on A, 200 g on B, and 300 g on C. It can never distinguish a from b.

Asking whether the reading exceeds a threshold selects whole groups. In contrast, asking whether the bag is specifically a splits group A. Here the σ-algebra represents the questions that this information can answer: every allowed event is a union of whole groups.

A measurable variable respects these questions. When we ask an admissible question about its value, the set of outcomes that answer yes must be an event in the σ-algebra. The word measurable refers to this mathematical property; it guarantees neither the accuracy of the sensor nor the practical possibility of building it.

All masses and probabilities on this page are fictional. The sensor represents the available information; no physical error or noise distribution is assumed. The letters denote the possibilities in the model, without claiming that their identities are observed.

The rule to remember

Start with a question about the values; work back to the outcomes that satisfy it; check that this set belongs to the σ-algebra before applying a probability to it.

✿02 Follow an example

Worked example

The reading does not exceed 200 g

For the same bags, set P(A) = 1/2, P(B) = 1/3, and P(C) = 1/6, with no units. These weights apply to the groups, rather than to each bag. We will check the measurability of X, then calculate P(X ≤ 200 g).

  1. Specify the space and the information

    Ω = {a, b, c, d, e, f} is the set of 6 outcomes; ω denotes any outcome. A, B, and C form a partition: they are nonempty, disjoint, and their union is Ω. The σ-algebra ℱ is the family {∅, A, B, C, A ∪ B, A ∪ C, B ∪ C, Ω}. ∅ is the empty set and ∪ denotes a union.

    Recall: a σ-algebra contains Ω and is closed under complements in Ω and countable unions. Here each event includes or excludes each whole group: 2 × 2 = 4 choices for A and B, then 4 × 2 = 8 events. Taking a complement or a union preserves this property, so ℱ is indeed a σ-algebra.

    P is a probability measure defined on ℱ. The positive weights 1/2, 1/3, 1/6 sum to 1. For a union of groups, P adds their weights. This defines the probability of every event in ℱ; no individual probability for {a} or {b} is specified.

  2. Define the variable and the preimage

    X is a function from Ω to ℝ: it assigns a real number to each outcome. Its numerical values are expressed in grams. X(a) = X(b) = 100, X(c) = X(d) = 200, X(e) = X(f) = 300. The symbols Ω, ℱ, and the sets of outcomes have no physical units.

    ℬ(ℝ) denotes the Borel σ-algebra, the smallest σ-algebra containing the open intervals of ℝ. A Borel set D is an admissible question about the real value. X is ℱ-measurable when, for every D belonging to ℬ(ℝ), its preimage belongs to ℱ:

    X−1(D)={ω∈Ω:X(ω)∈D}∈ℱ

    The exponent −1 means preimage, never division by X. The function does not need to be invertible. D contains numerical values in grams; its preimage contains outcomes. Measurability does not depend on the weights of P.

  3. Check all questions without listing them

    For any Borel set D, if 100 belongs to D, its preimage contains all of A; otherwise, it contains none of A. The same reasoning applies to B and C. The preimage is therefore a union of whole groups: it belongs to ℱ. We have checked all Borel sets with a single argument, rather than just a few thresholds.

    More generally, for a finite partition where ℱ is the set of unions of groups, a real function is measurable if and only if it is constant on each group. Sufficiency has just been shown. For necessity, if it takes values u < v within the same group, the Borel set (−∞, u] selects one of these outcomes and not the other: it splits that group, so its preimage is not in ℱ.

    Here u and v denote distinct numerical values, in the same unit as the function under consideration; ∞ indicates an infinite bound. In general, the tests {X ≤ t} for every real t also suffice: the half-lines (−∞, t] generate ℬ(ℝ), and preimages preserve complements and countable unions. Passing a single test is not enough.

  4. Work back from the threshold to the outcomes

    Take D = (−∞, 200], with values expressed in grams. On A, 100 ≤ 200: all of A is included. On B, the inequality 200 ≤ 200 holds at equality: all of B is also included. On C, 300 > 200: C is excluded. The set E that answers yes is therefore:

    E={ω:X(ω)≤200}=A∪B∈ℱ

    The shorthand notation {X ≤ 200} denotes this set of outcomes. We do not add the masses: we first identify the event to which P applies.

  5. Add the probabilities of the disjoint groups

    A and B are disjoint. Additivity gives P(E) = P(A) + P(B). To add the fractions, write them with the same denominator:

    P(E)=36+26=56

    The exact result is 5/6, or approximately 0.8333, with no units. This number is a probability in the fictional model. Counting the bags and dividing by 6 would be unjustified: we have not assumed that their identities are equally likely.

  6. Check using the complement and the bounds

    The complement of E in Ω is C. Another approach gives P(E) = 1 − 1/6 = 5/6, which agrees with the previous sum. The resulting probability lies between 0 and 1.

    For a threshold t below 100 g, the event {X ≤ t} is ∅, with probability 0. For t greater than or equal to 300 g, it is Ω, with probability 1. These checks verify the direction of the inequality and the inclusion of the threshold. They do not replace the measurability proof.

  7. Show how a well-defined function can fail the test

    Still using the same bags, define Y(a) = 100 − 10 = 90 g and Y(b) = 100 + 10 = 110 g; on B and C, Y keeps the values of X. Y is a perfectly well-defined real function, but it separates a and b.

    The Borel set (−∞, 100] has preimage {a} under Y. This set is not in ℱ, because no allowed event splits A. Y is therefore not ℱ-measurable. In this probability space, P(Y ≤ 100 g) is undefined: this does not mean that it equals 0.

    If we replaced ℱ with the set of all subsets of Ω, Y would become measurable. However, we would need to specify an extension of P before calculating probabilities for these new events. Nothing here provides that additional allocation of probability.

Explain it in your own words

Why does the question about X select whole groups, while the question about Y requires information absent from ℱ? State the definition again using an arbitrary Borel set, then redo the calculation and its check without looking.

✿03 Common mistakes

  • “If the function gives a number, it must be measurable.”

    Specify the σ-algebra on the domain. The function Y is defined everywhere, but the preimage of the threshold question splits A. A single preimage outside ℱ is enough to disprove measurability.

    Revisit the counterexample using Y

  • “The negative exponent means that I take the reciprocal of the number.”

    The preimage of D under X is a set of outcomes: keep the ω whose value X(ω) belongs to D. Several outcomes can be kept for the same value; neither division nor an inverse function is needed.

    Read the sensor’s arrows in reverse

  • “A question that cannot be observed has probability 0.”

    Here the probability measure P accepts only events in ℱ. If a set is not in its domain, its probability is undefined. To add it, we must enlarge the σ-algebra and specify an extension of P.

    Compare the empty event with an event outside the σ-algebra

An unjustified numerical answer

Hint 1

Is the list of outcomes that answer yes incorrect, or does the problem lie in applying P to it?

Hint 2

Changing the σ-algebra does not by itself choose the probabilities of the new events.

Compare with the solution

The set {a} is correctly identified: 90 ≤ 100, while 110, 200, and 300 are above the threshold. But {a} does not belong to ℱ. P therefore assigns it no value in the given model; the numerical claim is unjustified.

The counting argument also assumes that the identities are equally likely, which is absent from the problem statement. We would need to enlarge the σ-algebra to separate a and b, then specify their nonnegative weights whose sum remains P(A) = 1/2. This sum alone does not determine the weight of {a}. The weights of the other events already present would have to be preserved.

Check your reasoning

  • Recognize that the preimage is well-defined.
  • Identify the event outside the domain of P.
  • Distinguish extending the σ-algebra from choosing a probability extension.

Exercise 3 · Transfer and proof

Represent the same reading differently

Set Z = (X − 100 g)/(200 g − 100 g). Calculate the values of Z, prove its measurability using the group criterion, then calculate P(Z ≥ 1). Finally, explain why applying any Borel measurable function g to a measurable variable X gives another measurable variable g(X).

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The denominator is constant and nonzero; its unit is the gram.

Hint 2

A deterministic transformation of a value that is constant on a group remains constant on that group.

Hint 3

For a Borel set D, first work back under g to the values of X, then under X to the outcomes.

Compare with the solution

The scale is 200 − 100 = 100 g. The offsets are 0, 100, and 200 g. Dividing each by 100 g gives Z = 0 on A, 1 on B, and 2 on C. Z has no units: the grams in the numerator and denominator cancel.

Z remains constant on each group; the finite partition criterion therefore proves its measurability for all Borel sets. The event {Z ≥ 1} is B ∪ C. Its probability is 1/2 = 0.50, with no units.

In the general statement, g is a Borel measurable function from ℝ to ℝ: the preimage under g of every Borel set D is Borel. The composition g(X) denotes the function ω ↦ g(X(ω)). Working back under g and then under X gives the following identity, where the symbol ∘ means composition:

(g∘X)−1(D)=X−1(g−1(D))∈ℱ

The inner set is Borel by the assumption on g; its preimage under X therefore belongs to ℱ. This proves the result without assuming that g is invertible or continuous; continuity is sufficient for Borel measurability.

Check your reasoning

  • Find the values with no units and justify the nonzero denominator.
  • Give a proof for all Borel sets, rather than a single threshold.
  • Reconstruct the preimage identity and use each assumption in the right place.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What condition defines an ℱ-measurable real variable?

For each Borel set D in ℝ, the set of outcomes ω such that X(ω) belongs to D must belong to ℱ. The condition concerns preimages and does not depend on the probability weights.

Recall 2What criterion determines measurability in our finite model, and why?

The function must be constant on each group of the partition. Then every preimage is a union of groups. If two values differ within a group, a half-line separating these values splits that group and disproves measurability.

Recall 3Which objects does the preimage of D under X connect, and what does the exponent −1 mean?

D is a set of values; its preimage under X is the set of outcomes that produce a value in D. The exponent denotes the preimage of a set, without division or any requirement of invertibility.

Recall 4Can we say that the probability of {a} is 0 in our model?

No: it is undefined, because {a} is outside ℱ, the domain of P. An extension could assign it a weight, but the present model does not choose one. Do not confuse this lack of a definition with an event of probability 0.

Recall 5How can we prove that g(X) is measurable if g is Borel measurable?

For a Borel set D, its preimage under g is Borel. The preimage of this set under X belongs to ℱ. This is also the preimage of D under g(X). The assumptions are used in turn for these two steps.

What you understand
A measurable variable turns questions about its values into allowed events on the outcomes. In the example, the criterion is constancy on the sensor’s groups. A Borel measurable transformation of a measurable variable preserves this property.
