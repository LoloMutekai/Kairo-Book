Level 2 · C038·M4

Alarms and false positives

Your goalDistinguish an alarm from a confirmed failure, count false positives and choose the denominator that answers the question asked.

Before you start

✿01 See the idea

A pump circulates water on a test rig. Its control unit sends a periodic signal. The screen displays “pump may have stopped” when the latest signal is too old. Yet you can still see water flowing: a transmission delay can be enough to turn on this indicator.

The alarm is the output of a monitoring rule. The target failure here is a complete stop in flow throughout the observation window. These are different facts: the rule checks the age of a signal; the reference check examines the flow. A false positive is an alarm when this reference establishes that the target failure is absent.

Conversely, the control unit may keep sending signals when water is no longer flowing. A failure can therefore occur without an alarm. We will call this case a false negative. “Positive” means an alarm, and “negative” means no alarm; these words do not mean good or bad.

The scene and all its values are fictional. We will classify trials of this same pump, then calculate descriptive proportions for this batch. None of these numbers measures a real installation or predicts the reliability of another system.

The rule to remember

First write down the target failure, then the alarm rule and the independent reference. An indicator shows what its rule has detected; what this implies still needs to be established.

✿02 Follow an example

Worked example

What does the pump indicator really tell us?

The fictional batch is fully described as follows. With flow failure: 1 trial with a signal age of 20 s, 2 trials at 40 s and 1 trial at 60 s. Without failure: 13 trials at 20 s and 3 trials at 40 s. The initial threshold is 30 s. The stated age is recorded at the end of each window; the flow check covers that same window.

  1. Define the target and the conditions for comparison

    A trial is an observation window with the same duration throughout the batch. Count only one alarm decision per trial, even if the screen repeats the message. The reference, obtained separately from the indicator, classifies each trial: no flow throughout the window, or flow maintained throughout the window. No intermediate case is included in this small batch constructed for learning.

    The timestamps are readable and use the same clock; none is from the future. The threshold and the target failure are set before counting. The reference is assumed to be correct and available for all trials, including those that did not trigger an alarm. Without a reference, a case would remain unclassified, never automatically “without failure”.

  2. From the timestamp to the decision

    t denotes the time of the check, h the timestamp of the latest signal and a = t − h its age. These quantities are in seconds with a common time origin; τ, the Greek letter tau, is the threshold in seconds. A is the decision, with no unit: 1 for an alarm, 0 for no alarm.

    a=t−h=100−60=40 s
    A={1si a>τ0si 0≤a≤τ

    In the illustrated trial, 40 s > 30 s, so A = 1. The check finds that flow is maintained: this is a false positive for “flow has stopped”. If the alarm reported only “signal too old”, its finding would be correct. Keep the same target when judging an alarm.

    The rule above covers only valid ages. A missing signal or an unreadable timestamp requires an “unverifiable” state and an explicit checking procedure. Replacing this state with 0 would create a misleading absence of an alarm.

  3. Build the counts without treating the indicator as the reference

    With a threshold of 30 s, 20 s triggers nothing; 40 s and 60 s trigger alarms. Among the trials with failure, the alarms therefore give 2 + 1 = 3 true positives, while 1 failure is missed: the false negative.

    Among the trials without failure, 3 trigger alarms: these are the false positives. The other 13 do not trigger alarms: these are the true negatives. Delayed transmissions may explain these false positives; a control unit that remains active despite the stopped flow may explain the false negative. The ranking here groups trials by their alarm and reference states; it depends on the stated observations, not on these possible explanations.

    Check the totals: 3 + 1 = 4 trials with failure; 3 + 13 = 16 without failure; 4 + 16 = 20 trials. With the other grouping, 3 + 3 = 6 alarms and 1 + 13 = 14 cases without an alarm; 6 + 14 = 20. The cells do not overlap.

  4. Answer: among the cases without failure, how many trigger an alarm?

    Let F be the number of false positives and N the number of trials without failure, both counted in trials. The descriptive false-positive rate r is F/N, with no unit. Its denominator contains only cases where the failure is absent: this is the group in which an alarm can be triggered in error. We need N > 0.

    r=FN=316=0.1875

    To write this ratio as a percentage, multiply it by 100: 0.1875 × 100 = 18.75 %. This means that 3 of the 16 trials without failure trigger an alarm in this fictional batch. The exact count, 3/16, remains the evidence for the result; the decimal form is a reading aid.

  5. Changing the question requires changing the denominator

    Now ask: “Among the alarms received, what proportion is false?” Let B be the total number of alarms, counted in trials, and q the proportion F/B, with no unit. We need B > 0. The numerator is unchanged; the group it is compared with is now the alarms.

    q=FB=36=0.50

    Here 3/6 = 0.50, or 50 %. The statement “50 % of alarms are false” and the false-positive rate of 18.75 % answer different questions. There is no contradiction: B counts alarms; N counts cases without failure.

    Check: F is included in each group, so each ratio stays between 0 and 1. If the chosen group were empty, the ratio would be undefined, not automatically equal to 0.

  6. Use the results within the limits of this batch

    The batch contains 3 false alarms and 1 failure without an alarm. Before changing the threshold, examine the timestamps, transmission delays and the stated target. Raising the threshold will remove some alarms; it may also hide flow failures. The last exercise checks the counts on the same trials.

    These proportions describe only this fictional batch, its reference and its threshold. They do not give the probability of a failure at the next alarm. Such a prediction would require real observations and additional assumptions. Here, no statistical independence between trials is needed: we are only counting and dividing.

Explain it in your own words

Without looking at the diagram, explain how the same alarm can correctly identify an old signal and be a false positive for a flow failure. Then reconstruct the groups counted by the denominators of r and q.

✿03 Common mistakes

  • “The indicator proves that the pump has stopped.”

    Write down what is actually tested: the age of the signal. Then compare the reported failure with the flow check. An old signal with maintained flow is a false positive for this failure.

    Review the path from the signal to the separate check

  • “I divide false positives by all alarms: that is the false-positive rate.”

    Write the question before the fraction. The false-positive rate compares alarms triggered in error with cases without failure. The proportion of false alarms compares them with alarms. The word “among” names the denominator.

    Compare the questions that define r and q

  • “Fewer alarms prove that the setting is better.”

    Also count the failures that no longer trigger an alarm on the same trials. Record unverifiable cases separately; silencing them does not turn them into cases without failure. A trade-off requires criteria, not just an indicator that lights up less often.

    Try the higher threshold again in the last exercise

Exercise 1 · Decision at the boundary

A signal exactly at the threshold

On the same test rig, t = 100 s and h = 70 s. Keep τ = 30 s. Calculate the age, decide whether the rule triggers an alarm and state what you know about the flow, whose check is not yet available.

Hint 1

Subtract the times on the same clock. Then reread the strict inequality sign in the rule.

Hint 2

The absence of an alarm and the absence of a failure are two distinct pieces of information.

Compare with the solution

a = 100 − 70 = 30 s. Since 30 s = 30 s, the condition a > τ is false: A = 0. A rule using “greater than or equal to” would have a different boundary; that is not the rule stated here.

Without a reference check, the flow state remains unknown. You can report a decision of no alarm; you cannot yet classify it as a true negative or a false negative.

Check your reasoning

  • Calculate the age with its unit and justify the strict comparison.
  • Do not assume normal flow solely from the absence of an alarm.

Exercise 2 · Two ratios to explain

Reread a statement of results

At the initial threshold, a colleague writes: “3 false alarms out of 6 alarms, so the false-positive rate is 50 %.” Correct the terminology and calculate the false-positive rate. Also state which group would need to be observed to classify the cases without an alarm.

Assisted answer: try this exercise without help later.

Hint 1

Keep the fraction, then name exactly the group in its denominator.

Hint 2

For the requested rate, add the trials without failure that trigger an alarm and those that do not.

Compare with the solution

The fraction 3/6 describes the proportion of false alarms among alarms: 50 %. This calculation is correct, but its name in the statement is not.

The cases without failure number 3 + 13 = 16. The false-positive rate is therefore 3/16 = 0.1875, or 18.75 %. To classify the cases without an alarm, their flow must also be checked: among 14 cases without an alarm, the batch contains 1 failure and 13 cases without failure. Auditing only the alarms would leave this missed failure invisible.

Check your reasoning

  • Keep the correct fraction while correcting its name.
  • Justify the denominator 16 using the cases without failure.
  • Include trials without an alarm in the reference check.

Exercise 3 · Critical comparison

Silence the indicator

Run through exactly the same batch as in the example with τ = 50 s, still requiring the age to strictly exceed the threshold. Calculate the true and false positives, the false negatives and the true negatives. Can we conclude that the new threshold is better because it produces fewer alarms?

Assisted answer: try this exercise without help later.

Hint 1

Reuse the age groups in the problem: at 40 s, the new threshold no longer triggers an alarm.

Hint 2

The group at 60 s still triggers an alarm. Trials whose decision changes keep their reference state.

Hint 3

Compare false positives and missed failures, then check that all the counts are accounted for.

Compare with the solution

Only the age 60 s exceeds 50 s. It applies to 1 trial with failure: 1 true positive. No trial without failure exceeds this threshold: 0 false positives. The total number of alarms is 1.

The failures without an alarm are those at 20 s and at 40 s: 1 + 2 = 3 false negatives. All trials without failure now have no alarm: 13 + 3 = 16 true negatives.

Check: 1 + 0 + 3 + 16 = 20 trials. Alarms go from 6 to 1; false alarms go from 3 to 0, but missed failures go from 1 to 3. The number of alarms alone does not establish a better setting: a criterion for the cost of the two errors and validation on representative trials are missing. Even these fictional results do not authorize any change to a real pump.

Check your reasoning

  • Reclassify each age group with the new rule, without changing its reference.
  • Recover the total number of trials from the four cells.
  • Discuss missed failures as much as false alarms.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What must you know to call an alarm a false positive?

The precisely defined target failure, the alarm decision and a separate reference that establishes the absence of that failure in the same trial. An alarm that has not yet been checked remains unclassified.

Recall 2Which groups distinguish the false-positive rate from the proportion of false alarms?

The first divides false positives by cases without failure; the second divides them by alarms. Name the group and check that it is not empty.

Recall 3Why also check the flow during trials without an alarm?

To identify missed failures, called false negatives. The absence of an alarm alone does not provide a reference state of no failure.

Recall 4How should you handle an unreadable timestamp before judging the indicator?

Keep an unverifiable state and request suitable evidence. Do not invent an age of 0 or classify the case as being without failure.

Recall 5What is missing before you can prefer a threshold that triggers fewer alarms?

A count of missed failures and false alarms, a stable target and reference, then criteria for the consequences of each error. A fictional batch is not enough to choose a real setting.
