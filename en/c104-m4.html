LSTM and GRU

Your goalCalculate a step of an LSTM and a GRU, then distinguish memory retention, writing, and visible output.

Before you start

✿01 See the idea

Read “The parcel, despite the heavy rains, has arrived.” To choose the ending “has arrived”, the subject is still “parcel”, even though “rains” is closer. A recurrent network carries a state from word to word; it must also prevent transient information from replacing information that will be needed later.

Imagine a note kept alongside the current word. An LSTM, a long short-term memory network, separately controls what it retains in the note, what it writes into it, and what it exposes from it. Its gates are continuous multipliers: a small opening reduces what passes through, while a large opening lets more through.

A GRU, a gated recurrent unit, carries a single state. It first controls how the previous state is used to prepare a candidate, then the share of this candidate in the new state. The retention path is separate from the path that produces the candidate.

The entire numerical scenario is fictional. We will follow a coordinate at the word “rains”, using gates chosen for the calculation. The sign of this coordinate does not universally encode singular or plural; the diagrams illustrate a mechanism without claiming to reproduce a trained English language model. The LSTM example will even show an unwanted cancellation, which the exercise will then try to reduce.

The rule to remember

LSTM: retain and write into c, then expose an output h. GRU: prepare a candidate with r, then mix the previous state and the candidate with z. Always read which term each gate multiplies.

✿02 Follow an example

Worked example

What happens to the trace when “rains” is processed?

We calculate a step of each cell separately on the same sentence. For the LSTM, previous c = 1/2 and previous h = 1/4; f = 3/4, i = o = 1/2, g = -3/4. For the GRU, previous h = 1/2, r = 1/2 and z = 1/4. These values are fictional and dimensionless. The LSTM gates and candidate are supplied after activation; no learned matrix is inferred from this sentence.

  1. Name the states, gates, and their dimensions

    t identifies the current word; t − 1 identifies the previous word. xt is the vector representation of the word, with dimension d. ht is the state passed on, with dimension n; an LSTM also retains a memory ct with dimension n. We calculate the case n = 1. The coordinates, parameters, and function arguments have no physical units. h is neither a probability of grammatical agreement nor the final text output: a prediction layer, outside this calculation, would still need to use it.

    The LSTM gates are ft for forgetting, it for writing, and ot for output. gt is the candidate to be written. A gate depends on the word and the previous state, with the same parameters at each step. W transforms x, U transforms previous h, and b is a learned bias. For each subscript q, W_q has shape n × d, U_q has shape n × n, and b_q has dimension n. The subscript q labels a parameter set; it is not a factor to multiply by.

    qt=σ(Wqxt+Uqht−1+bq), q ∈ {f, i, o}
    gt=tanh(Wgxt+Ught−1+bg)

    σ is the sigmoid: it gives an opening between 0 and 1. tanh, the hyperbolic tangent, transforms its argument into a signed candidate between -1 and 1. These bounds are not reached for finite real arguments. The functions act coordinate by coordinate. For a real argument s, with exp denoting the natural exponential:

    σ(s)=11+exp(−s)
    tanh(s)=exp(s)−exp(−s)exp(s)+exp(−s)

    We use an LSTM with no direct connection from c to the gates. This is not an attempt to list all variants. A gate value is a learned coefficient; calling it “forgetting” does not mean that the network consciously decides what matters.

  2. Retain, then write into the LSTM memory

    The symbol ⊙ denotes a product taken coordinate by coordinate between vectors of the same dimension. In our scalar case, it is ordinary multiplication. The new memory adds a portion of the previous memory and a portion of the candidate:

    ct=ft⊙ct−1+it⊙gt

    Retain: 3/4 × 1/2 = 3/8, or 0.375, dimensionless. Write: 1/2 × (-3/4) = -3/8, or -0.375, dimensionless. The candidate is negative, so writing can reduce a positive memory.

    Add: 3/8 + (-3/8) = 0. The trace carried by this coordinate is cancelled. Check: the contributions have the same denominator and opposite numerators. The gates are not complementary: f + i = 5/4, greater than 1. The LSTM memory is therefore not generally a weighted average of the previous memory and the candidate; it can also fall outside their interval.

  3. Calculate the LSTM output and distinguish it from c

    ht=ot⊙tanh(ct)

    A compressed version of the memory is exposed, and gate o then controls this passage. Here exp(0) = 1, so tanh(0) = (1 − 1)/(1 + 1) = 0. The output is 1/2 × 0 = 0, dimensionless. The LSTM step is complete: the pair to pass on is (c, h) = (0, 0).

    Check: a positive output gate cannot recreate a memory that has already been cancelled. Conversely, in the ideal limit o → 0, a nonzero memory can remain hidden in c with an output h close to 0. Closing the output therefore does not directly erase c at this step; it can affect future gates, since they use h.

    We used tanh(s) = s only for s = 0, where this identity is exact. Systematically replacing tanh with its argument would be an error.

  4. Prepare the GRU candidate with resetting

    For the GRU, rt is the reset gate and zt is the update gate. They are calculated using the same sigmoid form as before, with q in {r, z} and their own parameters W_q, U_q, b_q. The dimensions remain n × d, n × n, and n. Here we choose the variant that applies r to previous h before multiplying by U_g:

    gt=tanh(Wgxt+Ug(rt⊙ht−1)+bg)

    In the scalar calculation, let a = W_g xt + b_g be the contribution of the word and the bias. We are given a = -1/4 and U_g = 1. Partial resetting: r × previous h = 1/2 × 1/2 = 1/4. The argument before tanh is a + U_g × r × previous h = -1/4 + 1 × 1/4 = 0. The candidate is therefore g = tanh(0) = 0.

    Check: a is the exact opposite of the recurrent contribution. Gate r has not yet affected the retention path in the final mixture. In multiple dimensions, applying r before or after matrix U_g does not generally give the same candidate; the position of this gate is part of the chosen mechanism. The parameter sets of the cells being compared are distinct.

  5. Mix the previous state and the GRU candidate

    Our convention assigns z the weight of the new candidate. With 1 representing the vector whose components all equal unity in dimension n, the rule is:

    ht=(1−zt)⊙ht−1+zt⊙gt

    Previous-state weight: 1 − 1/4 = 3/4. Previous-state contribution: 3/4 × 1/2 = 3/8. New contribution: 1/4 × 0 = 0. Sum: h = 3/8 + 0 = 3/8, or 0.375, dimensionless. This single state passes to the next word.

    Check using another expression: previous h + z × (g − previous h) = 1/2 + 1/4 × (0 − 1/2) = 3/8. The positive weights add up to 1: each new coordinate stays between the previous coordinate and the candidate coordinate. Our result is indeed between 0 and 1/2.

    If an implementation writes z × previous h + (1 − z) × g, its z weights the previous state. A value of z must be read with its accompanying equation. The convention changes the interpretation of “open gate”, but the terms still need to be checked.

  6. What the retention path allows us to conclude

    An LSTM passes on a pair (c, h), with 3 gates; a GRU passes on h, with 2 gates. In the standard LSTM described here, c is not compressed by tanh at every write: tanh acts on the candidate and then on the readout of c. In the GRU, the final mixture directly retains a portion of previous h. With the same dimensions d and n, the GRU described uses fewer affine parameter sets; this is not enough to conclude that it will suit the task better.

    To understand the benefit of the additive path of c, imagine a small initial difference in memory and freeze the gates and candidates. A step transmits f times this difference through the direct path. Over 2 intervening words with f = 3/4 at each step, the direct factor is 3/4 × 3/4 = 9/16, or 0.5625, dimensionless. The difference still decreases; a gate close to 1 preserves it better along this path.

    This factor is not the total gradient of the network: the gates and candidate also depend on the previous state. Gates offer an adjustable transmission path without guaranteeing perfect memory or removing all training problems. The numbers in our example, including the cancelled LSTM memory compared with the nonzero GRU state, do not measure any linguistic quality. Comparing predictions would require separate data and temporal validation, the subject of the next unit.

✿03 Common mistakes

  • “The output gate closes, so the LSTM memory is erased.”

    Gate o multiplies tanh(c) to produce h; it does not multiply c in its write equation. A small output can hide a memory. In our example, c is 0 for another reason: the previous contents and the write cancelled each other. Trace these operations in this order.

    Separate writing to c from reading out to h

  • “LSTM gates are probabilities, and their weights must add up to unity.”

    f and i come from separate sigmoids, with no constraint on their sum. Here f + i = 5/4. The GRU studied here, by contrast, imposes complementary weights z and 1 − z on the final mixture. An opening in the unit interval is a coefficient, with no automatic probabilistic interpretation.

    Compare the addition rules of the cells

  • “Setting r close to 0 forces the GRU to forget its entire previous state.”

    r reduces the previous state only while preparing the candidate. The final mixture still retains the term (1 − z) × previous h. In our convention, z close to 0 almost preserves the previous state, whatever r is. Check the limiting case in the exercise.

    Test r and z separately

Exercise 1 · Application · exact calculation

Reduce the unwanted write

At the same word “rains”, start again from the initial LSTM with previous c = 1/2, f = 3/4 and g = -3/4. Replace only i = 1/2 with i = 1/4. Calculate c and compare it with 0. Could a very small output gate o directly cancel this new memory?

Assisted answer: try this exercise without help later.

Hint 1

The previous-memory contribution remains 3/8. Only the product i × g changes.

Hint 2

The candidate is negative. Reducing its multiplier makes its contribution less negative. Then find which equation involves o.

Compare with the solution

Previous: 3/4 × 1/2 = 3/8. New: 1/4 × (-3/4) = -3/16. Their sum is 3/16, or 0.1875, dimensionless, instead of 0. Here the smaller write limits cancellation by the negative candidate; this is not a universal rule for choosing good settings.

Check: f + i is now 1 and c is between -3/4 and 1/2, as expected for these particular complementary weights. A small output gate o would make h small without directly changing c at this step. The exact output would be o × tanh(3/16); replacing tanh(3/16) with 3/16 would not be exact.

Check your reasoning

  • Calculate 3/8 and -3/16 separately before adding them to obtain 3/16.
  • Explain the effect of the sign of the candidate.
  • Distinguish retained memory from the visibility of its readout, without linearizing tanh.

Exercise 2 · Application · limiting cases

Open r and close z

Start again from the GRU with previous h = 1/2, a = -1/4 and U_g = 1. In the ideal limit r → 1, calculate the argument of tanh and state the sign of the candidate. Then also take the limit z → 0 in our convention: what state h is passed on? These bounds are mathematical limits of sigmoids, not outputs reached at a finite argument.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Replace r with its limiting value in a + U_g × r × previous h before applying tanh.

Hint 2

The final mixture multiplies the previous state by 1 − z and the candidate by z. tanh of a positive argument is positive and remains bounded.

Compare with the solution

The recurrent contribution tends to 1 × 1/2 = 1/2. The argument therefore tends to -1/4 + 1/2 = 1/4, greater than 0. It increases by 1/4 compared with 0. The candidate tends to tanh(1/4), which is positive; it is not exactly 1/4.

When z also tends to 0, the previous-state contribution tends to (1 − 0) × 1/2 = 1/2. The contribution of the bounded candidate tends to 0. Therefore h tends to 1/2, whatever this candidate is. Opening r changes the proposed candidate but does not force it to be written.

Check your reasoning

  • Obtain the argument 1/4 before tanh without presenting it as the value of tanh.
  • Justify each contribution to the final mixture separately.
  • Find the limit h = 1/2 and specify that these are ideal gates.

Exercise 3 · Reasoning · scope of a proof

Is memory guaranteed?

Over 2 intervening words in the same sentence, freeze the LSTM gates at f = 3/4 and keep identical writes in two trajectories whose initial memories differ by 1, dimensionless. What difference remains through the direct path? Someone concludes: “The LSTM retains the subject perfectly and will be better than the GRU.” Respond by separating the calculation, the assumptions, and the linguistic comparison.

Assisted answer: try this exercise without help later.

Hint 1

Subtracting the trajectories eliminates the identical writes. Multiply only their difference by f at each step.

Hint 2

A difference in coordinates does not measure whether the sentence ending is correct. What happens if the gates depend on the state, as in a real network?

Compare with the solution

After the first word, the direct difference is 3/4 × 1 = 3/4. After the next word, it is 3/4 × 3/4 = 9/16, or 0.5625, dimensionless. This result is smaller than the initial difference 1: even this simplified path does not preserve the difference perfectly.

The subtraction relies on frozen gates and identical writes. In the full network, changing the previous state can change the gates and the candidate: the calculated product is not the total gradient. Finally, neither this difference nor the outputs of the fictional step prove correct prediction of “has arrived” or superiority over the GRU. A protocol for temporal comparison on held-out examples would be needed; no such measurement is provided here.

  • Name the assumptions that allow the writes to be eliminated by subtraction.
  • Separate direct transmission, the behavior of the full network, and prediction quality.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1Why does an LSTM pass on c and h separately?

c is the memory updated by f × previous c + i × g. h is its readout o × tanh(c), used in subsequent steps. A small output does not prove that c is 0.

Recall 2Why is the LSTM update not always a weighted average?

f and i are independent gates; their sum is not constrained to 1. They multiply the previous c and the candidate g before addition. In our example, their sum is 5/4.

Recall 3Where do r and z act in our GRU?

r reduces the use of previous h in the candidate, before the recurrent matrix. The final mixture is (1 − z) × previous h + z × g: z weights the new candidate here, with no separate state c.

Recall 4What should you check before saying that a high z retains memory?

Read the equation: here a high z favors the candidate; in z × previous h + (1 − z) × g, it favors the previous state. The name of the gate is not enough.

Recall 5What does the product of forget gates over several words prove?

It gives transmission through the direct path of c if the gates and candidates are frozen. On its own, it does not give the total gradient, perfect memory, or measured linguistic quality.
