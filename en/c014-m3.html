Level 1 · C014·M3

Contradiction

Your goalAssume a complete arrangement, derive a precise incompatibility, and prove that no odd-sized set can be arranged entirely in pairs.

Before you start
c012-m5 : counterexamples · c011-m5 : binomial · c014-m1 : direct proof · c014-m2 : contrapositive

✿01 See the idea

Imagine a set of 5 socks in front of you. A pair contains exactly 2 socks, whatever their colours. You must use each sock exactly 1 time, without cutting it, sharing it, or adding or removing anything. The aim is to leave no sock unpaired.

The drawing shows 2 pairs and 1 sock left over. It shows that this arrangement fails. To rule out every arrangement, we need to understand a requirement that any complete arrangement would have to meet: its number of pairs would be an integer.

Let us temporarily assume that a complete arrangement is possible. If its pair count turns out to be incompatible with integers, we must reject this assumption. This is proof by contradiction: we derive a precise impossibility while keeping the rules of the problem. A search that takes a long time does not, by itself, establish such an impossibility.

The rule to remember

Keep the original assumptions, assume the negation of the conclusion, then name the properties that cannot be true together.

✿02 Follow an example

Worked example

From the set of 5 socks to any odd-sized set

The set in the drawing corresponds to n = 2. Let us count it again, then keep the same scene with an arbitrary odd size. The intended conclusion is that, under the stated rules, no arrangement uses all the socks in complete pairs.

  1. State the data and the number domain

    An integer is a number with no fractional part. We can count 0, 1, 2, and continue; integers can also be negative. A count of socks or complete pairs is a non-negative integer.

    N denotes the total number of socks. The set has an odd size: it contains 1 extra sock beyond the contents of n pairs. Thus N = 2n + 1, where n is an integer greater than or equal to 0. The factor 2 counts the socks per pair. The letters denote numbers in these counting units: N in socks, n in reference pairs.

    In the case drawn, 2 × 2 = 4 socks are in pairs; 4 + 1 = 5 socks in total. The remainder is 5 − 4 = 1 sock. This matches the drawing, but is not yet a general proof.

  2. Write exactly what is being assumed

    Now fix an arbitrary non-negative integer n. We keep N = 2n + 1 and all the rules about the socks. For this set, the negation of “no complete arrangement exists” is “a complete arrangement exists”. It is enough to assume that one exists, without claiming that every arrangement would be complete.

    Let k be the number of pairs in this assumed arrangement. k is a non-negative integer, counted in complete pairs. Since each sock is used exactly 1 time, this arrangement requires N = 2k. The total number does not change:

    2k=2n+1

  3. Derive the consequence that will cause a problem

    Subtracting 2n from both sides preserves the equality. We obtain 2k − 2n = 1. Taking out the common factor 2 gives 2(k − n) = 1. Since 2 is nonzero, we can divide both sides by this same factor.

    2(k−n)=1⇒k−n=12

  4. Identify the impossibility, then conclude

    The difference of integers is still an integer: if k and n are integers, k − n is too, even if the difference is negative. But 1/2 is strictly between 0 and 1; there is no integer between these consecutive integers. The same difference therefore cannot both be an integer and equal 1/2.

    This incompatibility was derived from the assumption of a complete arrangement, keeping the data and using justified operations. We reject this assumption: no integer k can count a complete arrangement of this set. Since n was arbitrary, the conclusion holds for every set of size 2n + 1, with n a non-negative integer.

    The proof depends on the rules: whole socks, no additions or removals, and no object shared between pairs. It does not rule out other tasks that change these rules.

  5. Repeat the full calculation and check it

    Return to n = 2. The assumed arrangement would require k = 5 ÷ 2 = 5/2 pairs, or 2.5 pairs. The difference would be k − n = 5/2 − 2 = 1/2 pair, or 0.5 pair. This is not an integer count of complete pairs.

    Check the calculation: 2 × (5/2) = 5 socks, the original total. The division is correct; it is the requirement for an integer k that fails. Rounding k to 2 uses only 4 socks and leaves 1 sock over: this does not fix the supposedly complete arrangement.

    Check the smallest allowed size: n = 0 gives N = 2 × 0 + 1 = 1 sock. The reference pairs contain 0 socks; a complete arrangement would require k = 1/2 pair, still not an integer. This case checks the boundary of the domain. It does not replace the argument with arbitrary n.

Explain it in your own words

Hide the calculations. Explain why k is an integer, why subtracting n preserves this property, and then exactly what contradicts this property. Finish by saying which assumption is rejected and which rules remain in place.

✿03 Common mistakes

  • “I tried arrangements without success, so it is impossible.”

    Your attempts rule out the arrangements you tried. To rule them all out, find a condition required of every complete arrangement: its total would be 2 times an integer number of pairs. The counting diagram prepares this step from an attempt to an impossibility.

    Reread what the drawing shows and what remains to be proved

  • “By assuming the arrangement is possible, I have already accepted it as true.”

    This assumption is temporary and concerns precisely the existence of a complete arrangement. Keep the odd-sized set and the integer domain of k. After the deductions, the equality k − n = 1/2 conflicts with this domain; that is when you reject the assumption.

    Review the assumption and the final incompatibility

  • “The drawing of 5 socks already proves the claim for every odd-sized set.”

    The calculation for 5 socks checks one case. To cover odd sizes, keep n arbitrary and justify each transformation up to k − n = 1/2. The difference remains an integer for any n, so the impossibility does not depend on the size drawn.

Exercise 1 · Warm-up · count and decide

Another size for the same set

In the same imagined scene, take n = 3. Calculate the total N, then the number of pairs that a complete arrangement would require. Someone reports only that they tried several arrangements without success. What argument actually allows you to conclude?

Hint 1

Count 2 socks per reference pair, then add the extra sock.

Hint 2

If everything were arranged in pairs, dividing the total by 2 would have to give an integer number of complete pairs.

Compare with the solution

N = 2 × 3 + 1 = 6 + 1 = 7 socks. A complete arrangement would require k = 7 ÷ 2 = 7/2 pairs, or 3.5 pairs.

This number is not an integer; it cannot count complete pairs. The assumed arrangement is therefore impossible under the rules of the scene. Unsuccessful attempts are not enough on their own. With 3 pairs actually formed, 6 socks are used and the remainder is 1 sock.

Check your reasoning

  • You connect the impossibility to the integer count of complete pairs.
  • You distinguish an unsuccessful search from this contradiction.

Exercise 2 · Application · check a proposed fix

Rounding does not make the arrangement complete

The set now contains 9 socks. Someone divides by 2, then rounds down to report the number of pairs. Find this number, the remainder, and the maximum number of complete pairs. Explain why this maximum is not enough to arrange the whole set in pairs. Also check what 1 more pair would require.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Compare 2 × 4 with the total; count the socks left over.

Hint 2

To prove the maximum, check that 5 pairs would require more socks than the set contains.

Compare with the solution

Exact division gives 9 ÷ 2 = 9/2 pairs, or 4.5 pairs. Rounding down gives 4 complete pairs: they use 2 × 4 = 8 socks. The remainder is 9 − 8 = 1 sock.

Adding 1 pair would give 5 pairs and require 2 × 5 = 10 socks. There would be a shortage of 1 sock. Any still larger pair count would require more. The maximum is therefore 4 pairs, but the remainder is nonzero: this is not a complete arrangement.

The assumption of a complete arrangement required an exact equality and an integer k. Rounding abandoned exact equality with the total; it answered a different question, the maximum number of pairs.

Check your reasoning

  • You state 4 pairs and 1 sock left over, with the units.
  • You justify the maximum by showing that 10 socks are needed for 5 pairs.
  • You explain why rounding does not fix the assumption of a complete arrangement.

Hint 1

Fix an arbitrary n, then assume that a complete arrangement exists. Introduce the integer k that counts its pairs.

Hint 2

Equate the sock counts, subtract 2n, then divide by 2. Which property of k − n is preserved?

Compare with the solution

Let n be an arbitrary non-negative integer. Suppose that a complete arrangement into k pairs exists, with k a non-negative integer. Counting requires 2k = N = 2n + 1.

2k=2n+1⇒2(k−n)=1⇒k−n=12

k − n is an integer, but 1/2 is not. This incompatibility rules out the assumed arrangement. Since n was arbitrary, no odd-sized set in the domain can be arranged entirely in pairs. No step requires n to be strictly positive: n = 0 is covered too.

Allowing a fractional k would abandon the rule that k counts complete pairs of whole socks. A fraction can solve the equation in another number domain without achieving the required arrangement. The conclusion is limited to the original rules. An answer reconstructed after a hint remains an assisted answer; repeat this proof without support on another day.

Check your reasoning

  • You keep n arbitrary and define k as an integer number of complete pairs.
  • You assume the existence of a complete arrangement, without assuming that all arrangements are complete.
  • You justify the operations and name the conflict between being an integer and having the value 1/2.
  • You reject the assumption, cover n = 0, and explain what accepting a fractional k would change.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1For a fixed set, what is the negation of “no complete arrangement exists”?

A complete arrangement exists. We temporarily assume this while keeping the odd size and the original rules. We do not assume that every arrangement is complete.

Recall 2Why does a complete arrangement require N = 2k, and what does k represent?

k is the non-negative integer number of complete pairs. Each pair contains 2 socks and each sock is used exactly 1 time, so the total is 2k socks.

Recall 3What is the precise conflict in the equality k − n = 1/2?

k and n are integers, so their difference is an integer. But 1/2 is strictly between 0 and 1, and is not an integer. The same difference cannot satisfy these properties simultaneously.

Recall 4What allows us to move from the drawing of 5 socks to every odd-sized set?

The proof keeps n an arbitrary non-negative integer and N = 2n + 1. No deduction depends on a particular value of n. The calculations for the sets drawn check cases; they do not replace this generality.

Recall 5After the incompatibility, what do we reject, and under which conditions?

We reject the assumed existence of a complete arrangement because it leads to an impossibility through valid deductions with the assumptions preserved. The conclusion keeps the socks whole, with no additions, removals, or sharing; changing these rules changes the question.

Reconstruct the reasoning

Reconstruct the proof without copying the steps: state the odd-sized set and the rules; formulate the negation of the conclusion; define the integer pair count it would require; work through the calculation; name the incompatibility; reject the assumption and specify the scope of the conclusion.
