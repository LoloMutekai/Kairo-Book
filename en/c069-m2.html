Level 1 · C069·M2

Orders

Your goalReconstruct a dependency order, check its properties, and distinguish its constraints from a sequence chosen to satisfy them.

Before you start
c014-m5 : invariants · c012-m5 : counterexamples · c006-m5 : composition · c069-m1 : equivalence relations

✿01 See the idea

You are preparing a sensor kit. A means unpacking the kit; B means mounting the sensor; C means preparing the reader; D means running the test. Unpacking comes before preparations B and C. The test must wait until B and C are complete. These are all the dependencies in our fictional scenario.

Must you mount the sensor before preparing the reader? Nothing here requires this. You can do B then C, or C then B. The tasks are linked by constraints, but these do not place every task before or after every other task. This illustrates a partial order.

The diagram goes upwards from a task to the task that depends on it. It shows only direct dependencies. Yet A must also precede D: every path from A to D carries the constraint through. By contrast, placing B to the left of C gives it no priority.

We will then choose a sequence for working alone. This list will order all the tasks; deciding between B and C will be an added choice about how to organize the work. This choice was absent from the kit dependencies. We are measuring neither preparation time nor efficiency.

The rule to remember

An order relation allows incomparable elements. To check it, look for reflexivity, antisymmetry, and transitivity; then ask whether every pair is comparable.

✿02 Follow an example

Worked example

From the kit to the relation, then to a sequence

On the set E = {A, B, C, D}, reconstruct the relation that expresses the direct or indirect dependencies, including equality. Check that it is a partial order and determine the compatible sequences for performing each task once.

  1. Define the exact meaning of the symbol

    E is the set of 4 distinct tasks. x and y denote any tasks in E. We write x ≼ y if x = y or if x is a direct or indirect prerequisite for y. This is a non-strict order: equality is included by convention, without requiring x to be performed before itself.

    R is the set of ordered pairs (x, y) for which x ≼ y. The first component of the pair is the prerequisite task, and the second is the task that depends on it. The symbol ∈ means “belongs to”; E × E denotes the set of ordered pairs of tasks. The letters identify tasks and have no physical units. The numbers below count tasks, ordered pairs, or sequences, as specified by their labels.

    R⊆E×E,x≼y⇔(x,y)∈R

    The symbol ⊆ means “is a subset of”; ⇔ means that the expressions on either side say the same thing. We assume that the dependencies are fixed and that no nonempty path leads from a task back to itself. Preparing the reader does not depend on mounting the sensor in this fictional model.

  2. State the criteria for an order

    A relation is a non-strict order if it satisfies the following properties for all tasks x, y, and z in E. Reflexivity: every task is related to itself. Antisymmetry: if the relation holds in both directions, the tasks are actually identical. Transitivity: a constraint carries through along a chain.

    Réflexivité : x≼x
    (x≼y et y≼x)⇒x=y
    (x≼y et y≼z)⇒x≼z

    ⇒ means “implies”. Antisymmetry does not mean that every pair must be related in one direction: the relation can be absent in both directions. Unlike an equivalence relation, an order does not require symmetry. The properties belong to the specific relation we are checking, rather than to the appearance of the diagram alone.

  3. Complete the ordered pairs and check the properties

    The arrows give (A, B), (A, C), (B, D), (C, D). The chain from A to B to D requires (A, D). The chain through C requires the same ordered pair: we include it once because R is a set. No path gives B to C or C to B.

    Add (A, A), (B, B), (C, C), (D, D) for reflexivity. The complete relation combines these ordered pairs with the previous ones. In the table, read the included entries by row: A to A, B, C, D; B to B, D; C to C, D; D to D.

    The diagonal gives reflexivity. Every ordered pair between distinct tasks has its reverse absent: antisymmetry holds. For transitivity, the only chains of constraints between distinct tasks are A to B to D and A to C to D; (A, D) is indeed present. A chain that repeats a task using the diagonal adds no new ordered pair. We have therefore checked all cases.

  4. Count, then check in another way

    First count the ordered pairs between distinct tasks: 4 direct dependencies + 1 distinct indirect dependency = 5 ordered pairs. The 4 ordered pairs on the diagonal complete the non-strict order.

    |R|=4+(4+1)=9 couples

    The bars |R| denote the number of elements in R. Now check using the rows of the table. Row A contributes 4 ordered pairs and D contributes 1, giving 5. Rows B and C each contribute 2 ordered pairs, giving 2 × 2 = 4. The total is 5 + 4 = 9 ordered pairs: the counts agree.

    This count helps detect an omission; by itself, it does not prove the properties. An incorrect relation could contain just as many ordered pairs. The previous checks are still necessary.

  5. Distinguish partial, total, and strict orders

    An order is total if, for every pair x, y in E, x ≼ y or y ≼ x. Here B ≼ C is false and C ≼ B is false. These tasks are incomparable: our order is partial and is not total. The word “partial” allows incomparable elements; it does not mean that the relation has been incompletely described. A total order is also a partial order.

    To express a strict prerequisite, we define x ≺ y by x ≼ y and x ≠ y. The symbol ≠ means “is distinct from”. Removing the diagonal leaves our 5 strict ordered pairs. This relation is not reflexive: x ≺ x is always false. It is transitive and asymmetric: x ≺ y rules out y ≺ x, including the case where the tasks would be equal.

    The diagram represents the direct strict constraints. The relation ≼ also contains the diagonal and the indirect constraints. Confusing these representations would make reflexivity or transitivity appear to fail.

  6. Choose a sequence and check every constraint

    To perform the tasks one at a time, A must come first and D last. In the middle, B and C can exchange places. Exactly 1 + 1 = 2 sequences remain: A, B, C, D or A, C, B, D. Each defines a compatible total order, also called a linear extension: it orders all the tasks while preserving the original constraints.

    Check the first list. r(x) denotes the position of x in this list, with no physical unit. It is 1 for A, 2 for B, 3 for C, and 4 for D. For every direct dependency x ≺ y, we must have r(x) < r(y), where < compares integer positions.

    A to B gives 1 < 2; A to C gives 1 < 3; B to D gives 2 < 4; C to D gives 3 < 4. The indirect constraint from A to D is also satisfied: 1 < 4. The equalities x ≼ x clearly do not require a strict inequality between positions.

    The list A, B, D, C fails because it puts the test before preparing the reader. An arbitrary list is therefore not necessarily a compatible extension. In a correct list, putting B before C expresses a choice about how to organize the work; it does not retrospectively make B a necessary prerequisite for C.

Explain it in your own words

Without looking at the table, reconstruct the ordered pairs from the diagram. Explain why A is related to D, why B and C remain incomparable, and how a list can order them without revealing a hidden dependency.

✿03 Common mistakes

  • “Antisymmetric means that every pair must be related in exactly one direction.”

    Antisymmetry only rules out relations in both directions between distinct elements. B and C can be unrelated in both directions. Requiring every pair to be comparable is the additional condition for a total order.

    Review the criteria and the test with B and C

  • “I see no arrow from A to D, so A does not precede D.”

    The diagram omits indirect constraints. Follow A to B to D: transitivity requires the ordered pair (A, D). The path through C confirms the same ordered pair without counting it a second time.

    Reconstruct the ordered pairs before counting them

  • “B comes before C in my list, so B is necessary for C.”

    Test the list A, C, B, D: it also satisfies every dependency. The chosen ranking can compare tasks that the original relation leaves incomparable. Separate the constraint from the choice of sequence.

    Review the compatible sequences and their positions

Exercise 1 · Identification with justification

Read the constraints without inventing an arrow

In the original kit, decide whether A ≼ D, B ≼ C, and D ≼ A are true or false. Justify each answer with a chain or the absence of a chain. Can you deduce C ≼ B solely from B ≼ C being false?

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Read upwards from a prerequisite to the task that depends on it.

Hint 2

A negation only tells you that the ordered pair in question is absent. Look for the reverse ordered pair separately.

Compare with the solution

A ≼ D is true: A precedes B, which precedes D. D ≼ A is false: the tasks are distinct and no path goes back down from D to A. B ≼ C is false: no chain leads from B to C.

C ≼ B is also false. The absence of B ≼ C therefore does not prove the reverse relation. B and C are precisely the incomparable pair that prevents the order from being total.

Check your reasoning

  • Give a path for the indirect constraint from A to D.
  • Check both directions between B and C without turning a negation into the reverse relation.
  • Interpret a 0 entry in the table as an absent ordered pair without inferring any new priority.

An almost correct relation

A worksheet contains every ordered pair of R except (A, D). In particular, it retains the diagonal and the 4 direct dependencies. Check reflexivity, antisymmetry, and transitivity separately. Give a specific counterexample for the property that fails, then repair the worksheet while preserving all its constraints.

Assisted answer: try this exercise without help later.

Hint 1

Look for tasks x, y, z such that the ordered pairs (x, y) and (y, z) are still listed, but (x, z) is not.

Hint 2

Repairing the relation while preserving its constraints requires adding an ordered pair rather than removing a useful arrow.

Compare with the solution

The entire diagonal remains: the relation is reflexive. No ordered pair between distinct tasks has its reverse present: the relation remains antisymmetric. However, (A, B) and (B, D) are present, but (A, D) is missing: transitivity fails. A, C, D gives another witness to the same omission.

The worksheet contains 9 − 1 = 8 ordered pairs. Adding (A, D) restores transitivity and brings the count back to 9. You must add 1 ordered pair, even though several paths justify it. All the properties are then those checked in the example; the count alone is insufficient to prove them.

Check your reasoning

  • Distinguish the properties that still hold from the one that fails.
  • Write the premises that are present and the missing conclusion in a counterexample to transitivity.
  • Repair the relation with the ordered pair (A, D) and count it only once.

Exercise 3 · Choice and objection

Complete the relation without creating a contradiction

To obtain a total order on the same tasks, someone proposes adding the ordered pairs (B, C) and (C, B) to R. Does this proposal work? Give a repair that preserves R and orders all the tasks. Count its ordered pairs and compatible sequences, then explain what this new ranking says about the original kit.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

B and C denote distinct tasks: what happens to antisymmetry if both ordered pairs are present?

Hint 2

Try adding only (B, C). Also check the transitive consequences of this choice.

Compare with the solution

Adding both ordered pairs breaks antisymmetry: B ≼ C and C ≼ B would imply B = C, contradicting the identities of the tasks. Keep only (B, C). The new chains A to B to C and B to C to D require (A, C) and (B, D), which are already present. A to D is also present. No other ordered pair is missing.

The resulting relation remains reflexive, antisymmetric, and transitive. Every pair is now comparable: this is the total order A ≼ B ≼ C ≼ D. It contains 9 + 1 = 10 ordered pairs and allows only 1 sequence: A, B, C, D. Choosing only (C, B) would give the other compatible total order.

This repair adds a rule for organizing the fictional preparation. The original kit still allows 2 possible sequences and requires neither ranking of B and C. Deciding to carry them out in a particular order is not proof of a physical dependency.

Check your reasoning

  • Challenge the proposal using the reverse ordered pair between distinct tasks.
  • Check the transitive consequences after choosing only one direction.
  • Find 10 ordered pairs and 1 sequence for the chosen total order without attributing this choice to the original dependencies.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1Which criteria must you check for a non-strict order?

Reflexivity: x ≼ x. Antisymmetry: x ≼ y and y ≼ x imply x = y. Transitivity: x ≼ y and y ≼ z imply x ≼ z. These conditions apply to all elements of the set.

Recall 2What does “B and C are incomparable” mean? Is this a flaw in the order?

Neither B ≼ C nor C ≼ B is true. This is allowed in a partial order and prevents the kit order from being total. The reverse direction cannot be deduced from the absence of the first direction.

Recall 3Why does the relation contain (A, D) without a corresponding direct arrow?

The chain A to B to D carries the constraint through by transitivity; the chain through C leads to the same ordered pair. The diagram shows only direct dependencies, whereas the relation also contains the indirect consequences and the diagonal.

Recall 4How do you obtain the strict order from the non-strict order? What happens to the diagonal?

Define x ≺ y by x ≼ y and x ≠ y. Remove the ordered pairs (x, x). The strict relation is transitive and asymmetric; it is not reflexive. The antisymmetry of the non-strict order allowed its diagonal ordered pairs.

Recall 5What does a compatible sequence prove, and what does putting B before C in it fail to prove?

It orders all the tasks while respecting the original constraints: it is a linear extension of the order. Putting B before C chooses one possible way to organize the work; it does not prove that B is necessary for C in the original kit.
