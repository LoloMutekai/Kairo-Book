Numerical reproducibility

Your goalExplain why changing the order of additions can change a sum, then define and check the contract for reproducing the calculation.

Before you start

✿01 See the idea

An energy balance calculation combines the signed contributions from the same simulation. An inflow adds 10000 J, an outflow removes the same energy, and a small contribution adds 1 J. J stands for joule. On paper, the balance is 1 J. Will we recover this balance if the tasks finish in a different order?

Reducing a collection by addition means combining its contributions until we obtain a total. In parallel, groups can be added separately and then combined. The diagram shows the dependencies in the calculation; it shows neither a duration nor a speed measurement.

A machine stores a finite number of digits. After an addition, it may replace the exact sum with a nearby representable number: this is rounding. A small term lost at this step does not reappear in the next addition. The associativity of real numbers, which allows us to change the parentheses, therefore does not generally extend to these rounded additions.

The energies and the results of the variants are fictional. To make rounding visible, our teaching calculator keeps 3 significant decimal digits. This model is not the binary format of a processor. It isolates the mechanism of information loss; it does not predict the outputs of real software.

The rule to remember

Decide what “reproduce” must mean, keep the inputs and calculation conditions, then compare the outputs using the rule announced before the trials.

✿02 Follow an example

Worked example

The balance changes when we regroup the additions

We add the contributions a = 10000 J, b = -10000 J and c = 1 J. They are exactly representable in our model. We keep the same data and change only the parentheses, rounding after each addition.

  1. Define the contract and symbols

    a, b and c are signed energies in joules; b = −a. s denotes their exact mathematical sum, in joules. R(x) denotes rounding the energy x to the nearest representable decimal number with 3 significant digits. If x is 0 J, R(x) is 0 J. For a halfway case, we choose the result whose last retained digit is even; none of the rounding steps in this example is a halfway case.

    Significant digits begin at the first nonzero digit; their count does not specify the number of decimal places after the decimal point. We do not bound the exponent of this fictional calculator. There is no overflow, no nonfinite value and no uncertainty in the inputs here. R does not represent any physical measurement error.

    A result is reproducible in the strict sense if its representation is identical across the reruns defined by the protocol. Numerical agreement accepts a difference specified in advance. In our calculator, distinct values of 1 J and 0 J are enough to disprove strict identity; we do not need to simulate bits.

  2. Build an exact reference

    We cancel the opposite contributions before adding the small energy. This gives us a check independent of the calculator that rounds. This reference checks the addition of the fictional data; it does not validate their suitability for a real installation.

    s=a+b+c=(10000+(-10000))+1=0+1=1 J

  3. Follow tree A: cancel first

    Adding a + b gives exactly 0 J, which remains 0 J after rounding. Adding c then gives 1 J, which is exactly representable. Each operation has therefore preserved the useful information. Let A denote the output of this tree.

    A=R(R(a+b)+c)=R(0+1)=1 J

  4. Follow tree B: lose the small term

    This time, the first exact sum is b + c = -10000 + 1 = -9999 J. Around this value, the representable neighbors are -10000 J and -9990 J. Their distances from the exact sum are 1 J and 9 J respectively. We therefore choose -10000 J, the nearest. This choice follows the rounding rule; it is not an algebraic simplification of b + c.

    The final addition gives 10000 + (-10000) = 0 J, and rounding no longer changes this result. Let B denote this output. The contribution c was absorbed in the first rounding step; the final cancellation cannot recover it.

    B=R(a+R(b+c))=R(10000+(-10000))=0 J

  5. Check the difference and its cause

    The exact check still gives s = 1 J. Here A coincides with s; B differs from it by 1 J. The difference between A and B is |1 − 0| = 1 J. The notation |x| denotes the absolute value, hence the distance from 0 in the same unit as x.

    The first operation in B introduced an error of −1 J; the final operation is exact. This error is enough to explain the entire final difference. The large contributions cancel and the expected sum is small: an error that is small on the scale of a can be large on the scale of the balance.

    A fixed order can therefore make a result repeatable while leaving it inaccurate. Conversely, different orders do not always produce a difference: our example demonstrates a possibility, not a systematic difference. It uses no random draws; a seed does not address this cause.

  6. Define and apply a numerical comparison

    Let us choose a rule for finite outputs r and s, in joules. d = |r − s| is their absolute difference. τa is an absolute tolerance in joules; τᵣ is a dimensionless relative tolerance. max chooses the larger of the absolute values. The threshold T is in joules, like d. We declare numerical agreement when the following relation holds.

    d=|r−s|≤T=τa+τr×max(|r|,|s|)

    For this exercise, τa = 1/100 J = 0.01 J and τᵣ = 1/1000 = 0.001. These fictional thresholds are chosen before the comparison; they are neither a software norm nor a validated physical tolerance. The absolute term provides a scale for agreement when the magnitudes are close to 0. Our rule never divides by a reference that could be 0.

    For r = B = 0 J and s = 1 J, the larger magnitude is 1 J. The relative part is 0.001 J; T = 0.010 + 0.001 = 0.011 J. But d = 1 J exceeds 0.011 J: agreement also fails under this rule. A shortened display or a threshold widened afterward does not repair the calculation.

  7. Prepare a rerun that can be assessed

    To rerun this same balance, keep the contributions in their order, their units and their content hash; also keep the exact code version, the parameters and the numerical format. Record the interpreter and library versions, the processor or accelerator, and the options that can reorganize operations. An identical hash establishes that the compared content is identical, not that it is correct.

    Next, describe the grouping of additions, the division into tasks and the number of workers. A variable arrival order can change the reduction even when the inputs are unchanged. A fixed tree makes this mechanism easier to control, without promising identity across all hardware and versions. We can also examine a more accurate summation algorithm, to be validated separately; we do not teach its construction here.

    If the simulation generates its contributions through random draws, also keep the generator, its seed and the assignment of draw sequences to tasks. The seed initializes a deterministic pseudorandom sequence; by itself, it fixes neither the order of additions nor the order in which this sequence is consumed.

    Finally, archive the raw outputs and the comparison rule before changing the organization of the calculation. Check each variant against the exact reference, when available, then compare the reruns with each other. Repeating the same error proves only its repetition. Agreement for this balance proves neither a speed gain nor the validity of an entire simulation.

Explain it in your own words

Hide the trees and identify the addition that loses c. Explain why fixing the order, increasing precision and fixing a seed address different causes. Then distinguish a repeatable sum, an exact sum and agreement accepted under a declared tolerance.

✿03 Common mistakes

  • “With the same seed, all results will be identical.”

    The seed concerns the draws. Our balance draws nothing at random, yet its trees already differ. The rounded operations, their order and their environment must also be described; if tasks draw values, their assignment to sequences matters too.

    Find the information loss, then the rerun protocol

  • “The same output on every trial proves that my calculation is correct.”

    Repeating tree B in our model always returns 0 J, while the reference is 1 J. Check identity across reruns separately from the difference from a justified reference.

    Compare the trees and the reference balance

  • “To make the check pass, I raise the tolerance after the trial.”

    Choose the rule and its units before seeing the differences, based on the needs of the analysis. Exceeding the threshold calls for an explanation. A justified threshold change still creates a new contract to document; it does not make the previous one pass retroactively.

    Apply the threshold, then limit the conclusion

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1Why can the parentheses change our balance?

Each addition is rounded. In B, b + c becomes b: the information carried by c is lost before cancellation with a. Real addition is associative; rounded addition generally is not.

Recall 2What are the differences between strict identity, numerical agreement and accuracy?

Strict identity compares the representations of the outputs from reruns. Numerical agreement accepts a difference under a declared rule and tolerances. Accuracy compares with the expected mathematical result. A repeated result can be wrong, and a nearby result can still be distinct.

Recall 3What does a seed fix, and what still needs to be checked?

It initializes a given pseudorandom generator. Its version and the assignment of draws, the inputs, the code, the format, the tools, the hardware and the order of operations still need to be checked. Our balance changes without any draws.

Recall 4Reconstruct the agreement threshold and its units for the balance.

We require |r − s| ≤ τₐ + τᵣ × max(|r|, |s|). r, s and τₐ are in joules; τᵣ is dimensionless. The absolute part keeps the threshold usable near 0. The rule is chosen before seeing the differences, according to the needs of the analysis.

Recall 5Does an accepted rerun prove speed and physical validity?

It establishes only the comparison verdict for the inputs, conditions and outputs examined. Speed requires comparable duration measurements; physical validity requires a check of the model and its data.

Reconstruct the reasoning

Without looking, draw the trees for the balance and indicate where c disappears. Then reconstruct the identity and agreement contracts, the threshold rule with its units, and the records that make a rerun possible. Finish by explaining why a repeatable or accepted output does not, by itself, prove its accuracy or a real gain.
