Level 0 · C008·M1

Variables and types

Your goalRead an assignment, find the value associated with each name and distinguish a number from text that looks like it.

Before you start
c003-m5 : scientific notation · c007-m5 : execution traces

✿01 See the idea

You are preparing rice. A label, portions, refers to the current request: 3 portions. You put another label, gardees, on this first value. Then the request changes to 5 portions. Which label needs to move?

Move only portions. The gardees label stays on the value it already referred to. Keep this picture in mind: a name lets you find a value; reassigning that name changes its association. It does not automatically rewrite the other names.

Also look at the card showing the text "3". It looks like the number 3, but it contains a written character. The type specifies the kind of value: integer, text, decimal number or truth value. Appearance alone is no reason to treat them as the same.

The dispenser, its cards and all the quantities are fictional. In this unit, we move labels and read their values again. No rice is poured; no dispensing rule has been programmed yet. The values shown do not change their contents: we can only associate a name with another value.

The rule to remember

In Python, read the value to the right of the = sign, then associate the name on the left with that value. An assignment takes effect when its line is executed.

✿02 Follow an example

Worked example

Keep the first rice request

The initial request is 3 portions, then it becomes 5 portions. We will keep the first value and read each assignment again in order. Before continuing, predict the value of gardees after the change.

  1. Define the words and assumptions

    Here, a variable is a name associated with a current value. portions refers to the current request; gardees refers to the request set aside. A value is what the name lets you find. The type describes the kind of value; int is the Python name for the integer type.

    The numbers count portions, with no unit of mass: we have chosen neither grams per portion nor a recipe. Python keeps the number; the name and context explain the unit. Each statement executes once, in the order written, with no other intervention. We use only the simple values shown on the cards.

  2. Associate portions with the initial request

    Python statement: “portions = 3”.

    The = sign means "assign". It reads the value on the right, then associates the name on the left with that value. After this statement, portions refers to the integer 3, meaning 3 portions in the scene. The name gardees has not received a value yet: do not give it 0 by default.

  3. Keep the value available now

    Next statement: “gardees = portions”.

    On the right, portions lets you find 3. On the left, gardees is therefore associated with the integer 3. The 2 names refer to the same value. This line records no rule saying "follow portions in the future"; it reads what portions refers to now.

  4. Change the current request

    Next statement: “portions = 5”.

    The new value on the right is 5. The name on the left is portions: its association is what changes. Final state of this program: portions refers to 5; gardees still refers to 3. The values are integers of type int, counted in portions. The initial integer has not been transformed: portions refers to another integer.

  5. Calculate the difference and check the trace

    To measure how much the current request exceeds the saved request, subtract the second from the first. The quantities have the same unit, so their difference is also counted in portions.

    5−3=2 portions

    Reverse check: adding the difference to the saved quantity should give the current request again.

    3+2=5 portions

    We do get 5 portions again. Also check which names the statements act on: gardees was assigned only at the time of the first request. The calculation on paper checks this trace; it is no new dispensing statement.

  6. Reassign portions to text

    Now extend the same program with: “portions = "3"”.

    Quotation marks delimit text in the code. Here, the value contains 1 character, the digit 3; the quotation marks are not part of its contents. Its type is str. So portions now refers to this text; gardees still refers to the integer 3. The name portions has been associated with a value of another type, which Python allows.

    Text containing a digit does not become a number because of its appearance. Even if the cards show the same digit, one contains an integer and the other contains text. No cooking unit is attached to the character. Converting text to a number will require an explicit operation, studied later.

  7. Recognize the other cards without calculating with them

    The half portion represents 1 portion divided into 2 equal parts: 1 ÷ 2 = 0.5 portion. The float card illustrates a decimal number; in Python code, its decimal notation uses a point. The comma in the diagram follows French formatting. Many decimal numbers are represented approximately; we do not calculate with them here.

    The bool card contains a truth value: True means true, False means false. In our fictional scene, True answers the statement "the dispenser is ready". This type does not count portions and has no cooking unit. A card marked true does not constitute a physical check of the dispenser.

    We have now named the types int, str, float and bool. Operations on these types, conditions and collections will be covered in their own units; the label rule is enough to trace the assignments here.

✿03 Common mistakes

  • “The = sign forces the names to remain equal forever.”

    An assignment takes effect when its line is executed. After gardees = portions, the line portions = 5 acts only on portions. Redraw the links: 5 portions requested, 3 saved. Updating gardees would require a new assignment to that name.

    Revisit the copy, then the change

  • “The name portions must be an integer forever.”

    The type belongs to the value received. After portions = "3", this name refers to text of type str. Write out the state again, including the type; keeping names consistent with their meaning helps avoid confusion, but Python does not require the previous type to be kept here.

    Read the extension with text again

  • “Quotation marks only decorate the number.”

    They delimit a value of type str. The card 3 is an integer; the card "3" contains text. Find the cards and say what they contain before discussing the quantity of rice.

Compare with the solution

First execute gardees = portions: the right side still refers to the integer 5. So gardees receives the integer 5, interpreted as 5 portions.

Then execute portions = "5": portions now refers to text of type str; gardees stays on the integer of type int. No statement has actually poured rice or sent a command to the dispenser.

The visible digit remains 5, but the saved type is str: the goal of keeping an integer is not met. ✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What is the distinction between portions and the value it refers to?

portions is a name. The value is what it lets you find now; reassignment can change this association.

Recall 2How do you read gardees = portions?

First find the current value of portions, then associate gardees with that value. This statement sets up no rule for following future changes.

Recall 3Why does gardees stay at 3 when portions changes from 3 to 5?

The last assignment acts only on portions. gardees keeps its previous association with the integer 3; changing it would require reassignment.

Recall 4Which types do you recognize on the dispenser cards?

int for integers; str for text; float for decimal numbers as represented by Python; bool for True or False, true or false. These types do not carry the cooking unit on their own.

Recall 5After portions = "3", what is the type of its value?

str: the quotation marks delimit text containing the character 3. The name can receive this new type; the written digit is not automatically converted to an integer.

Reconstruct the reasoning

Without looking at the cards, redraw portions and gardees after each assignment. Then explain the rule "read the right side, reassociate the left", the role of order and the difference between an integer and its text representation. Finish by separating the type of the value from its unit in the scene.
