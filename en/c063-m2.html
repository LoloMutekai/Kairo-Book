Level 2 · C063·M2

Bernoulli model and discrete path

Your goalTurn draws into binary outcomes, build their running total in order, and justify the probability of a path under explicit assumptions.

Before you start
c030-m5 : Poisson · c013-m5 : recursion · c055-m5 : confidence interval · c017-m5 : reproduction protocol · c063-m1 : seed and generator

✿01 See the idea

A small gate is tested each time a badge is presented. In this fictional simulation, we keep only the outcome: it opens or stays closed. We code “open” as 1 and “closed” as 0. The code describes what happens on that trial; it measures neither how long the gate is open nor a degree of reliability.

Imagine a marker placed at random on a ruler. Before a threshold p, the simulated gate opens; at or beyond the threshold, it stays closed. If the part before the threshold occupies a fraction p of the ruler, the probability of opening is p. This mechanism produces a Bernoulli outcome: a variable that takes only the codes 0 and 1.

The model chooses p = 0.60, dimensionless, for every trial. It also assumes independent draws: knowing the previous draws does not change the probability of the next. A gate that jams after staying closed would not follow this rule. Independence is an additional assumption; the word Bernoulli alone does not guarantee it.

A discrete path keeps the sequence of states at separate steps. We will track the cumulative number of openings after each trial. The running total rises by one when the gate opens and stays at the same level otherwise. Its last state gives the total, but this total alone does not tell us the order of the openings.

The parameters and draws below are entirely fictional, chosen for pencil-and-paper calculation. They come from neither real trials nor a generator run. The seed and generator have their role in the previous unit; here, the sequence of draws is already supplied.

The rule to remember

Define the outcome, threshold, and assumptions; turn each draw into a code; add that code to the running total; keep the states in order. Multiplying the outcome probabilities requires independence here.

✿02 Follow an example

Worked example

From the threshold to a path of 4 trials

The simulated gate has a constant probability p = 3/5 = 0.60 of opening. The supplied draws, in order, are 0.10; 0.80; 0.40; 0.70, all dimensionless. Let us build the outcomes, the running total, and the probability of this binary sequence under the independence assumption.

  1. Define what can vary

    n = 4 is the fixed number of trials; k is their integer position, from 1 to n. Xk denotes the random outcome before the draw is known: 1 if the gate opens, 0 otherwise. xk is the value obtained in our particular sequence. These codes are dimensionless; a value of 1 adds one opening to the count.

    Pr denotes a probability under the model. p is the chosen parameter, between 0 and 1, identical at every position; q = 1 − p is the complementary probability of the gate staying closed. Saying that each Xk follows a Bernoulli distribution with parameter p means exactly the following two probabilities.

    Pr(Xk=1)=p=35;Pr(Xk=0)=q=25

    Calculation: q = 1 − 3/5 = 2/5 = 0.40. Check: p + q = 1; the two outcomes cover all possibilities. The model ignores partial openings and assumes the same setting after each trial, with no effect from the history.

  2. Turn a draw into an outcome

    Uk is a uniform draw on the interval from 0 inclusive to 1 exclusive: the probability of a subinterval is its length. The Uk are assumed independent. The rule below compares each draw with p; uk denotes the supplied draw once it is known.

    Xk={1si Uk<p0si Uk≥p

    Why does this give p? The region that produces an opening runs from 0 to p exclusive and has length p. The remaining region has length q. The mechanism therefore produces the stated distribution in the ideal uniform model.

    In a program, a generator supplies a finite pseudorandom sequence: its seed allows the sequence to be replayed, but does not by itself prove the assumptions of the ideal model. Here, we check exact comparisons on the supplied sequence; we do not attribute these numbers to any generator.

  3. Apply each comparison

    First trial: 0.10 < 0.60, so x is 1. Second: 0.80 ≥ 0.60, so x is 0. Third: 0.40 < 0.60, so x is 1. Last: 0.70 ≥ 0.60, so x is 0.

    The resulting sequence is (1, 0, 1, 0). Check: every code belongs to the set { 0, 1 }. The threshold p is never used as an intermediate outcome: the gate does not open “by 0.60” on a trial.

  4. Keep the states in order

    Sk denotes the random number of openings after k trials; sk is its value on our path. Initially, S is 0 openings. To move to the next state, add the current outcome to the previous count. The index k − 1 means “at the previous position”.

    S0=0;Sk=Sk−1+Xk

    After the first trial: 0 + 1 = 1 opening. After the second: 1 + 0 = 1 opening. After the third: 1 + 1 = 2 openings. After the last: 2 + 0 = 2 openings.

    The path of the running total is therefore (0, 1, 1, 2, 2), including the initial state. The reverse check consists of subtracting each previous state from the next: this recovers exactly the outcomes (1, 0, 1, 0). The running total never decreases and rises by at most 1 opening per trial.

  5. Calculate the probability of this ordered sequence

    We calculate the probability of the binary sequence (1, 0, 1, 0), before generating it under the model. The event is “open, closed, open, closed” in that order. Independence allows the probabilities of these outcomes to be multiplied; it does not allow a probability to be replaced by a draw uk.

    Pr(X1=1,X2=0,X3=1,X4=0)=pqpq

    First, p × q = 3/5 × 2/5 = 6/25. Then 6/25 × p = 18/125. Finally 18/125 × q = 36/625, or 0.0576, dimensionless.

    Another check: there are 2 openings and 2 instances of the gate staying closed. Grouping the factors, p squared is 9/25 and q squared is 4/25; their product is 36/625, as in the calculation in order. This probability concerns a single ordered sequence. The event “obtain this total, in any order” brings together several distinct sequences.

    The result is not the probability of drawing exactly the supplied decimals: these serve to illustrate the ranking of the draws relative to the threshold. Nor is it a probability of observing this sequence on a real gate, whose parameters and dependencies remain unknown.

  6. Separate the realized path from the model

    The frequency for this path, denoted f, is the total number of openings divided by the number of trials: f = 2/4 = 0.50, dimensionless. It differs from p = 0.60. A frequency describes the realized sequence; the parameter p describes the probability assigned to each trial before its outcome.

    As a reference, the theoretical mean of the count, denoted E(Sn), is the weighted average of the possible totals with their probabilities. Each trial contributes p openings on average; adding these contributions gives E(Sn) = n × p = 4 × 3/5 = 12/5 = 2.4 openings. This mean can be fractional, whereas the realized count is an integer.

    These checks verify the consistency of the calculation under the assumptions. A single path validates neither the parameter nor independence, and does not require f to equal p. Quantifying variability across repetitions will be the work of the next unit.

✿03 Common mistakes

  • “With p = 0.60, every trial must give 0.60 openings.”

    p is a dimensionless probability, not an outcome. Each trial produces the code 0 or 1; the running total for our sequence ends at 2 openings. The frequency 0.50 and the theoretical mean 2.4 openings describe still other quantities.

    Distinguish the quantities in the worked example

  • “The final count is enough to recover the path.”

    Reordering outcomes can preserve the total while changing the intermediate states. Keep the ordered list of outcomes or all the running totals; the second exercise provides a reordering to check.

    Compare the states in the exercises

  • “The outcomes are Bernoulli, so I can always multiply their probabilities.”

    The distribution of each outcome does not say how the outcomes depend on one another. The product p × q × p × q is valid here because of the stated independence. The last exercise keeps the same individual probabilities and changes this dependence.

    Test the independence assumption

Exercise 1 · Applying the mechanism

A draw exactly at the threshold

Hint 1

The < sign is strict: check whether a value is less than itself.

Hint 2

Compare with the solution

The equality u = p does not satisfy u < p. The last code is therefore 0, and the final running total is 2 + 0 = 2 openings. Changing this draw has not changed the outcome in this particular case.

The convention at the threshold remains explicit, even though hitting exactly one point has probability 0 in the ideal continuous uniform model. A draw supplied in an exercise or by a generator with finitely many possible values can equal the threshold. Replacing < with ≤ would then change the code.

Compare with the solution

The comparisons give the outcomes (0, 1, 1, 0). The running total starts at 0, then successively takes the values 0, 1, 2, and 2 openings. Each state is obtained by adding the current code to the previous state.

After the first trial, this running total is 0 openings instead of 1; the total remains 2 openings. The total alone therefore cannot distinguish between these paths.

The probability of the ordered sequence is q × p × p × q. The product of the first factors gives 6/25, then 18/125 after the next opening, and finally 36/625 = 0.0576. The factors are the same as in the example, in a different order: the probabilities are equal under the stated assumptions. The sequences remain distinct.

Exercise 3 · Transfer and critique of an assumption

The programmer reuses the same draw

The programmer changes the gate simulation: they draw a single uniform U, then reuse this U for every trial. They still apply Xₖ = 1 if U < p and 0 otherwise. What is the probability of opening for a trial considered in isolation? Is the mixed sequence in the example still possible? Finally, compare the probability that the gate opens on every trial with that in the independent model.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

For a fixed U, the comparisons with p are identical at every position.

Hint 2

Separate “the distribution at a given position” from “the distribution of the whole sequence”. In the independent model, opening on every trial requires a factor p for each trial.

Compare with the solution

At each position considered in isolation, the region U < p still has length p = 0.60. The outcome therefore remains Bernoulli with parameter p. But knowing the first outcome now reveals all the following ones: they are dependent.

The only possible sequences are all open or all closed. The sequence (1, 0, 1, 0) contains both codes; its probability becomes 0, instead of 36/625 in the independent model.

With the shared draw, the gate opens on every trial exactly when U < p: the probability is p = 0.60. With independent draws, it is p to the power n. We calculate p × p = 9/25, then 9/25 × 9/25 = 81/625, or 0.1296, dimensionless. The change concerns dependence, even though the individual probabilities remain identical.

Check your reasoning

  • I keep p for each isolated trial without wrongly keeping independence.
  • I justify why a mixed sequence is impossible with a shared draw.
  • I calculate both probabilities of the all-open sequence and explain their difference.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What does a Bernoulli distribution with parameter p describe?

An outcome X with two codes: Pr(X = 1) = p and Pr(X = 0) = 1 − p. The parameter p is between 0 and 1, dimensionless. The distribution of one trial does not guarantee independence between trials.

Recall 2How does a uniform draw become an opening outcome?

Take X = 1 if U < p, and X = 0 otherwise. On the interval from 0 inclusive to 1 exclusive, the region U < p has length p. The strict convention places U = p on the closed side.

Recall 3How do you build and check the path of the running total?

Start at 0 openings, add each outcome to the previous running total, and keep each state in order. Differences between successive states recover the outcomes. The final total alone loses the order.

Recall 4When can you multiply p and its complement for a given sequence?

In our model with constant p, when the trials are independent. Take p for an opening and q = 1 − p for the gate staying closed. This product gives the probability of this particular sequence, not that of all sequences with the same total.

Recall 5Why can the frequency for a path differ from p?

p is the model parameter before the outcomes. The frequency is the realized total divided by the number of trials: here 2/4 = 0.50, whereas p = 0.60. A probabilistic model does not fix the frequency of each sequence.

Reconstruct the reasoning

Reconstruct the whole process without support: binary event and parameter; draws and assumptions; comparison with the threshold; list of outcomes; running total at each position; probability of the sequence. Then explain what the total alone loses and why the same Bernoulli distribution at each position does not guarantee the same path model.
