Precision and recall

Your goalCount the four cells of a labelled batch, calculate precision and recall with their denominators, then explain why accuracy alone and a threshold considered in isolation are not enough.

✿01 See the idea

An automatic detector checks study sheets and raises an alert when it thinks it has found an error. We try it on a fictional test batch of 200 sheets, whose errors have been identified by hand: 40 sheets actually contain an error and the tool flags 50 sheets. These counts are invented for the lesson; they do not describe any real tool.

Call a sheet positive if it actually contains an error, and flagged if the tool raises an alert for it. Each sheet belongs to exactly one of four cells: true positive (VP), flagged and containing an error; false positive (FP), flagged incorrectly; false negative (FN), containing an error but unflagged; true negative (VN), correct and unflagged. VP and VN are the symbols retained in the formulas.

There are two separate questions. When the tool raises an alert, is it right? This is precision. Of the sheets that actually contain errors, how many has it found? This is recall. Both quantities share the same numerator, VP, but divide it by different totals.

P=VPVP+FP;R=VPVP+FN

VP, FP, FN and VN are integer counts, measured in sheets. P (precision) and R (recall) are dimensionless ratios between 0 and 1. P requires at least one alert; R requires at least one sheet that actually contains an error; otherwise the denominator is 0 and the quantity is undefined.

Calculation assumptions: the reference labels are correct; the tool's threshold, for example for a logistic regression score, is fixed before counting; the test batch was not used to tune this threshold, otherwise the figures would be too favourable. Here, sheets with errors are in the minority, which sets up a pitfall involving accuracy.

Two words need care. Precision in this unit is different from precision meaning inverse variance, encountered elsewhere, for example with the Kalman filter. Recall here is a statistical quantity, rather than the memory exercise in the flashcards below.

The rule to remember

Precision: VP divided by the alerts, VP + FP. Recall: VP divided by the sheets that actually contain errors, VP + FN. Always state the denominator, threshold and batch.

✿02 Follow an example

Worked example

A detector for sheets with errors on a fictional batch

Fictional test batch: 200 sheets, including 40 with errors. The tool flags 50 sheets, of which 30 actually contain errors. Let us complete the four cells, calculate precision and recall, then check the result.

  1. State the data and assumptions

    Data: 200 labelled sheets, 40 positives, 50 alerts, 30 true positives. The labels are assumed correct, the threshold is fixed in advance and the batch was not used to tune it.

    These assumptions concern the fictional scene. If any of them fails, the two ratios calculated below describe a batch, rather than the quality of the tool.

  2. Complete the four cells

    The alerts are the true positives plus the false positives: the number of false positives is therefore the difference between alerts and true positives. Similarly, the sheets with errors are the true positives plus the false negatives.

    FP=50−30=20;FN=40−30=10

    The number of correct sheets is 200 − 40 = 160. Of these, 20 are flagged incorrectly: VN = 160 − 20 = 140 sheets.

  3. Calculate precision

    Precision answers this question: when the tool flags a sheet, is it right? We therefore divide by the alerts.

    P=3050=0.60

    On this batch, 0.60 of the alerts are correct; the rest are false alerts, meaning 20 sheets are checked again unnecessarily.

  4. Calculate recall

    Recall answers this question: of the sheets that actually contain errors, how many does the tool find? We divide by the sheets with errors.

    R=3040=0.75

    The tool finds 0.75 of the sheets with errors; 10 sheets with errors pass without an alert. The same VP gives two different ratios because the totals differ.

  5. Check by reconstructing the batch and by raising no alerts

    Consistency check: alerts + unflagged sheets with errors = 50 + 10 = 60; adding the true negatives gives 60 + 140 = 200, which is indeed the number of sheets in the batch.

    Accuracy check: the correct decisions are 30 + 140 = 170, or 0.85 of the batch. But a silent tool, which flags nothing, has 160 correct decisions out of 200, or 0.80, with recall of 0; this silent tool's precision is undefined because it raises no alerts. Accuracy alone therefore does not distinguish these two tools well.

  6. Tighten the threshold and read the trade-off

    With a stricter threshold on the same fictional batch, the tool flags only 30 sheets, including 24 with errors. Then FP = 30 − 24 = 6 and FN = 40 − 24 = 16.

    P=2430=0.80;R=2440=0.60

    The threshold removes 14 false alerts but also loses 6 true positives: precision rises and recall falls. This result applies to this fictional batch; it does not tell us which threshold to choose, because that depends on the relative cost of a false alert and a missed sheet with an error.

Explain it in your own words

Why does the same number of true positives give two different ratios? Then explain why the silent tool has good accuracy but 0 recall.

✿03 Common mistakes

  • “High accuracy proves that the tool finds errors.”

    Accuracy also counts correct sheets that are unflagged. On the example batch, a silent tool reaches 0.80 with recall of 0. Look at precision and recall with their denominators.

    Revisit the check with no alerts

  • “Precision and recall divide by the same total.”

    Precision divides by the alerts, VP + FP; recall divides by the sheets that actually contain errors, VP + FN. In the example: 30 out of 50, then 30 out of 40.

    Review the two questions and the diagram of the denominators

  • “A stricter threshold necessarily improves both measures.”

    Here, tightening the threshold changes precision from 0.60 to 0.80, but recall from 0.75 to 0.60. A threshold shifts a trade-off; it does not inherently improve both.

Exercise 1 · Application with explanation

A second detector

On another fictional batch, a detector flags 25 sheets; 50 sheets actually contain errors and 20 of the alerts are correct. Calculate FP, FN, precision and recall.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Start with FP = alerts − VP, then FN = sheets with errors − VP.

Hint 2

Precision: divide VP by the alerts. Recall: divide VP by the sheets with errors.

Compare with the solution

FP = 25 − 20 = 5 and FN = 50 − 20 = 30. Precision is 20 out of 25, or 0.80. Recall is 20 out of 50, or 0.40.

Check: VP + FP recovers the 25 alerts, and VP + FN recovers the 50 sheets with errors. This tool has high precision but misses many sheets with errors; this finding applies only to this fictional batch.

Check your reasoning

  • FP and FN obtained by subtraction, with sheets as their unit.
  • Correct denominator for each ratio.
  • Check that both totals are reconstructed.

Exercise 2 · Inverse reasoning

Recover the counts

Another fictional detector flags 40 sheets. Its precision is 0.75 and its recall is 0.60. Recover VP, the number of sheets with errors, FP and FN.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Precision is VP divided by the alerts: isolate VP.

Hint 2

Recall is VP divided by the sheets with errors: isolate this total, then deduce FP and FN.

Compare with the solution

VP = precision × alerts = 0.75 × 40 = 30. The number of sheets with errors is VP ÷ recall = 30 ÷ 0.60 = 50.

Then FP = 40 − 30 = 10 and FN = 50 − 30 = 20. Check: 30 out of 40 does give 0.75, and 30 out of 50 gives 0.60. The number of true negatives remains unknown: these two ratios do not contain it.

Check your reasoning

  • Isolate VP from precision before finding any other quantity.
  • Obtain the total number of sheets with errors using recall.
  • Check by recalculating both ratios.

Exercise 3 · Interpreting a limiting case

Flag every sheet

On the example batch, a tool flags all 200 sheets. Calculate its precision and recall, then compare them with those of the tool in the example. What can you conclude about choosing a threshold?

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

If everything is flagged, every sheet with an error is found: what are VP and FN then?

Hint 2

Compare the resulting precision with the proportion of sheets with errors in the batch.

Compare with the solution

Every sheet with an error is flagged: VP = 40 and FN = 0. The 160 correct sheets are false positives. Recall is 40 out of 40, or 1.00. Precision is 40 out of 200, or 0.20: this is exactly the proportion of sheets with errors in the batch.

This tool has the best possible recall but low precision; the silent tool in the example is its opposite. Perfect recall therefore proves nothing on its own, and neither does precision alone. Choose the threshold by considering both measures and the cost of each error, which are information external to this calculation.

Check your reasoning

  • VP, FN and FP justified without new data.
  • Precision related to the proportion of sheets with errors.
  • Conclusion that uses both measures and names the cost of errors as external information.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What is the denominator of precision?

The number of alerts, VP + FP: the proportion of flagged sheets that actually contain errors.

Recall 2What is the denominator of recall?

The number of sheets that actually contain errors, VP + FN: the proportion of these that the tool finds.

Recall 3Why can high accuracy hide a useless tool?

When sheets with errors are in the minority, a silent tool makes almost all its decisions correctly; in the example it reaches 0.80 with recall of 0.

Recall 4What is the precision of a tool that flags no sheets?

It is undefined because the denominator is 0. You must state a convention, for example returning 0, which says nothing about quality.

Recall 5What does a stricter threshold change in the example?

Fewer alerts: precision changes from 0.60 to 0.80 and recall from 0.75 to 0.60. This trade-off is specific to this fictional batch.

Reconstruct the reasoning

State the labelled batch, threshold and four cells; divide VP by the alerts for precision and by the sheets that actually contain errors for recall; check that the cells reconstruct the batch; state the denominators; draw no conclusion from either measure alone, and do not infer the behaviour of a real tool from a fictional batch.

What you understand
Precision divides the true positives by the alerts; recall divides them by the cases that actually need to be found. These two ratios describe a batch, a threshold and labels; they must always be read with their denominators.
