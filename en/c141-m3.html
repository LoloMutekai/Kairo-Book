Automata

Your goalBuild a deterministic finite automaton, trace a word through its transition table, and justify its acceptance at the end of the input.

Before you start

✿01 See the idea

A fictional locker terminal receives command letters: a means “arm”, and v means “validate”. Its reader accepts a word containing at least 1 a, possibly repeated, followed by exactly 1 v in the last position. For example, aav works. Validation sent before any arming, or a letter added after validation, makes the whole word invalid.

Imagine moving a card between boxes. It starts in D. Reading a moves it to A: “arming commands have been read, and validation is still expected”. Another a leaves it in A. Reading v from A moves it to V. An error sends it to R, where it stays until the end of the word. The reader stores only this box, called a state, to decide what to do with the next letter.

A finite automaton is this rule for moving among a finite set of states. Each letter consumed causes a transition, even when the card stays in the same box. The loop on A allows as many arming commands as needed without adding a state or remembering their number. The word can be long; the memory used for the state stays fixed in size.

The letters and rules of this terminal are invented for the course. We recognize the form of a command; we do not model the identity of its sender or the actual movement of the locker. Each word is finite and read from left to right, and each new attempt starts again in D. The end of the word is known separately: it is not an extra letter.

The rule to remember

For each letter, look up the current state–letter pair; decide whether the word is accepted only after consuming the entire input.

✿02 Follow an example

Worked example

Build the rule, then read aav

The alphabet contains only the lowercase letters a and v. The fictional word aav contains 2 a symbols and 1 v symbol. Let us build a complete automaton for the terminal rule, then calculate its state after each letter and its final verdict.

  1. Define the language and the model

    Σ, the Greek letter sigma, denotes the alphabet {a, v}. Σ* denotes the set of its finite words, including the empty word ε, which contains 0 symbols. A language is a set of words. Here, L is the set of words formed by a nonempty block of a symbols followed by a single v; the regular expression aa*v describes this rule when the entire word must match.

    L={amv∣m∈ℕ,m≥1}

    m is an integer counting the occurrences of a. Here, a to the power m means repeating the letter a, then appending v; this is not numerical multiplication. In aa*v, the star allows any number of repetitions, including 0, of the a before it. The word must end immediately after v.

    M=(Q,Σ,δ,D,F);Q={D,A,V,R};F={V}

    M is the name of the automaton. Q is its set of states; D is the initial state; F is the set of accepting states. δ, the Greek letter delta, is the transition function: it takes a state and a letter, and returns the next state. The letters and states are labels with no physical unit. Lengths count symbols, and the sizes of Q and F count states; no duration or probability is involved.

    We assume that the input has already been split into letters of Σ, with no spaces, uppercase letters, or other characters. Handling a character outside this alphabet would require an additional input rule. The model is deterministic: each state–letter pair has a unique destination. It is complete: none of these pairs is left without a destination.

  2. Complete the table from what needs to be remembered

    D means that no letter has been read. A summarizes a nonempty prefix consisting only of a symbols. V summarizes a word of the required form, whose input could end now. R means that an irreparable error has already been encountered in this word. A prefix is the initial part already read.

    État courantLettre aLettre vDARAAVVRRRRR

    To find δ(A, v), take row A and column v: you get V. The loop δ(A, a) = A forgets how many arming commands there have been, because this does not change the continuations still allowed. From V, every additional letter goes to R: v must be final. From R, no continuation can repair what has been read; R is a sink state.

    Completeness check: 4 states × 2 letters = 8 destination cells. All are filled, with 1 destination per cell. There is 1 accepting state and there are 3 nonaccepting states. Nonaccepting does not necessarily mean that success is impossible: from A, reading v can still lead to acceptance.

  3. Prepare to read and define the indices

    Let w denote the word aav and n its length. The indices count positions read: i is an integer between 0 and n. The letter wᵢ is the one at position i for i at least equal to 1. The state rᵢ is the one reached after i letters; r with index 0 therefore denotes the start. These indices are counts with no physical unit.

    n=2+1=3 symboles
    r0=D;ri+1=δ(ri,wi+1)

    The rule applies while a letter remains, so for i from 0 to n − 1. Here, the index 0 names the state before reading. It does not mean that D is the number 0. Counting positions helps check the trace; this counter is not part of the memory needed by the automaton.

  4. Consume the letters, including the one that does not change the state

    First letter a: row D, column a gives A. We have read 1 symbol and retain “at least one arming command, no validation yet”.

    r1=δ(D,a)=A

    Second letter a: we do need to consult the table again. Row A, column a gives A again. The count of letters read advances to 2, even though the state stays the same.

    r2=δ(A,a)=A

    Last letter v: row A, column v gives V. We have now consumed the entire word.

    r3=δ(A,v)=V

  5. Decide and check by reading another way

    The criterion is that w is accepted if and only if rn belongs to F. The sign ∈ means “belongs to”; n is the length of w. Here, rn = V and F = {V}: aav is accepted. The trace D → A → A → V has 3 transitions for 3 symbols, and 4 positions including the start. The states at these positions are not all different.

    w accepté⇔rn∈F;3+1=4 positions de trace

    A check independent of the table: aav splits into aa followed by v. The block aa contains 2 a symbols, so it satisfies m ≥ 1, and v is indeed the last symbol. The word directly fits the description of L. The table and this description give the same verdict.

    Boundary checks: the empty word leaves the state at D and is rejected. The prefix aa leaves the state at A and is rejected if the input stops there. The letter v alone leads to R and is rejected. Simply passing through V is not enough if the word continues: the diagnostic exercise asks you to check this case.

  6. Explain why the construction works for the entire language

    The explanation of each state remains true after every letter: D corresponds only to the empty prefix; A to a nonempty block of a symbols; V to such a block followed by a final v; R to all other prefixes. This property is preserved as the input is read. Check it from D, then row by row in the table.

    From A, a extends the block and v ends it correctly. From V, every new letter breaks the required form. From R, neither adding a nor adding v can erase validation that came too early or a letter after validation. Thus, ending in V is exactly equivalent to having read a word of L. This justification covers words of arbitrary length; checking only aav would have proved only the verdict for that example.

    We have built a deterministic finite automaton for this regular language. The regular expression describes the allowed words; the table gives a recognition mechanism. We have not proved that every language has such an automaton. The general question of which problems can be decided belongs to the next unit.

Explain it in your own words

✿03 Common mistakes

  • “I have reached V: everything that follows is accepted.”

    V allows acceptance only if the word ends there. If a letter remains, apply δ again: from V, both a and v lead to R. Repair your trace by also recording the letters after the first visit to V.

    Diagnose acceptance declared too early

  • “The loop on A does not count as a transition.”

    The second letter a is indeed consumed: A → A is an allowed move of the card back to its own box. Repair the count by matching each letter to its table lookup. For aav, there are 3 transitions and 4 positions, including the start.

    Review the trace letter by letter

  • “All nonaccepting states represent the same rejection.”

    D and A do not accept if the word stops, but their allowed continuations differ. Reading v from A leads to V, whereas from D it leads to R. R is different again: it no longer allows any acceptance in the current word. Clarify the state labels by describing what each state allows next.

The shortest valid word and a single letter

Using the same table, trace av and then v. Start again in D for each word. Give the number of symbols and transitions for av, then explain the difference between the verdicts.

Hint 2

The transition on v depends on the row you are in: compare rows A and D.

Compare with the solution

For av: D → A on a, then A → V on v. There are 2 symbols and 2 transitions; at the end, V belongs to F. The word is accepted and directly follows the pattern of an arming command followed by validation.

For v: D → R in 1 transition. R does not belong to F: the word is rejected because no arming command precedes validation. Starting again in D is essential; keeping A from the previous word would change the question.

Exercise 2 · Diagnostic

Correct validation followed by an arming command

The reader receives aava. Someone announces acceptance as soon as they recognize aav at the beginning. Finish the trace, count all its transitions, and explain their error precisely.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The word from the example is a prefix of the new word: its last letter is no longer the end of the input.

Hint 2

Look up row V for the letter a that is still present.

Compare with the solution

The full trace is D → A → A → V → R. The last a requires V → R. The length is 3 + 1 = 4 symbols: there are 4 transitions and 5 positions, including the start.

The word is rejected because it ends in R. The person recognized a valid prefix and took it to be the entire word. The repair is to consume the entire input before testing membership in F; we do not make V absorbing. An absorbing state is a state that returns to itself for every letter, like R in our table.

Check your reasoning

  • Keep the visit to V, then show the last transition to R.
  • Distinguish 4 transitions from 5 trace positions.
  • Identify the confusion between an accepted prefix and an accepted entire word.

Exercise 3 · Construction and justification

Can we merge the start and waiting states?

To reduce the number of boxes, someone proposes replacing D and A with the same nonaccepting state B, while keeping the intended language. Find a single continuation that should be rejected from D and accepted from A. Explain why merging cannot preserve these two verdicts in a deterministic automaton.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The empty word leaves the state at D; the prefix a leaves it at A. Look for what remains to be read to distinguish them.

Hint 2

Try the continuation v. If the states were merged, B and v could give only a single destination.

Compare with the solution

The continuation v is enough: from D, it leads to R and produces the rejected word v; from A, it leads to V and completes, for example, the accepted word av. It therefore distinguishes the empty prefix and a, even though their current states are nonaccepting.

After merging, δ(B, v) would have a unique destination. It could not both allow acceptance at the end for av and refuse it for v. Merging would lose necessary information: whether an arming command has already been read. However, different nonempty blocks of a symbols can all lead to A, because their acceptable continuations are the same. This argument rules out this particular merge; it is not a general algorithm for minimizing automata.

Check your reasoning

  • Give the same continuation v for the empty prefix and a.
  • Establish opposite verdicts through explicit destinations.
  • Relate the impossibility to the unique destination of a state–letter pair, without confusing nonaccepting states with equivalent states.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What does state A remember, and what information does it forget?

It remembers that a nonempty block of a symbols has been read, with no validation. It forgets the exact number of a symbols, which is unnecessary for deciding which continuations can still be accepted.

Recall 2What do deterministic and complete mean for our table?

Deterministic: each state–letter pair has a unique destination. Complete: all pairs are covered. The table has 4 × 2 = 8 destination cells.

Recall 3Why do aav and aava have different verdicts?

aav ends in V and is accepted. aava visits V but still has to read a, which leads to R: it is rejected. The test concerns the state after the whole word.

Recall 4Why must R be distinguished from A?

Words that have reached R already contain an irreparable error and stay in R regardless of the continuation. From A, the continuation v leads to acceptance. The two states therefore do not allow the same continuations.

Recall 5What justifies the table for all words, beyond the trace of aav?

We give the meaning of each state for the prefix read and check that each transition preserves that meaning. V represents exactly a nonempty block of a symbols followed by a v, with no letter after it. The final condition thus recognizes exactly the intended language.
