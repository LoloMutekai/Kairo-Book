Level 2 · C046·M5

Approximation error

Your goalChoose an approximation that meets a stated tolerance, then check that its rounded value still meets that tolerance.

Before you start
c031-m5 : asymptotes · c045-m5 : introductory quadrature · c046-m1 : series convergence tests · c046-m2 : power series · c046-m3 : Taylor · c046-m4 : remainder

✿01 See the idea

An empty tank needs 10 L of water. The tap normally supplies 2 L/min, but its flow rate falls by a fraction 1/5. To estimate the filling time, you replace a division with a short polynomial. The useful question becomes: is the remaining difference small enough for the intended use?

In our fictional scene, the calculation at degree 2 gives 6.20 min, compared with 6.25 min from the reference formula. The written values look similar, yet the difference amounts to 3 s. If the required error is at most 1 s, this approximation is unsuitable.

A tolerance is the largest accepted difference, chosen before calculating. An error bound is an upper limit proved under stated assumptions. It guarantees a level of accuracy without knowing the exact value sought. A bound that is too large leaves the question open; on its own, it does not mean that the actual error is large.

We will keep the same tank, add a term to the polynomial and examine the rounding of the displayed value. All data are fictional and treated as exact in the model. The flow rate is constant during filling, the tank does not leak and the volume to fill is known: we are checking an approximation to this formula, rather than the difference from an actual filling process.

The rule to remember

State the reference, range and tolerance; bound the remainder in the correct unit; then reserve part of the tolerance for the final rounding.

✿02 Follow an example

Worked example

Fill the tank with an error of at most 1 s

The volume V is 10 L and the nominal flow rate q₀ is 2 L/min. The relative decrease x can range from 0 to ρ = 1/5. We calculate the limiting case x = ρ and seek a guarantee over this entire range. The absolute tolerance ε is 1 s; equality with this limit is accepted.

  1. Define what is being approximated

    x is the fraction of flow rate lost and has no unit; ρ, read as “rho”, is its upper limit. The remaining flow rate is q(x) = q0(1 − x). T0 = V/q0 is the time with no decrease; T(x) is the time given by the model. All times in the formulas are initially in minutes.

    T(x)=Vq0(1−x)=T01−x

    We assume 0 ≤ x ≤ ρ < 1, so that the flow rate remains strictly positive. Here T0 = 10 ÷ 2 = 5 min. At the lowest flow rate, 1 − 1/5 = 4/5 and q = 2 × 4/5 = 1.60 L/min.

  2. Choose an error measure and its criterion

    n is a nonnegative integer, the degree of the chosen polynomial; Tn is the approximate time. The signed error en = Tn − T indicates whether the estimate is too high or too low. The absolute error En = |Tn − T| keeps only the size of the difference, in the same unit as T. The bars |…| denote absolute value.

    The relative error En/|T| compares this difference with the reference time; it has no unit and is defined only when T is nonzero. Here T is positive. A small relative error does not automatically meet a requirement expressed in seconds.

    En≤Bn≤ε

    Bn denotes a proved bound on the absolute error. If it is at most ε, the requirement is guaranteed. If Bn exceeds ε, a tighter bound or another argument is needed. Before comparing with ε = 1 s, we will convert minutes to seconds by multiplying by 60 s/min.

  3. Turn the remainder into a guarantee over a range

    We reuse the geometric polynomial Pn(x) = 1 + x + … + xⁿ, and set Tn(x) = T0Pn(x). For n = 0, Pn is simply 1. Multiplying Pn by 1 − x cancels the intermediate terms: what remains is 1 minus x to the power n + 1. This gives the exact remainder Rn without having to add infinitely many terms.

    (1−x)Pn(x)=1−xn+1
    Rn(x)=T(x)−Tn(x)=T0xn+11−x

    Over our range, Rn is positive or 0: En = Rn. We can replace the power of x with the larger power of ρ, and the denominator with 1 − ρ, which is smaller and positive. The same bound then holds for all flow rates in the range; we call the guarantee uniform.

    En(x)≤Bn(ρ)=T0ρn+11−ρ

    Bn(ρ) is a time in minutes. At x = ρ, this bound is exactly the error. If x > 0, the first omitted term, T0 multiplied by x to the power n + 1, is insufficient as an upper limit: the following terms, all positive, add more time. The factor 1/(1 − x) accounts for them. For x = 0, the remainder is 0.

  4. Test degree 2

    At x = ρ = 1/5, the square of x is 1/25. First add 1 + 1/5 = 6/5, then 6/5 + 1/25 = 31/25. This is P2, which has no unit. Multiplying by T0 gives T2 = 5 × 31/25 = 31/5 min = 6.20 min, or 372 s.

    The omitted part starts with T0 multiplied by the cube of ρ. This cube is 1/125, so 5 × 1/125 = 1/25 min. Divide by the remaining relative flow rate to obtain the entire tail of the expansion.

    B2(ρ)=0.040.8=0.05 min=3 s

    3 s exceeds 1 s: this upper limit does not certify the range. We can go further in this particular case: at the endpoint x = ρ, the exact remainder attains this upper limit. There is therefore an allowed flow rate for which degree 2 fails.

  5. Add a term and certify degree 3

    P3 adds the cube of x to P2: 31/25 + 1/125 = 156/125. The time becomes T3 = 5 × 156/125 = 156/25 min = 6.24 min, or 374.4 s. These decimal forms are exact here.

    For fixed ρ, going from one degree to the next multiplies Bn by ρ: the denominator stays the same and the numerator gains another factor. Thus B3 = 3 × 1/5 = 3/5 s = 0.6 s.

    0.6 s ≤ 1 s: degree 3 guarantees the tolerance over the entire range, before rounding. This conclusion follows from the remainder and the assumptions, rather than the number of decimal places displayed.

  6. Check using the reference and the missing volume

    Here the reference is easy to calculate, so we can check our guarantee: T(ρ) = 5 ÷ 4/5 = 25/4 min = 6.25 min = 375 s. The differences are 375 − 372 = 3 s and 375 − 374.4 = 0.6 s. They match the bounds attained at x = ρ.

    For another check, return to the tank: after T2, the volume received would be 1.60 × 6.20 = 9.92 L. The missing volume would be 10 − 9.92 = 0.08 L. At a flow rate of 1.60 L/min, finishing takes 0.08 ÷ 1.60 = 1/20 min, or 3 s. This check recovers the error from a volume without subtracting the times again.

  7. Also check the number actually displayed

    Suppose the display rounds to the nearest second. The value T3 = 374.4 s is displayed as 374 s. Let A denote this displayed number and d = |A − T3| the change caused by rounding: here d = 0.4 s. A and d are times in seconds.

    |T−A|≤|T−Tn|+|Tn−A|≤Bn+d

    This inequality says that the path through the approximation cannot be shorter than the direct difference. At the point studied, the total error budget is 0.6 + 0.4 = 1 s. The display therefore still meets the tolerance, with equality allowed. Direct check: 375 − 374 = 1 s.

    This last certificate concerns this display at x = ρ. For another x in the range, we must recalculate d or use a rounding bound valid for all displays. The uniform guarantee for the polynomial alone does not automatically carry over to the rounded number. It also does not cover an error in volume, a variable flow rate or errors in a computer calculation.

Explain it in your own words

Hide the calculations. Explain why the first omitted term is insufficient here, why the next degree guarantees the entire range and why the display must then be checked separately. State what would remain unknown for a real tank.

✿03 Common mistakes

  • “The next term is small, so it must be the maximum error.”

    For positive x, the omitted terms are all positive. The first does not include the following ones: divide it by 1 − x to obtain the exact remainder, then check the range of validity. When x is 0, all omitted terms are 0.

    Review the geometric remainder and its bound

  • “The bound exceeds the tolerance: the approximation must be poor.”

    A bound is an upper limit, sometimes a very loose one. When this upper limit exceeds the tolerance, the guarantee is missing. In our degree 2 calculation, failure is established by an additional argument: at x = ρ, the error actually attains the upper limit.

    Examine the rounding certificate in the exercise

  • “The polynomial is certified, so I can now round freely.”

    The number delivered is A, rather than Tₙ. Add the change caused by rounding to the polynomial bound and compare the sum with the tolerance in the same unit. A certificate at the point studied does not guarantee all displays over the range.

    Review the error budget for the displayed number

Exercise 1 · Application · distinguish errors

A small percentage can miss the requirement

For the tank at x = ρ, T₂ is 372 s and the reference is 375 s. Calculate the signed error T₂ − T, the absolute error and the relative error. Express the last as a percentage, then decide whether the requirement of at most 1 s is met.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The sign indicates the direction of the difference; the absolute value gives its size.

Hint 2

For the relative error, divide the absolute difference by the reference, then multiply by 100 for the percentage.

Compare with the solution

Signed error: 372 − 375 = -3 s. It is negative: the time is underestimated. Absolute error: |-3| = 3 s.

Relative error: 3/375 = 1/125, with no unit. As a percentage: 100 × 1/125 = 0.8 %. The denominator is the reference, rather than the approximate time.

Despite this small percentage, 3 s > 1 s. The requirement concerns an absolute difference: it is not met. The percentage does not replace the stated criterion.

Check your reasoning

  • Give a negative signed difference and a positive absolute difference, both in seconds.
  • Justify using the reference in the denominator of the relative error.
  • Decide using the tolerance in seconds, without substituting an opinion about the percentage.

Exercise 2 · Diagnosis · guarantee and rounding

An upper limit that leaves the question open

For degree 3, the uniform bound before rounding is 0.6 s. Rounding to the nearest second changes the number by at most 0.5 s. Someone adds these upper limits and claims: “The display must exceed the tolerance of 1 s.” Evaluate this reasoning. At x = ρ, can you refine the certificate using T₃ = 374.4 s and A = 374 s?

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

A sum of upper limits is still an upper limit. If it exceeds the requirement, does this prove that the actual difference is too large?

Hint 2

For this displayed number, replace the general rounding limit with the change that can actually be calculated.

Compare with the solution

The general error budget is 0.6 + 0.5 = 1.1 s. It exceeds 1 s: this estimate does not certify all displays over the range. It does not show that they fail; the upper limits being added may be attained at different points.

At the point studied, d = |374.4 − 374| = 0.4 s. The refined error budget is 0.6 + 0.4 = 1 s. This point is certified because equality with the tolerance is accepted.

The reference confirms |375 − 374| = 1 s. This particular check does not constitute a proof for all flow rates in the range; their rounding would also need checking.

Check your reasoning

  • Calculate the general error budget and explicitly state “not certified by this bound”.
  • Do not turn an overly loose upper limit into proof of failure.
  • Refine the certificate using the known rounding change and limit the conclusion to the point studied.

Exercise 3 · Transfer · choose the degree

The same tank with a stricter tolerance

Keep 0 ≤ x ≤ ρ = 1/5, but now require an error of at most 0.5 s before any rounding. Does degree 3 guarantee the entire range? Try degree 4 using the relationship between successive bounds. Then calculate the time at x = ρ and check its error against the reference.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

At the endpoint x = ρ, the geometric bound is attained: this provides a decisive case.

Hint 2

The next degree multiplies the bound by ρ and adds the corresponding power of x to the polynomial.

Compare with the solution

At degree 3, B3 = 0.6 s > 0.5 s. At x = ρ, the error actually equals 0.6 s: this degree therefore does not guarantee the new requirement over the entire range.

B4 = ρB3 = 1/5 × 3/5 = 3/25 s = 0.12 s, less than 0.5 s. We could also calculate ρ to the power 5, which is 1/3125, multiply by T0, divide by 1 − ρ, then convert to seconds. Degree 4 certifies the entire range before rounding.

At x = ρ, x to the power 4 is 1/625. P4 = 156/125 + 1/625 = 781/625; T4 = 5 × 781/625 = 781/125 min = 6.248 min, or 374.88 s.

Check: 375 − 374.88 = 0.12 s, which attains the calculated bound. The time given here in decimal form is exact; this exercise did not require a display rounded to the nearest second.

Check your reasoning

  • Establish the failure of the previous degree using a point where the error is known, rather than only a bound that is too large.
  • Justify the uniform guarantee using the relationship between remainders and the range of x.
  • Give the time and check its difference in seconds, keeping fractions until the result.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1How do signed error, absolute error and relative error differ?

With the convention used on this page: eₙ = Tₙ − T; Eₙ = |eₙ|, in the unit of T; relative error = Eₙ/|T|, with no unit, if T is nonzero. The sign convention must always be stated.

Recall 2What can you conclude from a bound below the tolerance? And from a bound above it?

If Eₙ ≤ Bₙ ≤ ε, the tolerance is guaranteed under the assumptions. If Bₙ > ε, this certificate is missing; the actual error may still be acceptable. Proving failure requires an actual difference that is too large or another decisive argument.

Recall 3Why is the tank bound valid over the entire stated range?

Over 0 ≤ x ≤ ρ < 1, the remainder is T₀ multiplied by x to the power n + 1, divided by 1 − x. Replacing x with ρ increases the numerator and decreases the positive denominator. The same bound therefore holds for every x in the range.

Recall 4What check remains when the approximation is then rounded?

For the displayed number A, calculate or bound d = |A − Tₙ|, then use |T − A| ≤ Bₙ + d. Compare with the tolerance in the same unit. A guarantee for the polynomial alone does not automatically guarantee its displayed value.

Recall 5Does a certified approximation of the time prove the actual filling time?

It controls the difference from the chosen formula. The volume, constant flow rate, absence of leaks and computer calculations still need justification. A proof about the approximation does not by itself validate the physical model.

Reconstruct the reasoning

Without rereading, reconstruct the chain from the requirement to a value ready to use: which reference and assumptions? Which error measure and unit? Which remainder over which range? Which degree is sufficient? How much margin remains for rounding? Finish by explaining what this certificate does not prove about a real tank.
