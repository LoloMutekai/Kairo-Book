Regular expressions

Your goalBuild and read a regular expression using its three operations (choice, concatenation, star), test a whole word, count words of a given length, then distinguish recognizing a whole word from searching for a pattern in text.

Before you start

✿01 See the idea

A log filter needs to identify decimal numbers written with at least 3 digits after the decimal point so that they can be rounded later. Describing this form in a sentence leaves room for doubt; a regular expression describes it precisely enough to test a word and even count the possible words. The setting is fictional and deliberately simplified: we use d for any digit and p for the decimal point, without ever handling an actual reading.

Imagine a recipe with three operations. Choose: one thing or the other, written with a vertical bar. Concatenate: one thing followed by the other, written by placing them next to each other. Repeat: do something 0, one or more times, written with a star. A word is recognized when its entire sequence of symbols can be read as the result of the recipe. A single matching part is not enough.

An alphabet Σ is a finite set of symbols, a word is a finite sequence of symbols, and a language is a set of words. The regular expression r describes the language L(r), which we define recursively below. A language described by a regular expression is called regular. The connection with state machines belongs to the next unit on automata; it is not proved here.

Limits: programming libraries add shortcuts, character classes such as “a digit”, and options. We keep the mathematical core and expand only the useful shortcuts. Library features that go beyond this core are not covered.

The rule to remember

A regular expression reads like a recipe made of symbols, choices, concatenations and repetitions; a word belongs to its language only if the entire string can be split according to that recipe.

✿02 Follow an example

Worked example

Recognizing decimals with many digits over a two-symbol alphabet

Fictional setting. A log filter needs to identify numbers written with at least 1 digit before the decimal point and at least 3 digits after it. To calculate by hand, we reduce the alphabet to Σ = {d, p}: d represents any digit, and p the decimal point. We write r = d d* p d d d d*, test words, count those of length 8, then check this count.

  1. Define the alphabet, words and syntax

    Our alphabet is Σ, consisting of the two symbols d and p. A word is a finite sequence of symbols. The empty word, written ε, contains no symbols: its length is 0. The word uv is the word u followed by the word v. A language is a set of words.

    A regular expression over Σ is built using three rules. A symbol of Σ is an expression. If r and s are expressions, then r|s (choice), rs (concatenation) and r* (star) are expressions too. Star takes precedence over concatenation, which takes precedence over choice. Assumptions: the alphabet is finite, words are finite, and the vertical bar and star characters are operators, rather than symbols of Σ.

  2. Define the language of an expression

    The language L(r) is the set of words that r describes. It is defined recursively over the construction of r.

    L(a)={a} pour tout symbole a de Σ
    L(r|s)=L(r)∪L(s)
    L(rs)={uv pour u∈L(r) et v∈L(s)}
    L(r*)=⋃k≥0L(r)k avec L(r)0={ε}

    L(r) to the power k denotes the words obtained by concatenating k words from L(r), for an integer k. When k equals 0, we obtain only the empty word. Star therefore allows 0 repetitions: the empty word always belongs to L(r*).

  3. Expand library shortcuts

    Libraries write d+ for “at least one d” and d{m,} for “at least m d symbols”, where m is an integer. These are abbreviations: d+ means d d*, and d{m,} means m copies of d followed by d*. With m equal to 3, the form d+ p d{m,} becomes:

    r=dd*pdddd*

    The first block requires at least 1 d, the decimal point requires 1 p, and the last block requires at least 3 d symbols. Minimum length: 1 + 1 = 2, then 2 + 3 = 5. No word in L(r) is shorter than dpddd, of length 5. The stars never remove these requirements.

  4. Test words by splitting the entire string

    Testing a word means looking for a split of the entire string, symbol by symbol, according to the blocks of r.

    dpddd: the block d d* reads d with 0 extra d symbols, p is read by the block p, then ddd is read by d d d d* with 0 extra d symbols. All symbols are used: the word belongs to L(r).

    ddpdd: after p, 2 d symbols remain, but the last block requires at least 3. There is 1 missing: the word does not belong to L(r).

    pddd: the first block requires at least 1 d before p and the word begins with p, so it is rejected. dddd: there is no p, but the block p must read exactly one symbol p, so it is rejected. Since p is the only letter that the block p can read, its position fixes the split: a single attempt is enough to reject the word.

  5. Count words of a given length

    Let us find the words in L(r) of length 8. The shortest word has 5 symbols, so there are 8 − 5 = 3 d symbols left to place in the two stars: the first follows the initial d, and the second follows the group ddd.

    If x symbols go into the first star, 3 − x remain for the second, and x takes values from 0 to 3. This gives 3 + 1 = 4 words.

    Necessary assumption: each word has a unique split, because it contains a single p and the stars contain only d symbols. Otherwise, we would be counting splits rather than words.

    Here are the 4 words, with their numbers of d symbols before and after p, respectively: dpdddddd (1 and 6), ddpddddd (2 and 5), dddpdddd (3 and 4), ddddpddd (4 and 3). Each pair sums to 7 = 8 − 1, since p occupies one position out of 8.

  6. Check using another method

    Each position in a word of length 8 takes d or p, giving 2 choices. The total is therefore 2 × 2 = 4, then 4 × 4 = 16, then 16 × 16 = 256 possible words.

    A checking script supplied with the page constructs L(r) directly from the recursive definition in step two, then separately tests the 256 words using a small state machine written by hand. Both methods find 4 words, exactly those in the list. The count of 4 out of 256 describes this toy model; it says nothing about an actual log.

  7. Searching for a pattern differs from recognizing a whole word

    Take w = dpdpdddd, of length 8. It contains two p symbols, whereas every word in L(r) contains exactly one: w does not belong to L(r).

    Yet from symbol 3 to symbol 8, the substring dpdddd belongs to L(r). Its length is 8 − 3 + 1, or 5 + 1 = 6. A search therefore finds a pattern in w, while whole-word recognition rejects it.

    w contient un morceau de L(r)⇔w∈L((d|p)*r(d|p)*)

    Searching therefore amounts to recognizing a larger language, with arbitrary symbols before and after the pattern. This lesson does not specify which substring a library returns first when there are several.

Explain it in your own words

Why does the formula libres + un count words rather than splits? What would happen if the expression contained two stars over d next to each other? And why is the word w in the last step both searched successfully and rejected as a whole word?

✿03 Common mistakes

  • “Star means at least once.”

    Star allows 0, one or more repetitions, so the empty word belongs to L(r*). To require at least once, write r r*, which libraries abbreviate as r+. This is why the first block in the example is d d* rather than d*.

    Review the definition of star and the expansion of shortcuts

  • “If the expression finds a pattern in the text, the entire text belongs to its language.”

    Finding a recognized substring amounts to recognizing the larger language in which arbitrary symbols surround L(r). The entire text belongs to L(r) only if the entire string can be split according to r; the word w with two p symbols is a counterexample.

    Review the step on searching and whole-word recognition

  • “To count the words in a language, just count the ways to read the expression.”

    The same word can have several splits when the expression is ambiguous, as with two consecutive stars over d. In that case, we count splits rather than words. First check that there is a unique split for each word, or adjust the count.

Exercise 1 · Application with explanation

A lower threshold

The same fictional setting, but the filter now requires only 2 digits after the decimal point. The expression becomes r′ below. What is its shortest word? How many words of length 6 does it describe?

r′=dd*pddd*

Assisted answer: try this exercise without help later.

Hint 1

Add the minimum requirement of each of the three blocks, as in step three of the example.

Hint 2

Subtract this minimum length from 6: the remainder is distributed between the two stars, and each distribution gives one word.

Compare with the solution

Minimum length: 1 + 1 + 2 = 4, so the shortest word is dpdd.

There are 6 − 4 = 2 d symbols left to place. With x in the first star, the second receives 2 − x, and x ranges from 0 to 2: 2 + 1 = 3 words.

Check by writing them out: dpdddd, ddpddd, dddpdd. Each has length 6, a single p, at least 1 d before it and at least 2 d symbols after it. The unique p guarantees a unique split for each word.

Check your reasoning

  • Add the minimum requirements of the three blocks.
  • Distribute the remaining symbols between the two stars and add one for the value 0.
  • Check the count by writing out the words.

A number that can start with the decimal point

r″=d*pdddd*

Hint 1

Star alone requires no d: what is the minimum length now?

Hint 2

Compare with the minimum number of d symbols before p in the example, and count the possible values of this number.

Compare with the solution

Minimum length: 1 + 3 = 4, with the word pddd. There are 8 − 4 = 4 d symbols left, distributed between the two stars: 4 + 1 = 5 words.

There are 5 words here compared with 4 in the example. The number of d symbols before p can be 0 here; it could not in the example, where the block d d* required at least 1. This extra value adds exactly one word, pddddddd.

The split remains unique: a single p, and the stars read only d symbols.

Exercise 3 · Critique of an argument

Two stars next to each other

A reader writes t below and claims: “t has the same language as r″, and for length 8 there are as many words as ways to read t.” A split places each d before p in one of the first two stars, keeping the order. Check both claims for length 8.

t=d*d*pdddd*
Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

A word in L(t) has k d symbols before p. In how many ways can these k symbols be split between the two stars?

Hint 2

Add these numbers of splits for all possible values of k, from 0 to 4.

Compare with the solution

Same language: concatenating d* and d* allows any number of d symbols, including 0, before p. The words of t are those of r″: 5 words of length 8.

With k d symbols before p, the split between the two stars can come after 0, 1, … or k symbols: k + 1 splits. For k from 0 to 4, add 1 + 2 = 3, then 3 + 3 = 6, then 6 + 4 = 10, then 10 + 5 = 15.

There are therefore 5 words but 15 splits: the second claim is false. Counting readings of the expression counts words only if each word has a single reading.

Check your reasoning

  • Show that d* d* describes the same language as d*.
  • Count the splits for each number of d symbols before p.
  • Conclude that words and splits have different counts and explain why.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What operations build a regular expression, and what language does each describe?

A symbol describes the language consisting of that symbol alone. Choice r|s takes the union of the languages. Concatenation rs forms the words uv with u in L(r) and v in L(s). Star r* concatenates words from L(r) 0, one or more times.

Recall 2What do d* and d+ denote, and which contains the empty word?

d* means 0, one or more d symbols and contains the empty word. d+ means d d*: at least one d, without the empty word.

Recall 3How can d{m,} be expanded using only concatenation and star?

As m copies of d followed by d*. With m equal to 3, this gives d d d d*, with minimum length 3.

Recall 4What is the difference between recognizing a whole word and searching for a pattern in text?

Recognition requires the entire string to belong to L(r). Searching succeeds if a substring belongs to it, which amounts to recognizing the larger language in which arbitrary symbols surround L(r).

Recall 5Why does counting words of a given length amount here to distributing d symbols between two stars?

The p is unique and the stars contain only d symbols: each word has a unique split. The d symbols beyond the minimum are distributed between the two stars, giving a word count equal to the number of extra d symbols plus one.

Reconstruct the reasoning

Define the alphabet, words and languages; build the expression using symbols, choice, concatenation and star; read its language using the recursive definition; expand shortcuts; test a word by splitting the entire string; count while checking that the split is unique; distinguish recognizing a whole word from searching for a pattern.
