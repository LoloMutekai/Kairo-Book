Coordinates

Your goalTurn a table row into a point in a coordinate system, plot it using the scale of each axis, then read it back to check that it represents the same record.

Before you start
c004-m5 : rational equations

✿01 See the idea

You are filling a water bottle with volume markings under a gently running tap. Every minute, you read the level and write it in a notebook. Each row in the notebook keeps together two readings taken at the same instant: a time, in minutes (min), and a volume of water, in decilitres (dL). A decilitre is a tenth of a litre.

The notebook for this trial is fictional: its values were chosen for the lesson and are not actual measurements. It contains 5 records. At 0, 1, 2, 3 and 4 min, it gives 2, 4, 6, 8 and 10 dL respectively.

To see these rows at a glance, draw a coordinate system. The horizontal axis is marked in minutes: it is the time axis. The vertical axis is marked in decilitres: it is the volume axis. They meet at a right angle at a point O, the origin, which represents both 0 min and 0 dL.

The row “3 min, 8 dL” becomes a point. From O, move 3 min along the horizontal axis, then move up 8 dL, parallel to the vertical axis. Write this point as (3 ; 8). These numbers are its coordinates. The first, called the x-coordinate or abscissa, is read on the horizontal axis; the second, called the y-coordinate or ordinate, is read on the vertical axis. A semicolon separates them to avoid confusion with a decimal comma.

The order matters: it is stated with the coordinate system, here (time ; volume). Swapping the numbers gives (8 ; 3), which would mean 8 min and 3 dL. This is a different point, and a record that the notebook does not contain, since it stops at 4 min.

Finally, a point tells us nothing about what happened between two readings. Draw separate points without joining them: a line between them would assert volumes that nobody read. That would require an additional rule, which is not given in this unit.

The rule to remember

A coordinate consists of a number, the axis it belongs to and its unit. First move according to the first coordinate along the horizontal axis, then move up according to the second; read the point back to recover exactly the same table row.

✿02 Follow an example

Worked example

Plot the record at 3 minutes on graph paper

You have a sheet of graph paper. On the horizontal axis, one square represents 1 min; on the vertical axis, one square represents 2 dL, so that the 10 dL of the last record fit on the sheet. Let us plot the record at 3 min, then read it back to check.

  1. Read the row and identify each number

    Let t be the time elapsed since filling began, in minutes, and V the volume of water in the bottle, in decilitres. The chosen row gives t = 3 min and V = 8 dL. These two numbers belong to the same record: keep them together.

    The coordinate system states the order (t ; V): time first, then volume. The point we want is therefore written as follows.

    P=(t;V)=(3;8)

  2. Set up the coordinate system and its scales

    Draw the axes at right angles and mark the origin O = (0 ; 0). Let h be the value represented by one horizontal square, h = 1 min per square, and k the value represented by one vertical square, k = 2 dL per square.

    Assumptions for plotting: each axis starts at 0 at the origin, and all squares along the same axis represent the same quantity. The two axes can have different scales because they measure different things; a horizontal length therefore cannot be compared directly with a vertical length.

  3. Move along according to the first coordinate

    To find how many squares to move, divide the quantity by the value represented by one square on that axis. The minutes cancel, leaving a number of squares, denoted by a.

    a=th=3 min1 min par carreau=3 carreaux

    From O, move 3 squares to the right along the time axis. Do not move up yet.

  4. Move up according to the second coordinate

    Use the same reasoning on the vertical axis, with its own scale. Denote the number of squares to move up by b.

    b=Vk=8 dL2 dL par carreau=4 carreaux

    From the position reached, move vertically up 4 squares. Mark the point, then write its label (3 ; 8) beside it. Moving up 8 squares would be wrong: each vertical square represents 2 dL, which would place the point at twice the volume.

  5. Check by reading the point back

    Reverse the construction. From the point, go down to the horizontal axis and count 3 squares along that axis from the origin; from the point, go across to the vertical axis and count 4 squares along that axis from the origin. Multiply each count by the scale of its axis.

    a×h=3×1=3 min
    b×k=4×2=8 dL

    This recovers exactly the notebook row. A second check, independent of the calculation: the point must be higher than the one at 2 min (6 dL) and lower than the one at 4 min (10 dL), as in the notebook. It is.

  6. Compare with the reversed pair

    Apply the same method to (8 ; 3). You would have to move 8 squares along, representing 8 min: this is 4 min after the last record, which is at 4 min. You would then have to move up 3 ÷ 2 = 1.5 squares, between two scale marks.

    This point exists in the coordinate system, but no notebook row corresponds to it. Reversing the pair has changed the role and unit of each number; it has not produced another way of writing the same record.

Explain it in your own words

Without looking back, explain why you move up 4 squares, rather than 8, to represent 8 dL. Then explain why the reversed pair does not identify the same record.

✿03 Common mistakes

  • “The height of the point gives the time.”

    Read the name of each axis before reading a value. Here, height is read on the vertical axis, which gives volume in decilitres. Read the time by going down from the point to the horizontal axis.

    Review the diagram of the notebook and coordinate system

  • “Coordinates are two numbers with no order.”

    The order is stated with the coordinate system: (time ; volume). Swapping the numbers sends the point to 8 min, a time that the notebook does not contain. The first coordinate is always read on the horizontal axis.

    Revisit the step on the reversed pair

  • “Joining the points must give the values between them.”

    Each point comes from a notebook row. Between two records, no reading was taken: a line would propose volumes with no source. An additional rule is needed; it will be studied in the next unit.

    Redo the exercise on the point that contradicts the notebook

Exercise 1 · Guided reading

Recover the record represented by a point

On the sheet used in the example (one horizontal square represents 1 min and one vertical square represents 2 dL), a point is placed 2 squares to the right of the origin and 3 squares above it. Give its coordinates with their units. Does it correspond to a notebook row?

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Multiply each number of squares by the value represented by one square on its own axis.

Hint 2

Write the time first, then the volume, and look for that row in the notebook.

Compare with the solution

Time: 2 squares × 1 min = 2 min. Volume: 3 squares × 2 dL = 6 dL. The point is (2 ; 6).

The notebook does give 6 dL at 2 min: this point represents that record. Reverse check: 6 ÷ 2 = 3 squares. Answering “3 dL” would mean forgetting the vertical scale.

Check your reasoning

  • The coordinates are in the order (time ; volume).
  • Each number has its unit, minutes or decilitres.
  • The scale of each axis is used separately.
  • The result is compared with the notebook as well as calculated.

Exercise 2 · Change of unit

The same record, written in litres

A friend records volumes in litres (L). One litre equals 10 dL. Write the record at 3 min with the volume in litres. On your friend’s vertical axis, one square represents 0.2 L: how many squares should the point be moved up? Is the point in the same place as yours on the sheet?

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

A decilitre is a tenth of a litre: multiply the number of decilitres by that fraction.

Hint 2

To count the squares, divide the volume in litres by the value represented by one square, also in litres.

Compare with the solution

One decilitre equals 1 ÷ 10 = 0.1 L. So 8 dL = 8 × 0.1 L = 0.8 L, and the record is written (3 ; 0.8) in the coordinate system (min ; L).

Squares to move up: 0.8 ÷ 0.2 = 4, meaning 8 tenths of a litre divided into groups of 2 tenths. This is the same number of squares as in the example: the point is in the same place.

The second coordinate has a different numerical value because its unit has changed; the record and position have stayed the same. A coordinate written without a unit would therefore be ambiguous.

Check your reasoning

  • The conversion starts from one decilitre being equal to a tenth of a litre.
  • The scale and volume are expressed in the same unit before division.
  • The conclusion distinguishes the number written from the quantity represented.

Exercise 3 · Diagnosis

The point that contradicts the notebook

A classmate has plotted the points (0 ; 2), (1 ; 4), (2 ; 6), (3 ; 4) and (4 ; 10). How many agree with the notebook? For the one that differs, give the difference in decilitres and then in squares, using the scale from the example. Is joining the points enough to correct it?

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Compare row by row: at the same time, the volumes must be equal.

Hint 2

Convert a vertical difference in decilitres to squares using the vertical scale.

Compare with the solution

At 0, 1, 2 and 4 min, the proposed volumes equal those in the notebook. At 3 min, the notebook gives 8 dL and the point proposes 4. Therefore, 1 point out of 5 disagrees, and 5 − 1 = 4 points agree.

Difference: 8 − 4 = 4 dL, or 4 ÷ 2 = 2 squares. The point is too low: move it up 2 squares without changing its x-coordinate.

Joining the points corrects nothing and adds no records. A point can be neatly drawn and still contradict the data: comparison with the table decides whether it is correct, rather than the appearance of the drawing.

Check your reasoning

  • The comparison is made at the same time, row by row.
  • The number of agreeing points is a justified whole number.
  • The difference is given in decilitres, then converted using the vertical scale.
  • The answer rejects drawing a line as a way to correct the point.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What does a point in a coordinate system represent?

An ordered pair of coordinates: the first is read on the horizontal axis and the second on the vertical axis, each with the unit of its axis.

Recall 2In the bottle’s coordinate system (time ; volume), what does the first number in (3 ; 8) mean?

3 minutes, read on the horizontal axis. The second number, 8, represents 8 decilitres on the vertical axis.

Recall 3How do you convert a value to the number of squares to move?

Divide the value by the value represented by one square on that axis, then check by multiplying the number of squares by that same scale.

Recall 4Do the notebook points give the volume at a time that was not recorded?

No. A point comes from a recorded row; between two records, an additional rule would be needed, and none is given here.

Recall 5Why is a graph without axis names or units insufficient?

You can no longer tell which number represents time or volume, or in what unit; the point no longer lets you recover the meaning of the record.

Reconstruct the reasoning

A table row becomes a point: name the axes and their units, state the order of the coordinates, move along according to the first and up according to the second by dividing each value by the scale of its axis, then read the point back to recover the row. Without an additional rule, do not join the points.
