Level 3 · C105·M2

Multi-head attention

Your goalCalculate the outputs of several heads from the same input, concatenate them, then apply their output projection, checking the dimensions.

Before you start
c104-m5 : temporal validation · c102-m5 : finite difference checking · c050-m5 : conditioning · c105-m1 : queries-keys-values

✿01 See the idea

Consider the fictional phrase “cat sleeps”. When building the new representation of “sleeps”, one head may give more weight to “cat”, another to “sleeps”. They work on the same input, with their own settings. The second head does not receive the output of the first.

Each head produces a mixture of values. These values are themselves transformations of the input representations: heads differ in more than where they look. We will keep their results separate, then combine them.

Concatenating means placing coordinates end to end, in a fixed order. The output projection then multiplies this long row by a matrix: it can add, subtract or otherwise combine the heads’ coordinates. Concatenation alone does not calculate an average.

All numbers in this scene are fictional and have no physical unit; they are coordinates and coefficients. They were not learned from texts. The word labels help us keep track of rows; they do not establish a grammatical function for the heads. A diversity of learned relationships is possible, but the number of heads does not guarantee it.

The rule to remember

Same input, projections specific to each head; separate mixtures; coordinates concatenated in a fixed order; output projection.

✿02 Follow an example

Worked example

The new row for “sleeps”

We calculate only the output associated with “sleeps”, using 2 heads with 1 coordinate each. The attention weights are supplied after normalization, as input data for the calculation. We will calculate the value projections, mixtures and their recombination in full; we do not claim to recalculate numerical queries and keys that have not been provided.

  1. Define the objects and dimensions

    X is the matrix of representations for the phrase: n rows, one per word, and d coordinates per row. Here n = 2 and d = 2. The rows are row vectors, in the order cat, sleeps. h = 2 is the number of heads; i denotes a head, named a or b in the example. The letters d_k and d_v denote the width of queries and keys, and the width of values, respectively; here they equal 1 and 1.

    X=(4008)

    The matrix W_i^Q transforms an input row into a query, W_i^K into a key and W_i^V into a value. The query and key matrices have shape d × d_k; the value matrix has shape d × d_v. They are specific to the head and are normally adjusted during training. We treat them as fixed during this calculation. All numerical quantities have no physical unit.

    Assumptions: self-attention over the whole phrase, with no visibility mask, no bias added to the projections and no random dropping of coordinates. We study only the multi-head operation, with no addition of the input to the output and no other sublayer. Positions will be covered in the next unit.

  2. Reconstruct the mechanism shared by the heads

    Qi=XWiQ;Ki=XWiK;Vi=XWiV
    Pi=softmax(QiKiTdk);Hi=PiVi

    hympkx snuegg wyditz zqzful szmjcw punbqh yvvh T means transpose: rows and columns are exchanged. The product Q_iK_iᵀ compares each query with each key. The square root of d_k is the scaling factor for the scores. hsggzm jdwgqw mnibyz vnmoov jihxkr kdraxx gqay

    The softmax function acts separately on each row of scores: for a score s_j, it gives exp(s_j) divided by the sum of exp(s_l) over visible words. exp is the exponential function; j and l index words. Each weight is positive and the row sums to 1. This reminder of C105·M1 explains where the weights come from; below they are supplied, without inventing values for Q_i and K_i.

    For the “sleeps” row, the weights are (3/4 ; 1/4) in a and (1/4 ; 3/4) in b, always in the order cat, sleeps. Check: 3/4 + 1/4 = 1, and 1/4 + 3/4 = 1. This check is needed in each head; adding the weights of all heads is not the normalization used here.

  3. Project the values before mixing them

    Choose the following projection columns. Head a extracts the left coordinate of each word; b extracts the right coordinate. These are particularly simple linear projections, not grammatical functions.

    WaV=(10);WbV=(01)

    In a, the value for cat is 4 × 1 + 0 × 0 = 4. The value for sleeps is 0 × 1 + 8 × 0 = 0. The column V_a is therefore (4 ; 0), with one row per word.

    In b, the value for cat is 4 × 0 + 0 × 1 = 0. The value for sleeps is 0 × 0 + 8 × 1 = 8. The column V_b is (0 ; 8). Check: multiplying a 2 × 2 matrix by a 2 × 1 column does give a 2 × 1 column.

  4. Calculate each mixture for “sleeps”

    Call the output rows of heads a and b at the “sleeps” position u_a and u_b. Since d_v = 1, each contains a single number. The weight for cat multiplies the value for cat in that same head; the weight for sleeps multiplies the value for sleeps.

    ua=3/4×4+1/4×0=3+0=3
    ub=1/4×0+3/4×8=0+6=6

    Check the bounds: 3 lies between 0 and 4, and 6 between 0 and 8. Positive weights summing to 1 produce a mixture between the extreme values of each head. This checks the mixtures before the output projection.

  5. Concatenate while keeping the results separate

    The concatenation c = (u_a ; u_b) is the row vector (3 ; 6). The semicolon here separates coordinates in the same row; it does not mean vertical stacking. We keep the order a then b. The width is h × d_v = 2 × 1 = 2.

    Taking the average would give (3 + 6)/2 = 4.5, a single number. This would be a different operation: we could no longer take the sum and difference of the original results separately.

    For all positions at once, C = concat(H_a, H_b) is a matrix with shape n × (h d_v), built by placing the heads’ columns side by side. c is its row corresponding to sleeps.

  6. Apply the output projection

    W^O is the output projection matrix, with shape (h d_v) × d. The superscript O denotes output, not a power. For the whole phrase, Y = CW^O has shape n × d; here we calculate only its row y = cW^O for sleeps.

    WO=(111-1)

    Multiplying a row by a matrix uses each column of the matrix. First coordinate of y: 3 × 1 + 6 × 1 = 9. Second coordinate: 3 × 1 + 6 × (-1) = -3. Thus y = (9 ; -3), with no physical unit.

    The first column specifies a sum; the second, a difference. This projection could be learned with other coefficients. It is not another normalization of the attention weights.

  7. Check by working backwards

    The dimensions are consistent: (1 × 2) multiplied by (2 × 2) gives a 1 × 2 row. The output does have the same width as the input; no general equality between h d_v and d was needed to allow the projection.

    Our particular choice of W^O is reversible: half the sum of the output coordinates recovers u_a, and half their difference recovers u_b. Indeed, (9 + (-3))/2 = 3, and (9 − (-3))/2 = 6. This check uses the final results in reverse; an arbitrary projection would not necessarily be reversible.

    cwlwcn imlihp twxmmn mgyojp xcmaqv ppbxap ungn W^O may contain negative coefficients. A multi-head output is therefore neither a probability nor necessarily a number between the input values.

✿03 Common mistakes

  • “Head b continues the work of head a.”

    In this layer, each head projects the same input X. Draw the branches from X, with no line between the heads. Software may execute the calculations sequentially; this does not turn their mathematical dependency into a chain.

    Find the shared input in the diagram

  • “Concatenating outputs means calculating their average.”

    Write the row (3 ; 6), then count its 2 coordinates. The average 4.5 would keep only one. The matrix W^O needs the separate coordinates to calculate the difference.

    Review the concatenation and final product

  • “Since attention uses positive weights, its output cannot be negative.”

Exercise 3 · Transfer · resolving an objection

Can the heads be swapped without changing anything?

Return to the original data. Someone concatenates b then a, keeping W^O as it is, and claims that the names of the heads make no difference. Calculate the resulting output. What change to W^O recovers exactly the original output? Justify it for arbitrary head outputs.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The row becomes (6 ; 3). The second output coordinate is still the first input minus the second.

Hint 2

Each row of W^O specifies the contribution of a concatenated coordinate. If that coordinate changes position, also move its corresponding row.

Compare with the solution

With W^O unchanged, the new output is (6 + 3 ; 6 − 3) = (9 ; 3). The sum is preserved, but the difference has changed sign: this is not the original output (9 ; -3).

The rows of W^O must be swapped to associate each head result with its coefficients again. The corrected matrix is:

WO′=(1-111)

For arbitrary outputs u_a and u_b, (u_b ; u_a) multiplied by this matrix gives (u_b + u_a ; −u_b + u_a), which recovers the original sum and difference. Numerically, we recover (9 ; -3). The prime simply marks the modified matrix. What matters is the correspondence between a head’s result and the rows of the projection, rather than the head’s name.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What do the heads in the same layer receive, and what can they transform differently?

They receive the same input X. Each head has its own query, key and value projections, so it can produce its own weights and values. The heads do not form a chain.

Recall 2What does the sum of weights equal to 1 apply to?

For a given query position and head, it applies to the visible words. The weights of all heads are not normalized together. The output matrix W^O is not subject to this constraint.

Recall 3What does concatenation preserve, and what is its width?

It preserves the coordinates of the head outputs in a fixed order by placing their columns side by side. Its width is h × d_v; averaging across heads would perform a different operation and lose their separation.

Recall 4How does the concatenated row become an output of width d?

It is multiplied on the right by W^O, with shape (h d_v) × d. Its coefficients combine the heads’ coordinates; they are not necessarily positive or normalized.

Recall 5What does simply having several heads fail to demonstrate?

It demonstrates neither distinct grammatical functions nor a measured improvement. Heads can be redundant. Their number describes an architecture; their role and usefulness require separate evidence.
