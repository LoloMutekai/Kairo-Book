Data leakage

Your goalIdentify which information crossed the boundary between training and test data, recalculate its effect and repair the protocol without confusing a favorable score with a valid evaluation.

Before you start

✿01 See the idea

At 8 on the twenty-four-hour clock, you want to predict the energy a house will consume between 18 and 22. You already know the energy consumed since midnight. You do not yet know the evening consumption. In a historical data file, both appear side by side: their proximity in the file does not make them available at the same time.

Let x be the morning energy consumption, available at prediction time, and y the evening energy consumption to be predicted. They are expressed in kilowatt-hours, written kWh, a unit of energy. Data leakage occurs when information forbidden by the situation being evaluated enters the preparation, selection or calculation of predictions. It can come from the future, but also from the test set used to tune the method.

The training set is used to learn the parameters. The validation set lets you compare choices before finalizing them. The test set is used to evaluate the finalized method. Here, we study a rule that has already been chosen: predict as much energy consumption in the evening as in the morning. If x is missing, replace it with the mean of the training mornings. This replacement is called imputation; its mean is therefore also a learned parameter.

The agreed protocol for this example is precise: freeze the rule and the mean before all the test days, then apply them without learning them again between those days. We are not evaluating a method that adapts continuously. The days and all the values are fictional. The rule is deliberately simple to isolate a case of leakage; it is not a recommended energy forecasting method.

The rule to remember

Separating the rows is not enough: every learned parameter must stay on the permitted side, and every variable must be available at prediction time. The test answers are then used to calculate the score.

✿02 Follow an example

Worked example

A missing morning value, two ways to fill it

Days A and B form the training set: their x values are 2 and 4 kWh. Test days C and D come later: x is 8 kWh for C and is missing for D; after the evenings, we observe y = 8 kWh for C and y = 8 kWh for D. The rule and the choice of mean imputation were finalized before the test. Let us calculate the predictions and their mean absolute error.

  1. Set the protocol and define the symbols

    A, B, C and D name days; they are not quantities. mrspcz flpxyw qedaqr onvjqb giuxey zxwjfy uvfg The hat in ŷ denotes a predicted value. x, y, ŷ and the means are in kWh. n_T = 2 counts the observed training mornings; n_E = 2 counts the days evaluated, with no physical unit.

    The mean m_T is calculated from A and B only. The rule is ŷ = x if x is observed, and ŷ = m_T if x is missing. The implicit coefficient is 1, with no unit. The symbol E will denote the mean absolute error over C and D, in kWh: the bars |…| give the distance between prediction and observation.

    Exercise assumptions: the known morning value is available at 8 h; the missing morning value remains missing at that time; the evening reference values are recorded after the prediction. The sets are fixed, with no further adaptation during the test. We do not assume that these days are enough to represent all future uses of the house.

  2. Learn the mean from the right set

    Adding the permitted morning values gives 2 + 4 = 6 kWh. Dividing by their count gives the replacement value. No test row contributes to this operation.

    mT=xA+xBnT=62=3 kWh

    This mean is now frozen. Observing the morning value for C allows us to predict C; it does not permit us to learn the replacement for D again under the stated protocol.

  3. Predict before checking evening consumption

    C has an x value: the rule gives ŷ_C = 8 kWh. D does not: apply the learned replacement, giving ŷ_D = 3 kWh. meiewv zxmygu npyzjb vkeaqr jokhkv qxmfnl pslx

    A day with a missing value is not removed from the score because it is difficult. The agreed protocol here evaluates the 2 days C and D, including the handling of a missing value.

  4. Measure the error using the revealed reference values

    E=|yC−y^C|+|yD−y^D|nE

    For C: |8 − 8| = 0 kWh. For D: |8 − 3| = 5 kWh. Taking absolute values prevents differences with opposite signs from canceling out; adding these distances and then dividing by the number of days gives the mean error.

    E=0+52=5/2 kWh=2.50 kWh

    Consulting the test answers at this stage is used to measure a finalized method. Leakage would occur if they then fed back into its selection or tuning to produce a score presented as independent.

  5. Let test data enter through the replacement

    Now imagine a preparation error: calculating the mean over all present x values before separating the sets. We combine 2, 4 and 8 kWh. The x value for D is missing: it contributes neither to the sum nor to the count of present values. Call this overall mean m_G.

    mG=2+4+83=14/3 kWh≈4.67 kWh

    The training and test rows can then be placed in separate files: the contamination is already in m_G. C keeps the same prediction; D is now predicted at 14/3 kWh, or about 4.67 kWh. Test day C has influenced a parameter that should have been learned only from A and B.

  6. Recalculate the contaminated score and check it

    The error for C is still 0 kWh. The error for D becomes |8 − 14/3| = 10/3 kWh. Their sum is 10/3 kWh; divided by 2, it gives 5/3 kWh, about 1.67 kWh.

    This score is lower than the previous 2.50 kWh, but it evaluates a different preparation procedure, which used the test set. This fictional decrease proves no real improvement. Leakage can also leave the score unchanged or make it worse: it is defined by the path of information, not by a score that is always better.

    Independent check: C contributes no error, so each mean error must be the error for D divided by 2. Also, the contaminated replacement exceeds the permitted replacement by 5/3 kWh. Both remain below 8 kWh: this shift reduces the error for D by exactly the same amount. These observations cross-check the fractions without rounding during the calculation.

  7. Repair the protocol at the information boundary

    Keep the raw sets, learn m_T from A and B only, then reuse this same m_T to replace the missing x value for D. Merely moving rows after imputation does not remove information that has already crossed the boundary. Comparisons between preparation choices belong in validation; implementing this sequence in software will be the subject of the next unit.

    If a test result has already guided a change to the method, that set has been used for development. Keep a record of this fact and plan to use a still untouched test set for an independent final evaluation. The scores on this page are a teaching calculation on fictional data, with no implications for performance on future days.

✿03 Common mistakes

  • “The test rows are elsewhere, so the separation is safe.”

    If their information has already been used to calculate a shared mean, it travels in that parameter. Start again from the raw data, learn the mean from the training set and then apply it without recalculating it on the test set.

    Follow the calculation of the overall mean

  • “I have never looked at y, so leakage is impossible.”

    dszurw zverxh qbxanz fqjyaz luvnwc zkduwv jnuj Using it to predict C, however, is permitted. Ask which operation each piece of information is permitted for, and at what time.

    Review the agreed protocol for the frozen test

  • “The test favors this mean, so I can choose it.”

    The score has then been used to select the method. This set no longer provides a final evaluation independent of that choice. Use validation to compare methods and an untouched test set for the final assessment.

Exercise 1 · Identification

An accurate column, available too late

In the same house data file, an “evening energy consumption” column is filled in after 22 h. Someone wants to include it among the inputs for the prediction at 8 h because it is complete. Can it be used? Can it still be used to score a prediction recorded in the morning?

Assisted answer: try this exercise without help later.

Hint 1

Distinguish when the value is present in the historical file from when it is available during the day.

Hint 2

The same reference value can be forbidden as an input and necessary for calculating the error afterwards.

Compare with the solution

This column gives y, the very quantity that is unknown at 8 h. Using it as an input would feed the future answer back into the prediction. It remains legitimate after 22 h for comparing ŷ and y, provided that the prediction and parameters were finalized beforehand.

The repair consists of removing this column from the inputs and checking the time of origin of every input retained. A value that is accurate at analysis time may be unavailable at decision time.

Check your reasoning

  • Name the target y and the time when it becomes available.
  • Distinguish its forbidden role in the inputs from its permitted role in the score.
  • Propose a repair before calculating the predictions.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1How can you recognize leakage without relying on the score?

Reconstruct the information permitted for each parameter and each prediction. Under the stated protocol, information from the future or reserved for evaluation must not feed back into the preparation or selection of the method. The score does not need to decrease for leakage to occur.

Recall 2Why can a mean calculated without y still contaminate our test?

Because the mean is a learned parameter. rnrdvg tsjdoo fkppdx dqdmek wsxfgo wbwqbm aczc Our protocol requires it to be learned from A and B only, then frozen.

Recall 3When can evening consumption be used without becoming a forbidden input?

After the prediction has been finalized, to calculate its error. At the time of the morning prediction, it is still unknown. If its result is then used to select the method, the set becomes a development resource.

Recall 4What should changing C show in the cross-check on D?

With the replacement learned from A and B and frozen, changing only C must not change the prediction for D. A change here reveals an improper dependency; the absence of a change does not guarantee that all other leakage paths are closed.

Recall 5Can a test already used to make choices become untouched again after the program is corrected?

No: its results have already guided decisions. It remains useful for diagnosis. Choices must be finalized using separate validation, followed by evaluation on a still untouched test set to support a claim of an independent final evaluation.

Reconstruct the reasoning

Hide the page and reconstruct the path: what is available in the morning; the set used to learn the replacement; the frozen rule; the recorded predictions; the reference values revealed for the score. Then draw the forbidden path from C to the mean and then to D. Finally, explain why repairing this path does not make a test already used to make choices untouched again.
