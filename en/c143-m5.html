Level 2 · C143·M5

Uniform convergence

Your goalDistinguish an index chosen for each point from an index that works everywhere, then prove or disprove uniform convergence on a stated domain.

Before you start
c142-m5 : convergence criteria · c045-m5 : introductory quadrature · c046-m5 : approximation error · c143-m1 : rigorous continuity · c143-m2 : compactness · c143-m3 : Riemann integration · c143-m4 : sequences of functions

✿01 See the idea

An imaginary lamp brightens gradually. Each new version of its controller makes it brighten faster. We want to approach an ideal target: the lamp is off at the initial instant, then immediately at full brightness. Observing it at the same fixed time after the start eventually gives exactly the expected result.

But you can also examine each version while it is brightening. However fast it brightens, it still passes through half the required brightness. That instant moves closer to the start as the version changes. A curve can therefore meet the target at each fixed time while still having a large error somewhere.

Pointwise convergence checks times individually, with a waiting index that may depend on the time. Uniform convergence requires the same index for the entire domain: from that index onward, the whole curve must stay within the chosen tolerance of the target.

The curves and values are imaginary. Relative brightness is a dimensionless fraction of full brightness; it does not measure actual illuminance. We observe the initial duration T = 1 s and use dimensionless normalized time x = t/T. The diagrams use the same scale: they do not enlarge the brightening ramp of the second version.

The rule to remember

Fix the domain and tolerance, then look for a common index for all its points. To disprove the existence of such an index, a different point at each index may be enough.

✿02 Follow an example

Worked example

A shorter ramp does not make the error small everywhere

On D = [0, 1], compare all controller versions for the same lamp with the same target. We will calculate brightness and error using exact values, then check what changes when we exclude a fixed initial duration.

  1. Write the model and its target

    n is the integer index of the controller version, n ≥ 1; it is not time. t is time in seconds, T = 1 s is the reference duration, and x = t/T belongs to D. The function fn gives relative brightness at index n. The notation min takes the smaller of its arguments: the ramp nx is capped at full brightness 1.

    fn(x)=min(nx,1)

    The target f equals 0 for x = 0 and 1 for x > 0. fn, f and their differences are dimensionless; a difference of 1/2 means half of full brightness. We assume exactly this ramp, with no noise or additional delay. Each fn is continuous: the branches meet at x = 1/n. The target has a jump at the origin.

  2. State where the index may depend on the point

    For real functions fn and f defined on the same domain D, ε denotes a strictly positive tolerance, in the unit of their values. N is an integer index at least equal to 1. |fn(x) − f(x)| is the absolute error, the distance between the values. The symbol ∀ reads “for all”, ∃ reads “there exists”, and ∈ means “belongs to”. The indices n below are integers.

    Pointwise convergence: first fix x. The index N may then depend on ε and x.

    ∀x∈D,∀ε>0,∃N≥1:∀n≥N,|fn(x)−f(x)|<ε

    Uniform convergence: N is chosen before the point x. It may depend on ε and the fixed domain, but it must work for all its points and all subsequent indices.

    ∀ε>0,∃N≥1:∀n≥N,∀x∈D,|fn(x)−f(x)|<ε

    Thus uniform convergence implies pointwise convergence: the common index still works for any fixed point. The reverse implication requires a proof and can be false.

  3. Calculate at index 4 and check the branch

    Given: n = 4 and x = 1/4, so t = 0.25 s. Multiplying the index by x gives 4 × 1/4 = 1. Taking the minimum with 1 therefore gives fn(x) = 1. Since x is positive, f(x) = 1. The error is 1 − 1 = 0 units of relative brightness.

    Now examine x = 1/8, so t = 0.125 s. The product is 4 × 1/8 = 1/2, less than 1: we are still on the ramp. The target equals 1, giving an error of 1 − 1/2 = 1/2 units of relative brightness.

    Independent check: the ramp lasts T/n = 0.25 s. The instant 0.125 s is exactly halfway through it, so the linear ramp must be at half brightness. The other instant is at the end of the ramp: its 0 error is consistent. A correct result at a single instant is not enough to certify the entire curve.

  4. Prove pointwise convergence for each fixed time

    At x = 0, fn(x) = f(x) = 0 at every index: the error is already 0. Now fix a strictly positive x. We can choose an integer N ≥ 1/x. Then, for all n ≥ N, nx ≥ 1 and the cap gives fn(x) = 1 = f(x). The 0 error is less than every positive tolerance.

    This reasoning covers all points of D and proves pointwise convergence to f. But the chosen index depends on x: the closer x is to the origin, the larger 1/x becomes. We have not yet provided a common index for all of D.

  5. Construct a counterexample point that works at every index

    Fix a tolerance ε = 1/4 units of relative brightness. For each n ≥ 1, choose the point xn = 1/(2n). The subscript indicates that the point changes with the index. It belongs to D and remains strictly positive, so its target equals 1.

    nxn=n12n=1/2;|fn(xn)−f(xn)|=1−1/2=1/2

    The error therefore always equals 1/2, greater than ε = 1/4. For any proposed index N, taking n = N and this xn contradicts the uniform condition. This disproves uniform convergence at all indices, not just those shown in the diagrams.

    At index 8, the counterexample point becomes xn = 1/16 and gives 8 × 1/16 = 1/2, then an error of 1/2. At the previous point 1/8, the brightness now equals 8 × 1/8 = 1. The error has moved; its height has not decreased.

  6. Measure the error over the entire domain

    When the errors are bounded on D, denote their supremum by En(D), using the symbol sup. It is the smallest number that bounds them all from above; it may not correspond to any point. The distinction from a maximum is necessary here.

    En(D)=supx∈D|fn(x)−f(x)|

    We write En(D) = sup { |fn(x) − f(x)| : x ∈ D }. Uniform convergence is equivalent to En(D) → 0. Indeed, En(D) < ε controls the error at all points. In the other direction, applying the uniform definition with ε/2 gives En(D) ≤ ε/2 < ε; this handles the case where the bound is not attained.

    For our lamp, if 0 < x < 1/n, the error equals 1 − nx. It equals 0 at the origin and whenever x ≥ 1/n. All errors are strictly less than 1, but taking positive x as close to the origin as desired makes them approach 1. Thus En(D) = 1 for each n, with no maximum equal to 1. This bound does not tend to 0: it confirms the disproof.

  7. Keep the same lamp and change the stated domain

    Exclude a fixed initial duration: Da = [a, 1], where a is a fixed number with 0 < a ≤ 1. On this domain, f equals 1 everywhere. The error decreases as x increases until the cap is reached, so its largest value is at the endpoint x = a.

    En(Da)=max(1−na,0)

    For a = 1/4, n ≥ 4 gives na ≥ 1. All controller versions from this index onward coincide exactly with f on Da: En(Da) = 0. This index works simultaneously for all points of the domain and every positive tolerance. Convergence is uniform there.

    Check at the previous index: 3 × 1/4 = 3/4, so the error at the endpoint equals 1/4. With the tolerance fixed at exactly 1/4, this index still fails, because the error equals the tolerance. More generally, choosing an integer N ≥ 1/a suffices for each fixed a. Letting a approach the origin changes the domain and the required index; it does not restore uniform convergence on D.

Explain it in your own words

Without rereading, explain why fixing x and then increasing n makes the error disappear, whereas choosing x after n can preserve the same error. Reconstruct the counterexample point and explain why excluding a fixed initial duration changes the conclusion.

✿03 Common mistakes

  • “I have found an index for each point, so I have found an index for the entire curve.”

    Check what N depends on. The choice N ≥ 1/x proves pointwise convergence; it changes with x. For uniform convergence, N must be chosen before knowing x and must work at all subsequent indices.

    Reread the order of choices and the pointwise proof

  • “The point that contradicts uniform convergence must stay the same when the index changes.”

    A claim about all points must withstand a point chosen after the index. Our xₙ = 1/(2n) is therefore allowed. Keeping it fixed would test a different question: pointwise convergence.

    Compare the counterexample points in the diagrams at the same scale

  • “A perfect grid proves that the error is small everywhere.”

    A grid only controls its own points. The last exercise leaves an entire ramp between the origin and the first positive grid point. Look for an upper bound valid over the interval or a counterexample point between the tested points.

    Test the conclusion drawn from the sampled points alone

Exercise 1 · Numerical application

A strict inequality at the endpoint

On [1/4, 1], calculate the largest error at index 3, then at index 4. For ε = 1/4 units of relative brightness, which of these indices can start a guarantee valid for all subsequent indices? Also justify where the error is largest.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

On this domain, the target equals 1. The ramp increases with x, then stays at the cap.

Hint 2

Calculate at the endpoint x = 1/4; an error equal to ε does not satisfy the strict condition.

Compare with the solution

The largest error is at the left endpoint: elsewhere, brightness can only increase toward the target. At index 3, the endpoint gives 3 × 1/4 = 3/4, then En = 1 − 3/4 = 1/4 units of relative brightness. This value equals ε, so it does not qualify.

At index 4, the endpoint reaches 1 and all other points are also at the cap: En = 0. For all n ≥ 4, nx ≥ 1 on this domain. Index 4 therefore starts the guarantee, with 0 error at all subsequent indices.

Check your reasoning

  • You justify choosing the endpoint by explaining how the error varies.
  • You find 1/4 then 0, in units of relative brightness.
  • You respect the strict inequality and cover all subsequent indices.

Exercise 2 · Proof on an interval

Move the endpoint closer to switch-on

The same controller is now studied on [1/8, 1]. The tolerance is ε = 1/8 units of relative brightness. Find the first index N guaranteeing an error strictly less than ε for every point and every n ≥ N. Prove that a smaller index does not suffice.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

At the endpoint, the error equals max(1 − n × 1/8, 0).

Hint 2

Compare indices 7 and 8; at lower indices, the error at the endpoint is even larger.

Compare with the solution

At index 7, the brightness at the endpoint is 7 × 1/8 = 7/8. The error equals 1 − 7/8 = 1/8, exactly ε. This index fails. For every lower index, the product at the endpoint is smaller and the error larger: none of these indices works.

At index 8, the endpoint reaches 8 × 1/8 = 1. For n ≥ 8 and x ≥ 1/8, nx ≥ 1. The entire curve on the domain is therefore at the cap, with an error of 0 < ε. The first index sought is N = 8.

This is a common index on a fixed interval. The need for a larger index as the endpoint approaches the origin is consistent with the failure on the full domain.

Check your reasoning

  • You propose N = 8 and prove that the error is controlled at all points.
  • You rule out 7 because the error equals ε, and all lower indices by comparison.
  • You keep the domain fixed throughout the reasoning.

Exercise 3 · Objection and transfer of a proof

All the tested points are perfect

We observe the lamp only at points x = 0, 1/4, 1/2 and 1. For each n ≥ 4, the error there is 0. Someone concludes that convergence is uniform on [0, 1]. Respond to this conclusion with a counterexample point valid at every index. Illustrate your answer at index 8, then state what proof would be needed to establish uniform convergence.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

A point on the ramp can lie between the origin and the first positive grid point.

Hint 2

Use xₙ = 1/(2n) again with a fixed tolerance; do not restrict yourself to the illustrated index.

Compare with the solution

The stated grid errors are indeed 0: at the origin, the values are 0; at the positive tested points, nx ≥ 1 whenever n ≥ 4. The grid calculation is correct, but it does not cover the other points of the interval.

For all n ≥ 4, xn = 1/(2n) is a positive point before 1/4. Its brightness equals 1/2 and its error equals 1/2. The fixed tolerance ε = 1/4 is therefore violated, even at an arbitrarily large index. At index 8, xn = 1/16 and 8 × 1/16 = 1/2; the error remains 1/2 units of relative brightness.

To establish uniform convergence, we would need a bound En on the same error valid for all points and tending to 0, or directly a common index for each tolerance. The maximum over the grid does not replace this bound. Here, the general proof instead gives En(D) = 1.

Check your reasoning

  • You acknowledge that the grid values are correct while limiting the scope of that result.
  • You fix a positive tolerance and construct a point that violates it at every index.
  • You distinguish a numerical illustration from the disproof for all indices.
  • You describe the proof needed for the entire domain.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1Which choice changes position between pointwise convergence and uniform convergence?

In pointwise convergence, the point is fixed before choosing the index: N may depend on that point. In uniform convergence, for each tolerance, a common index is chosen before the point; it works for all points of the domain and all subsequent indices.

Recall 2How can a point that changes at each index disprove uniform convergence for our lamp?

Choosing xₙ = 1/(2n) keeps the controller curve at 1/2 and the target at 1. The error 1/2 exceeds the fixed tolerance 1/4 at every index. No common index can therefore work on the full domain.

Recall 3What does Eₙ(D) represent, and why do we speak of a supremum here rather than a maximum?

Eₙ(D) is the least upper bound of all errors on D. For the lamp on [0, 1], it equals 1: the errors approach it near the origin without ever reaching it. Uniform convergence would require Eₙ(D) → 0.

Recall 4Why does the same sequence converge uniformly on [a, 1] for a fixed strictly positive a?

An integer N ≥ 1/a ensures nx ≥ 1 for all n ≥ N and all x ≥ a. All values then equal the target. The index is common on this fixed domain; the reasoning gives no common index when the domain includes positive points arbitrarily close to the origin.

Recall 5Why does a maximum error of 0 on a finite grid fail to prove uniform convergence on an interval?

It only controls the tested points. Errors can remain between them, as with the lamp’s ramp. A proof of uniform convergence covers all points of the domain and all indices beyond the same threshold.
