Level 3 · C183·M3

Implicit scheme

Your goalAdvance a finite difference diffusion calculation by one step with the implicit scheme: write the tridiagonal system, solve it by elimination and back substitution, then check it without confusing the absence of anomalies with accuracy.

Before you start
c167-m5 : initial and boundary value problem · c051-m5 : error diagnostics · c175-m5 : model limitations · c050-m5 : conditioning · c183-m1 : grid · c183-m2 : explicit scheme

✿01 See the idea

A thin rod is warm in the middle, and both ends are held at 0 °C. We track the temperature at 3 interior points, spaced 1 cm apart, and want to advance by one step of 1 s. The rod and its values are fictional: they are used for calculations and describe neither a real object nor a price.

The explicit scheme, introduced in the previous unit, calculates each new temperature using the old temperatures of its neighbours. This is direct. But with this step, it gives a result of −18 °C at the central point. In this diffusion model, a rod whose ends are at 0 °C and which contains only heat does not become colder than its ends. This negative sign is a diagnostic of numerical error, rather than physical information.

The implicit scheme changes just one part: exchange with neighbouring points is evaluated using the new values, the ones we are looking for. Each node then depends on its neighbours at the same instant, and we can no longer calculate the nodes one at a time. We must find them together by solving a small linear system.

This system is very sparse: each equation contains only its own node and the two neighbouring nodes, so its matrix is tridiagonal. Successive elimination followed by back substitution solves it in a single pass along the rod and back. The cost is a system to solve at each step; in this example, the benefit is that the same step no longer produces a negative temperature.

Assumptions: a constant diffusion coefficient, a regular grid, ends held at a prescribed temperature (0 here), and a single time step. This page does not establish the stability of the implicit scheme in general. It observes its behaviour in one case and teaches how to check a solution.

The rule to remember

Write the exchange with neighbouring points using the new values; set r = ν Δt / Δx²; solve the tridiagonal system for the step; check the solution using the residual, the balance and the expected range.

✿02 Follow an example

Worked example

One diffusion step on a fictional rod

Fictional values: ν = 2 cm²/s, Δx = 1 cm and Δt = 1 s, so r = 2 is dimensionless. The ends remain at 0 °C. The 3 interior points have temperatures of 0, 6 and 0 °C. Let us calculate the temperature after one step with the implicit scheme, then check it.

  1. Set out the quantities, units and assumptions

    The temperature u depends on position x in centimetres and time t in seconds; the model is ∂u/∂t = ν ∂²u/∂x², with constant ν in cm²/s. The grid has 4 equal intervals of width Δx, giving points x0 to x4; x0 and x4 are the ends. We write uᵢ for the known temperature at the current step and vᵢ for the unknown temperature at the next step, with v0 = v4 = 0 °C.

    The number r combines the three parameters:

    r=νΔtΔx2
    r=2×112=2

    The units cancel (cm²/s × s ÷ cm²): r is dimensionless. It compares how far diffusion spreads during one step with the width of a grid cell.

  2. See the failure of the explicit step

    The explicit scheme is written as:

    vi=ui+r(ui−1−2ui+ui+1)

    At the first point, the exchange term is 0 − 2 × 0 + 6 = 6, so v1 = 0 + 2 × 6 = 12 °C. At the central point, u1 − 2u2 + u3 = −12, so v2 = 6 − 2 × 12 = −18 °C. By symmetry, v3 = 12 °C. The result is 12 ; −18 ; 12 °C: it exceeds the initial maximum, 6 °C, and falls below the 0 °C of the ends. We keep this counterexample as a diagnostic: this step is unusable. It does not prove the stability limit from the previous unit; it makes that limit visible.

    As a reminder, the standard limit for the explicit scheme on this problem is r ≤ 1/2; our r exceeds it by a large margin.

  3. Write the implicit system

    In the implicit scheme, only the time level changes: the centred difference uses the new values.

    vi−ui=r(vi−1−2vi+vi+1)

    We move the unknowns to the left and set b = 1 + 2r:

    bvi−rvi−1−rvi+1=ui
    b=1+2r=1+2×2=5

    For the first and third points, v0 and v4 are known and equal to 0: their terms −r v0 and −r v4 vanish. If an end had a nonzero temperature, r times its value would move to the right-hand side. The three equations and their matrix form are:

    5v₁−2v₂=0−2v₁+5v₂−2v₃=6−2v₂+5v₃=0
    [5−20−25−20−25][v₁v₂v₃]=[060]

  4. Eliminate downwards

    We divide the first equation by b: v1 = q1 v2 with q1 = r/b, and its right-hand side 0 remains 0. We substitute v1 into the second equation, which becomes p2 v2 − r v3 = 6 with p2 = b − r q1. We divide by p2: v2 = g2 + q2 v3, with q2 = r/p2 and g2 = 6/p2. Each division is allowed because its divisor remains strictly positive.

    q₁=rb=25=2/5
    p₂=b−rq₁=5−2×2/5=21/5
    q₂=rp₂=221/5=10/21;g₂=621/5=10/7

    We now substitute v2 into the third equation. One equation with a single unknown remains: p3 v3 = r g2, with p3 = b − r q2.

    p₃=b−rq₂=5−2×10/21=85/21

  5. Back substitution

    The last equation gives v3. Each value already found is then used to find the preceding one.

    v₃=rg₂p₃=2×10/785/21=12/17
    v₂=g₂+q₂v₃=10/7+10/21×12/17=30/17
    v₁=q₁v₂=2/5×30/17=12/17

    The solution is 12/17 ; 30/17 ; 12/17 °C, or approximately 0.71 ; 1.76 ; 0.71 °C. The two outer values of the result are equal, as required by the initial symmetry, and the central point remains the warmest.

  6. Check in three ways

    Residual: we substitute the solution into the middle equation, which elimination changed the most.

    5×30/17−2×(12/17+12/17)=150/17−48/17=6

    The expected right-hand side is 6: the result is indeed 6. Balance: adding the three equations shows that the sum of the values plus r × (v1 + v3) must give the initial sum.

    54/17+2×(12/17+12/17)=54/17+48/17=6

    The sum falls from 6 to 54/17; the loss 48/17 is exactly r × (v1 + v3) = 48/17: this is the heat leaving through the ends at 0 °C. Range: 0.71 ; 1.76 ; 0.71 °C stay between 0 and 6 °C. These three checks validate the solution of this system. They do not tell us how accurate this step is or whether the model represents a real rod.

Explain it in your own words

Why can we no longer calculate the three new temperatures one at a time? Which checks of the solution do not require repeating the elimination, and what do they fail to prove?

✿03 Common mistakes

  • “The implicit scheme gives the new value at a node directly, just like the explicit scheme.”

    Each equation contains a new, unknown neighbouring value: the three values are coupled. First write the equations, then solve them together. Here the first equation contains v₁ and v₂, never v₁ alone with known values.

    Review how to write the system and perform elimination

  • “An output with no negative temperature proves that the result is exact, whatever the step size.”

    The absence of anomalies does not establish accuracy. Check the solution using the residual and the balance, then measure the effect of Δt with convergence tests, the subject of unit c183-m5. This page gives no numerical assessment of accuracy.

    Repeat the balance calculation in exercise three

  • “The ends are at 0 °C, so they do not appear anywhere in the system.”

    They are 0 here: their contribution r × v₀ vanishes. If an end had a nonzero temperature, r times its value would be added to the right-hand side for the first or last point. The ends also enter the balance, where the loss is r × (v₁ + v₃).

    Review how to write the system

Exercise 1 · Guided application

An implicit step with a smaller r

Use the same fictional rod and the same initial temperatures (0, 6, 0 °C), but with ν = 1 cm²/s: r is therefore 1. Write the implicit system, solve it using the symmetry v₁ = v₃, then check the first equation.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

First calculate b = 1 + 2r, then write the three equations.

Hint 2

The first equation relates v₁ to v₂: express v₁ in terms of v₂ and substitute it into the second equation.

Hint 3

Since v₃ = v₁, the second equation becomes b v₂ − 2r v₁ = 6. Multiply by b to eliminate the fraction.

Compare with the solution

The coefficient is b = 1 + 2 × 1 = 3. The equations are 3v1 − 1v2 = 0, then −1v1 + 3v2 − 1v3 = 6, then −1v2 + 3v3 = 0. The symmetry of the system and the right-hand side gives v1 = v3: if a solution exists, its reflection is also a solution, and the solution is unique because the determinant is nonzero.

The first equation gives v1 = q v2 with q = r/b = 1/3. In the second: b v2 − 2r q v2 = 6, so (b² − 2r²) v2 = b × 6. Here b² = 9 and 2r² = 2, giving the reduced determinant 9 − 2 = 7 and the right-hand side 6 × 3 = 18. Thus v2 = 18/7 = 18/7, or approximately 2.57 °C, then v1 = v3 = 1/3 × 18/7 = 6/7, or approximately 0.86 °C.

Check: 3 × 6/7 − 1 × 18/7 = 0, as the first equation requires. The three values stay between 0 and 6 °C.

Check your reasoning

  • The written system has b on the diagonal and −r on either side.
  • The symmetry is justified, rather than simply used.
  • The three values are given with the unit °C and checked in an equation.

Exercise 2 · Diagnostic

The explicit step, even with a smaller r

With r = 1, calculate one explicit step starting from (0, 6, 0) °C. Compare it with the implicit result from the previous exercise: which respects the expected range between 0 and 6 °C?

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The exchange term at the first point is 6, as in the example: it does not depend on r.

Hint 2

For the central point, the absolute value of the exchange term is 12, and its sign is negative.

Compare with the solution

First point: 0 + 1 × 6 = 6 °C. Central point: 6 − 1 × 12 = 6 − 12 = −6 °C. Third point, by symmetry: 6 °C. The explicit step therefore gives 6 ; −6 ; 6 °C.

The negative value falls outside the range, and the first point already reaches the initial maximum. The implicit step from the previous exercise gives 6/7 ; 18/7 ; 6/7 °C, all between 0 and 6 °C. The value r = 1 still exceeds 1/2, the standard threshold for the explicit scheme on this problem: this calculation supplies a counterexample, rather than proving the threshold, and does not assess the accuracy of the implicit solution.

Check your reasoning

  • The sign of the exchange term at the central point is handled correctly.
  • The comparison concerns the expected range, rather than an impression.
  • The conclusion distinguishes a counterexample, a proof and accuracy.

Exercise 3 · Independent check

Balance of the heat lost

In the example, calculate the sum of the three new values and its difference from the initial sum. Show that this loss equals r × (v₁ + v₃), then explain why a loss is expected here.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Add the three equations of the system, column by column.

Hint 2

The coefficients of v₁ and v₃ become b − r; that of v₂ becomes b − 2r, which equals 1.

Hint 3

The ends are at 0 °C: heat can leave through them, and the model supplies none.

Compare with the solution

Adding gives (b − r)v1 + (b − 2r)v2 + (b − r)v3 = 6 + 0 + 0. Since b − 2r = 1 and b − r = 1 + r, this can be written as: sum of the values + r × (v1 + v3) = 6. The balance can therefore be read without repeating the elimination.

Numerically, v1 + v3 = 24/17, the sum of the three values is 24/17 + 30/17 = 54/17, and the loss is 6 − 54/17 = 48/17. Also, r × (v1 + v3) = 48/17: the two agree. A positive loss is expected because heat leaves through both ends, held at 0 °C. This agreement validates the solution process, rather than the accuracy of the step or the relevance of the model.

Check your reasoning

  • The identity is proved from the equations, rather than merely checked with the numbers.
  • The loss is compared with r × (v₁ + v₃).
  • The interpretation in terms of the ends is given, together with the limitation of the model.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What distinguishes the implicit scheme from the explicit scheme when writing the diffusion equation?

The exchange term with neighbouring points is evaluated using the unknown values at the next step, rather than those at the current step.

Recall 2What do we solve at each implicit step, and what form does it take?

A tridiagonal linear system: b = 1 + 2r on the diagonal, −r on either side, and the old values and contributions from the ends on the right-hand side.

Recall 3Which checks can be applied to an implicit solution without repeating the elimination?

The residual in the original equations, the sum balance with the loss r × (v₁ + v₃) at the ends, and the expected range of the values.

Recall 4Does an output with no negative value prove that the implicit result is accurate?

No: it shows only the absence of this anomaly. Accuracy as a function of Δt is measured using convergence tests, the subject of unit c183-m5.

Reconstruct the reasoning

Write diffusion using the new values; set r = ν Δt / Δx²; form the tridiagonal system (b = 1 + 2r on the diagonal, −r beside it, and old values and ends on the right-hand side); eliminate downwards, then use back substitution; check using the residual, the balance and the range; never confuse the absence of anomalies with accuracy.
