Level 2 · C076·M4

Strings, entropy and indicators

Your goalExtract a string while keeping its position, calculate the empirical entropy of a small file, and state what hypothesis these indicators can only help prepare.

Before you start

✿01 See the idea

You receive balise.bin, a fictional file whose bytes are all known to us. Without executing it, you first see 8 NUL bytes, then the characters ABABCDCD. This small object does not claim to represent any real executable format. It helps separate what the bytes show from what we imagine about them.

An extracted string is a contiguous sequence of bytes that a rule chooses to read as text. Here, the rule accepts printable ASCII characters, including spaces, and keeps sequences of at least 6 bytes. It finds ABABCDCD. Keeping the string together with its position lets you return to the region that produced it. Being able to read it does not mean a program will use it.

Entropy answers another question: if you randomly select a position in the region, how predictable do the frequencies make its byte value? Many repetitions concentrate the frequencies; a more uniform distribution spreads them out. The calculation looks at the count of each value, without keeping the order of the positions.

These observations are indicators: they guide a check. A region that is hard to read and has high entropy may contain compressed data, encrypted data or other varied data. A string may be a label or unused text. Neither readability nor entropy alone gives a verdict on how the file is used.

The rule to remember

Keep the exact region and the reading rule; count before calculating; connect each indicator to a hypothesis that still needs checking.

✿02 Follow an example

Worked example

From a readable region to a numerical indicator

The fictional file contains 8 NUL bytes followed by exactly ABABCDCD. In the ASCII encoding used here, A has value 65, B has value 66, C has value 67 and D has value 68, in decimal notation. There are no additional bytes or hidden headers. Let us calculate over this entire file, then keep track of the limits of the observation.

  1. Set the scope and extract the sequence

    A byte contains 8 bits and can take 256 values. For this extraction, a byte b is printable if 32 ≤ b < 127. Here, the letter b denotes an integer value with no physical unit; the offset denotes a position, in bytes from the start. We look only for ASCII: text in another encoding may escape this rule.

    NUL bytes interrupt any printable sequence. The sequence ABABCDCD starts at offset 8, is 8 bytes long and meets the minimum 6. We keep the triple “ABABCDCD; offset 8 bytes; length 8 bytes”. The last character occupies 15; the exclusive end is 16, since 8 + 8 = 16.

  2. Go from counts to frequencies

    N denotes the number of bytes in the region, here 16. S is the set of byte values actually present. For each b in S, c(b) counts its occurrences and p(b) = c(b)/N is its frequency, which has no unit. In the formula, p with subscript b denotes the same frequency p(b). We select a position uniformly from the positions in the region; its value then follows exactly these frequencies. This does not assume that the file was produced randomly.

    NUL occurs 8 times: p_NUL = 8/16 = 1/2 = 0.500. Each of the 4 letters occurs 2 times: p_lettre = 2/16 = 1/8 = 0.125. “p_lettre” denotes the frequency of each letter, not of their group.

    Count check: 8 + 4 × 2 = 16 bytes. Frequency check: 1/2 + 4 × 1/8 = 1/2 + 1/2 = 1. A sum other than 1 would require counting again.

  3. Define the entropy being calculated

    The empirical entropy Ĥ is the average information content −log of the frequency, calculated for individual bytes. The hat reminds us that the frequencies come from the observed region. Using log to base 2 gives a result in bits per byte selected. The sum Σ runs over each distinct value b in S once; its count is already included in p(b).

    H^=−∑b∈Spblog2(pb)

    We assume that N is strictly positive and that all counts use the same scope. Absent values do not belong to S, so we do not need to calculate the logarithm of 0. For a byte alphabet, Ĥ is between 0 and 8 bits/byte. The upper bound corresponds to uniform frequencies over the 256 values; our very small file does not achieve this situation.

    This calculation describes a distribution of individual bytes. Interpreting it as a property of future data would require an additional model of how those data are produced. It calculates neither the size achieved by a real compressor nor a probability that the file is dangerous.

  4. Calculate the logarithms without rounding

    The logarithm to base 2 finds the exponent of a power of 2. For −log(p), we can find log(1/p). NUL has frequency 1/2; its reciprocal is 2 = 2 to the power 1, so its information content is 1 bit. Each letter has frequency 1/8; its reciprocal is 8 = 2 to the power 3, so it provides 3 bits.

    We weight each information content by its frequency because Ĥ is an average over positions. NUL contributes 1/2 × 1 = 1/2 bit/byte. Each letter contributes 1/8 × 3 = 3/8 bit/byte. The 4 letters together contribute 4 × 3/8 = 3/2 bit/byte.

  5. Add and check using positions

    H^=1/2+3/2=2.00 bits/octet

    Let us check by starting from positions rather than categories: the 8 NUL bytes each provide 1 bit of information and the 8 printable positions each provide 3 bits. The average (8 × 1 + 8 × 3)/16 again gives 2 bits/byte. The units are indeed bits per byte selected, and the result stays within the stated interval.

    Another mental check: if the whole region consisted of NUL bytes, its only frequency would be 1, and its entropy would be 0 bit/byte. The certain repetition of the same value brings no surprise in this model.

  6. Write a conclusion supported by the indicator

    Observed conclusion: “Over the 16 bytes of balise.bin, the ASCII rule with minimum 6 keeps ABABCDCD at offset 8; the empirical entropy of individual bytes is 2.00 bits/byte.” These results are reproducible from the stated data.

    Permitted hypothesis: the final region could hold text or a marker. Check to prepare: compare its position and content with the documented structure of the format, if it becomes available. Here, no format description lets us determine its role. The low entropy of the file does not prove it is harmless; the presence of letters does not prove any action. The next unit will address the scope of a more complete static analysis.

Explain it in your own words

Hide the calculations. Explain why a letter contributes less than its information content alone, then why a permutation can keep the entropy while destroying the extracted string. End with a conclusion that separates observation, hypothesis and the check still needed.

✿03 Common mistakes

  • “I found a readable string: the program does what it says.”

    The rule guarantees only a sequence of bytes compatible with the chosen ASCII rule. Keep the offset and length, then look for its role in a documented structure. An unused label also meets the rule. In our file, no role for ABABCDCD has been established.

    Review the extraction and conclusion in the example

  • “There are 4 different letters, so their frequencies are 1/4 everywhere.”

    Choose the region first. Across the whole file, NUL occupies positions and the denominator is 16: each letter has frequency 1/8. The frequency 1/4 applies only to the final region of 8 bytes. The exercise on windows asks you to make this choice again.

    Repeat the calculation over the separate regions

  • “Entropy decides whether the file is encrypted or dangerous.”

    Entropy summarizes frequencies without keeping order or describing behaviour. Compressed data can have high entropy; a file with low entropy can still be dangerous. Write the result with its scope, then a hypothesis and the evidence that would allow you to check it.

Exercise 1 · Identification

Find the string and its boundary

In the unchanged balise.bin, apply the minimum 6 to printable ASCII sequences. Give the string, its offset, its length and its exclusive end. Explain why NUL is not part of the text.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The first character follows 8 bytes. Positions start at 0.

Hint 2

The exclusive end is the starting offset plus the length; it is not the position of the last character.

Compare with the solution

ABABCDCD is a sequence of 8 bytes, so it reaches the minimum 6. It starts at offset 8 bytes. Its exclusive end is 8 + 8 = 16, and its last position is 15.

NUL has value 0, below the first printable ASCII value 32. It breaks the sequence. The character “0” would be a different byte: writing the name NUL on the page does not make it text present in the file.

Check your reasoning

  • Keep the text, offset 8 bytes and length 8 bytes together.
  • Distinguish the exclusive end 16 from the last position 15.
  • Justify rejecting NUL using the character rule, without assigning it a hidden meaning.

Exercise 2 · Calculation and checking

Changing the region changes the frequencies

Split the same file into its initial block of 8 NUL bytes and its final block ABABCDCD of 8 bytes. Calculate the entropy of each block. Since their sizes are equal, average the results. Do you recover the entropy of the whole file? Justify your answer.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

In the first block, the value NUL has frequency 1. In the second, divide each count by 8, without using 16.

Hint 2

The reciprocal of 1/4 is 4, which is 2 to the power 2. Then compare an average of local calculations with the calculation of global frequencies.

Compare with the solution

The initial block has only one value present: its entropy is 0 bit/byte. In the final block, each letter has frequency 2/8 = 1/4 = 0.25. Its information content is 2 bits; its contribution is 1/4 × 2 = 1/2 bit/byte. The 4 contributions give 2.00 bits/byte.

The blocks have the same size, so the average of their entropies is (0 + 2)/2 = 1 bit/byte. It differs from the global calculation 2 bits/byte. The local calculation already knows which block contains the position: in the first, NUL is certain. The global calculation must also distinguish NUL from the letters. By averaging entropies calculated separately, we lose this part of the global uncertainty.

We therefore cannot report the entropy of a file by averaging the entropies of its regions without justification. The scope is part of the result, even when all bytes have been read.

Check your reasoning

  • Change the denominator with the region and obtain 0 then 2 bits/byte.
  • Calculate the local average 1 bit/byte without confusing it with 2 bits/byte over the whole file.
  • Explain that knowing the block already provides information.

Exercise 3 · Transfer and challenge

Same entropy, string gone

Only reorder the bytes of balise.bin as follows: NUL A NUL B NUL A NUL B NUL C NUL D NUL C NUL D. Without repeating the whole logarithmic sum, predict the global entropy and the extraction result with the same minimum 6. Someone concludes: “No string left, so the file is encrypted.” Respond and suggest evidence to look for.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Count each value again; the order changes, but do the counts change?

Hint 2

Find the maximum length of a printable sequence. A change in order alone is enough here to make the retained strings disappear.

Compare with the solution

The counts remain 8 NUL bytes and 2 occurrences of each letter: the frequencies, and then the global entropy, remain 2.00 bits/byte. No new sum is needed because the formula depends only on these counts.

Each letter is now separated from the others by NUL. The longest printable sequence is 1 byte long, below the minimum 6: 0 strings kept. We obtained this result by an explicit permutation, without any encryption operation. It refutes the inference “no string implies encryption”.

A suitable conclusion keeps the rule and its limits: no sufficiently long ASCII sequence is found, leaving other encodings or a different organization possible. To examine the hypothesis of text in another encoding, we would look for a description of its encoding and its position within the format. This evidence is not provided for our fictional file, so we leave the hypothesis open.

Check your reasoning

  • Justify the unchanged entropy using the counts, not visual resemblance.
  • Compare the maximum length 1 with the minimum 6.
  • Refute the encryption verdict using the known permutation and name a check suited to the remaining hypothesis.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What must you keep with an extracted string so that the observation can be checked?

The region examined, the character and length rule, the retained text, its offset and its length. A readable sequence alone proves neither its role nor its use.

Recall 2Why does the frequency of A change when you go from the whole file to just the final block?

Its count remains 2, but the number of reference positions goes from 16 to 8: its frequency goes from 1/8 to 1/4. The scope determines the denominator.

Recall 3Reconstruct the entropy calculation for balise.bin and state its unit.

NUL has frequency 1/2 and provides 1 bit; each letter has frequency 1/8 and provides 3 bits. The average is 1/2 × 1 + 4 × 1/8 × 3 = 2 bits/byte. It summarizes the frequencies of individual bytes over the region.

Recall 4Why can a permutation destroy the retained strings without changing the global entropy?

A string depends on characters being contiguous; a permutation changes their neighbours. The entropy of individual bytes depends only on counts, which a permutation preserves.

Recall 5What conclusion is supported by a region with high entropy and no retained ASCII string?

It provides indicators compatible with several explanations, including compression, encryption or another organization of the data. You must keep the scope and rules, formulate a hypothesis, then look for evidence specific to it. No verdict of danger follows from these indicators alone.
