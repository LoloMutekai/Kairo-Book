Dimensions and axes

Your goalRead the shape of an array, name its axes and predict what remains after summing over an axis.

Before you start
c032-m5 : computational rank · c013-m5 : recursion · c017-m5 : reproduction protocol · c024-m5 : measurement quality · c036-m1 : arrays

✿01 See the idea

A log records bicycle departures from North, Central and South stations on Monday and then Tuesday. To find the total for North, move down its column while keeping the station name fixed. To find the total for Monday, move across its row while keeping the day fixed. You use the same log, but group different cells.

The numbers are fictional. Each cell counts departures from a station over a whole day. All counts follow this same definition, no cells are missing and each departure belongs to exactly one cell. The stations and days therefore form distinct groups that can be added without counting a departure more than once.

An axis is a direction used to locate entries in the array. Here, changing rows changes the day; changing columns changes the station. In the NumPy array convention used here, axis numbering starts at 0: axis 0 for days, axis 1 for stations. These are positions in the structure, rather than axes for geographical coordinates.

Before calculating, ask yourself which name should accompany each result. “Per station” must leave the stations; you need to combine the days. The arrows in the log show what varies, while the cells in the second diagram show what remains.

The rule to remember

To choose an axis to sum over, name what must remain, then sum over the other axis. Check the shape of the result before checking its numbers.

✿02 Follow an example

Worked example

How many departures are there at each station over the period?

The log becomes the numerical array A. Its rows are ordered Monday, Tuesday; its columns North, Central, South. We want the total per station over the 2 days, in departures. Keep these labels beside the numbers throughout the calculation.

  1. Write the data and their meaning

    A denotes the whole array; its values are numbers of departures. The Monday row contains 4, 7, 2 departures; the Tuesday row contains 6, 5, 9 departures. The brackets below mark the boundaries of the array without adding any values.

    A=[472659]

    We assume a rectangular array: each row describes the same stations in the same order. The calculation adds counts with the same definition over distinct days. It does not count distinct bicycles: the same bicycle can depart several times.

  2. Distinguish the number of axes, shape and size

    The dimension, in the sense of the number of axes, is 2: you must choose a day and a station to identify a cell. In NumPy, A.ndim gives this number. This differs from the computational rank studied with matrices: here we count the axes used to locate entries.

    The shape, given by A.shape, is the ordered list of axis lengths: (2, 3). Its first entry describes axis 0, the days; its second describes axis 1, the stations. Lengths and indices are counts with no physical unit.

    The total size, A.size, counts all the cells. We multiply the lengths because each day has a cell for each station: 2 × 3 = 6 cells. The dimension 2, the shape (2, 3) and the size 6 therefore answer different questions.

  3. Read a cell without swapping the indices

    i denotes the day index, j the station index. An index is an integer position starting at 0. Here i ranges from 0 to 1, and j from 0 to 2. A[i, j] means: select row i, then column j. The comma separates the indices; it is not a decimal comma.

    For Tuesday at South, i = 1 and j = 2: A[1, 2] = 9 departures. The maximum index equals the axis length minus 1. Row index 2 would therefore be outside the array.

    If you select just the Tuesday row with A[1], the ordinary NumPy result is a sequence with 1 axis, of shape (3,). The trailing comma indicates that the shape contains a single length. A sequence of 3 values does not have 3 axes.

  4. Predict the axis to combine and the output shape

    The question asks for a total for each station. For a fixed station, we must vary the day: that is axis 0. The NumPy notation A.sum(axis=0) performs this sum. Here we use the ordinary behavior, which removes the axis being summed over.

    The shape (2, 3) loses its day length and becomes (3,). The result is a sequence with 1 axis, in the order North, Central, South. Predicting 3 values already lets you reject an output containing only 2 values for this question.

    S denotes the sequence of totals per station; S[j] is the total at the station with index j. For each valid j, we add the Monday and Tuesday cells:

    S[j]=A[0,j]+A[1,j]

  5. Calculate the totals per station

    North: 4 + 6 = 10 departures. Central: 7 + 5 = 12 departures. South: 2 + 9 = 11 departures. In each addition, the station stays fixed and the days change.

    S=(10;12;11) départs

    The semicolons here separate the values in the sequence. The total covers the whole period, without division by its duration. Station names are retained in our log; a numerical array alone cannot infer them.

  6. Also calculate by day to check the grouping

    Change only the question: for a total per day, we must combine the stations, so A.sum(axis=1). The shape becomes (2,), because the days remain. Call this sequence T; T[i] denotes the total for the day with index i.

    Monday: 4 + 7 = 11, then 11 + 2 = 13 departures. Tuesday: 6 + 5 = 11, then 11 + 9 = 20 departures. Thus T = (13 ; 20) departures.

    Axis 1 is called the station axis here because it identifies the columns. Summing over this axis calculates a total for each row. Saying only “sum of columns” is ambiguous: it may refer to the columns being combined or to those for which a result is retained. Naming the axis being removed avoids this trap.

  7. Check the numbers and the question separately

    By station: 10 + 12 = 22, then 22 + 11 = 33 departures. By day: 13 + 20 = 33 departures. Both routes recover the same total because each counts all the cells exactly once.

    Direct check, without using sequences S and T: 4 + 7 + 2 + 6 + 5 + 9 = 33 departures. This checks the arithmetic total; it is not enough to choose the correct grouping.

    To answer the original question, you still need 3 values associated with North, Central, South. Sequence T has a correct total but answers a different question. A correct overall sum can therefore accompany the wrong axis.

Explain it in your own words

Hide the calculations. To obtain a total per station, which index stays fixed, which index varies and which length disappears from the shape? Reconstruct the South calculation, then explain why the overall total is not enough to validate the axis.

✿03 Common mistakes

  • “There are 6 numbers, so the array has 6 dimensions.”

    The number of values is the size. Instead, count the independent choices needed to reach a cell: a day and a station, giving 2 axes. The shape (2, 3) gives their lengths, whose product is 6.

    Review dimension, shape and size

  • “To keep the stations, I must choose the station axis.”

    In this ordinary sum, the chosen axis is combined and removed. To keep the stations, combine the days, axis 0. Axis 1 would combine the stations and leave the days.

    Compare the names retained in the diagrams

  • “The overall total is correct, so my axis must be correct.”

    The 33 departures can be grouped by day or by station. Check the expected shape and the name of each result. The exercise on averages shows how a correct arithmetic operation can handle the wrong group.

    Diagnose the output and its denominator

Exercise 3 · Diagnosis and repair

A correct average for the wrong group

Someone wants the average number of departures per day at each station. They add each row, then divide by 3: their output is (13/3 ; 20/3) departures per station over the day in question. Explain what they actually calculated, then correct the axis, shape and denominators. An arithmetic mean is the sum of the values in a group divided by their number.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Their output contains 2 values. How many values would be needed to name all the stations?

Hint 2

For each station, the group contains the counts for the 2 days. Keep the station fixed during the addition and divide by the length of the combined axis.

Compare with the solution

The person averaged across the stations separately for Monday and Tuesday: they reduced axis 1. The fractions 13/3 and 20/3 are arithmetically correct for that other question. They do not indicate a daily average per station.

To answer the question, combine the days, axis 0, and predict the shape (3,). North: 10 ÷ 2 = 5 departures per day. Central: 12 ÷ 2 = 6 departures per day. South: 11 ÷ 2 = 11/2 departures per day, that is 5.50 departures per day.

The correct output is therefore (5 ; 6 ; 5.50) departures per day, associated with North, Central, South. An average can be noninteger even when every count is an integer: it distributes the total over the days in the log.

Reverse check: 5 × 2 = 10, 6 × 2 = 12, and 11/2 × 2 = 11 departures. Each average reconstructs its station total. Nothing in this calculation guarantees the departures on a future day.

Check your reasoning

  • Identify the faulty output as an average across stations for each day.
  • Reduce axis 0 and state that there will be 3 labeled averages.
  • Divide by 2, justify the units and reconstruct each total by multiplication.
  • Keep 11/2 exact until expressing it in French decimal notation.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What do dimension, shape and size each describe in the log?

Dimension counts the axes: 2. Shape gives their lengths in the order days, stations: (2, 3). Size counts all the cells: 2 × 3 = 6.

Recall 2How do you locate Tuesday at South using indices, and why is row index 2 invalid?

Indices start at 0. Tuesday has index 1 and South has index 2, so A[1, 2] equals 9 departures. The day axis has 2 positions, from 0 to 1, with no position 2.

Recall 3For a total per station, which axis must you sum over and what shape remains?

Summing over the days, axis 0, removes their length from (2, 3). The shape (3,) remains, with one value per station. The chosen axis is the one being combined, rather than the one whose labels you want to retain.

Recall 4An extracted row contains 3 numbers. How many axes does it have?

In the ordinary selection A[1], it has 1 axis and the shape (3,). Only the choice of station remains. The number of values does not become the number of axes.

Recall 5Why is recovering 33 departures not enough to prove that the correct axis was chosen?

Grouping by day or by station can give the same overall total. You must also check the shape and associate each result with the expected name. For an average, you must additionally divide by the number of values in the group actually combined.

What you understand
An axis describes what varies when you change an index. A sum or mean over an axis combines its positions; in the ordinary behavior studied here, the other axes remain in the result. Shape alone does not provide the data labels.
