Level 0 · C006·M3

Domains

Your goalDetermine the times for which the filling rule actually describes the water bottle, test each request against this domain, then distinguish outside the domain, a missing reading and a measured 0.

Before you start
c004-m5 : rational equations · c006-m1 : coordinates · c006-m2 : straight lines

✿01 See the idea

Return to the water bottle from the previous two units. It contains 2 dL when the tap opens, the tap adds 2 dL per minute, and the rule V(t) = 2t + 2 gives the volume after t minutes. All these values are fictional: they were chosen for the course and are not readings.

There is a new constraint: the bottle can hold only 10 dL. Ask the rule for the volume at 5 min: it gives 12 dL. Yet no bottle with a capacity of 10 dL holds 12 dL. Once the water reaches the rim, it overflows, and the rule, which does not account for overflow, stops describing what happens.

The calculation is still possible; it is its meaning that is lost. In a given situation, the domain of a formula is the set of inputs for which we accept it as a description. Here the inputs are times. The situation imposes two limits: the stopwatch starts when the tap opens, so a negative time does not refer to any instant in this trial; and the volume cannot exceed the capacity.

With rational equations, you have already excluded a value because it made a denominator 0: that restriction came from the calculation itself. Here, 2t + 2 can be calculated for any number t. The restriction comes from the situation, and you need to state it yourself.

A third question is separate from the domain. At an allowed time, the sensor that reads the water level may transmit nothing. The time is valid, but no volume has been read. Writing 0 dL in the log would invent an empty bottle. We therefore keep separate statuses: “measured”, “missing reading” and “outside the domain”. A true 0 would be an actual reading taken from an empty bottle.

The rule to remember

Before using a formula, write its domain based on the situation. Reject an input outside the domain even if the calculation succeeds. Leave a missing reading blank and state the reason: it never means 0.

✿02 Follow an example

Worked example

The 10 dL water bottle and the log with a gap

Fictional data: initial volume b = 2 dL, flow rate r = 2 dL/min, capacity C = 10 dL. There are three requests for a volume, at t = 1, t = 5 and t = −1 min. The trial log records 4 dL read at 1 min, nothing at 2 min, and 8 dL read at 3 min. Write the domain, then assign a status to each request and each row.

  1. Name the quantities and assumptions

    t is the time elapsed since the tap opened, in minutes; it can be fractional, such as half a minute. V(t) is the volume predicted by the rule, in decilitres. b is the initial volume (dL), r the flow rate (dL/min) and C the capacity (dL). The first two parameters come from the unit on straight lines; C is new.

    V(t)=rt+b

    Model assumptions: the flow rate stays constant during the trial; the model does not represent overflow; the stopwatch starts when the tap opens. Notation: “a ≤ b” is read as “a is less than or equal to b”, and “a ≥ b” as “a is greater than or equal to b”.

  2. First limit: the start of the trial

    The log starts at t = 0. A negative time would refer to an instant before the tap opened, which is not part of this trial. First condition:

    t≥0

    This does not prohibit calculation: the rule does give a number for t = −1. It is the situation that excludes these times.

  3. Second limit: the capacity

    We also need V(t) ≤ C. First find the time T, in minutes, when the bottle is exactly full. This is a linear equation in T:

    rT+b=C donc T=C−br

    Why divide by r? There are C − b decilitres left to add, and each minute adds r. Here r = 2 dL/min is nonzero, so division is allowed.

    T=10−22=82=4 min

    Since r is positive, the volume increases with time: before T it stays below C, and after T it exceeds C. The condition V(t) ≤ C is therefore equivalent to t ≤ T.

  4. Write the domain and check it

    Together, the two limits give the domain D, the set of accepted times:

    D=[0;T]=[0;4] en minutes

    The inward-facing square brackets mean that both endpoints are included: t = 0 is the starting instant, and t = 4 is the instant the bottle is exactly full, without overflow. If the trial had stopped just before the bottle was full, we would have excluded 4 by writing [0 ; 4[, with an outward-facing bracket. This notation uses a semicolon between endpoints; the outward-facing bracket has the same meaning as a round bracket in English interval notation.

    Check by substitution: V(0) = 2 dL and V(4) = 2 × 4 + 2 = 8 + 2 = 10 dL, exactly C. Over this domain, the predicted volumes range from 2 to 10 dL.

  5. Test three requests, checking the input first

    t = 1 min: 1 is between 0 and 4, so the request is valid. V(1) = 2 × 1 + 2 = 2 + 2 = 4 dL.

    t = 5 min: 5 exceeds 4, so the request is outside the domain. The algebraic calculation gives 2 × 5 + 2 = 10 + 2 = 12 dL, which is 2 dL above the capacity. This number is not reported as the volume in the bottle: in this situation, the bottle overflows and never holds more than 10 dL.

    t = −1 min: also outside the domain. The calculation gives 2 − 2 = 0 dL, a value that looks plausible because it lies between 0 and 10 dL. Yet it describes no instant in the trial: before the tap opened, the bottle already contained its 2 dL.

    Always test the input against the domain before looking at the output: a plausible output cannot make a rejected input valid.

  6. The gap in the log: a missing reading, not 0

    At 2 min, the time belongs to the domain, but the sensor transmitted nothing. The status is “missing reading”. The rule predicts V(2) = 4 + 2 = 6 dL: this is a prediction, to be placed in a “predicted” column, never in the “read” column.

    If we filled the gap with 0 dL, the graph would show a drop of 4 − 0 = 4 dL, then a rise of 8 − 0 = 8 dL. The bottle never lost any water: both movements would be created by the replacement.

    A true 0 is different: if the bottle had been empty and the sensor had read it, 0 dL would be a reading, drawn as a dot on the horizontal axis.

  7. Check the whole result

    The time between the two available readings is 3 − 1 = 2 min. The rule predicts an increase of 2 × 2 = 4 dL; the log shows 8 − 4 = 4 dL. The fictional readings are consistent, and the gap has required no invented value.

    Of the requests, 1 is valid and 2 are outside the domain; in the log, 2 rows are measured and 1 remains a missing reading. Each rejection keeps its reason: an input outside the situation, or a missing reading.

Explain it in your own words

Why is the request at −1 min rejected when its result, 0 dL, fits in the bottle? And why is the gap at 2 min not “outside the domain”?

✿03 Common mistakes

  • “If the formula gives a number, it is suitable.”

    A calculation that succeeds proves only that the algebra works. First compare the input with the domain: at 5 min, the rule gives 12 dL, but 5 exceeds 4 and the bottle holds only 10 dL.

    Review the test of the three requests

  • “Missing and 0 look the same on the graph.”

    A 0 is a reading: a dot on the axis. A missing reading is a labelled gap. Confusing them creates a drop of 4 dL here that the bottle never experienced.

    Review the three symbols

  • “A value between 0 and the capacity must be a reading.”

    The bounds say that a value is possible, not where it comes from. The 6 dL predicted at 2 min satisfy them, but no one read that volume; the 0 dL calculated at −1 min also satisfy them, for a rejected input. Check the input, then the origin of the value.

    Review the gap in the log

Exercise 1 · Apply

A 6 dL water bottle

The same initial volume (2 dL) and the same flow rate (2 dL/min), but a 6 dL bottle. Write the domain of the rule, including its endpoints, then give the status of the request t = 3 min.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Calculate the volume left to add before the bottle is full, then the time needed at 2 dL per minute.

Hint 2

Compare 3 with the endpoint you found before discussing the calculated volume.

Compare with the solution

There are 6 − 2 = 4 dL left to add, giving T = 4/2 = 2 min. The domain is [0 ; 2], in minutes. Check: V(2) = 2 × 2 + 2 = 4 + 2 = 6 dL, exactly the capacity.

The request t = 3 min is outside the domain because 3 exceeds 2. The raw calculation gives 2 × 3 + 2 = 6 + 2 = 8 dL, which is 2 dL above the capacity: this number is not a volume in this bottle.

Check your reasoning

  • The domain is written with both endpoints and its unit.
  • The endpoint for a full bottle comes from the capacity, rather than from reading the graph in the example.
  • The status of t = 3 min is decided before the calculated volume is discussed.

Exercise 2 · Classify

Four requests for a 12 dL water bottle

The same initial volume and the same flow rate, with a capacity of 12 dL. Write the domain, then classify the requests t = −1, t = 0, t = 5 and t = 6 min as “valid” or “outside the domain”. For each valid request, give the predicted volume.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Solve 2T + 2 = 12.

Hint 2

Remember the starting limit: it excludes negative times, whatever the calculated volume.

Compare with the solution

There are 12 − 2 = 10 dL left to add, so T = 10/2 = 5 min and the domain is [0 ; 5].

t = −1: outside the domain, before the start. The raw calculation would give 0 dL; this plausible number does not change the status.

t = 0: valid, endpoint included; V = 2 dL, the initial volume.

t = 5: valid, endpoint included; V = 2 × 5 + 2 = 12 dL, exactly the capacity.

t = 6: outside the domain; the raw calculation 2 × 6 + 2 = 12 + 2 = 14 dL would exceed the capacity by 2 dL.

Check your reasoning

  • Both endpoints are included and justified by the situation.
  • The status of t = −1 does not depend on the calculated volume.
  • No volume is reported for a request outside the domain.

Exercise 3 · Transfer and justify

A second trial starting with an empty bottle

A new fictional trial: the 10 dL bottle starts empty (0 dL), with the same flow rate. The log shows: t = 0 min, 0 dL read; t = 1 min, nothing received from the sensor. There is also a request for the volume at t = 6 min. Write the domain, give the status of each row and of the request, then say which entry is drawn as a dot on the horizontal axis.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The initial volume has changed: recalculate the volume left to add.

Hint 2

A 0 that has been read is a reading; a silent sensor supplies no value.

Compare with the solution

There are 10 − 0 = 10 dL left to add, so T = 10/2 = 5 min; the domain is [0 ; 5].

t = 0: measured. The 0 dL were read from an empty bottle: this is a true 0, drawn as a dot on the horizontal axis.

t = 1: missing reading. The time is allowed, but no reading exists. The rule predicts 2 dL; this can be written in a “predicted” column, but not as a reading, and certainly not as 0.

t = 6: outside the domain because 6 exceeds 5; the raw calculation 2 × 6 + 0 = 12 dL exceeds the capacity by 2 dL.

The number 0 therefore appears once, as a reading; it must never appear as a replacement for the gap.

Check your reasoning

  • The domain is recalculated using the new initial volume.
  • All three statuses are named, each justified by its reason.
  • The true 0 and the gap are drawn differently.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What does the domain of a formula describe in a situation?

The set of inputs for which the formula is accepted as a description of the situation; for the 10 dL bottle, the times from 0 to 4 min, including both endpoints.

Recall 2How do you find the time when the bottle is full?

Solve rT + b = C, giving T = (C − b)/r with r nonzero: (10 − 2)/2 = 4 min.

Recall 3The rule gives 12 dL at 5 min. What should be reported?

No volume in the bottle: the input 5 is outside the domain, and the calculated number is only an algebraic extension.

Recall 4Does a silent sensor at an allowed time give 0 dL?

No: the status is “missing reading”, drawn as a labelled gap. A 0 would be an actual reading that had been taken.

Recall 5Does a value between 0 and 10 dL prove that a reading was taken?

No: the bounds say that a value is possible. An input within the domain and an actual reading are also needed.

Reconstruct the reasoning

Name the quantities and their units; write each limit imposed by the situation; solve for the time when the bottle is full; write the domain with its endpoints included or excluded; test the input before reading the output; classify each row as measured, missing reading or outside the domain, without ever filling a gap with 0.
