Positions

Your goalExplain why attention needs a position signal, add a position vector to two identical words, and verify by calculation that their scores no longer match.

Before you start

✿01 See the idea

Consider a fictitious sentence of 3 words: a, b, then a again. Each word is represented by a vector with 2 coordinates, chosen by hand for this lesson: a is (2 ; 1) and b is (0 ; 3). These values are fictitious; they allow exact calculations and do not describe a real model.

In the attention mechanism introduced with queries, keys and values, each position compares its vector with the vector at every position using dot products, called scores. To keep the calculation exact, we take the query, key and value to be the vector itself, with no learned projection and no division of the scores. The first a and the last a then have the same vector, so they have the same scores and the same output: attention alone does not see order.

The solution is to add a position vector to each word vector. This vector depends only on the index of the word in the sentence: index 0, then 1, then 2. Here, these vectors are obtained by rotating a vector of length 5 through a fixed angle; the cosine of this angle is 0.6 and its sine is 0.8.

Standard sinusoidal constructions combine several angles; we keep just one, chosen because its cosine and sine are exact fractions. The example therefore demonstrates neither the quality of a real model nor a measured improvement: it shows only what changes in the scores.

The rule to remember

Add the vector for each word’s position to its word vector, then compare the summed vectors: two occurrences of the same word are no longer interchangeable.

If two score rows do not differ by the same constant added everywhere, their weights differ.

  2. Without positions: two identical rows

    hpawqt vlgnkf wnskhe yxxyur fmvivt jnfdmg dtjc For two a occurrences, the score is 2 × 2 + 1 × 1 = 4 + 1 = 5.

    The query at index 0 and the query at index 2 are the same vector; so are their keys. In each row, columns 0 and 2 equal 5: their difference is 0 for both rows. Nothing therefore distinguishes the two a occurrences.

  3. Construct the vector for position 2

    The first two vectors are given: p0 = (5 ; 0) and p1 = (3 ; 4). To move from one index to the next, rotate the vector (ξ ; η) to (ξ′ ; η′), through an angle θ such that cos θ = 3/5 and sin θ = 4/5.

    ξ′=ξcosθ−ηsinθ
    η′=ξsinθ+ηcosθ

    Using p1: first coordinate 3 × 3/5 − 4 × 4/5 = 9/5 − 16/5 = -7/5, or -1.4. Second coordinate 3 × 4/5 + 4 × 3/5 = 12/5 + 12/5 = 24/5, or 4.8. The sum of the squares of the two coordinates remains 25: rotation preserves the length 5.

  4. Add the word and its position

    For the first two positions: x0 = (2 + 5 ; 1 + 0) = (7 ; 1). x1 = (0 + 3 ; 3 + 4) = (3 ; 7).

    x2 = (2 + -7/5 ; 1 + 24/5) = (3/5 ; 29/5), or (0.6 ; 5.8). Indices 0 and 2 still contain the same word a, but their summed vectors are no longer equal.

  5. Calculate three scores

    The score is s00 = 7 × 7 + 1 × 1 = 49 + 1 = 50.

    s02 = 7 × 3/5 + 1 × 29/5 = 4.2 + 5.8 = 10. By symmetry, s20 also equals 10.

    s22 = 3/5 × 3/5 + 29/5 × 29/5 = 0.36 + 33.64 = 34. Here we read only columns 0 and 2, which contain the same word; column 1 is the subject of the first exercise.

  6. Compare the two rows using their differences

    In the row for index 0, the difference between columns 0 and 2 is 50 − 10 = 40. In the row for index 2, it is 10 − 34 = -24.

    These differences are unequal and even have opposite signs: position 0 favors its own column, and position 2 favors its own. Two rows with the same weights would have the same difference between two columns; that is not the case here. The weights for the two a occurrences therefore differ, whereas without positions both differences were 0.

    Check: we have calculated no weights and no outputs; the conclusion rests on the two assumed properties of softmax, rather than on a weight value.

  7. Check what the positions alone encode

    p0 · p1 = 5 × 3 + 0 × 4 = 15 + 0 = 15. Dividing by r² = 25 gives 0.6, which is the cosine 0.6 of the rotation angle.

    pi·pj=r2cos((j−i)θ)

    For two position vectors of the same length r, the dot product depends only on the distance j − i. This property concerns the position vectors alone: the full score adds word terms and cross terms.

✿03 Common mistakes

  • “Attention already recovers word order on its own.”

    Without a position vector, two occurrences of the same word have the same query, key and value: their score rows match. The calculation without positions in the example verifies this, with a 0 difference.

    Reread the calculation without positions

  • “The position vector replaces the word vector.”

    mheeyu jcdbhp jqca Replacing the word with its position would erase its identity; addition keeps both pieces of information in the same vector, coordinate by coordinate.

    Review the addition of the word and its position

  • “A high score between two positions means that they are neighbors in the sentence.”

    Only the product of the position vectors alone depends solely on distance. The full score also adds word terms and cross terms. To isolate the contribution of position, compare the products of position vectors with one another, as in the second exercise.

    Redo the exercises, keeping word and position separate

Recall 4What did this example calculate, and what did it leave unestablished?

Exact scores using fictitious values and a single angle. It calculated neither weights nor a complete output, and it proves neither the quality of a real model nor an improvement.

Reconstruct the reasoning

Without positions, two identical words have the same scores; add a vector that depends on its index to each word; compare the summed vectors using a dot product; check the score differences between columns; verify that, for positions alone, the product depends on distance; keep the limits in mind: fictitious values, a single angle, no calculated weights.
