Factorisation

Your goalReorganise cards counted by a sum into equal bundles, write the corresponding product and check it by expanding again.

Before you start
c003-m5 : scientific notation · c004-m1 : expressions · c004-m2 : linear equations · c004-m3 : polynomials

✿01 See the idea

The card order is ready, but it takes up several small piles. You want to make bundles of equal size, without adding or throwing away any cards. The right move is to shift the boundaries between the piles: the total stays the same, while its organisation changes.

In our fictional order, n initially equals 2. The first group contains n times n cards, the next contains 3 times n cards, and the reserve contains 2 cards. This gives 4 + 6 + 2 = 12 cards. Look at the dots before following the letters: each dot represents a card, never an area.

Split up the 3 packs of n cards: 2 packs extend the bundles in the first group; the last joins the reserve. You get the same size everywhere, n + 2 cards per bundle. All that remains is to count the bundles: n bundles, then 1 extra bundle.

To factorise means to write a sum as a product equal to that sum. A factor is a quantity multiplied by another; here, the common size of the bundles becomes a factor. To expand again means to carry out the multiplications in the brackets again to recover the original sum. The number of cards has not decreased.

The rule to remember

Identify a factor that is exactly the same in each term, count what multiplies it in each term, then expand again to check that nothing has been lost.

✿02 Follow an example

Worked example

Finding the packs in the order

The total for the fictional order is written n × n + 3n + 2. For n = 2, we will calculate the total, regroup the same cards, then justify the transformation beyond this test value.

  1. State what the symbols count

    n is a positive integer that counts the bundles in the initial group and the cards per bundle in that group. It has no physical unit: it is a count of objects. The square of n means n × n; 3n means 3 × n. Every term in our sum counts cards; the result is stated in cards.

    The cards are distinct and can be moved. Each card belongs to exactly one group; together, the groups cover the whole order. These assumptions allow us to add the counts, then move the cards without changing the total. The coefficients have no unit.

  2. Count for the first time

    With n = 2, the initial group contains 2 × 2 = 4 cards. The small packs contribute 3 × 2 = 6 cards. We add these non-overlapping groups, then the reserve: 4 + 6 = 10; 10 + 2 = 12 cards.

    This first count gives the quantity to preserve. It does not yet tell us how to obtain equal bundles.

  3. Split the term that hides the bundles

    We split 3n into 2n + n, because 3 = 2 + 1. With our data, this amounts to writing 6 = 4 + 2 = 6 cards. We have only separated the packs, without changing their count.

    n2+3n+2=n2+2n+n+2

    Why split here? The first terms have n in common; the last terms can form a bundle of the same size. This grouping reveals the factor we need.

  4. Recognise the same bundle size

    n × n + 2n = n × n + n × 2 = n(n + 2): we factor out n, the common multiplier. In practical terms, we add 2 cards to each of the n initial bundles. In the remaining terms, n + 2 forms 1 more bundle of this size.

    n2+2n+n+2=n(n+2)+1×(n+2)

    Numerically, the common size is 2 + 2 = 4 cards per bundle. The first bundles contain 2 × 4 = 8 cards; the last contributes 4. The intermediate check gives 8 + 4 = 12 cards.

  5. Count the bundles rather than the separate cards

    The bracketed expression n + 2 is now exactly the same in both terms. Its multiplier is n in the first term and 1 in the second. The second multiplier exists even though we usually omit it when writing the expression. We therefore add these multipliers.

    n(n+2)+1×(n+2)=(n+1)(n+2)

    Adjacent brackets mean multiplication. The first factor counts the bundles: 2 + 1 = 3 bundles. The second gives their size: 4 cards per bundle. The product is 3 × 4 = 12 cards. The initial total minus this product is 0 cards.

  6. Expand again to check all values

    The distributive property multiplies each term in one bracket by each term in the other. Here, the products are n × n, n × 2, 1 × n and 1 × 2. Keeping the intermediate terms avoids losing the last bundle.

    (n+1)(n+2)=n2+2n+n+2=n2+3n+2

    We recover every original term. This is an identity: the equality is true for all allowed values of n, thanks to the algebraic rules. The card arrangement explains the positive integers; the same algebraic operations remain valid for any real number n. The single check 12 = 12 at n = 2 could have missed another expression that is false elsewhere.

    In the rule aB + bB = (a + b)B, a and b represent the numbers of bundles and B their common size. Here a = n, b = 1 and B = n + 2. The letter B is an explained abbreviation, rather than a new quantity added to the cards.

Explain it in your own words

Hide the calculation. Work out how to split the middle term, then explain what each factor counts. Why does the last bundle require you to keep the multiplier 1? Finish by expanding again, without replacing n with a number.

✿03 Common mistakes

  • “Factorising means reducing the number of cards.”

    Count the dots in the diagrams: 12 cards before and 12 afterwards. Only the boundaries change. The product counts bundles multiplied by cards per bundle; it still gives cards.

    Count the cards again before and after

  • “Two similar bracketed expressions are enough; I can also forget the single bundle.”

    The factor taken out must be exactly identical in every term involved. Write n(n + 2) + 1 × (n + 2) before factoring it out. If a bracketed expression becomes n + 3, the size changes; if you drop 1, you lose a bundle.

    Revisit factoring out the common factor

  • “One correct test value proves my factorisation.”

    A difference of 0 cards checks only the calculated test case. One value that fails is enough to reject a proposal; one value that succeeds does not guarantee all the others. Expand again while keeping n to check the identity.

    Repair the incorrect proposal, then expand it again

Exercise 1 · Numerical application

The order grows

The same rule now describes the order with n = 4. Evaluate (n + 1)(n + 2). State the number of bundles, their size and the total, then check using n × n + 3n + 2.

Compare with the solution

Number of bundles: 4 + 1 = 5. Size: 4 + 2 = 6 cards per bundle. Total: 5 × 6 = 30 cards.

Exercise 2 · Diagnosis and repair

A bundle that is too large

For n × n + 3n + 2, someone proposes (n + 1)(n + 3). Test it with n = 2, find the excess cards, then expand the proposal again and repair it. Explain which factor does not match the arrangement.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The number of bundles is preserved; look at their size.

Hint 2

Expand again while keeping n: both the coefficient of the term in n and the reserve must be recovered.

Compare with the solution

The proposal gives 3 bundles of 5 cards, so 15 cards instead of 12. The excess is 15 − 12 = 3 cards. This counterexample is enough to reject the proposed identity.

(n+1)(n+3)=n2+3n+n+3=n2+4n+3

The size has been increased by 1 card in each bundle. To repair it, restore n + 2 as the size: (n + 1)(n + 2). Expanding this again restores n × n + 3n + 2, including the constant term. The repair comes from counting and algebra, rather than merely similar brackets.

Check your reasoning

  • I found 3 excess cards and identified a size error.
  • I expanded the incorrect form again and compared its terms with the order.
  • I gave the repaired form and justified the equality while keeping n.

Exercise 3 · Applying the method to grouping

Bundles already assembled into large groups

In the same card order, we now bring together 2n bundles of n + 2 cards and 3 other bundles of this same size. Factorise 2n(n + 2) + 3(n + 2). Expand your answer again to check it, then check numerically for n = 2.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Read the whole bracketed expression as the common size of a bundle.

Hint 2

Add the numbers of bundles that multiply this size, then keep the common bracketed expression just once.

Compare with the solution

The common size is n + 2. It is multiplied by 2n in the first group and by 3 in the second. The total number of bundles is therefore 2n + 3.

2n(n+2)+3(n+2)=(2n+3)(n+2)

Expanding again gives 2n × n + 4n + 3n + 6, or 2n × n + 7n + 6. The intermediate coefficient 4 comes from 2 × 2; the constant term 6 comes from 3 × 2. Expanding the original sum directly gives the same terms.

For n = 2, the groups contain 4 × 4 = 16 cards and 3 × 4 = 12 cards, giving 28 cards. The factorised form gives 7 × 4 = 28 cards. Finally, the expanded sum gives 8 + 14 + 6 = 22 + 6 = 28 cards. All three counts agree.

  • I kept the multipliers 2n and 3 in their sum.
  • I expanded again and recovered every term before the numerical check.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What does factorisation change in the card order?

It changes the written form and the grouping: a sum becomes a product with the same value. The cards counted remain the same.

Recall 2What split reveals the common size in n × n + 3n + 2?

Write 3n = 2n + n. Then n × n + 2n gives n bundles of size n + 2, and n + 2 gives 1 more bundle of this size.

Recall 3Why does n(n + 2) + (n + 2) become (n + 1)(n + 2)?

The common bracketed expression n + 2 is exactly the same in both terms. Its multipliers are n and 1; their sum counts n + 1 bundles. The multiplier 1 must not disappear.

Recall 4What can a numerical test prove, and what can expanding again prove?

A test that fails rejects the identity; a successful test checks only that value. Expanding again while keeping n recovers all the terms and justifies the identity through the distributive property.

Recall 5Reconstruct the rule aB + bB and explain what the letters mean.

aB + bB = (a + b)B. With our cards, a and b count the bundles and B represents their common size. We factor out B just once and keep the sum of its multipliers.

Reconstruct the reasoning

Without rereading, reconstruct the sequence: name the cards and bundles; split the middle term; identify a size that is exactly the same for all bundles; count all the bundles; write the product; expand it again. Finally, explain why a successful numerical test is not enough to prove an identity. Reading and an assisted answer never constitute an attained level.
