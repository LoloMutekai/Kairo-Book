Level 1 · C012·M1

Logical connectives

Your goalTranslate a rule about a lunchbox into propositions, calculate its truth value and check it in every possible state.

Before you start
c004-m5 : rational equations · c006-m5 : composition

✿01 See the idea

You are preparing a lunchbox. The lid is closed, but no label has been attached. One rule requires “closed and labelled”; another accepts “closed or labelled”. The box has not changed between readings of the rules. Yet it satisfies the second rule and fails the first: the rule is what changes.

Let P be the statement “the lid is closed” and Q the statement “a label is attached”. Here, a proposition is a statement to which we can assign a value: true or false. A connective builds a new proposition from these values. It does not close anything or attach a label.

We reason about a fixed instant and simple states: the lid is closed or open, and the label is present or absent. Each proposition receives exactly one truth value. If the lid is hidden, our lack of information does not allow us to declare P false. We must check the state before applying the rule to this box.

The scene and data are fictional. In this model, the lid and label states can be freely combined; this does not assume probabilistic independence. “Accepted” will mean only “satisfies the chosen rule”, without any judgement about food safety. In the diagrams, T stands for true and F for false.

The rule to remember

Define the statements, fix their values, then apply the connective: AND requires both to be true; inclusive OR also accepts both being true; NOT reverses a truth value.

✿02 Follow an example

Worked example

Which rule accepts our box?

Initially, the box is closed and has no label: P is true and Q is false. We will calculate the verdicts, then list all the states to check the rules. No physical preparation takes place during these calculations.

  1. Define the symbols and what we count

    P and Q denote the propositions defined above. The symbols ∧, ∨ and ¬ are read as “AND”, “inclusive OR” and “NOT”, respectively. Parentheses delimit the proposition to which a connective applies. The symbol = can indicate equality between calculated values.

    To count on paper, let us code true as 1 and false as 0. These codes have no unit: 1 denotes neither a lid nor a box. Only the counts that follow have a unit: a possible state. Each of the 2 values of P combines with each of the 2 values of Q: 2 × 2 = 4 states, with none repeated or omitted.

    The lowercase letters p and q will denote only the numerical codes of P and Q in the arithmetic checks. Here p = 1 and q = 0. We remain within classical logic, with fully specified values; no intermediate or unknown state is coded as false.

  2. Require a closed lid and a label

    The conjunction P ∧ Q is true exactly when P and Q are both true. The lid is closed, but the label is missing: our box does not satisfy this rule. The result is false, coded as 0.

    The product of the codes gives a simple check: 1 × 0 = 0. With codes that can only be 0 or 1, the product equals 1 only if every factor equals 1. This product checks the AND table; it does not multiply physical actions.

    p×q=1×0=0

  3. Accept a closed lid or a label

    The disjunction P ∨ Q is true if at least one proposition is true, including when both are true. Here P is enough: the result is true, coded as 1. The rule does not say that the label is present.

    To check using the codes, add p and q, then subtract their product. When both are true, addition would count them 2 times; subtracting the product brings the code back to 1. Here the sum is 1 + 0 = 1, and the product is 0: 1 − 0 = 1.

    p+q−pq=1+0−0=1

  4. Negate a statement without touching the box

    The negation ¬P is true when P is false and false when P is true. It reads “the lid is not closed”. Since the box is closed, ¬P is false. In our binary states, not closed means open; this equivalence depends on the chosen states.

    Using the codes, negation can be checked with 1 − p: 1 − 1 = 0. For Q, we obtain 1 − 0 = 1: “the label is absent” is true. These evaluations change neither the lid nor the label. If you actually opened the lid, you would first have to update P, then calculate again.

  5. Build the complete table

    A truth table lists the input values and the result of each rule. Read each row as another possible configuration of our box, never as a required sequence of actions. The columns on the left contain the data; those on the right are calculated.

    PQP∧QP∨Q¬P00001010111001011110

    Check the row for closed and labelled: both AND and OR are true. Then check the rows where the lid is open: ¬P is true regardless of the label. There are 2 such states: 1 open value of P × 2 values of Q.

  6. Count the accepted states, then check the total

    For AND, P must have its true value and Q must too: 1 × 1 = 1 accepted state. For OR, only the open box without a label is rejected: 1 state. Subtract it from the total: 4 − 1 = 3 accepted states. OR therefore accepts 3 − 1 = 2 more states, those in which only one action has been carried out.

    Independent check: count the letters T again in the OR column of the diagram. You find 3. Acceptance and rejection together cover all the rows: 3 + 1 = 4 states, matching the initial total.

    The fractions of accepted states are 1/4 = 1/4 for AND, and 3/4 = 3/4 for OR. Their decimal forms are 0.25 and 0.75, with no unit. These are ratios of counts, not the probability that a real box will be accepted: we have not defined any random selection.

  7. Read “if P, then Q” in the same scene

    Finally, introduce material implication P ⇒ Q: “if the lid is closed, then a label is attached”. P is the initial condition, and Q is the condition required when P is true. This rule is false only when P is true and Q is false. Our initial box is exactly this case: the verdict is false, coded as 0.

    If P is false, the conditional rule is not violated, whether Q is true or false: by definition, material implication is then true. It therefore does not certify that Q is true. In everyday language, “if” can suggest more; here it describes neither a cause, nor a sequence of actions, nor a mechanism that attaches the label.

    (P⇒Q)≡(¬P∨Q)

    The symbol ≡ means “the same values in every state”. To check, follow the row order in the table: ¬P ∨ Q is true, true, false, true. This is exactly the rule that rejects only closed without a label. It accepts 4 − 1 = 3 states.

    Another check on the initial case: the product p × (1 − q) identifies a violation, with closed true and labelled false. It equals 1 × 1 = 1. Subtracting it from 1 gives the implication code 1 − 1 = 0. The calculation reproduces the logical verdict.

  8. Check the rules rather than memorising the results

    For the initial state, the codes are: AND 0, OR 1, NOT P 0, implication 0. Explain each answer using the lid and label before comparing it with the table. A correct value without its rule is not enough to check your reasoning.

    Finally, observe that every row accepted by AND is also accepted by OR: having a closed lid and a label guarantees that at least one is present. The converse is false: our closed box without a label satisfies OR and fails AND. Likewise, counting 3 states for OR and 3 for implication does not make these rules identical; they reject different states.

Explain it in your own words

Hide the tables. Define P and Q again, reconstruct all the states and explain why OR accepts both being true. Then show the only state that contradicts “if P, then Q”. Finish by distinguishing the calculation of NOT P from the action of opening the box.

✿03 Common mistakes

  • “OR means one or the other, but never both.”

    The OR in this unit is inclusive. Test the closed and labelled box: P and Q are true, so P ∨ Q is true. If a rule forbids both together, it must say so; that would be a different rule.

    Reread the last row of the state diagram

  • “Calculating NOT P opens the box.”

    Negation applies to the statement. When the lid is closed, NOT P is false; the lid stays closed. Revisit the difference between evaluating this state and carrying out an action that creates a new one.

    Revisit the step on negation

  • “If P implies Q, closing the box makes the label appear.”

    Material implication specifies a truth verdict. A closed box without a label is enough to make this implication false in that state. This connective demonstrates neither a cause nor the automatic attachment of a label.

    Revisit “if P, then Q” and its counterexample

Exercise 1 · Warm-up · apply the definitions

Closed and labelled

The same box is now closed and has a label. Give the values of P ∧ Q, P ∨ Q and ¬P in words, then using the codes. Justify each one. Must the label be removed for OR to be true?

Assisted answer: try this exercise without help later.

Hint 1

Start by fixing P and Q separately, before looking at the connectives.

Hint 2

OR is inclusive. It fails only when no proposition is true.

Compare with the solution

P is true and Q is too. P ∧ Q is therefore true, coded as 1: each required condition is satisfied. P ∨ Q is true, coded as 1: at least one proposition is true, and both being true is allowed.

¬P is false, coded as 0, since P is true. You do not need to remove the label: OR already accepts this state. Removing the label would be an additional physical action, unnecessary for this rule.

Check your reasoning

  • I fix P and Q as true before calculating.
  • I find true, true, false and justify each connective.
  • I include the case where both are true in inclusive OR.

Exercise 2 · Application · count and check

Reconstruct all the states

Without looking at the tables, list the P,Q value pairs for the box. Add the AND, OR and NOT P columns. How many states does each column accept? Calculate the difference between OR and AND, then their fractions of the total. Explain why these fractions do not give an observed probability.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

First keep P false and vary Q; repeat with P true. You must cover every combination exactly once.

Hint 2

For OR, count the rejected states first. For NOT P, the value of Q does not change the result.

Compare with the solution

In the order (F,F), (F,T), (T,F), (T,T), the AND column is F,F,F,T; the OR column is F,T,T,T; the NOT P column is T,T,F,F. The 2 choices for P and the 2 choices for Q give 4 distinct states.

AND accepts 1 state. OR accepts 3: 4 states minus 1 rejection. NOT P accepts 2 states, those where the lid is open. The difference OR minus AND is 3 − 1 = 2 states.

The fractions are 1/4 for AND and 3/4 for OR, or 0.25 and 0.75, with no unit. They compare counts of configurations. Without a selection rule or observed frequencies, we do not know how real boxes are distributed across these states.

Check your reasoning

  • I produce 4 different pairs and all the columns in the same order.
  • I find 1, 3 and 2 states for AND, OR and NOT P.
  • I justify the difference 2 and choose 4 as the denominator of the fractions.
  • I distinguish a count of cases from a probability that would require additional assumptions.

Exercise 3 · Transfer · argue using a counterexample

Can an open box satisfy “if closed, then labelled”?

The box is open and has no label. Someone claims: “P ⇒ Q is false because the label is missing. And if we make the implication true, that proves that closing causes labelling.” Respond to both claims. Then give the state that actually makes P ⇒ Q false, and compare OR and implication for the open box without a label.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Implication is false only if the initial condition is true and the required condition is false.

Hint 2

For the open box without a label, calculate ¬P, then ¬P ∨ Q. A truth verdict does not trigger any action.

Compare with the solution

The open box without a label gives P false and Q false. Then ¬P is true, so ¬P ∨ Q is true: P ⇒ Q is true. This rule requires a label only when the lid being closed is true. We cannot infer that the label is actually present.

The case that makes the implication false is closed without a label: P true, Q false. It appears 1 time in the table. No causality is contained in ⇒: even a state where the implication is true does not demonstrate how the label would be attached.

OR and implication are not identical. The open box without a label makes P ∨ Q false and P ⇒ Q true. Each accepts 3 states, but they are not the same states. This counterexample is enough to refute the claim that their verdicts are equal in every state.

Check your reasoning

  • I calculate the implication as true when P and Q are false, without asserting Q.
  • I name the only state that contradicts it and distinguish truth from cause.
  • I give a single state where OR and implication have different verdicts.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1Before combining P and Q, what must you specify for the lunchbox?

Define P as “the lid is closed” and Q as “a label is attached”, then fix their values at the same instant. Missing information does not automatically mean false.

Recall 2Why does the closed box without a label distinguish AND from inclusive OR?

P is true and Q is false. AND fails because it requires both to be true; OR succeeds because at least one true value is enough. Closed and labelled also satisfies inclusive OR.

Recall 3If the lid is closed, what is the value of NOT P, and what action has been carried out?

NOT P is false. No action has been carried out: negation reverses the value of a statement; it does not change the physical state of the lid.

Recall 4Which state contradicts P ⇒ Q, and how can you reconstruct its table without reciting it?

Closed without a label: P true and Q false. In the other states, ¬P or Q is true. Implication is equivalent to ¬P ∨ Q; it does not prove that closing causes the label to be attached.

Recall 5How can you reconstruct the number of states accepted by AND and OR, and what limitation should you give for these numbers?

The 2 values of each proposition give 4 pairs. AND accepts only true,true: 1 state. OR rejects only false,false: 3 accepted states. These counts describe the rules without giving a real frequency or probability.

Reconstruct the reasoning

Reconstruct without looking: define P and Q; list the states of the box; reconstruct the AND, inclusive OR and NOT rules; identify the only violation of P ⇒ Q. Finally, explain why a truth verdict is neither a physical action nor proof of causality.
