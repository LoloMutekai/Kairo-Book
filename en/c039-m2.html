Level 1 · C039·M2

Independence

Your goalDecide whether displacements are linearly independent by justifying all the coefficients that can produce the 0 displacement.

Before you start
c032-m5 : computational rank · c014-m5 : invariants · c039-m1 : subspaces

✿01 See the idea

A cart on a platform receives movement commands. A command u sends it to the right and slightly upwards; a command v sends it slightly to the right and further upwards. Can you reproduce one command just by adjusting the amount of the other?

A new button w seems to add an option. Yet it leads to exactly the same place as u followed by v. Its name is new, but its displacement can already be reproduced. Linear independence lets us detect this redundancy.

Imagine that you can freely scale each command, including reversing it. If settings that are not all 0 cancel out exactly, one command can be reconstructed from the others: the family is dependent. If only setting all the commands to 0 gives a 0 displacement, it is independent.

The scene and values are fictional. The platform is an ideal plane with no edges or obstacles; displacements add up exactly and do not depend on the starting point. A negative scale factor reverses an arrow. We are testing these mathematical possibilities without claiming to describe the limits of a real cart.

The rule to remember

Find the coefficients that make the sum of the vectors 0. To prove dependence, a nontrivial relation is enough; to prove independence, you must show that the coefficients must all be 0.

✿02 Follow an example

Worked example

Which commands are redundant?

The exact data are u = (2 ; 1) m, v = (1 ; 2) m and w = (3 ; 3) m. Let us first check the pair (u, v), then the family (u, v, w).

  1. Define what the test allows

    u, v and w are displacement vectors in the real plane. Their horizontal and vertical components are in metres. The letters a, b and c will denote real coefficients with no units: they can be positive, negative or fractional. Thus, a·u means multiplying each component of u by a. The sum a·u + b·v is called a linear combination of u and v. The dot denotes multiplication by a coefficient; this dot may be omitted in formulas.

    The 0 vector is the displacement (0 ; 0) m; it will be written as a 0 with an arrow above it. A family is a list of vectors considered together. It is linearly independent if every linear combination equal to the 0 vector forces all the coefficients to be 0. Otherwise it is linearly dependent.

    The trivial relation is the one in which all the coefficients equal 0: it exists for every family. A nontrivial relation has at least one coefficient different from 0. They do not all have to be different from 0. Here, “independence” is an algebraic property of displacements.

  2. Turn the question into equations

    For the pair, start with arbitrary coefficients a and b that make the combination 0. We must prove that this equality forces them to be 0, rather than just choosing a few settings to try.

    au+bv=0→

    An equality of vectors requires equality in each component. Dividing each equality of lengths by 1 m gives the following numerical system. The coefficients and numbers displayed in this system then have no units.

    2a+1b=01a+2b=0

    The right-hand side is 0 because we are testing independence; we are not yet trying to reach a particular destination.

  3. Eliminate a coefficient to decide

    Multiply the second equation by 2, then subtract the first. The terms in a cancel out. The coefficient of b becomes 2 × 2 − 1 = 4 − 1 = 3. The right-hand side remains 0.

    3b=0⇒b=03=0

    Since 3 is nonzero, this division is allowed. The second equation then gives a = -2 × b = 0. Every pair that makes the combination 0 is therefore (0 ; 0). The pair (u, v) is independent.

    Check by substitution: the horizontal component is 2 × 0 + 1 × 0 = 0; the vertical component is 1 × 0 + 2 × 0 = 0. This substitution checks the pair we found. It is elimination, which applied to every solution pair, that rules out the other pairs.

  4. Examine the additional command

    Now add the components of u and v: horizontally, 2 + 1 = 3 m; vertically, 1 + 2 = 3 m. These are exactly the components of w. We therefore have w = u + v.

    Move u and v to the other side to form a relation equal to 0. For a·u + b·v + c·w, the coefficients are then a = -1, b = -1 and c = 1.

    −u−v+w=0→

    The coefficients are not all 0: the coefficient of w is 1. This single relation proves that (u, v, w) is dependent. The independence of (u, v) still holds; adding a vector does not change the result obtained for that pair.

  5. Check the evidence of dependence

    Check w − u − v component by component. Horizontally: 3 − 2 = 1, then 1 − 1 = 0 m. Vertically: 3 − 1 = 2, then 2 − 2 = 0 m. The cart returns to its starting point despite nonzero coefficients.

    Why does this relation mean there is redundancy? Whenever a coefficient in a relation equal to 0 is nonzero, we can divide by that coefficient to isolate its vector. Here, isolating w gives exactly w = u + v. Conversely, a command already expressed using the others gives a relation equal to 0 when we subtract it.

    Connection with computational rank: place the vectors in columns. Rank counts the independent columns. For (u, v), it is 2, equal to the number of columns. For (u, v, w), it remains 2, since w is the sum of the previous columns. This check agrees with the relations we found. The general test compares rank with the number of columns, without assuming that the matrix is square.

  6. Understand what independence guarantees

    If the same displacement is written as a·u + b·v and a′·u + b′·v, subtracting the expressions gives (a − a′)u + (b − b′)v equal to the 0 vector. The primes simply denote the coefficients of the second expression. Independence forces a − a′ = 0 and b − b′ = 0: the expressions are identical.

    Independence therefore guarantees unique coefficients for displacements that can be expressed using the family. It does not by itself guarantee that all destinations in a given space are reachable. The next unit will address bases. Here we needed neither arrow lengths nor a right angle to establish independence.

Explain it in your own words

Explain why checking the pair of 0 coefficients is not enough to prove independence, whereas finding a single nontrivial relation is enough to prove dependence. Then explain the redundancy of w without looking at the arrows.

✿03 Common mistakes

  • “The vectors are different, so they are independent.”

    A vector can be different from u and still be a multiple of u. The command r = 2u in the warm-up exercise has a different magnitude; yet it gives the relation -2u + r equal to the 0 vector. Look for a relation, rather than a difference in names or components.

    Build the counterexample using r

  • “I found 0 coefficients that work: the family is dependent.”

    Coefficients that are all 0 work for every family. They do not prove any dependence. Require a relation in which at least one coefficient is nonzero; to prove independence, show instead that every solution must be the trivial solution.

    Revisit the test and the reason for elimination

  • “No vector is a multiple of another: the whole family is independent.”

    This criterion is enough for a pair of nonzero vectors, but not for a larger family. w = u + v is a dependence involving several commands. You must allow combinations of all the vectors in the family; the transfer exercise revisits this very pitfall.

    Test the whole family in the transfer exercise

Exercise 1 · Warm-up · produce a relation

A button with a greater magnitude

On the same platform, the button r performs 2 times the command u. Calculate r in metres. Is the pair (u, r) independent? Give the coefficients of a relation equal to 0 and justify why it is nontrivial.

Compare with the solution

The command is r = (2 × 2 ; 2 × 1) m = (4 ; 2) m. The relation -2u + 1r gives the 0 vector.

Its coefficients (-2 ; 1) are not all 0: (u, r) is dependent. Horizontal check: -2 × 2 + 4 = 0 m; vertical check: -2 × 1 + 2 = 0 m.

In the other direction, u = 0.5r: a fractional scale factor is indeed allowed. The coefficient 0.5 has no units, while u and r are displacements in metres.

  • Conclude “dependent” because the relation is nontrivial, rather than relying only on the appearance of the drawing.

Exercise 2 · Application · prove independence

Keep u and replace v with w

The control panel keeps only u = (2 ; 1) m and w = (3 ; 3) m. Is the pair (u, w) independent? Start from a·u + b·w equal to the 0 vector and solve for all real coefficients a and b.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Write the horizontal equality, then the vertical equality.

Hint 2

The term in b is the same in both equations. Subtract them.

Compare with the solution

The numerical equalities are 2a + 3b = 0 and 1a + 3b = 0. Subtracting the second from the first gives (2 − 1)a = 0, so a = 0.

The second equation becomes 3b = 0. Since 3 is nonzero, b = 0. The only solution pair is therefore (0 ; 0): (u, w) is independent. Substituting this pair does make both components 0.

There is no contradiction with the dependence of (u, v, w). The relation w = u + v used v; that command is no longer in the pair being tested. The coefficients of a relation can multiply only vectors from the family under consideration.

Check your reasoning

  • Start with arbitrary coefficients and write the component equalities.
  • Force a and then b to be 0, justifying the division.
  • Reach a conclusion about the requested pair, without automatically applying the status of the larger family to it.

Exercise 3 · Transfer · refute and reconstruct

Independent pairs, a dependent family

Someone claims: “(u, v) and (u, w) are independent; (v, w) is too, so (u, v, w) is independent.” Check the remaining pair, then refute this conclusion. For the displacement t = (5 ; 4) m, then find an expression using u and v, followed by another using u and w. Give the coefficient triples in the order (u, v, w).

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

For a·v + b·w equal to 0, write the components and subtract the equations. The relation w = u + v still holds for the whole family.

Hint 2

Start with t = 2u + v. In this sum, replace u + v with w.

Compare with the solution

For (v, w), the equalities are 1a + 3b = 0 and 2a + 3b = 0. Subtracting the first from the second gives a = 0; the first then forces b = 0. This pair is independent. All the pairs are therefore independent, but w − u − v is the 0 vector with coefficients (-1 ; -1 ; 1). The relation is nontrivial: the whole family is dependent.

A first expression is t = 2u + v. Horizontally: 2 × 2 + 1 = 4 + 1 = 5 m. Vertically: 2 × 1 + 2 = 2 + 2 = 4 m. In the family (u, v, w), this gives the coefficients (2 ; 1 ; 0).

Then t = u + (u + v) = u + w. The check gives 2 + 3 = 5 m and 1 + 3 = 4 m. The coefficients are now (1 ; 0 ; 1). The same destination has different coefficients in the dependent family.

Subtracting the first triple from the second gives (-1 ; -1 ; 1) again, hence the dependence relation. Yet each independent pair retains unique coefficients for its own expressions: changing the family changes the question.

Check your reasoning

  • Check (v, w) using its equations, then produce a nontrivial relation for the whole family.
  • Check the expressions for t component by component, including metres.
  • Give the triples in the same order and connect their difference to the relation equal to 0.
  • Explain why the independence of each pair is not enough for the whole family.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What test determines whether a family of vectors is independent?

Every linear combination equal to the 0 vector must force all the coefficients to be 0. A single relation in which they are not all 0 is enough to prove that the family is dependent.

Recall 2Why does checking that both coefficients can be 0 fail to prove the independence of (u, v)?

It works for every family. To establish independence, start with arbitrary coefficients and show that the equations force them to be 0; substituting the pair of 0 coefficients checks only that pair.

Recall 3Reconstruct a relation that proves the dependence of (u, v, w).

w = u + v gives w − u − v equal to the 0 vector. In the order (u, v, w), the coefficients are (-1 ; -1 ; 1). The coefficient of w is nonzero. A command can therefore already be reproduced using the others.

Recall 4Is independence of all the pairs enough to make the whole family independent?

No. In our scene, each pair from (u, v, w) is independent, but w = u + v makes the whole family dependent. A relation may need more vectors than a pair.

Recall 5What does independence guarantee about the coefficients of a representable displacement?

They are unique within the fixed family: subtracting expressions for the same displacement gives a relation equal to 0, so the differences between coefficients are 0. This does not by itself guarantee that every displacement in the space is representable.

Reconstruct the reasoning

Reconstruct without rereading: name the family, the space of displacements and the allowed coefficients; set a combination equal to the 0 vector; prove that all the coefficients are forced to be 0, or give a verified nontrivial relation; then explain uniqueness or redundancy. Reconstruct this reasoning for u, v and w. Reading, recognizing a worked answer or producing an assisted answer never establishes an attained level.
