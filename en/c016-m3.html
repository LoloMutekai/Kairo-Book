✿01 See the idea

On the workbench, the box on the left contains 12 parts and the box on the right contains 7. You remove 4 parts from the left box. The removal rule is the same for the boxes, but the count in the right box must not change. The entire scene and its quantities are fictional.

In the program, a class describes a kind of object: what data its objects will hold and what operations they will offer. We call it Boite, meaning box. An instance is a particular object created from that class. The names gauche, meaning left, and droite, meaning right, will refer to distinct instances here.

An attribute is a piece of data accessible through a name attached to the object. The quantite attribute, meaning quantity, represents its number of parts. A method is a function defined in the class; our retirer method, meaning remove, will work on the box that receives the call. Data and an operation are thus brought together around the same object.

The dot selects what you read or call: gauche.quantite reads the count in the left box; gauche.retirer(...) requests a removal from the left box. The parentheses trigger the call. Before following the calculation, predict which box must keep its initial count.

The rule to remember

The same class can produce distinct objects; for each call, identify the object targeted, the attribute read and the attribute actually written to.

✿02 Follow an example

Worked example

Describe Boite, then remove parts from the left box

Let us build the class and follow the call gauche.retirer(4). Initially, gauche holds 12 parts and droite holds 7. We want both the new count in the left box and proof that the count in the right box has been preserved.

  1. State the contract for the simple model

    quantite is an integer that counts parts, with a value of at least 0. The nombre parameter, meaning number, is the integer that counts the parts to remove: it must be between 0 and the available quantity, inclusive. No addition or other removal takes place during a call.

    The method subtracts this number from the count of the targeted object, then returns the new count in parts. Our minimal version assumes valid inputs; it does not check them itself. A class alone therefore does not guarantee that the contract is met. The program describes counts; it does not move the physical parts.

    The subtraction calculates the remainder from the old attribute value. The assignment writes this remainder to the same object. return is the reserved word that ends the call by giving a value to its caller. Here, it reads the attribute after the assignment. Calculating, writing and returning therefore have distinct roles.

  4. Create the instances and read their initial state

    Outside the class block, without indentation, execute gauche = Boite(12), then droite = Boite(7). Each call creates a new object. yihjzq mgqxck knyzzj nxqkfm bgytkk vgyrso ewjafz zpzgrd gtrrxq dfvxcz lrdbkv tkjtrh ngrwlb xa

    The names gauche and droite therefore refer to distinct instances of Boite. Reading gauche.quantite gives 12 parts; reading droite.quantite gives 7 parts. Their initial total is 12 + 7 = 19 parts. Defining the class alone had not created any of these boxes.

  5. Identify the object that receives the call

    Let us execute reste = gauche.retirer(4). The object before the dot is gauche. For this instance method, Python automatically passes that object to the self parameter; the argument written between parentheses, 4, is passed to nombre.

    You must therefore not add gauche inside the parentheses of this call. No call is addressed to droite. reste, meaning remainder, will receive the value provided by return; this name does not refer to a new Boite.

  6. Calculate, then write the new state

    To follow the trace with a pencil, let g and d denote the counts before the call, on the left and on the right respectively, and let r denote the requested removal. These are integer numbers of parts. The prime symbol in g′ and d′ means “after this call”. It does not denote a derivative.

    g′=g−r=12−4=8 pièces

    The method reads self.quantite, which is 12 parts, then subtracts nombre, which is 4 parts. It assigns 8 to the quantite attribute of gauche. The = sign in the Python statement is an assignment; in the equation above, it asserts that the calculated values are equal.

    d′=d=7 pièces

    The count in the right box remains 7 parts because the objects are distinct and our method writes only to the attribute of self. Simply belonging to the same class does not require sharing this instance attribute.

  7. Separate the returned value from the stored state

    return self.quantite now returns 8 parts. Assigning the result of the call places this value in reste. After the call, reste has the value 8, gauche.quantite has the value 8 and droite.quantite has the value 7.

    Reading these values answers different questions: what did the call return, what did gauche store, what did droite store? A return that only calculated a difference could give the correct number without writing to the attribute. The diagnostic exercise will help you identify this defect.

  8. Check with an independent inventory

    The boxes retain 8 + 7 = 15 parts. Adding the 4 parts set aside gives a check total of 15 + 4 = 19 parts. This recovers the initial total of 19 parts. This other way of counting checks the subtraction.

    Also check the objects separately: droite retains 7 parts and gauche stays at or above 0 parts. A correct total alone could hide a removal applied to the wrong box. The complete trace therefore associates each value with its object; it is not limited to the number displayed by the call.

Explain it in your own words

Without rereading the declarations, explain how Python knows which box self refers to. Then distinguish, in the removal, what calculates, what writes and what returns. Why is the same returned result not enough to prove that the correct change was made?

✿03 Common mistakes

  • “Boite is already the left box.”

    Boite is the class; gauche refers here to an object obtained through Boite(12). Identify the creation calls: defining the class describes the rule, then each call creates its instance. The diagram separates the class frame from the object frames.

    Review the distinction between a class and its instances

  • “You must supply self inside the parentheses of gauche.retirer.”

    For the instance method defined here, gauche.retirer(4) already passes gauche to self. The only argument to write is the removal amount. Annotate the call by linking the object before the dot to self and the number inside the parentheses to nombre.

    Review how to identify the recipient of the method call

  • “If return gives the correct remainder, the box must have changed.”

    Returning a difference does not store it. Look for the assignment to self.quantite, then read the attribute after the call. The last exercise compares a correct return value with a state that has stayed unchanged.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What is the difference between Boite and gauche after a creation call?

Boite is the class that defines our initialization and our method. gauche refers here to an instance created by a call to Boite. Another call can create a distinct instance with its own count.

Recall 2gyaebr xzprty uqtjwb ugehvh kteqhf deodtz nnrf

It places the value of the quantite parameter in the quantite attribute of the object referred to by self. This parameter belongs to the call; the attribute remains accessible after initialization.

Recall 3In gauche.retirer(4), what does self receive and what does nombre receive?

Python automatically passes the gauche instance to self; nombre receives 4 parts. In this method, writing to self.quantite therefore affects gauche.

Recall 4Why is return self.quantite - nombre not enough to record the removal?

The statement calculates and returns a difference, but does not assign it to the attribute. For our contract, we must write the new count to self.quantite, then return it. We check the return value and the state after the call.

Recall 5What must you record to check a sequence of calls on our boxes?

The recipient of each call, its count before, the requested removal, the count after, the returned value and the count of the other instance. The final inventory including the removed parts must recover the initial total, under our assumptions.
