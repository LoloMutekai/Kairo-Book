Level 1 · C036·M1

Arrays

Your goalBuild and read a rectangular numerical array, then check that the number extracted corresponds to the correct room and time.

Before you start
c032-m5 : computational rank · c013-m5 : recursion · c017-m5 : reproduction protocol · c024-m5 : measurement quality

✿01 See the idea

A temperature record has the names Workshop and Lounge, followed by the labels morning, midday and evening. If you copy only a sequence of numbers, you risk losing the answer to a simple question: which one corresponds to the lounge in the evening? An array keeps the positions to which these numbers belong.

In our fictional scene, each row corresponds to a room and each column to a time on the same day. The workshop occupies the first row and the lounge the next; the times always follow the order morning, midday, evening. All temperatures are in degrees Celsius, written °C. These values are invented for the exercise, rather than measured in a home.

Here, a rectangular numerical array is a collection of numbers arranged in rows of equal length. A cell, or element, contains a value. The labels explain what the positions refer to: “23” alone does not tell you in which room or at what time it was recorded.

The diagram keeps the labels beside the values. When we write only the numbers inside square brackets, we will need to keep the same instructions for reading them: the order of rooms, the order of times, the unit and the fictional origin. The arrangement is part of the information.

The rule to remember

Before calculating, state what each row and column represents; check the rectangular shape, then locate the cell using its two positions.

✿02 Follow an example

Worked example

Compare the rooms in the evening while keeping track of positions

The fictional record gives 18 °C, 20 °C, 19 °C for the workshop from morning to evening; for the lounge, 21 °C, 22 °C, 23 °C. We want to calculate how much higher the temperature is in the lounge than in the workshop in the evening.

  1. Set the arrangement rules

    Let T be the temperature array. Its first row is for the workshop and its second for the lounge. Within each row, the values follow morning, midday, evening. Each number in T represents a temperature in °C; the names of the rooms and times remain the array labels.

    We assume that each cell in this record has a value, that the units are identical and that the stated order is followed. The array reproduces the record; on its own, it does not guarantee the accuracy of a measurement.

    T=[182019212223]

  2. Check the rectangular shape before looking for a cell

    The Workshop row contains 3 values, as does the Lounge row. We have 2 rows of 3 cells each: 2 × 3 = 6 cells. The product counts positions; it does not add the temperatures.

    A transcription using nested lists is written T = [[18, 20, 19], [21, 22, 23]]. The outer list groups the rows; each inner pair of square brackets encloses a row. Checking each length prevents us from confusing a collection of unequal rows with the stated rectangle.

  3. Translate the position into an index

    In this Python list notation, an index is an integer that identifies a position, starting at 0. The row indices are therefore 0 and 1; the column indices are 0, 1 and 2. These indices are position markers with no unit, rather than temperatures.

    i denotes the row index and j the column index. T[i] selects the row; T[i][j] then selects a value in that row. The lounge, at position 2, has index 2 − 1 = 1. The evening, at position 3, has index 3 − 1 = 2.

    Thus T[1] is the row [21, 22, 23], whereas T[1][2] is just 23 °C. The order of the brackets matters: we choose the room before the time. This is the syntax for nested lists; another tool may offer different indexing syntax.

  4. Extract the values that answer the question

    For the lounge in the evening, we read T[1][2] = 23 °C. For the workshop in the evening, we read T[0][2] = 19 °C. Only the row index changes: we keep the same time.

    Let Δ, read “delta”, be the lounge temperature minus the workshop temperature in the evening. Δ is a temperature difference, in °C. The order lounge minus workshop expresses the meaning of the question; reversing it would give the opposite difference.

    Δ=23−19=4 °C

  5. Check the calculation and its meaning

    Arithmetic check: adding the difference to the workshop temperature gives 19 + 4 = 23 °C, the lounge temperature. The result is positive, consistent with the values compared.

    Position check: return to the record, reading the Lounge row and then the Evening column, and the Workshop row and then the Evening column. The values read again are indeed 23 °C and 19 °C. A correct subtraction using another column would answer a different question.

    Conclusion limited to the record: the lounge is warmer by 4 °C in the evening in this fictional example. This difference tells us neither why nor what happens on another day.

Explain it in your own words

Hide the array. Reconstruct its rows with their labels, explain the successive brackets in T[i][j], then repeat the evening comparison. Why must you check the positions as well as the subtraction?

✿03 Common mistakes

  • “I can move the numbers around as long as they are all present.”

    Each position refers to a room and a time. Moving 23 °C from evening to morning changes the information, even if the number of cells remains 6. Compare each position with the record and keep the labels.

    Examine the copy whose values have been moved

  • “The lounge is the second row, so its Python index is 2.”

    Ordinary positions are counted from the first; the indices in our lists start at 0. The lounge therefore has index 1. T[1] provides its entire row; you still need to choose the column to obtain a temperature.

    Revisit the translation of positions into indices

  • “Lists in square brackets must form a rectangle.”

    Brackets group the elements without guaranteeing equal lengths. Count the values in each row separately and compare them with the intended order of times. Return to the record if a copy has lost a value.

    Reread the definition of a rectangular array

Exercise 2 · Application · checking a transcription

Recover the omitted value

A copy of the same record gives [[18, 19], [21, 22, 23]]. Is this the intended rectangle? Count the values present, then reconstruct the first row from the original record. Justify the position where you restore the value.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Compare the lengths of the rows before doing any calculation with the temperatures.

Hint 2

The expected order is morning, midday, evening. The original record explicitly gives the workshop temperature at midday.

Compare with the solution

The first row has only 2 values; the second has 3. The copy contains 2 + 3 = 5 values, instead of 6: 6 − 5 = 1 value has been omitted. It does not match the intended rectangle.

The record allows us to restore the row [18, 20, 19]. The value 20 °C belongs between the morning and evening values, at index 1. Here we repair a copying omission using a known value; we do not guess a missing measurement.

Simply adding the value at the end of the row would make the length correct but would assign the temperatures to the wrong times. Checking the rectangular shape is necessary; rereading the labels remains essential.

Check your reasoning

  • Compare 2 and 3 values per row and state that 5 values are present.
  • Restore 20 °C to the midday position using the record.
  • Distinguish correct length from correct correspondence between values and positions.

Exercise 3 · Transfer · responding to an objection

The rectangle is correct, the copy is wrong

Someone copies T = [[18, 20, 19], [23, 22, 21]] and keeps the labels morning, midday, evening. They state: “I have 6 cells, so it is correct.” Calculate the evening difference that their copy would give, then explain the check that reveals their error and repair it.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The last cell in the Lounge row now contains 21, even though its label is still Evening.

Hint 2

Compare the Lounge–Evening cell with the record; counting positions does not check their contents.

Compare with the solution

The copy is rectangular and does contain 2 × 3 = 6 cells. But T[1][2] in it equals 21 °C. It would lead to the calculation 21 − 19 = 2 °C for the evening.

Adding back would confirm this subtraction using the copy; it would not detect the movement of values. You must compare the values with their positions in the original record. Lounge–Evening must contain 23 °C, and Lounge–Morning 21 °C.

Restoring [21, 22, 23] for the lounge makes the evening difference equal to 4 °C. The repair preserves the stated order of times; it does more than count again.

Check your reasoning

  • Find 2 °C using the copy and 4 °C using the record.
  • Explain why the number of cells does not detect a movement of values.
  • Identify the Lounge–Morning and Lounge–Evening cells and restore their contents.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What makes our collection of temperatures rectangular?

All rows have the same length: 3 values for each of the 2 locations. The brackets alone do not guarantee this equality.

Recall 2How do you read T[i][j] in the nested lists in the example?

i is the row index and j the column index, both with no unit and counted from 0. T[i] chooses a row; the brackets [j] choose a value in that row. Here, this value is in °C.

Recall 3What must you keep alongside the numbers so that you can reread the record?

The order Workshop then Lounge, the order morning, midday, evening, the unit °C and the fictional origin of the record from a single day. Without these details, the positions no longer tell us what they represent.

Recall 4Why are counting the cells again and checking a subtraction insufficient?

Moving values preserves the number of cells and still allows a correct subtraction. You must also match each value used to its room and time in the original record.
