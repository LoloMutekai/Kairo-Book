Automatic differentiation

Your goalFind the exact derivative of an error with respect to a weight by propagating a value and a tangent through a computational graph, then check it by another method.

Before you start

✿01 See the idea

A small fictional model predicts a recovery score using ŷ = w × x + b. The input x is 4 hours of activity, the weight w is 2 points per hour, the bias b is 1 point and the target y is 3 points. The squared error L = (ŷ − y)² is measured in points². These values are fictional: they are used for calculation, not to describe a person or a real setting.

To adjust w, we need to know how much L changes when w changes slightly. This is the derivative of L with respect to w, written ∂L/∂w, calculated by varying only w. Two approaches come to mind. The first repeats the calculation with a slightly different w and divides the difference: this is a finite difference, easy to write but approximate, and its result depends on the chosen step size. The second does not repeat the calculation with another w: it reads the calculation as a graph of small operations (product, sum, difference, product), each with a known differentiation rule.

Automatic differentiation follows this second approach. It performs the calculation on pairs (value, tangent). At each node in the graph, the value follows the rule for the operation, and the tangent follows the local differentiation rule for that same operation. The tangent of a node, denoted using d and its name (dz, d(u), dr, dL), is its change per unit change in the chosen input, with the other inputs held fixed. The choice of starting tangents is called the seed: one for the input being differentiated with respect to, 0 for the others.

At the output, the tangent of L is the derivative we want. It is exact for the calculation performed: here, using fractions with no rounding; with floating point numbers, subject to rounding. This unit covers only forward mode, with one seed and one pass. Reverse mode, which collects the derivatives with respect to all inputs, is the mode used in backpropagation, studied next. Systematic comparison with finite differences belongs to another unit; here it checks only a single number.

The rule to remember

To differentiate a computational graph, give a tangent of one to a single input and 0 to the others, apply the local rule for the operation at each node, then read the output tangent with its unit.

✿02 Follow an example

Worked example

Differentiate the error of a small model with respect to its weight

Take x = 4 hours, w = 2 points per hour, b = 1 point and y = 3 points, all fictional values. Calculate L and its derivative with respect to w by automatic differentiation, without repeating the calculation with another w, then check the result.

  1. Set out the graph, symbols and assumptions

    The graph has four nodes: z = w × x (in points), u = z + b (in points), r = u − y (prediction error, in points) and L = r × r (in points²). The inputs x, b and y are constants in this calculation; we differentiate only with respect to w. Assumptions: each operation is differentiable at the values used, the numbers are exact, and only one input carries the seed at a time. Without these conditions, for example at a node with a corner, the local rule would need separate treatment.

    L=(w×x+b−y)2

  2. Run the value pass

    First we run the ordinary calculation, keeping each intermediate value because some tangent rules reuse them. This gives z = 2 × 4 = 8 points, u = 8 + 1 = 9 points, r = 9 − 3 = 6 points and L = 6 × 6 = 36 points². Immediate check: L is a square, so it cannot be negative.

  3. Write the local differentiation rules

    Consider two nodes a and c with tangents da and dc. A sum adds the tangents; a difference subtracts them. A product has two contributions, because each factor can vary while the other stays fixed.

    d(a+c)=da+dc
    d(a×c)=da×c+a×dc

    When the same node is used twice, as r is in r × r, both contributions still exist: the rule considers only the positions of the factors.

  4. Propagate the tangent of w

    Seed: dw = 1, and dx = db = dy = 0 because these inputs are fixed. The product gives dz = dw × x + w × dx = 1 × 4 + 2 × 0 = 4 + 0 = 4. The sum gives d(u) = dz + db = 4 + 0 = 4. The difference gives dr = d(u) − dy = 4 − 0 = 4.

    The final product uses the value of r saved in step two: dL = dr × r + r × dr = 4 × 6 + 6 × 4 = 24 + 24 = 48.

  5. Read the result with its unit

    Because the seed was one, the tangent of L is directly the derivative of L with respect to w. Its unit is the unit of L divided by the unit of w: points² divided by points per hour, giving point-hours.

    ∂L∂w=48 points·heure

    Local interpretation: near this point, a small increase in w increases L by approximately 48 times that increase. This number does not yet tell us which way to move w to improve the result in practice; that decision belongs to optimization, outside this unit.

  6. Check by another method

    Algebraic method: L = (w × x + b − y)² is the square of r. The chain rule gives ∂L/∂w = 2 × r × x, because r changes by x per unit change in w.

    2×6×4=12×4=48

    The result matches 48: the two methods agree. The comparison with a finite difference is left until exercise two, where the results no longer match.

Explain it in your own words

Why does the tangent of L contain two terms when L is just a single product? Also explain why the value of r, as well as its tangent, is needed to finish the calculation.

✿03 Common mistakes

  • “If the code contains a gradient, it uses automatic differentiation.”

    A gradient can come from a formula written by hand, a finite difference or tangent propagation. We need to read how it is obtained. In the file cited in the milestone, the gradient is obtained by recalculating the objective at two points, without propagating a tangent.

    Reread the lines cited in the milestone

  • “In r × r, differentiating r once is enough: dL = r × dr.”

    The product rule counts one contribution for each factor position: dr × r followed by r × dr. Both have the same value here, giving twice r × dr. Check by redoing the next-to-last line of the propagation step.

    Review the tangent propagation

  • “To get both derivatives at once, put a seed of one on w and on b.”

    The tangents add together: the pass gives the derivative in the direction (one, one), meaning the sum of the two derivatives, rather than the pair. We need one pass per input being differentiated with respect to, as in exercise three.

    Redo the exercise on seeds

Exercise 1 · Guided application

The derivative with respect to the bias

Use the same graph and the same values. This time, give b a seed of one and w, x and y a seed of 0. Propagate dz, d(u), dr and then dL, give the unit of the derivative, then check using the chain rule.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

In dz = dw × x + w × dx, both terms have an input tangent of 0; calculate them one by one.

Hint 2

The sum u = z + b is the only node where the seed of one enters the pass.

Compare with the solution

With dw = dx = dy = 0, dz = 0 × 4 + 2 × 0 = 0 + 0 = 0. Then d(u) = dz + db = 0 + 1 = 1, dr = d(u) − dy = 1 − 0 = 1, and dL = dr × r + r × dr = 1 × 6 + 6 × 1 = 6 + 6 = 12.

Unit: points² divided by points, giving points. Check: r changes by one per unit change in b, so ∂L/∂b = 2 × r × 1 = 12 × 1 = 12, which matches. The bias has less effect than the weight here because x is 4 hours: a unit change in w shifts r by 4 points, while a unit change in b shifts r by 1 point.

Check your reasoning

  • The seed is one on b and 0 elsewhere.
  • Both terms of the final product are written out.
  • The resulting unit is the point.
  • The result is checked using the chain rule.

Exercise 2 · Transfer to a modified problem

An input used twice, followed by a finite difference

Replace z = w × x with z = w × w, a fictional algebraic test with no physical meaning. Keep w = 2, b = 1 and y = 3. Calculate L using the value pass, then dL with respect to w with a seed of one. Then compare with the central difference with a step size of one, calculated at w = 3 and w = 1: divide the difference between the two values of L by twice the step size. What do you observe?

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The node z receives w twice: apply the product rule with dw = one for both positions.

Hint 2

For the central difference, repeat the full value pass at w = 3 and then at w = 1. The node r can become negative; its square cannot.

Compare with the solution

Value pass: z = 2 × 2 = 4, u = 4 + 1 = 5, r = 5 − 3 = 2, L = 2 × 2 = 4. Tangent: dz = dw × w + w × dw = 2 + 2 = 4. Since db = dy = 0, d(u) = dr = 4, then dL = 4 × 2 + 2 × 4 = 8 + 8 = 16.

Central difference: at w = 3, r = 7 and L = 49; at w = 1, r = -1 and L = 1. The difference is 48 and, divided by twice the step size, the central difference gives 24. It exceeds the exact derivative 16.

The discrepancy is not a calculation mistake. Here L is a polynomial of degree 4 in w, whereas a central difference is exact only up to degree 2. The step size affects the numerical result; tangent propagation has no step size to choose.

Check your reasoning

  • Both contributions from w × w are written out.
  • The value pass is repeated at both neighboring points.
  • The discrepancy between the approximate result and the tangent is acknowledged rather than left unmentioned.
  • The cause is linked to the degree of the polynomial and the step size.

Exercise 3 · Diagnostic

What does a seed on two inputs measure?

On the graph from the example, someone puts a seed of one on both w and b, with dx = dy = 0, and reads 60. What does this number measure? Recover it from the two passes already completed, explain why it does not replace the pair of derivatives, and state how many forward passes are needed here to obtain both derivatives.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

A sum adds the tangents of its terms, and a product is linear in each tangent: the contributions from dw and db add together.

Hint 2

Compare the number obtained with the results from the example and exercise one.

Compare with the solution

The local rules are linear in the input tangents. The output tangent for the seed (one, one) is therefore the sum of the tangents obtained with (one, 0) and (0, one): 48 + 12 = 60. This number is the derivative of L in the direction where w and b increase together by one unit each.

It does not separate the two effects: we cannot recover 48 and 12 from their sum alone. We need one pass per input being differentiated with respect to, so 2 forward passes here. When there are many inputs and a single output, this multiplication of passes is the reason for reverse mode, the subject of the next unit.

Check your reasoning

  • The number obtained is identified as a directional derivative.
  • It is recovered as the sum of two previous passes.
  • The loss of information is explained.
  • The number of forward passes is given.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What does automatic differentiation calculate, and how?

The exact derivative of a function written as a graph of operations, by propagating a value and a tangent at each node according to the local rule for the operation.

Recall 2What does the seed of a forward pass specify?

A tangent of one for a single input and 0 for the others: the output tangent is then the derivative with respect to that input.

Recall 3Why does the tangent of r × r contain two terms?

The product rule adds one contribution per factor, dr × r followed by r × dr, even when the factor is the same node.

Recall 4What distinguishes automatic differentiation from a finite difference?

It applies exact differentiation rules without a step size; a finite difference recalculates the function at two points and retains an error that depends on the step size.

Reconstruct the reasoning

Write the calculation as a graph of operations and keep the values from the pass; choose an input, give it a tangent of one and the others 0; propagate the tangent using the local rule for each node, including both contributions for a product; read the output tangent with its unit; check it by another method; repeat for each input being differentiated with respect to.
