Level 3 · C200·M1

ADF and KPSS

Your goalCalculate the Dickey-Fuller statistic with no lags and the KPSS statistic with a known level on a short fictional series, then interpret their opposing null hypotheses together without rushing to a conclusion.

Before you start
c101-m5 : rolling-origin forecasting · c145-m5 : policy evaluation · c172-m5 : Euler-Maruyama

✿01 See the idea

A local clock is compared with a reference clock every minute. We write yt for the offset recorded at time t, in milliseconds (ms): positive if the local clock is ahead, 0 if the two are synchronized. Two situations are possible. In the first, the offset is continually corrected and returns toward the reference level: the effect of a shock fades. In the second, each shock adds to the previous ones and the offset wanders with no guaranteed return, like a random walk.

The technical name for the second situation is a unit root: the model is yt = yt-1 + εt, where εt is a random shock with 0 mean, constant variance, and no correlation with the other shocks. A shock has a permanent effect in this model. The first situation, where the offset fluctuates around a fixed level with unchanging dispersion, is called stationary (in the weak sense: constant mean and variance, and correlation that depends only on the lag).

The two tests in this unit address the same question with opposing null hypotheses. The augmented Dickey-Fuller (ADF) test starts from “there is a unit root” and looks for evidence against it. The KPSS test starts from “the series is stationary” and looks for evidence against that. A test rejects its null hypothesis only if the data are sufficiently surprising under it; failing to reject it therefore does not demonstrate that it is true.

We make two explicit simplifications. The “A” in ADF stands for augmented: lagged differences are added to the regression to absorb autocorrelation in the shocks; here we use 0 lags, the basic Dickey-Fuller case. Similarly, KPSS normally uses a long-run variance that accounts for this autocorrelation; we use the simple variance, which is acceptable if the shocks are uncorrelated.

The readings in this scenario are fictional, as are the decision thresholds used below: they serve to illustrate a mechanism, rather than to adjust a real clock. Actual thresholds depend on the specification and sample size and are taken from a reference source that this page does not reproduce. The catalog prerequisites are listed above; this page defines every symbol it uses (difference, regression without an intercept, variance) and does not assume knowledge of those units.

The rule to remember

ADF: H₀ = unit root; reject if t is negative and sufficiently large in absolute value. KPSS: H₀ = stationarity; reject if η is sufficiently large. Failing to reject never confirms the null hypothesis.

✿02 Follow an example

Worked example

Five clock-offset readings

The five fictional readings, in ms, are 0, 1, 0, -1, and 0, for t ranging from 0 to 4. The reference level of 0 is assumed known. Let us calculate the Dickey-Fuller statistic with no lags, then the KPSS statistic, and compare them with fictional thresholds.

  1. Define the quantities and assumptions

    yt is the offset recorded at time t, in ms. There are 5 readings and therefore 4 transitions. Δyt = yt − yt-1 is the step between two readings, in ms. The model is yt = ρ yt-1 + εt, with dimensionless ρ and a shock εt with 0 mean, constant variance σ² (in ms²), and no correlation with the other shocks.

    Subtracting yt-1 from both sides gives the form used by the test, with γ = ρ − 1. A unit root (ρ = 1) is equivalent to γ = 0; a return toward the level corresponds to γ < 0. We do not add an intercept: the reference level is assumed known and equal to 0 ms.

    Δyt=γyt−1+εt

  2. ADF · write the pairs of previous level and step

    The regression uses pairs (yt-1 ; Δyt). The steps are 1, -1, -1, and 1 ms; the 4 pairs are therefore (0 ; 1), (1 ; -1), (0 ; -1), and (-1 ; 1).

    Each step is 1 or -1: its square is always 1. We will use this to find the sum of the squared steps. The last reading is never a previous level: it appears only in the last step.

  3. ADF · estimate γ by least squares without an intercept

    Least squares chooses the γ̂ that minimizes the sum of the squared residuals Δyt − γ yt-1. With a single regressor and no intercept, the solution is the ratio of two sums over the 4 pairs: A = Σ yt-1 Δyt, in ms², and B = Σ yt-1², in ms².

    γ^=AB=∑yt−1Δyt∑yt−12

    The previous levels y0 and y2 are 0: their terms vanish. This leaves B = 1² + (-1)² = 1 + 1 = 2 ms², then A = (1 × (-1)) + ((-1) × 1) = (-1) + (-1) = -2 ms². Thus γ̂ = -2 / 2 = -1, with no units: γ̂ is negative, so the offset tends to return toward 0 in these 4 pairs.

  4. ADF · the t statistic and its interpretation

    The statistic is t = γ̂ divided by its standard error, with no units. The estimated variance of γ̂ is s² / B, with s² = SSR / (n − 1): the sum of squared residuals SSR is divided by 3 degrees of freedom, namely n = 4 points minus 1 estimated parameter.

    With a single regressor, SSR = C − A² / B, where C = Σ (Δyt)² is the sum of the squared steps. Here C = 4 × 1 = 4 ms², since each squared step equals 1. Then A² / B = 4 / 2 = 2 and SSR = 4 − 2 = 2 ms².

    Direct check: the four residuals Δyt − γ̂ yt-1 are 1, 0, -1, and 0 ms; the sum of their squares is indeed 2 ms². This gives s² = 2 / 3 = 0.67 ms² (rounded to two decimal places; exact value 2/3), then the variance of γ̂: (2/3) / 2 = 1/3, or approximately 0.33.

    t2=γ^2s2/B

    Calculation: t² = 1 ÷ (1/3) = 3. We keep t² to avoid approximating a square root; since γ̂ is negative, t is negative and equals minus the square root of t².

    Interpretation with a fictional threshold c = 2 for |t|, so c² = 4. We would reject the unit root if γ̂ were negative and t² exceeded c². Here γ̂ = -1 is negative, but t² = 3 remains below 4: ADF does not reject the unit root. Actual thresholds do not come from a Student’s t distribution: under the unit root, t has a nonstandard distribution, with thresholds taken from tables specific to the specification.

  5. KPSS · partial sums and the η statistic

    The level is assumed known and equal to 0: the deviations from this level are the readings themselves. The partial sums Sk = sum of the first k readings accumulate these deviations, in ms. They are 0, 1, 1, 0, and 0. The statistic compares their size with an estimated variance σ̂², in ms², with T = 5 readings.

    η=∑Sk2T2σ^2

    Numerator: the first, fourth, and fifth squares are 0; this leaves 1² + 1² = 1 + 1 = 2 ms². Simple variance: the sum of the squares of the 5 readings is 2 ms², because the last reading (0) adds nothing to the sum B already calculated; therefore σ̂² = 2 / 5 = 0.40 ms² (exactly 2/5).

    Denominator: T² = 25, then 25 × 2/5 = 10 ms². Thus η = 2 / 10 = 1/5, or 0.20, with no units since ms² is divided by ms². With a fictional threshold of 1/2 (or 0.50), we would reject stationarity if η exceeded it: 0.20 remains below it, so KPSS does not reject. Since the level is known rather than estimated, the distribution of η differs from that in tables where the level is estimated: this fictional threshold does not approximate those tabulated thresholds.

  6. Interpret both results together and check

    ADF does not reject the unit root (t² = 3 below 4), and KPSS does not reject stationarity (η = 0.20 below 0.50). This is the “too little data to decide” box in the second diagram. The series nevertheless seems to return to 0; but 4 transitions give very little power, meaning very little chance of rejecting a false null hypothesis.

    Checks: the steps cancel out, 1 + -1 + -1 + 1 = 0, which is y4 − y0; the last partial sum is 0, equal to the sum of the readings; and the independent calculation in the accompanying materials gives the same t² using the combined expression (n − 1) A² / (B C − A²). These checks describe the calculation rather than the quality of a model for a real clock.

Explain it in your own words

Why can we assert neither a unit root nor stationarity when neither test rejects? Explain the role of the opposing null hypotheses and the number of points.

✿03 Common mistakes

  • “Failing to reject the ADF null hypothesis proves that there is a unit root.”

    Failing to reject only indicates that the data do not contradict the null hypothesis strongly enough. In the example, t² = 3 remains below 4 even though the curve returns to 0: 4 transitions give little power. Write “not rejected,” never “confirmed.”

    Review the final interpretation of the example

  • “ADF and KPSS test the same hypothesis: if one agrees, the other confirms it.”

    Their null hypotheses are opposed: a unit root for ADF, stationarity for KPSS. The four combinations in the second diagram give four interpretations, two of which are inconclusive.

    Review the two null hypotheses

  • “The ADF t statistic is looked up in a table of the normal distribution or Student’s t distribution.”

    Under the unit root, t has a nonstandard distribution: thresholds come from tables specific to the specification (intercept, trend) and sample size. The thresholds on this page (2 for |t| and 0.50 for η) are fictional and serve only to illustrate the mechanism; they are never chosen after seeing the statistic.

Exercise 1 · Explained application

From coefficient γ̂ to coefficient ρ̂

Using A = -2 ms² and B = 2 ms² from the example, calculate γ̂, then ρ̂ = 1 + γ̂. What would ρ be for a unit root? Interpret ρ̂ without drawing a conclusion about the test.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

γ̂ is the ratio A / B; check its sign before calculating ρ̂.

Hint 2

A unit root corresponds to ρ = 1, hence γ = 0.

Compare with the solution

γ̂ = -2 / 2 = -1. Thus ρ̂ = 1 + (-1) = 0. A unit root corresponds to ρ = 1, hence γ = 0.

The point estimate ρ̂ = 0 means that, in these 4 pairs, the previous level does not help predict the next one beyond 0. It says nothing about its precision: that is the role of the t statistic, which does not reject here. Do not confuse estimation with testing.

Check your reasoning

  • Calculate γ̂ = A / B with its sign.
  • Write ρ̂ = 1 + γ̂ and recall that a unit root corresponds to ρ = 1.
  • Distinguish the point estimate from the test decision.

Exercise 2 · Critical reading

A threshold chosen after the fact

A colleague proposes replacing the fictional KPSS threshold with 1/10 (or 0.10) because “0.50 is too strict.” With η = 1/5 from the example, does the KPSS decision change? What do you think of this approach?

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Apply the same rule: reject if η exceeds the threshold.

Hint 2

Consider when the threshold was chosen relative to seeing the data.

Compare with the solution

With the threshold 1/10, η = 1/5 (or 0.20) exceeds it: KPSS would reject stationarity, whereas it did not reject it with 1/2. The decision therefore depends on the threshold.

That is exactly the danger: a threshold is set before seeing the statistic, based on the test distribution and the accepted risk of error. Changing it after the fact to obtain a rejection manufactures a result. Combined with ADF failing to reject, the interpretation would be “favors a unit root,” solely because the threshold was changed.

Check your reasoning

  • Apply the same rejection rule, η greater than the threshold.
  • Recognize that the decision changes with the threshold.
  • Reject a threshold chosen after seeing the statistic.

Exercise 3 · Transfer

Change units

The readings are now expressed in tenths of a ms: each value is multiplied by 10. Calculate the new A and B, then γ̂. What happens to t² and η? Justify your answer without repeating the entire calculation chain.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

A is a sum of products of two readings: by what factor is each product multiplied?

Hint 2

Compare the effect of the change of units on the numerator and denominator of each statistic.

Compare with the solution

Each product of two readings is multiplied by 10 × 10 = 100. Thus A becomes 100 × -2 = -200 and B becomes 100 × 2 = 200, in squared tenths of a ms. Then γ̂ = -200 / 200 = -1: unchanged.

In t², γ̂ does not change, nor does the variance of γ̂, because s² and B acquire the same factor. In η, the sum of the squared partial sums and the product T² × σ̂² also acquire the same factor. Both statistics are dimensionless and still equal 3 and 1/5; the independent calculation in the accompanying materials verifies this for other factors. Only A, B, and the variances change value.

Check your reasoning

  • Multiply the products by the square of the factor, rather than the factor itself.
  • Recover an unchanged γ̂.
  • Conclude that t² and η are dimensionless.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What is the null hypothesis of ADF, and what is that of KPSS?

ADF: a unit root. KPSS: stationarity. They are opposed, so rejection does not have the same meaning in each test.

Recall 2What does γ mean in Δyₜ = γ yₜ₋₁ + εₜ?

γ = ρ − 1. A γ equal to 0 corresponds to a unit root; a negative γ corresponds to a return toward the reference level.

Recall 3Why do we not look up the ADF t statistic in a Student’s t table?

Under the unit root, t has a nonstandard distribution; thresholds come from tables specific to the specification and sample size and are fixed before seeing the statistic.

Recall 4What can we conclude when neither ADF nor KPSS rejects?

The data do not allow a decision: failing to reject is not confirmation, especially with few points.

Recall 5How is the KPSS statistic constructed?

Accumulate the deviations from the level (partial sums Sₖ), add their squares, then divide by T² times an estimated variance σ̂²: η = Σ Sₖ² / (T² σ̂²).

Reconstruct the reasoning

Write the model yₜ = ρ yₜ₋₁ + εₜ and define γ = ρ − 1; estimate γ̂ = A / B without an intercept; calculate t from SSR, s², and B; interpret t using thresholds specific to the specification (fictional here, fixed before seeing the statistic). For KPSS, accumulate the deviations, form η = Σ Sₖ² / (T² σ̂²), and compare it with its threshold. State the two opposing null hypotheses, consider the four combinations, and never treat failing to reject as proof.
