✿01 See the idea

An automated reader receives the message “not urgent”, word by word. When it reaches “urgent”, the previous word is no longer the current input. It needs to carry forward something from what it has already read. Imagine a small writing board: at each word, the reader replaces its contents with a new summary, calculated from the word received and the previous summary.

A recurrent neural network, abbreviated RNN, uses this principle. Its hidden state is this numerical summary: “hidden” means that it is calculated inside the model, rather than supplied directly with the message. The cell is the calculation rule that produces the new state. It is reused at each position with the same weights, meaning the same coefficients.

The previous unit represented words using numbers. Here, to calculate everything with a pencil, we set a scalar code: “not” becomes 1, and “urgent” becomes 2. These values and all the weights are fictional, chosen by hand and without physical units. This code is not a learned representation; a larger value does not mean a more important word.

Our only aim is to understand how word order can change a state. The reversed message “urgent not” provides a mechanical comparison. No score on this page measures actual urgency or understanding of English.

The rule to remember

At each word: take the previous state, combine it with the current input, apply the activation, then pass on the new state. The states change; the weights remain shared.

✿02 Follow an example

Worked example

The numerical writing board for “not urgent”

Read the 2 words in order, with an initial state h = 0, a recurrent weight a = 1/2 = 0.50, an input weight u = 1 and a bias b = 0. Apply a rectified activation after each combination. We will perform a reading with fixed weights, without training.

  1. Write the rule and define each symbol

    t is the word position, an integer index starting at 1; t − 1 denotes the previous position. xt is the code for the current word and ht is the state obtained after reading it. Before the first word, the state is h initial = 0. rt denotes the sum before activation. a multiplies the previous state; u multiplies the input; b is the bias added to this sum. All these quantities are scalars and have no physical units.

    rt=aht−1+uxt+b
    ht=φ(rt);φ(r)=max(0,r)

    φ is read as “phi” and denotes the rectified activation function, often called ReLU. max takes the largest of the numbers supplied: a negative sum becomes 0; a positive or 0 sum is kept. This change of rule at 0 makes the activation nonlinear. For a positive r, applying φ here therefore means keeping r, without any further arithmetic operation.

    Assumptions for this reading: the words arrive in order, the code is fixed, the cell receives only the current input and the previous state, and a, u, b remain identical at all positions. The state is reset between independent messages.

  2. Process “not” from the initial state

    First, multiply the previous state by a to calculate its contribution: 1/2 × 0 = 0. Then weight the current input: 1 × 1 = 1. Add these contributions, then the bias: 0 + 1 = 1, then 1 + 0 = 1.

    h1=max(0,1)=1

    The sum is positive: the activation keeps it. Pass 1 to the next step. Do not reset the state to 0 between words in the same message, because that would erase the recurrent link.

  3. Process “urgent” with the state passed on

    The weight a is still 1/2. The contribution from the past is now 1/2 × 1 = 1/2 = 0.50. The contribution from the new word is 1 × 2 = 2. We obtain 1/2 + 2 = 5/2, then 5/2 + 0 = 5/2.

    h2=max(0,12×1+1×2+0)=5/2

    The sum is positive again; the final state is 5/2, or exactly 2.50, with no units. The word “not” contributes through the state passed on, while only the input “urgent” is supplied at the current step.

  4. Read an output without inventing a meaning for it

    T denotes the message length: T = 2 positions. For this demonstration, we take the output to be the score s = h final, or 2.50. Reading the state directly in this way is enough to observe a result. In a model designed for a task, an output layer can transform ht into a prediction, and training adjusts the weights using examples and an error to reduce.

    The score 2.50 is neither a probability nor a degree of urgency. We have supplied no target and learned no weights. Reading a new word changes h, rather than a, u or b. A program that increments a counter also has a state; that alone does not make it a trained neural network.

  5. Check by expanding the recurrence

    Since the sums encountered are positive, we can remove max to check this specific path. Substituting the calculation for the intermediate state gives:

    h2=a2h0+aux1+ux2+(a+1)b

    h with the index 0 denotes the initial state. Since it equals 0 and b equals 0, this leaves 1/2 × 1 × 1 + 1 × 2 = 1/2 + 2 = 5/2. This second route recovers exactly the state calculated step by step. It replaces the recurrence only on paths where the activations stay in this branch.

  6. Explain word order, then the limits of the summary

    Reversing the words, the same starting point first produces 2, then 1/2 × 2 + 1 × 1 + 0 = 2. The sums remain positive. Yet the sum of the codes is 3 in both orders. The first word goes through an extra multiplication by a; it therefore plays a different role from the last word. The final difference is 5/2 − 2 = 1/2.

    The network can therefore distinguish these orders. Yet it cannot distinguish all messages: “urgent” alone gives 2, and “urgent not” also gives 2. These identical final states do not allow us to reconstruct which message was read. More generally, the rectified activation also maps all negative sums to the same value 0. With our weights, the contribution of a previous state is multiplied by 0.50 at each step as long as the activation remains positive; an old difference fades. A recurrent memory is therefore not an intact copy of the text.

    In a larger network, x and h can be vectors, meaning lists of numerical components, and the weights can be matrices that combine these components through sums of products. The rule remains: the same transformation at each position, with a new state passed on. Here we limit ourselves to the scalar cell and its forward pass.

Explain it in your own words

✿03 Common mistakes

  • “The weights change every time the network reads a word.”

    Separate the coefficients a, u, b from the state h. For this reading, the coefficients are shared and fixed; only h is recalculated. Changing the weights through training requires examples, a target and an adjustment rule that are not used here.

    Reread the output and the distinction between state and weights

  • “Adding the codes is equivalent to reading the message.”

    The sum is 3 in both orders. The cell also uses the previous state: the results 2.50 and 2.00 differ. Start again from the same initial state to compare only the effect of word order.

    Review the two reading paths

  • “I always keep the final state to start the next message.”

    First decide whether the next message continues the same sequence. For independent messages, our contract requires the starting point 0; keeping 2.50 would pass on context that does not belong to them. When continuing the same message, however, keep the state.

Compare with the solution

The previous state contributes 1/2 × 5/2 = 5/4, or 1.25. The word “not” contributes 1. The sum is 5/4 + 1 + 0 = 9/4.

This sum is positive; the activation keeps it. The new state is 9/4 = 2.25, with no units. Starting again from 0 would have treated “not” as a separate message, which does not match the problem statement.

Exercise 3 · Diagnosis · change the boundary

A new independent message

“Not urgent” has ended. Another independent message starts with “not”. Yet a program keeps the final state 5/2 of the completed message. Calculate the state after this first word with and without the required reset. Identify what must be reset and what must remain shared.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Without a reset, the calculation is the continuation calculation; with a reset, it is the calculation for the first word in the example.

Hint 2

Compare 9/4 with 1. The weights a, u, b are not the state of the message.

Compare with the solution

Without a reset: 1/2 × 5/2 + 1 × 1 + 0 = 9/4, giving 2.25 after activation. With the required starting point 0: 1/2 × 0 + 1 × 1 + 0 = 1, giving 1. The sums are positive in both cases.

The extra context passed on changes the result by 9/4 − 1 = 5/4 = 1.25, with no units. h must be reset to 0 at the boundary between independent messages. The same coefficients a = 1/2, u = 1, b = 0 continue to be used: resetting the state does not erase weights.

If the application instead decided that these messages form a single sequence, keeping h would be a different explicit contract. Here the fault is the mismatch with the stated independence, rather than the mere presence of a persistent state.

Check your reasoning

  • You obtain 9/4 without a reset and 1 with one.
  • You reset the state without changing the network parameters.
  • You justify the boundary using the contract for independent messages.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What changes during reading, and what remains shared?

The state h changes after each word. The weights a, u and the bias b remain identical at all positions for this reading. Training the parameters would be a separate operation.

Recall 2Reconstruct the calculation of a cell and the role of its activation.

Weight the previous state by a and the current input by u, add these contributions and b, then apply φ. Here φ keeps a positive or 0 sum and replaces a negative sum with 0. The result becomes the state for the next step.

Recall 3Why can the same words give different final states?

Each position receives a different state. The first word then passes through more transitions than the last. On our positive path, its final contribution carries an extra factor a; a simple sum of the codes does not retain this difference in role.

Recall 4When should the state be kept, and when should it be reset?

Keep it to continue the same sequence. For our independent messages, start again from 0 at each new message while keeping the weights. The boundary must be set by the task, rather than guessed by the cell.

Recall 5Does a state that depends on the past prove that the network keeps everything or understands the text?

No. The state is a calculated summary that can lose distinctions, particularly when the activation rectifies negative sums. Our fictional codes and weights prove only the calculations shown. They establish neither learning of meaning nor quality on new messages.
