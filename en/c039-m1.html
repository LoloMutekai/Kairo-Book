Subspaces

Your goalRecognize a subspace by checking the 0 vector and closure under addition and multiplication by any real number, then distinguish a general proof from a numerical trial.

Before you start
c032-m5 : computing rank · c014-m5 : invariants

✿01 See the idea

A cart slides along a straight rail. Viewed from above, moving 1 cm horizontally requires moving 2 cm vertically. Moving backwards is allowed, as is staying still. An allowed displacement can therefore be extended, shortened or reversed without leaving the direction of the rail.

We represent a displacement by a vector, which here means an ordered pair (x ; y). x and y are its signed components, read in centimetres on perpendicular axes with the same scale. A negative sign indicates the direction opposite to the axis. The arrow is drawn from a common origin to compare displacements; it does not give the absolute position of the cart.

Adding vectors means carrying out their displacements in sequence: we add corresponding components. Multiplying a vector by a real number λ multiplies all its components by this number, which has no unit; if λ is negative, the direction reverses. A real number can be negative or non-integer. ℝ denotes the set of real numbers.

A subspace is a set of vectors preserved by these operations: the 0 displacement belongs to the set, the sum of vectors in the set stays in it, and so does every real multiple. Being “closed under” an operation means precisely that its result stays in the set. The requirement concerns all allowed choices, not just the arrows in the drawing.

The scene and its values are fictional. The mathematical rail is an entire line, without end stops or width, and can be travelled in both directions. We impose neither a maximum length nor a minimum step. These assumptions are needed to represent all real multiples; the travel of an actual cart may be bounded.

The rule to remember

To recognize a subspace, specify the ambient space, check the 0 vector, then prove that every addition and every multiplication by a real number keeps the vectors in the set.

✿02 Follow an example

Worked example

Combining displacements along the rail

In the plane of displacements, u = (2 ; 4) cm, v = (-1 ; -2) cm and λ = -3/2, or -1.50 with no unit. Calculate w = λu + v, check that it belongs to the rail, then prove that the entire set of rail displacements is a subspace.

  1. Specify the set and the criterion

    The ambient space E here is the real plane: the set of all pairs of real numbers, with addition and multiplication by a real number performed component by component. In the notation for ℝ below, the exponent 2 indicates the number of components. We express each in the common unit cm. S is the subset defined by the rail constraint:

    S={(x;y)∈ℝ2:y=2x}

    The symbol ∈ means “belongs to”; the braces describe the set of pairs satisfying the condition after the colon. A subset F of E is a real vector subspace if and only if it contains the 0 vector and is closed under addition and multiplication by every real number. The operations are those of E, without modification.

    (0;0)∈F;p,q∈F⇒p+q∈F
    p∈F,λ∈ℝ⇒λp∈F

    p and q denote arbitrary vectors in F, and λ an arbitrary real number; ⇒ means “implies”. The conditions hold for all these choices. The 0 vector expresses being stationary; it does not require the cart to occupy a particular position.

  2. Check the given vectors before combining them

    For a pair (x ; y), calculate y − 2x, the deviation from the constraint. The pair belongs to S exactly when this deviation is 0 cm. This test avoids dividing by x, which would be impossible for the 0 vector.

    For u: 2 × 2 = 4 cm, then 4 − 4 = 0 cm. For v: 2 × (-1) = -2 cm, then -2 − (-2) = 0 cm. The given vectors therefore do belong to S.

  3. Apply the coefficient to all components

    λ = -3/2 has no unit. Multiplying by this coefficient reverses the displacement and makes it longer. We keep exact fractions throughout the operations; the notation -1.50 is used only to read the coefficient in French decimal notation.

    λu=-32(2;4)=(-3;-6) cm

    In detail, the horizontal component is (-3/2) × 2 = -3 cm, and the vertical component is (-3/2) × 4 = -6 cm. The coefficient does not apply only to the horizontal component.

  4. Add and check using another relation

    To follow this with v, add the components in the same direction: -3 + (-1) = -4 cm horizontally; -6 + (-2) = -8 cm vertically. This gives w = (-4 ; -8) cm.

    wy−2wx=-8−(-8)=0 cm

    wx and wᵧ denote the horizontal and vertical components of w. The check uses the rail equation: 2 × (-4) = -8 cm, so w belongs to S. The units remain centimetres because the coefficients have no unit. This result checks our particular combination; we still need to prove the property for all choices.

  5. Move from the calculated case to the general proof

    First, the 0 vector belongs to S because 0 = 2 × 0. Next, take arbitrary vectors p = (a ; 2a) and q = (b ; 2b) in S. a and b are arbitrary real numbers representing horizontal components in cm. This choice describes every vector in S, since its vertical component is determined by its horizontal component.

    p+q=(a+b;2a+2b)=(a+b;2(a+b))

    The second component remains 2 times the first. Addition therefore keeps the result in S. For any real number λ, the same distributive law gives:

    λp=(λa;λ2a)=(λa;2(λa))∈S

    There is no requirement for λ to be positive or an integer. S contains the 0 vector and satisfies the required closure properties: it is a subspace of E. A sum of vectors each multiplied by a real number is called a linear combination; it stays in S by applying these operations in sequence. This is why λu + v had to stay on the rail, even before our numerical calculation.

  6. Review the limits of the conclusion

    The relation y − 2x = 0 is preserved by these operations: it is the invariant guiding the proof. Having 0 on the right-hand side is essential. A rule y = 2x + 1 describes a shifted line; we cannot apply the conclusion to it without checking the 0 vector and the closure properties again.

    Restricting the rail to forward displacements or to the section between end stops also changes the set. A displacement may then belong to it while its opposite lies outside it. We have proved a property of the ideal set S; we have not described all movements a machine can perform. The question of choosing a basis will come in a later unit.

✿03 Common mistakes

  • “My combination lands back on the rail, so I have proved that S is a subspace.”

    A numerical trial checks this combination. To prove closure, start with arbitrary vectors (a ; 2a) and (b ; 2b), then an arbitrary real coefficient. A single counterexample is enough to disprove closure; a collection of successful trials does not prove it.

    Return to the general proof after the calculation

  • “The set contains the 0 vector and allows addition: that is enough.”

    All real coefficients are also required. The ray along the rail contains the 0 vector and allows forward movements to be carried out in sequence, but multiplying a nonzero displacement by -1 takes it outside this ray.

    Test the ban on moving backwards

  • “A line is always a subspace: its position does not matter.”

    For vectors drawn from the origin, the line must pass through the 0 vector. The line y = 2x + 1 does not contain it. Distinguish positions on this shifted rail from differences between these positions: these differences can form a subspace.

Exercise 2 · Application · disproving

The cart can no longer move backwards

Keep the same rail but allow only displacements D = {(x ; 2x) : x ≥ 0}. The 0 displacement and sums are allowed. Is D a subspace of E? Give a specific vector and a real coefficient that settle the question. What change to the set restores the properties?

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Start with u, which represents a nonzero forward movement, then find its opposite.

Hint 2

The condition x ≥ 0 must still hold after multiplication by -1.

Compare with the solution

u = (2 ; 4) cm belongs to D. Its multiple by -1 is (-2 ; -4) cm. Its horizontal component is negative, so it does not belong to D. Closure under multiplication by a real number fails; D is not a subspace.

Yet this backwards displacement stays on the line: 2 × (-2) = -4 cm, and -4 − (-4) = 0 cm. The problem is the restriction on the sense of travel along the line. Removing x ≥ 0 and allowing every real x gives S again, whose general proof is in the example.

The 0 vector is in D and, for nonnegative a and b, a + b is also nonnegative: addition is indeed closed in D. This confirms that these properties alone are insufficient.

Check your reasoning

  • Choose a nonzero vector that initially belongs to D.
  • Exhibit a coefficient allowed in ℝ and a result outside D.
  • Identify exactly which condition fails, then change the restriction to restore it.

Exercise 3 · Transfer · positions and displacements

Moving the rail without changing its direction

The rail is shifted: the positions of the cart form T = {(x ; 2x + 1) : x real}, in cm. Is T a subspace of E? Check that A = (1 ; 3) cm and B = (3 ; 7) cm are on T, calculate displacement d = B − A, then use letters to explain why all displacements between positions in T form exactly S.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

For T itself, start with position (0 ; 0).

Hint 2

Take positions (a ; 2a + 1) and (b ; 2b + 1). In their difference, what happens to the shift?

Hint 3

To obtain any displacement (t ; 2t), start from position (0 ; 1) on T.

Compare with the solution

T is not a subspace: for x = 0 cm, its rule requires y = 1 cm, rather than 0 cm. The 0 vector does not belong to T. This test is enough to disprove that it is a subspace, without having to test all sums.

A is on T because 2 × 1 + 1 = 2 + 1 = 3 cm. B is too: 2 × 3 + 1 = 6 + 1 = 7 cm. The displacement is d = (3 − 1 ; 7 − 3) = (2 ; 4) cm. This is precisely vector u from the lesson.

Check: 2 × 2 = 4 cm; 4 − 4 = 0 cm. So d belongs to S. With arbitrary positions, the same calculation gives:

(b;2b+1)−(a;2a+1)=(b−a;2(b−a))

a and b are the horizontal components of the positions, expressed in cm. The shift cancels: every difference belongs to S. Conversely, for any real number t expressing a component in cm, positions (0 ; 1) and (t ; 2t + 1) are in T and their difference is (t ; 2t). We therefore obtain every vector in S, rather than just some of them. The positions form T; the displacements form S.

Check your reasoning

  • Disprove that T is a subspace using the 0 vector, keeping position and displacement distinct.
  • Check the given positions and subtract the components in the correct order.
  • Show that the shift cancels for arbitrary positions.
  • Justify both directions of the equality: every displacement is in S and every vector in S can be obtained.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What complete criterion identifies a real subspace in a specified ambient space?

The set contains the 0 vector, the sum of any vectors belonging to it still belongs to it, and so does every real multiple of one of its vectors. The operations are those of the ambient space.

Recall 2How can you prove closure of S = {(x ; 2x) : x real} without testing a list of vectors?

Start with (a ; 2a) and (b ; 2b), with arbitrary a and b. Their sum is (a + b ; 2(a + b)). Any multiple λ(a ; 2a) equals (λa ; 2λa). These results are in S; add the 0 vector check to conclude that S is a subspace.

Recall 3Why does a ray containing the 0 vector fail the criterion?

It can be closed under addition and multiplication by positive coefficients, but the coefficient -1 turns a nonzero vector into its opposite, outside the ray. All real coefficients must be allowed.

Recall 4Why do the positions of the shifted rail and its displacements have different status?

The positions satisfy y = 2x + 1 and do not include the 0 vector. In a difference of positions, the shift cancels: the displacements satisfy y = 2x and form subspace S.

Recall 5What is the difference between a successful trial and a counterexample for a closure property?

A successful trial checks only the chosen inputs. A counterexample meets the assumptions but produces a result outside the set: it is enough to disprove the universal property. A proof must handle arbitrary inputs.
