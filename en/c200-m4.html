Johansen

Your goalRead the rank of the adjustment matrix as the number of long-term relations, calculate a trace statistic from canonical correlations, then carry out the sequential test without inventing a threshold.

Before you start

✿01 See the idea

Two basins connected by a channel each have a water-level sensor. The values in this scene are fictitious. The level u in the upstream basin and the level v in the downstream basin, both in centimetres, wander without a fixed value to return to: each resembles a random walk, a series with a unit root, as in the unit on ADF and KPSS.

Yet the channel pulls the difference s = u − v towards a stable value: when s widens, the upstream level tends to fall or the downstream level to rise. A stable combination of series that are themselves unstable is a cointegrating relation. Engle-Granger looks for it in two stages: choose a series to explain, run a regression, then test the residuals. This choice and the search for a single relation at a time constrain the method; Johansen avoids these constraints by treating the entire system.

It writes a single equation for the change ΔY in the two levels over one time step, linked to the levels at the previous step by a table of coefficients Π, a matrix. Each row of Π gives the response of a basin to the levels it observes. The number of independent directions that Π uses is called its rank. Rank 0: past levels do not help predict changes, so there is no stable relation. Rank one: a single combination of levels guides the changes, here the difference s. Rank equal to the number of series: all combinations matter, describing levels that are already stationary.

For a table with two rows and two columns, the rank can be read from the determinant ad − bc. It is two if this determinant is nonzero, one if the determinant is 0 but some coefficients are nonzero, and 0 if all coefficients are 0. This size is enough for the entire page.

det(abcd)=ad−bc

The rank cannot be seen directly in a sample: noise almost always makes the estimated matrix full rank. Instead, Johansen measures canonical correlations λ̂ between changes and lagged levels, with values between 0 and one. A trace statistic combines them and is then compared with thresholds. These thresholds come from tables specific to the method, which this page does not reproduce: it will use fictitious thresholds, identified as such, to show the order of operations.

The rule to remember

The rank of Π is the number of stable relations between levels. The trace statistic −T Σ ln(1 − λ̂) tests ranks in order, r = 0 then r ≤ 1, and the first rank that is not rejected is selected.

✿02 Follow an example

Worked example

Two basins: how many stable relations?

Fictitious values. Levels u and v are recorded every hour, and T = 48 time steps are used for estimation. The model has no constant term or lagged difference, because these additions change the thresholds. We first read what rank one implies, then the canonical correlations of a fictitious sample summary, and finally the trace statistic and sequential test with fictitious thresholds.

  1. Define the symbols and assumptions

    Yt is the column vector of the two levels (ut, vt) at hour t, in cm. ΔYt = Yt − Yt-1 is their change over one time step, in cm. The error-correction model with no lagged differences is written as follows, with εt a Gaussian noise term with mean 0, uncorrelated across time steps, an assumption of the likelihood used by Johansen:

    ΔYt=ΠYt−1+εt

    Π is dimensionless, since it links centimetres to centimetres. When its rank is one, it can be factored as Π = αβ′. The vector β describes the long-term relation, so β′Y is the stable combination; the prime transposes a column vector into a row. The vector α contains the adjustment speeds of the two basins.

    Π=αβ′

    Assumptions: a single lag in levels, no constant or trend, and no explosive root. If any assumption fails, the regression formulas and tabulated thresholds change.

  2. Read what rank one implies

    Take β = (1, −1)′: the stable combination is s = u − v. Take fictitious adjustment speeds a1 = 0.2 for the upstream basin and a2 = 0.1 for the downstream basin: each hour, u loses the fraction a1 of the difference and v gains the fraction a2 of it. Then α = (−a1, a2)′ and the matrix takes the following form.

    Π=(−a1a1a2−a2)=(−0.20.20.1−0.1)

    Its determinant is (−a1)(−a2) − a1a2 = a1a2 − a1a2, hence 0: the two rows are proportional. The matrix is nonzero, so its rank is one. For the difference, Δs = Δu − Δv = −(a1 + a2)s plus noise, so st = φ st-1 plus noise:

    φ=1−(a1+a2)=1−0.3=0.7

    Check: φ lies between minus one and one, so the difference retains the fraction 0.7 of its value each hour before noise and returns towards 0 on average. This is the stationarity expected of a cointegrating relation.

  3. Summarize the sample with sums of products

    Johansen does not observe Π; it starts from sums of products calculated over the T time steps. Write them in the basis (s, w), where s = u − v is the difference and w = u + v the sum of the levels. At each step, R0 is the vector of changes (Δs, Δw) and R1 the vector of lagged levels (s, w). Since there are no lagged differences or constant, R0 and R1 are these vectors themselves. The sums M00 = ΣR0R0′, M11 = ΣR1R1′ and M01 = ΣR0R1′ are in cm². Changing basis through an invertible matrix does not change the canonical correlations calculated next, which allows this choice of coordinates.

    Take the following fictitious summary, which was not obtained from a reading. The scale factors 2, 5 and 30 are square roots of the diagonal terms; the rows of M01 represent changes and the columns represent lagged levels.

    M00=(220022),M11=(5200302),M01=(540−29)

  4. Whiten the data, then obtain canonical correlations

    A canonical correlation is the strongest correlation between a combination of changes and a combination of lagged levels, followed by the next strongest among combinations uncorrelated with the first ones. To calculate it, divide row i of M01 by the scale factor of change i and column j by that of level j: this is whitening. The divisors are 2 × 5 = 10 for the first column and 2 × 30 = 60 for the second.

    Ĉ=(5104060−210960)=(1/22/3−1/53/20)

    The squares λ̂ of the canonical correlations are the eigenvalues of ĈĈ′, the numbers λ such that det(ĈĈ′ − λI) = 0. For two rows and two columns, this equation becomes λ² − tr·λ + det = 0, where tr is the sum of the squares of the four entries of Ĉ and det = det(Ĉ)². The second row of Ĉ starts with a negative number: det(Ĉ) = Ĉ11Ĉ22 − Ĉ12Ĉ21 can therefore be written, using absolute values, as 3/40 + 2/15.

    tr=1/4+4/9+1/25+9/400=109/144,det=(3/40+2/15)2=(5/24)2=25/576

    We chose the data so that the discriminant is an exact square and the roots are therefore rational: λ̂1 = 25/36 (or 0.694) and λ̂2 = 1/16 (or 0.0625). Check using the sum: 25/36 + 1/16 = 109/144, equal to tr. Check using the product: 25/36 × 1/16 = 25/576, equal to det. Here, the two rows of Ĉ are orthogonal, a special feature of the example: the λ̂ values are then the sums of squares in each row, 25/36 and 1/16.

  5. Calculate the trace statistic

    To test whether there are at most r relations among n series, the trace statistic adds the terms for the n − r smallest correlations. T is the number of time steps used, and ln is the natural logarithm.

    λ^trace(r)=−T∑i=r+1nln(1−λ^i)

    The term −ln(1 − λ̂) is 0 when λ̂ is 0 and grows without bound as λ̂ approaches one: a strong correlation contributes a lot, an almost 0 correlation almost nothing. Here 1 − λ̂1 = 11/36 and 1 − λ̂2 = 15/16. The two logarithms, calculated separately at higher precision and then rounded to five decimal places, are −ln(1 − λ̂1) = 1.18562 and −ln(1 − λ̂2) = 0.06454. For r = 0, add both terms; for r ≤ 1, only the second remains.

    T×(1.18562+0.06454)=48×1.25016=60.01,T×0.06454=48×0.06454=3.10

    Check: the rank-one statistic is smaller than the rank-0 statistic because it contains one fewer positive term, the one for the strongest correlation.

  6. Carry out the sequential test with fictitious thresholds

    The actual procedure compares each statistic with a tabulated critical value, which depends on the number of remaining relations and the deterministic terms in the model. To show the order of operations, we set two fictitious thresholds: c0 = 20 for r = 0 and c1 = 8 for r ≤ 1. They come from no table and are not used for any real decision.

    First test r = 0: 60.01 exceeds 20, so reject the absence of a relation. Then test r ≤ 1: 3.10 remains below 8, so do not reject and stop: the selected rank is one. This result is compatible with step two, a single relation represented by the difference s, but the fictitious summary was not constructed from these adjustment speeds: the two analyses do not confirm each other.

    Limits: the summary and thresholds are fictitious, and failure to reject does not prove that the rank is exactly one. With real series, the lags and deterministic terms would also need to be chosen before consulting the tables.

Explain it in your own words

Why test r = 0 before r ≤ 1, and why does the second statistic contain only the term for the smallest correlation? What does failure to reject r ≤ 1 not prove?

✿03 Common mistakes

  • “Rank one means that one of the series is stationary.”

    Rank counts stable combinations of levels, rather than series. In the scene, u and v each remain nonstationary and only the combination u − v is stable. In contrast, a rank equal to the number of series would describe levels that are themselves stationary, to be checked with ADF and KPSS, as in exercise three.

    Return to the exercise on full rank

  • “It is enough to compare the trace statistic with a threshold from a normal distribution or a Student t-distribution.”

    Under the hypothesis being tested, the statistic does not have a standard distribution: it depends on the number of remaining relations and the deterministic terms, and its critical values come from tables or simulations specific to Johansen. The thresholds on this page are fictitious and show only the order of comparisons.

    Review the sequential decision

  • “As in Engle-Granger, you must choose which series explains the other, and the relation found is unique.”

    Johansen treats the system without choosing a dependent variable. When the rank exceeds one, only the space spanned by the relations is determined: any basis of this space describes the same system, and β is fixed only through normalization.

    Reread the intuition behind the system

Exercise 1 · Explained application

Only one basin responds

Keep the model, β = (1, −1)′ and the scene, but assume, using fictitious values, that the upstream basin does not respond: a₁ = 0 and a₂ = 0.1. Write Π, give its rank and calculate the coefficient φ of the difference s = u − v.

Assisted answer: try this exercise without help later.

Hint 1

Copy the form of Π with a₁ = 0: one row becomes 0.

Hint 2

For the coefficient, apply φ = 1 − (a₁ + a₂).

Compare with the solution

With a1 = 0, the first row is 0 and the second is (a2, −a2).

Π=(000.1−0.1)

The determinant is 0 × (−a2) − 0 × a2, hence 0, and the matrix is nonzero: the rank is one. A cointegrating relation therefore does not require both basins to respond. The coefficient is φ = 1 − (0 + 0.1) = 0.9, between minus one and one: the difference is stationary, but it returns more slowly than in the example, where φ was 0.7. If both adjustment speeds were 0, Π would be 0 and the rank would be 0.

Check your reasoning

  • Write a 0 row for the upstream basin.
  • Conclude rank one from a 0 determinant and a nonzero matrix.
  • Calculate φ with a₁ = 0 and compare it with the value in the example.

Exercise 2 · Variation

Fewer observations

The summary gives the same canonical correlations λ̂₁ = 25/36 and λ̂₂ = 1/16, but for only T′ = 24 time steps (an exercise assumption). Recalculate both trace statistics, apply the fictitious thresholds 20 and 8 and explain the effect of T.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The terms 1.18562 and 0.06454 do not change: only multiplication by T changes.

Hint 2

For r = 0, add both terms before multiplying.

Compare with the solution

For r = 0: 24 × 1.25016 = 30.00. For r ≤ 1: 24 × 0.06454 = 1.55.

Compare in order: 30.00 exceeds 20, so reject r = 0; 1.55 remains below 8, so do not reject r ≤ 1 and select rank one, as with T = 48. The statistic is proportional to T: dividing T by 2 divides it by 2, and half of 60.01 is close to 30.00, allowing for rounding. With fewer time steps, the same correlation strength contributes less; here the decision stays the same, but it could change with a higher threshold.

Check your reasoning

  • Keep the canonical correlations and change only T.
  • Add both terms before multiplying for r = 0.
  • Compare in order, r = 0 then r ≤ one, with fictitious thresholds.
  • Explain the effect through proportionality to T.

Exercise 3 · Interpretation

A strong second correlation

Return to T = 48. Assume, using fictitious values, λ̂₂ = 9/16 instead of 1/16, with λ̂₁ = 25/36 unchanged. You are given −ln(1 − λ̂₂) = 0.82668 to five decimal places. Calculate the statistic for r ≤ 1, decide using the fictitious threshold 8, then say what the result implies for u and v and what you would check next.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The test of r ≤ 1 keeps only the term for the smallest correlation.

Hint 2

With only two series, if r ≤ 1 is rejected, what rank remains?

Hint 3

Reread what a rank equal to the number of series says about the levels.

Compare with the solution

Statistic: 48 × 0.82668 = 39.68, which exceeds the fictitious threshold 8: reject r ≤ 1. There are only two series, so the selected rank is two, full rank.

Full rank means that Π is invertible and that the levels themselves are stationary. This contradicts the scene, where each level resembles a random walk. Before accepting this result, check each series with ADF and KPSS, then the specification (lags, deterministic terms) and the thresholds, which are fictitious here. Full rank is therefore not “a lot of cointegration”: it signals a need to recheck the stationarity of the levels.

Check your reasoning

  • Calculate the statistic using the sole remaining term.
  • Conclude full rank after rejection, with no further test possible for two series.
  • Interpret full rank as stationary levels, rather than more cointegration.
  • Name the checks to perform: ADF and KPSS, specification, actual thresholds.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What does the rank of Π count in the Johansen procedure?

The number of stable combinations of levels, hence long-term relations. Rank 0: none; rank equal to the number of series: stationary levels.

Recall 2How is the trace statistic for a rank r constructed?

As −T times the sum of ln(1 − λ̂) over canonical correlations with indices greater than r. Each term grows with its corresponding correlation.

Recall 3In what order are ranks tested, and where do you stop?

Test r = 0, then r ≤ one, and so on, and select the first rank whose hypothesis is not rejected.

Recall 4Why are Johansen thresholds different from those of a standard distribution?

Under the hypothesis being tested, the distribution of the statistic is nonstandard and depends on the number of remaining relations and the deterministic terms. The thresholds on this page are fictitious.

Reconstruct the reasoning

Write ΔY = ΠY₋₁ + ε under explicit assumptions; read the rank of Π as the number of stable relations, with Π = αβ′ when it is one; whiten the sums of products to obtain squared canonical correlations; calculate −T Σ ln(1 − λ̂) for r = 0 then r ≤ 1; compare in order with thresholds specific to Johansen, fictitious here; stop at the first failure to reject; then check the levels using ADF and KPSS.
