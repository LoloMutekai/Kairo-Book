Level 2 · C071·M4

Synthetic graphs and seeds

Your goalBuild and replay a small graph from a seed, then distinguish a reproducible result from a conclusion valid for a real network.

Before you start

✿01 See the idea

You are planning a network of 4 alarm relays on paper, named A, B, C and D. A line means that an alert can travel in 2 directions. Before programming a simulation, you want to be able to restore exactly the same lines to investigate an error. This entire installation and its values are fictional.

A synthetic graph is a network made according to a stated rule. It can be drawn by hand, built systematically or sampled using a generator. The word synthetic describes its origin; it does not by itself mean random or representative of a real building.

We will assign an integer code to the drawing. Here, this code will act as a construction seed: with the same rule, it produces the same links again. To make every decision visible, this seed directly contains the choices about which links are present. This is a finite teaching generator, with no hidden sampling. In a pseudorandom generator, the seed instead initializes a state from which an algorithm produces a deterministic sequence of decisions; their statistical quality would require other checks.

Keep the construction seed separate from the starting point of the alert from the outset. The seed 13 determines the lines; A is the initially active relay. Changing either one changes a different input to the experiment. Here, the links always transmit: we check only which relays are reachable. We do not re-estimate Noisy-OR or a percolation threshold.

The rule to remember

A seed can be replayed with a fixed rule, parameters and order. A reproducible experiment also preserves its graph and assumptions; repetition does not turn it into evidence about the real world.

✿02 Follow an example

Worked example

Build the drawing, then start the alert from A

The initial version of the “link mask” generator uses relays A, B, C, D and the order AB, AC, AD, BC, BD, CD. Its seed is s = 13. The links are undirected, with no loop from a relay to itself and no duplicates. Let us reconstruct the entire network and count the relays reached, including the starting relay.

  1. Specify the construction rules

    Write G = (V, E): V is the set of relays; E is the set of links present. n = 4 counts the relays. P denotes the list of possible pairs in the stated order. For a pair e in P, we is its encoding weight: AB receives 1, AC 2, AD 4, BC 8, BD 16, CD 32. The subscript e denotes a pair, not a relay number.

    The choice be equals 1 if link e is present, 0 otherwise. The seed s adds up the weights of the links present. The symbol Σ means to add one term for each pair in P. s, we and be are codes with no physical unit; n and set sizes are counts. None of these weights is a probability.

    s=Σe∈Pbewe

    To decode, go through the weights from largest to smallest. If the remainder is at least as large as the current weight, keep that link and subtract its weight; otherwise, move on without subtracting. The list of pairs and the version of this rule are among the parameters to preserve.

  2. Count what can vary

    Each relay can be paired with n − 1 other relays. This counts each link 2 times, in 2 directions; divide by 2 to obtain the undirected pairs. The notation |P| denotes the number of pairs in P.

    |P|=n(n−1)2=4×32=6

    Each pair has 2 states, present or absent. Doubling the number of possibilities for each pair gives 64 possible labeled graphs. Our successive weights let us encode them using every integer from 0 to 63 inclusive. The representation in successive powers of 2 is unique: each code gives exactly one drawing, with the labels fixed.

    This count provides no sampling distribution. We set a seed by hand. To obtain independent, equally likely choices about link presence in this small model, we would need to sample uniformly from all these codes; choosing a few neighboring integers does not achieve this.

  3. Decode the seed with every decision explicit

    Initial remainder: 13. The CD weight is 32, greater than the remainder: CD is absent. The BD weight is 16, also greater: BD is absent. The BC weight is 8, less than the remainder: keep BC and calculate 13 − 8 = 5.

    The AD weight is 4: keep AD, then 5 − 4 = 1. The AC weight is 2, greater than 1: AC is absent. Finally, keep AB, with weight 1: 1 − 1 = 0. A remainder of 0 completes the decoding.

    In the original order AB, AC, AD, BC, BD, CD, the choices are therefore (1, 0, 1, 1, 0, 0). Thus E = {AB, AD, BC}. Reverse check: 8 + 4 = 12, then 12 + 1 = 13, the original seed.

  4. Check the drawing with another count

    We count 3 links present. The density d is the fraction of possible pairs that are present: d = |E|/|P| = 3/6 = 1/2, or 0.50 with no unit. This describes the drawing; it is not the probability that the alert travels across a link.

    Read the neighborhoods again: A connects to B and D, B connects to A and C, C connects to B, D connects to A. The degrees are therefore 2, 2, 1, 1. Their sum is 6; it must equal 2 × 3 = 6, because each link has 2 distinct endpoints. This check detects a missing line without reusing the sum of the weights.

  5. Separate construction and propagation

    Now fix the propagation rule: A is active at round 0; at each round, the neighbors of relays that are already active become active, and the previous active relays remain active. All links transmit with certainty, with no additional delay or sampling. A round is a calculation step, with no physical duration assigned to it. Each relay is counted only once.

    At round 0, the active set is {A}, giving 1 relay. At round 1, neighbors B and D are added: {A, B, D}, giving 1 + 2 = 3 relays. At round 2, B adds C: {A, B, C, D}, giving 3 + 1 = 4 relays. The next round adds no one: we have reached the final set.

    The final fraction is 4/4 = 1 with no unit. Check using paths: B is connected by AB, D by AD and C by AB followed by BC. Every relay does have a path from A. This result is deterministic for our drawing and rule; it does not represent an observed frequency of successful alarm operation.

  6. Preserve an experiment that can be challenged

    The reproduction notebook records the generator name and version, the labels A, B, C, D, the ordered list of pairs and their weights, s = 13, the drawing E = {AB, AD, BC}, the starting point A, the transmission rule and the stopping criterion “no new relay”. The seed alone is not enough to reconstruct all these choices.

    Replaying these inputs checks that we obtain the same calculation. Changing the seed examines another topology; changing the order of the weights changes the generator; changing the starting point or transmission changes the experiment on a given graph. If a simulation also includes random propagation draws, their initial state and order must be preserved separately. The exercises will show why a favorable drawing does not validate the real network.

✿03 Common mistakes

  • “The seed 13 identifies the relay where the alert starts.”

    Here 13 is a construction code; the relays are named A, B, C, D. The starting point A is a separate input. Review the distinction between choosing the links and specifying the propagation rule.

    Review the construction rules and the starting point A

  • “I recorded the seed, so everything else will be reproduced.”

    You also need the rule, its version, the parameters, the order and the labels. In the exercise that swaps the weights of AC and AD, the same seed produces a different drawing. Also preserve the starting point and the simulation rules.

    Examine the weight swap

  • “All relays are reached: my real alarm is validated.”

    The result concerns a fictional drawing and transmission with certainty. Compare the neighboring seed, then ask which topologies and transmission rules represent the real installation. Faithfully repeating the same case does not answer that question.

    Compare the cases specified in the notebook

Exercise 2 · Diagnosing reproducibility

Same seed, different convention

Another person keeps s = 13, but swaps the weights of AC and AD: AC now receives 4 and AD 2. The other weights stay the same. They claim to have reproduced the original drawing. Find their links and the relays reached from A. Is the density enough to detect the change?

Hint 1

The numerical decomposition into weights stays the same; the label associated with one of the weights changes.

Hint 2

Draw the links with weights 1, 4 and 8 using the new convention. Find the neighborhood of D.

Compare with the solution

The decomposition remains 13 = 8 + 4 + 1. But the links are now BC, AC and AB. AD is absent and D is isolated. From A, the final set is {A, B, C}, giving 3 relays; having several paths to C does not create an additional relay.

The number of links remains 3 and the density 1/2. These identical counts hide different topologies: they do not replace the list of links. Reproduction failed because the correspondence between pairs and weights changed. This convention must be preserved, along with the seed and the generator name.

Check your reasoning

  • Name BC, AC and AB under the new convention and identify that D is isolated.
  • Obtain 3 relays reached without counting a relay more than once.
  • Explain why an identical seed and density do not guarantee an identical graph.

Exercise 3 · Comparison and scope of the evidence

Keep the less favorable cases

Calculate the mean number of relays reached across these cases. Then respond to the claim: “Let us keep only seed 13; it demonstrates that our real installation propagates the alert everywhere.” State what the mean proves and what should be examined next.

Hint 1

Add the final counts for the 2 cases, including the starting relay, then divide by the number of cases specified.

Hint 2

Distinguish the accuracy of the calculation, the diversity of the graphs studied and their relationship to the real installation.

Compare with the solution

The counts are 4 and 2 relays. Their sum is 6 relays across 2 cases; the mean is 6/2 = 3 relays per case. This is a descriptive mean for this chosen list, with neither uniform sampling nor independence of the cases established. It is not the expected value for a population of networks.

Removing the unfavorable seed changes the specified list and hides the sensitivity to construction. The 4 relays in the first drawing demonstrate only reachability for that case and rule. For a real installation, the connections, any direction they may have, the transmissions and possible starting points must be justified; preserving the cases and protocol before looking at the results allows a comparison that can be challenged. A larger number of seeds does not by itself fix unsuitable assumptions.

The next lesson on cycles and double counting will examine other limitations of a probabilistic cascade. This notebook estimates neither a real failure probability nor any gain from a tool.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What makes our graph synthetic?

Its connections are made using a stated rule for a fictional experiment. This origin guarantees neither randomness nor representativeness of a real network.

Recall 2Why are seed 13 and starting point A 2 separate inputs?

The seed fixes the links using the chosen generator; A indicates where the alert starts on this drawing. A different starting point does not imply reconstructing the graph.

Recall 3What must be preserved along with the seed to reproduce our experiment?

The generator and its version, the labels, the pairs and their weights in the agreed order, the resulting graph, the starting point, the propagation rule and the stopping criterion. Any random propagation draws would also require their initial state and order to be preserved.

Recall 4Why is density 1/2 not enough to predict how many relays A will reach?

It counts the fraction of possible links that are present, without saying which ones. The example and the weight swap have the same density, with 4 and 3 relays reached respectively.

Recall 5What does replaying a synthetic graph identically demonstrate?

It checks that a calculation can be reproduced for fixed inputs. It does not by itself validate the assumptions, the diversity of cases or their suitability for a real installation.
