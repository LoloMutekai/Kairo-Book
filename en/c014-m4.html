Induction

Your goalProve the drawer count at every integer index, distinguishing the starting case, the step to the next case, and individual checks.

Before you start

✿01 See the idea

A drawer contains 3 socks. In each cycle, you add a pair, or 2 socks. You want to state its contents after any whole number of cycles, even without carrying out all those additions.

To do this, first check the drawer before any additions. Then ask yourself: if my count is correct at an arbitrary stage, does the planned action keep it correct at the next stage? A verified starting case and a step that works at every stage let you reach every integer index.

This scene and its quantities are fictional. We assume that no socks leave the drawer, that each cycle adds exactly a pair, and that the drawer in the model has no capacity limit. The result applies to this model, rather than an infinite physical stock.

The rule that produces the next count is already a recurrence relation for calculation. Proof by induction has a different role: to justify a property of all the counts. The first checks help you understand this property; they do not replace the general step.

The rule to remember

State the property and its indices; check the base case; assume the property at an arbitrary index to prove it at the next index; conclude by induction.

✿02 Follow an example

Worked example

Prove the count after every number of cycles

Keep the starting count of 3 socks and the addition of 2 socks per cycle. The proposed formula is “starting count + size of a pair × number of cycles”. We will prove it, then check its calculation at indices 4 and 5.

  1. Define the sequence and the property

    n denotes the number of completed cycles; it is an integer greater than or equal to 0. Sn denotes the number of socks in the drawer at that index. The subscript n identifies when the count is taken: it does not mean multiplication by n. The indices are numbers of cycles, with no physical unit; the values of S are numbers of socks.

    The initial value sets the count before any cycles. The addition rule sets the next count from the previous count. These two pieces of information define our sequence, meaning our ordered list of counts:

    S0=3;Sn+1=Sn+2 pour tout entier n≥0

    Call the property “Sn = 3 + 2 × n” P(n). Here P names a statement, rather than a probability. The = sign asserts that the counts are equal. Our goal is P(n) for every integer n ≥ 0. The term 3 counts the starting contents; 2 × n counts the socks added. The two terms are added in the same unit.

  2. Establish the base case: check the actual starting count

    Establishing the base case means checking P at the first index in the domain. Here, no cycles have taken place: replace n with 0 in the proposed formula, without removing the initial contents.

    3+2×0=3+0=3=S0

    The added part is 0 socks; the 3 socks present at the start remain. The result matches the initial value: P(0) is true. We have established a single case; we have yet to establish all indices.

  3. Assume the property at an arbitrary index

    Fix an integer k ≥ 0, without giving it a particular value. To prove the step, temporarily assume P(k), meaning Sk = 3 + 2 × k. This is the inductive hypothesis: a local assumption used in conditional reasoning.

    We must then prove P at the next index, k + 1. We assume neither this next property nor the formula for all indices. Keeping k arbitrary will let us prove the same step at every stage.

  4. Carry the property forward using the actual rule

    The inductive step takes the property assumed at index k and proves it at the next index. Start from the drawer rule, then replace only Sk with the value given by the hypothesis:

    Sk+1=Sk+2=(3+2×k)+2

    To recognize the formula at the next index, write the last addition as 2 × 1, then use the distributive property in reverse:

    3+2×k+2×1=3+2×(k+1)

    The final expression is exactly what P(k + 1) requires. The step is therefore established for every integer k ≥ 0. The first equality comes from the addition rule; the substitution comes from P(k); the last equality comes from the distributive property. None of these reasons depends on a selected value of k.

  5. Conclude using the principle of induction

    The principle of induction states that a property which is true at the initial index and carries from every index to the next is true at all integer indices from the starting index onwards. We have checked these two requirements separately. We can therefore conclude:

    Pour tout entier n≥0,Sn=3+2×n

    Why does this reach a distant index? For any fixed integer, we can start at the initial index and follow a finite number of steps to reach it. The general step justifies each of these steps. There is no final index to check, and no “infinite” index to reach.

  6. Calculate a count and check it another way

    At index 4, the product counts the socks in the 4 added pairs: 2 × 4 = 8 socks. Then add the initial contents: 3 + 8 = 11 socks.

    Check by successive additions: 3 + 2 + 2 + 2 + 2 = 11 socks. This other way of counting gives the same result without using the product directly.

    At the next index, the rule gives 11 + 2 = 13 socks. The direct formula gives 3 + 2 × 5 = 3 + 10 = 13 socks. The difference in counts between the indices is 13 − 11 = 2 socks, exactly a pair.

    These checks can reveal a calculation error. The scope “for every n” comes from the base case and the inductive step, rather than agreement between these few counts.

  7. Test the limit when the action changes

    Keep the same initial drawer contents, but now add 3 socks in each cycle. The first count becomes 3 + 3 = 6 socks. The old formula would predict 3 + 2 × 1 = 5 socks. The difference is 6 − 5 = 1 sock.

    The base case remains correct, but the step specifically used the addition of 2 socks. Changing this assumption removes the justification for the old step, and the first cycle already gives a counterexample to the old formula. A proof remains tied to its assumptions.

✿03 Common mistakes

  • “Assuming P(k) already means accepting the conclusion.”

    We assume P(k) only to prove that this property implies the property at the next index, with k arbitrary. The truth of P at the start is proved separately. Together, the starting case and the implication allow the universal conclusion.

    Reread “Assume the property at an arbitrary index”, then the step

  • “The step works, so the starting case is unnecessary.”

    In the actual drawer, the false formula Sₙ = 4 + 2 × n would also carry forward when a pair is added. Yet it predicts 4 socks at the start instead of 3, which is 1 too many. At the first cycle, it still predicts 6 instead of 5. A conditional step does not provide its own starting case.

    Revisit the base case and the conclusion

  • “I have checked up to index 5, so all indices are proved.”

    The checked counts concern particular indices. To go beyond this list, we need a calculation with arbitrary k and the actual addition rule. The second diagram separates the verified starting case from the general step; a list of counts does not provide this step.

Exercise 2 · Writing · complete proof

Give the reasons behind the equalities

Without looking at the example, prove Sₙ = 3 + 2 × n for every integer n ≥ 0. Define P(n), write the base case and then the step with arbitrary k, and conclude. Then calculate the count at index 5 and check it from index 4.

Assisted answer: try this exercise without help later.

Hint 1

In the step, start with the rule defining the next count, before using P(k).

Hint 2

You need to obtain 2 × (k + 1) by grouping the additions.

Compare with the solution

P(n) is the equality Sn = 3 + 2 × n. At index 0, its formula gives 3 socks, matching the initial count: the base case is established.

Fix an integer k, k ≥ 0, and assume P(k). The rule gives the next count by adding a pair; the hypothesis replaces the count at index k; the distributive property gives the required form:

Sk+1=Sk+2=3+2×k+2=3+2×(k+1)

P(k + 1) is therefore established assuming P(k), for arbitrary k. The base case and the inductive step let us conclude by induction that P(n) is true for every integer n ≥ 0.

Application: 2 × 5 = 10 socks added; 3 + 10 = 13 socks present. Check: index 4 has 11, and 11 + 2 = 13 socks. This calculation illustrates the formula now proved.

Check your reasoning

  • You state the property and the integer domain starting at 0.
  • You check the base case independently of the step.
  • You keep k arbitrary and justify the rule, substitution, and distributive property.
  • You conclude for all indices in the domain before the numerical check.
  • You obtain 13 socks by both methods.

Exercise 3 · Transfer · repair a proof

A correct base case with an incorrect transition

The drawer still starts with 3 socks, but each cycle adds 3. Someone keeps the formula 3 + 2 × n because the base case remains correct. Refute this formula at the first cycle, then propose and prove a formula suited to the new action.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

First compare the count obtained by the new action with the count predicted by the old formula.

Hint 2

To repair the formula, replace the number of socks added per cycle in it, then reconstruct the base case and the step.

Compare with the solution

At index 1, the new action gives 3 + 3 = 6 socks. The old formula predicts 5 socks, which is 1 fewer. This single counterexample is enough to refute the universal formula.

Let Tn denote the number of socks after n cycles with this new action. The name T distinguishes this count from the old sequence S. Propose Q(n): Tn = 3 + 3 × n, for integer n, n ≥ 0. The base case is true: 3 + 3 × 0 = 3 socks, matching the starting count.

For an arbitrary integer k, k ≥ 0, assume Q(k). Using the new rule and then this hypothesis gives:

Tk+1=Tk+3=3+3×k+3=3+3×(k+1)

The distributive property gives Q(k + 1). With the base case and step established, the new formula is true for every integer n ≥ 0 by induction. At the first index after the start, it correctly predicts 6 socks. Refuting the old formula and proving the new one are separate tasks.

Check your reasoning

  • You give the counterexample: 6 socks instead of 5.
  • You identify the addition rule as the changed assumption.
  • You check the base case and step again for the repaired formula.
  • You conclude for all integer indices in the domain, with the new count T.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What does P(n) assert, and at which indices do we want to prove it?

P(n) asserts Sₙ = 3 + 2 × n, in socks. The goal concerns every integer n ≥ 0, because n counts completed cycles.

Recall 2What does the base case check, and why does a correct step not replace it?

It compares the formula with the actual starting count: 3 + 2 × 0 = 3 socks. The step only states what follows if the property is true; it does not give a true first case.

Recall 3What exactly do we assume in the step, and what remains to be shown?

For an arbitrary integer k, k ≥ 0, we assume P(k) to prove P(k + 1) using the actual rule. We do not assume the formula for all indices or the property at the next index.

Recall 4How does adding a pair carry P(k) forward to the next index?

The rule gives the next count by adding 2. The hypothesis supplies 3 + 2 × k; the distributive property turns 3 + 2 × k + 2 into 3 + 2 × (k + 1).

Recall 5What justifies all indices, and what happens to these reasons if the addition changes?

The base case and the step for arbitrary k justify the conclusion by induction. Individual checks alone are insufficient. If the addition changes, the step must be reviewed; the base case can remain true while the formula becomes false.
