Level 2 · C062·M2

Missing value and error

Your goalDistinguish an observed 0 from a missing value and calculate a mean error while stating which comparisons are actually available.

Before you start
c061-m5 : identifiability and uncertainty · c056-m5 : effect size · c009-m5 : reading notes · c062-m1 : measurement, score and probability

✿01 See the idea

A bakery forecasts how many loaves will remain unsold at the end of each batch. For batch B, the record shows 0 loaves: someone counted, and none remained. For C, the record has not arrived. The empty cell describes a lack of information; it does not say that everything was sold.

Can we say whether the forecast for C is right or wrong? The reference quantity needed for the comparison is missing. The forecast error therefore cannot be calculated for C. For B, however, the comparison is possible, even when the quantities equal 0.

The quantities, batches and recovered record in the exercises are fictional. We are assessing forecasts of quantities, rather than probabilities. The “?” symbol in the diagram means “not recorded”; it does not represent any number.

A data entry error is something else again: a cell containing unreadable text or an impossible quantity must be checked before comparison. Here, the available records are assumed to be valid and exact. We do not replace any missing cell with an estimate.

The rule to remember

An error requires a valid forecast and reference for the same batch. Keep missing values visible and state how many comparisons the mean covers.

✿02 Follow an example

Worked example

Assess the forecasts without filling in cell C

The 4 forecasts were recorded before the final count. In loaves: A forecasts 6 and the record gives 8; B forecasts 0 and the record gives 0; C forecasts 6 but its record is missing; D forecasts 4 and the record gives 2. Let us calculate the mean of the observable absolute errors and specify its scope.

  1. Set the comparison rules

    The letter i identifies a batch. pᵢ is its forecast quantity and rᵢ its recorded quantity, both in loaves. We compare the same category of bread at the same closing time. The forecasts remain fixed; the available references are treated as exact in this exercise. A comparison requires neither a normal distribution nor independence between batches.

    N denotes the number of planned batches, here 4. I is the set of letters for which both the forecast and the reference are available and valid. Here I = {A, B, D}. n = |I| is the number of elements in this set: 3 comparisons. The bars around I count its elements; around a number, they will give its absolute value.

    It is the reference for C that is missing; its forecast exists. If the forecast were missing instead, the error for that batch would also be impossible to calculate. Keep the reason for exclusion rather than silently deleting the row.

  2. Define an error before taking its mean

    eᵢ denotes the signed error, in loaves. We choose the convention forecast minus reference: a negative sign indicates an underestimate of the unsold quantity. aᵢ denotes the absolute error, always nonnegative, in loaves. It measures the distance between the quantities without allowing the signs to cancel out.

    ei=pi−ri;ai=|ei|,i∈I

    The symbol ∈ means “belongs to”. These formulas apply only to the comparisons in I. For C, write “not calculable”. Do not form a subtraction with a question mark or turn an unknown error into a 0 error.

  3. Calculate each available difference

    A: e_A = 6 − 8 = -2 loaves. The quantity was underestimated; its distance from the reference is a_A = |-2| = 2 loaves.

    B: e_B = 0 − 0 = 0 loaves; a_B = 0 loaves. The recorded count 0 is valid information: B counts in the denominator, even though its error does not change the sum.

    D: e_D = 4 − 2 = 2 loaves; a_D = 2 loaves. Here the forecast exceeds the recorded count. C still has no calculated error. We do have 3 differences for 4 forecasts.

  4. Add, then divide by the number of comparisons

    S denotes the sum of the available absolute errors, in loaves. The symbol ∑ means “add for all the indicated letters”. E_obs denotes their mean, in loaves per comparable batch. The label obs is a reminder that it covers the observed references.

    S=∑i∈Iai;Eobs=Sn,n>0

    Adding the distances gives S = 2 + 0 + 2 = 4 loaves. Dividing by the 3 comparisons gives them equal weight: E_obs = 4/3 = 4/3 loaves per comparable batch, or approximately 1.33 loaves per comparable batch.

    If no comparison is available, n equals 0 and division is impossible. Report “mean not calculable”, never a mean error of 0.

  5. Report the number of references with the result

    There are N − n = 4 − 3 = 1 missing references. Let c be the coverage of the assessment: c = n/N = 3/4, or 0.75, with no unit. This fraction describes the availability of comparisons; it measures neither forecast accuracy nor a probability of success.

    An accurate statement is: “Mean absolute error of approximately 1.33 loaves per comparable batch, over 3 comparisons out of 4 planned batches; reference for C missing.” This tells us what the result summarizes and what remains unresolved.

    We do not know why the record for C is missing. If records are missing mainly when unsold loaves are difficult to count, the available comparisons may favor certain cases. Without further information, their mean does not determine the mean for the 4 batches. We do not need to call this missingness “random” to perform the descriptive calculation on I; that assumption would not be justified here.

  6. Check the calculation and its scope

    Check the distances: from 6 to 8, there are 2 loaves; from 0 to 0, 0; from 4 to 2, 2. Their sum gives 4 loaves again. Multiplying the exact mean by the number of comparisons must give this sum: (4/3) × 3 = 4 loaves.

    Check the bounds: 4/3 lies between the smallest difference 0 and the largest 2 loaves. Check the denominator: A, B and D each contribute a difference, C contributes none. Dividing the same sum by N would give 1 loaf per planned batch, as though C contributed a 0 error. This number is not the mean error for the complete set.

    Keep the exact fraction throughout; only the value displayed for reading is rounded. The exercises distinguish this incorrect denominator from another operation: inventing a 0 reference for C.

Explain it in your own words

Without looking at the record, explain why B must be counted and C must be left without a numerical error. Then reconstruct the statement reporting the mean and its scope.

✿03 Common mistakes

  • “An empty cell is the same as a 0.”

    Ask whether someone actually counted. The 0 for B describes an observed quantity; the cell for C describes a missing reference. Keep a “missing” state separate from the numerical value.

    Review the record and the observed 0

  • “I add nothing for C, but divide by all the batches.”

    The numerator and denominator must cover the same comparisons. Keep B, whose 0 error is known; exclude C from the mean calculation while reporting its missing reference. With no available comparison, leave the mean as not calculable.

    Revisit the sum and denominator

  • “The available references are enough to know the error for the whole list.”

    They give the mean for their own subset. The missing records may concern batches that differ from the observed ones. The exercise with the recovered record shows that a result for the complete set can change without any change to the forecasts.

    Test the consequences of recovering the record

Exercise 1 · Distinguish the states

A known 0 and an unknown error

In the initial record, state whether the reference and the error are available for B and for C. Calculate what can be calculated, then give n and N. What should be reported if all records were missing?

Hint 1

An observed quantity of 0 allows subtraction; a missing record does not.

Hint 2

Count the available forecast–reference pairs, including the pair for B.

Compare with the solution

For B, the reference is observed and equals 0 loaves. The error is calculable: 0 − 0 = 0 loaves, so the absolute error is 0 loaves. For C, the reference is missing and the error remains not calculable, even though the forecast of 6 loaves is known.

A, B and D provide n = 3 comparisons for N = 4 batches. If all records were missing, n would equal 0; the mean would be not calculable. It would not equal 0, because no error would have been measured.

Check your reasoning

  • Distinguish availability status from numerical value.
  • Keep B among the comparisons and report the missing reference for C.
  • Refuse to divide when no comparison is available.

Exercise 2 · Audit a calculation

Shortcuts that make different claims

An initial report calculates 4/4 using only the differences for A, B and D. Another replaces the missing record for C with 0 loaves, calculates its difference, then takes the mean over all rows. Find the exact results and explain the assumption invented by each report. Restore the statement justified by the initial record.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The first report implicitly adds a 0 error for C; the second assigns it a 0 reference.

Hint 2

In the second, calculate |6 − 0| before adding this difference to 4.

Compare with the solution

First report: 4/4 = 1 loaf per planned batch. It keeps the available sum but inflates the denominator; numerically, this amounts to adding a 0 error for C. Yet a 0 error would require a comparison confirming its forecast.

Second report: the invented reference gives e_C = 6 − 0 = 6 loaves, then a_C = 6 loaves. The sum becomes 4 + 6 = 10 loaves; the mean is 5/2 = 2.50 loaves per batch. This calculation is exact for the modified record, but that record does not match the information received.

The assumptions differ: no error for C in the first report, no unsold loaves for C in the second. The initial record justifies only 4/3 loaves per comparable batch, approximately 1.33, over 3 comparisons out of 4 planned, with C missing. Choosing the most flattering result does not repair the data.

Check your reasoning

  • Obtain 1 and 5/2 while keeping exact fractions.
  • Distinguish a 0 reference from a 0 error.
  • Report the available mean with its denominator and its limitation.

Exercise 3 · Update and interpret

The record for C arrives

In a fictional continuation of the same scene, a valid record for C is recovered: 9 unsold loaves. The initial forecasts remain fixed. Recalculate the absolute error for C, the mean for the complete set and the number of comparisons. Does the difference from the initial mean prove that the forecaster has deteriorated? If the record is missing precisely when unsold loaves are difficult to count, how valid is generalizing the first report?

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Compare the initial forecast 6 with the recovered reference 9; do not replace the forecast with the recorded count.

Hint 2

Add the new difference to the sum 4, then divide by the now complete number of comparisons.

Hint 3

Ask yourself what has changed: the forecasts, or the set of available references?

Compare with the solution

C: e_C = 6 − 9 = -3 loaves; a_C = |-3| = 3 loaves. The sum for the complete set becomes 4 + 3 = 7 loaves. All 4 batches are now comparable: the mean for the complete set is 7/4 = 7/4 = 1.75 loaves per batch.

The change from approximately 1.33 to 1.75 loaves per batch does not measure deterioration between periods: the forecasts are the same and we have completed their references. The first calculation described A, B and D; the second describes A, B, C and D. The mean for the complete set is consistent with the differences, since it remains between 0 and 3 loaves.

If missingness depends on counting difficulty, there is no guarantee that the observed batches represent those whose records are missing. Before recovering C, the first report had to keep this qualification. Even after all records have arrived, these fictional batches demonstrate no performance on future batches.

Check your reasoning

  • Keep the initial forecast for C and take the absolute value of the new difference.
  • Update the sum and the number of comparisons together.
  • Distinguish completeness of the record, changes in forecasts and generalization.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1Why are the 0 for B and the empty cell for C not interchangeable?

The 0 is the result of a count; the empty cell says that no reference is available. Only the former allows comparison with the forecast.

Recall 2What is needed to calculate a forecast error?

A valid forecast and reference for the same quantity and the same batch. Here eᵢ = pᵢ − rᵢ in loaves, and the absolute error aᵢ is the distance |eᵢ|. If a value is missing, the error remains not calculable.

Recall 3Which denominator goes with the sum of the available errors?

The number n of comparisons actually included, including those whose error equals 0. If n equals 0, the mean is not calculable. The planned number N describes coverage; it must not inflate the denominator.

Recall 4What is missing if we want to turn the available mean into a result for the whole list?

The errors for the excluded rows. Without these references or a justified assumption about their absence, the available mean describes only the observed comparisons. State the comparable number, the planned number and the known reason for exclusions.

Reconstruct the reasoning

Reconstruct without rereading: start with the counted 0 for B and the missing record for C; define the pair that makes an error calculable; recover the sign, then the distance; form the sum and the correct denominator; report coverage and explain why it does not guarantee representativeness. What you understand
