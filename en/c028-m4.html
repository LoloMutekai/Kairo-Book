Level 1 · C028·M4

Inclusion-exclusion

Your goalCount the files in at least one of two lists, correct for their overlap, and check the result without counting the same file twice.

Before you start
c014-m5 : invariants · c011-m5 : binomial · c028-m1 : sum and product rules · c028-m2 : permutations · c028-m3 : combinations

✿01 See the idea

You are preparing a stack of files to check. One list flags files with no signature; another flags files with no date. A file flagged by both checks must go into the stack only once. We are counting distinct files, rather than the actions needed to fix them.

In our fictional batch of 12 files, 6 have no signature and 5 have no date. Maple and Fern appear in both lists: they are the 2 shared files. Adding the lengths of the lists would count each of these files 2 times.

The idea of inclusion-exclusion is to include everything first, then remove the extra occurrences. For each shared file, removing 1 count from the 2 counts leaves 1 count. Maple and Fern therefore remain in the stack.

Here, a list will be treated as a set: a collection in which each identified file appears at most once and order does not matter. The data and names are entirely fictional. The diagrams show membership; their areas do not represent the numbers of files.

The rule to remember

To count files belonging to at least one of the two lists, add the numbers of files in the lists, then subtract the number of shared files once. Then check by separating the files belonging only to each list from the shared files.

✿02 Follow an example

Worked example

Prepare the stack without duplicating Maple and Fern

Batch U contains Amber, Mist, Cedar, Dune, Maple, Fern, Pebble, Holly, Iris, Jade, Kiwi and Ivy. A contains Amber, Mist, Cedar, Dune, Maple and Fern; B contains Maple, Fern, Pebble, Holly and Iris. How many distinct files must you take out to check for at least one of the issues?

  1. Name the objects and symbols

    U is the finite set of files in the batch. A is the set of files with no signature and B is the set of files with no date. The bars in |A| denote the cardinality of A, meaning its number of distinct elements: |A| = 6 files; |B| = 5 files; |U| = 12 files. Here, these bars do not denote an absolute value.

    The symbol ∪ is read as “union”: A ∪ B contains the files in A or B, including those in both. The symbol ∩ is read as “intersection”: A ∩ B contains only the files present in both. “At least one issue” asks for the union; “both issues” would ask for the intersection.

    Assumptions: the lists describe the same batch at the same time; a name identifies the same file in both lists; duplicates within each list have been removed. All the quantities counted are numbers of files. The reasoning does not assume any independence between the issues.

  2. Include both lists in a provisional count

    Adding the lengths counts appearances in the lists. This gives 6 + 5 = 11 appearances. We cannot yet call this total a number of distinct files: Maple and Fern have each contributed 2 times.

    We start with this sum because it includes every file we need. All that remains is to correct the extra occurrences without missing any file.

    |A|+|B|=6+5=11

  3. Measure how much has been overcounted

    Comparing the names gives A ∩ B = {Maple, Fern}. There are therefore 2 shared files. This is neither the whole of list A nor the whole of list B.

    The shared files produce 2 × 2 = 4 appearances in the sum. We need to keep 2 of them, so we remove 2 occurrences: 4 − 2 = 2. Each file only in A or only in B remains counted 1 times; each shared file goes from 2 counts to 1. Files outside the lists contribute 0.

  4. Subtract the overlap just once

    We have justified the formula file by file: after the correction, every file in the union contributes exactly 1 and every other file contributes 0. This is the inclusion-exclusion principle for 2 finite sets.

    |A∪B|=|A|+|B|−|A∩B|
    |A∪B|=6+5−2=11−2=9 dossiers

    You must take out 9 distinct files. Some will need both issues fixed, but each occupies only one place in our count.

  5. Check by recounting separate groups

    A only contains Amber, Mist, Cedar and Dune, giving 6 − 2 = 4 files. B only contains Pebble, Holly and Iris, giving 5 − 2 = 3 files. These groups do not overlap, so we can add their sizes without a correction.

    The number of files with exactly one issue is 4 + 3 = 7. Add the 2 shared files once: 7 + 2 = 9 files. We obtain the same result by splitting the union into disjoint groups, meaning groups with no shared element.

    Jade, Kiwi and Ivy are outside the union. This leaves 12 − 9 = 3. Checking the batch gives 9 + 3 = 12 files. Finally, the stack contains at least all the files in A and does not exceed the whole batch: these checks are consistent.

  6. Check the extreme cases before generalizing

    Keep the sizes 6 and 5, but imagine different memberships within the same batch. If the lists share no files, their intersection contains 0 files and their union contains 11 − 0 = 11 files: we recover the sum rule for disjoint groups.

    At the other extreme, if every file in B is already in A, there are 5 shared files. The union then contains 11 − 5 = 6 files: it is exactly A. The number of shared files cannot exceed the size of the smaller list; between these extremes, the union therefore contains between 6 and 11 files, including both bounds.

    This page establishes the case of 2 lists. Adding another criterion requires an analysis of the new overlaps; blindly repeating the subtraction written here is not a justification.

Explain it in your own words

Hide the calculation. Explain what happens to Maple, Amber and Jade in the sum and then after the subtraction. Then recover the size of the stack using the separate groups, stating what each number counts.

✿03 Common mistakes

  • “Adding the lengths of the lists is enough.”

    The sum 11 counts appearances. Find Maple and Fern: each appears 2 times. Remove one occurrence per shared file, giving 2 in total; you obtain 9 distinct files. Addition alone works when the intersection is empty.

    Revisit the provisional count and its correction

  • “Subtracting the overlap means removing the shared files from the stack.”

    You are correcting counts, rather than whether the files are present. Maple had 2 counts; removing 1 leaves 1 count. Excluding the shared files entirely would give the files with exactly one issue, meaning 7 files, and would answer a different question.

    Follow the count for Maple in the second diagram

  • “Knowing both list sizes must tell me the number of shared files.”

    The same sizes 6 and 5 allow between 0 and 5 shared files in our batch. The union can then range from 6 to 11. You must read the shared identifiers or have additional information; a drawing of circles does not provide this number.

    Examine the draft and its bounds in the last exercise

Exercise 1 · Warm-up · distinguish the counts

Exactly one issue or at least one issue?

Use the original lists again. How many files have exactly one of the issues? How many have at least one? Write down the groups you add and explain why Maple is excluded from the first count.

Hint 1

Separate A only, the shared files and B only before calculating.

Hint 2

For “exactly one”, the shared files are excluded. For “at least one”, they are kept just once.

Compare with the solution

A only contains 6 − 2 = 4 files; B only contains 5 − 2 = 3 files. These groups are disjoint, so exactly one issue corresponds to 4 + 3 = 7 files.

At least one issue also includes the shared files: 7 + 2 = 9 files. Maple has both issues; it is excluded from the “exactly one” count but kept just once in the union count.

Exercise 2 · Inverse application · calculation on paper

Recover the overlap from the stack

A new fictional record of the same batch still has 6 files with no signature and 5 with no date. This time, we know that 10 distinct files need checking. Memberships have changed: do not use the original lists of names. Find the number of shared files, then the numbers belonging only to each list and the number outside the lists.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The sum of the lengths is still 11. Subtracting the number of distinct files from it gives the excess count.

Hint 2

After finding the number of shared files, subtract it separately from each list size. For the files outside the lists, start from the whole batch.

Compare with the solution

The formula says that the union size is the sum minus the number of shared files. The number of shared files is therefore the sum minus the union size: 11 − 10 = 1 file. This is possible because the number is positive and does not exceed either list size.

A only: 6 − 1 = 5 files. B only: 5 − 1 = 4 files. Outside the lists: 12 − 10 = 2 files.

Check using disjoint groups: 5 + 1 + 4 = 10 files. Adding the 2 files outside the lists recovers the 12 files in the batch. We did not need to invent file names for the new record.

Check your reasoning

  • I find 1 shared file by isolating the overlap.
  • I give 5, 4 and 2 files for the requested regions.
  • I check both the distinct total and the whole batch.

Exercise 3 · Transfer · assess incomplete information

What a draft lets you conclude

A draft of another record of the same batch gives only |A| = 6 files and |B| = 5 files. Can you find the exact union size? Give its possible bounds. The draft then claims a union of 5 files: accept or reject this claim with a justification independent of the diagram.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The largest possible overlap contains the whole of the smaller list. The smallest overlap here is empty: the batch is large enough to accommodate disjoint lists.

Hint 2

The union must contain all the files in A. You can also calculate the number of shared files that the claimed result would imply.

Compare with the solution

The list sizes alone do not determine the overlap, and therefore do not determine the exact union size. The number of shared files can range from 0 to 5 files. The minimum union size is 11 − 5 = 6 files; the maximum union size is 11 − 0 = 11 files. These extremes are possible in the batch of 12 files: B can be entirely within A or entirely outside A.

The claim of 5 files is impossible: the union must contain the 6 files in A. Another check: it would require 11 − 5 = 6 shared files, whereas B contains only 5 files. The data contradict each other; we request a correction to the draft before announcing a total.

To obtain a valid exact number, we would need to know the number of shared files, read the identifiers in the lists, or have other equivalent information. Choosing a value arbitrarily within the bounds does not complete the data.

Check your reasoning

  • I distinguish a possible range from a uniquely determined exact total.
  • I justify the bounds 6 and 11 using possible memberships.
  • I refute the claim both because A is contained in the union and because the implied overlap is impossible.
  • I identify the missing information without inventing it.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1In the file scenario, what do the union and intersection count?

The union A ∪ B contains files with at least one of the issues, each included just once. The intersection A ∩ B contains those with both issues. The bars indicate the number of distinct elements in the set.

Recall 2Reconstruct the inclusion-exclusion formula and justify the minus sign without rereading it.

|A ∪ B| = |A| + |B| − |A ∩ B|. The sum counts each shared file 2 times; subtracting the number of shared files once leaves each counted 1 times. The other files in the union remain counted 1 times.

Recall 3How can you check the total without simply repeating the same subtraction?

Separate A only, the shared files and B only, then add their sizes: these groups do not overlap. Adding the files outside the lists lets you check the whole batch. In the original record, the union count is 4 + 2 + 3 = 9 files.

Recall 4What precautions make the counts compatible? Must the issues be assumed independent?

Count finite sets from the same batch at the same time, using consistent file identities and with no duplicates within each list. Independence of the issues is not necessary. The numbers of files alone do not give their overlap.

Recall 5Why can a claimed union size be impossible even before you read all the names?

It must contain each list and cannot exceed either the sum of their sizes or the whole batch. The inferred number of shared files must be nonnegative and cannot exceed either list size. A violation reveals incompatible data; choosing a total at random does not fix it.

Reconstruct without reference material: state what object is being counted and what “at least one” means; define union, intersection and cardinality; explain the double counting of Maple; recover the subtraction of the overlap; check using disjoint groups and then the whole batch. Finally, say what is missing when only the list sizes are known.
