Level 1 · C048·M1

Eigenvalues

Your goalFind the factors that transform a nonzero displacement into a multiple of itself, then check the equality for all its components.

Before you start
c040-m5 : least squares

✿01 See the idea

Imagine a plotter whose pen starts from the same point for each trial. You give it a displacement command on a sheet of squared paper. A rule combines the horizontal and vertical displacements before moving the pen. The resulting arrow can therefore leave the line of the requested arrow.

Some displacements have a simple property: after transformation, their arrow stays on the same line through the starting point. The rule lengthens them, shortens them or reverses their direction. The number that then multiplies the whole arrow is called an eigenvalue; the original nonzero arrow represents an associated eigenvector.

With our settings, a command of (1 ; 1) cm produces (3 ; 3) cm. The same factor 3 acts on the components. A command of (1 ; -1) cm produces (-1 ; 1) cm: the factor -1 reverses the direction without changing the line or the length.

The plotter and its values are fictional. We are studying an exact mathematical transformation of displacements, with no mechanical play, noise or added offset. An endpoint on another line fails the criterion, even if a component seems to have the right factor.

The rule to remember

An eigenvalue λ is a factor for which there is a nonzero vector v such that Av = λv. The factor must work for all components of the same vector.

✿02 Follow an example

Worked example

The special factors of the same settings

The plotter always applies the rule A below. Let us find its real eigenvalues: factors common to all components of at least one nonzero displacement. Input and output displacements are expressed in centimetres in the same orthonormal coordinate system.

  1. Read the rule and its units

    Here, a vector is a column of components: x gives the horizontal displacement and y the vertical displacement. The array A is a square matrix with 2 rows and 2 columns. Its product with this column is read row by row: multiply the entries in the row by the corresponding components, then add.

    A=[1221],A[xy]=[x+2y2x+y]

    The entries of A have no units: they multiply centimetres and produce centimetres. The orthonormal coordinate system has perpendicular axes and the same unit of length on each. A acts on all real displacements in the plane according to this fixed rule. It is linear: transforming a sum gives the same result as adding the transformed vectors, and multiplying the input by a factor multiplies the output by that factor. No constant displacement is added.

  2. Define what we are looking for

    The Greek letter λ, read as “lambda”, denotes a real number with no units. It is an eigenvalue of A if there is a vector v, different from the 0 vector, whose image Av is exactly λv. All components of the 0 vector equal 0; it is excluded because its image is the 0 vector for any linear transformation, whatever λ is.

    Av=λv,v≠[00]

    v is then an eigenvector associated with λ. This term names the displacement, while the eigenvalue names the factor. For positive λ, the arrow keeps its direction; for negative λ, it reverses direction. If λ = 0, a nonzero arrow is sent back to the starting point: this is possible for some matrices, even though there is then no output arrow showing a direction.

  3. Transform a candidate arrow

    Take v = (1 ; 1) cm, a way of writing the column on a single line. It is nonzero. We calculate the image before deducing a factor: this avoids assuming in advance that the arrow represents an eigenvector.

    First component: 1 × 1 + 2 × 1 = 1 + 2 = 3 cm. Second component: 2 × 1 + 1 × 1 = 2 + 1 = 3 cm.

    A[11]=[33] cm

  4. Propose the factor, then check the whole equality

    The first input component is nonzero. The output/input quotient gives the candidate λ = 3/1 = 3. This quotient has no units: the centimetres cancel. We still need to test the second component: 3 × 1 = 3 cm, which does equal 3 cm.

    Av=[33]=3[11]=λv

    The differences between the calculated image and the expected multiple are 0 cm and 0 cm. Equality of the whole vector establishes that 3 is an eigenvalue.

    Check using another operation: adding the input components gives 2 cm; adding the output components gives 6 cm. The ratio 6/2 = 3 gives the factor again. This sum is a useful check here because its denominator is nonzero; it does not replace checking each component.

  5. Examine the other diagonal in the diagram

    Now try w = (1 ; -1) cm, still with the same matrix. The horizontal component becomes 1 × 1 + 2 × (-1) = 1 + (-2) = -1 cm. The vertical component becomes 2 × 1 + 1 × (-1) = 2 + (-1) = 1 cm.

    The candidate given by the first component is -1/1 = -1. Check the second: -1 × (-1) = 1 cm, which does equal 1 cm. Therefore Aw = -1w. The eigenvalue is negative; the direction changes, while the line stays the same.

  6. Justify that there is no other real eigenvalue here

    Checking candidates proves that they exist, but does not prove that the list is complete. For this particular matrix, we can finish without an additional procedure. If (x ; y) is a nonzero eigenvector, its components satisfy x + 2y = λx and 2x + y = λy. Adding these equalities gives:

    3(x+y)=λ(x+y)

    If x + y is nonzero, we can divide by this sum: λ = 3. If x + y = 0, then y = −x. Since the vector is nonzero, x is nonzero; replacing y with −x in the first equality gives −x = λx, so λ = -1. These cases cover all nonzero displacements. Since we have provided a vector for each factor, the real eigenvalues are exactly 3 and -1.

    Yet the diagonal entries of A equal 1. We therefore cannot read off the eigenvalues by taking the diagonal entries of an arbitrary matrix. The method used here takes advantage of this particular rule; it does not claim to provide a general algorithm. The next unit will cover diagonalisation.

✿03 Common mistakes

  • “Eigenvalues are the numbers on the diagonal.”

    The diagonal entries of our matrix equal 1, but the equalities we checked give the factors 3 and -1. Reading them directly from a diagonal would require an additional assumption about the form of the matrix. Here, return to the criterion Av = λv and the proof that the cases are complete.

    Review the search and the proof of completeness

  • “A negative eigenvalue makes the arrow change lines.”

    Multiplying w by -1 changes the direction of the arrow while preserving its line. Distinguish the line, the direction and the length. The diagram of w and Aw shows opposite arrows along the same line.

    Review the diagram of the negative factor

  • “A quotient that works is enough; the 0 vector even works with everything.”

    A quotient is allowed only for a nonzero input component, and it gives only a candidate. Then check all components by multiplication, even those equal to 0. The vector with all components 0 is excluded: it cannot distinguish any factor.

    Test the claim and the 0 vector in the last exercise

Exercise 1 · Application · exact calculation

Shorten the displacement command along the same line

The same plotter receives p = (1/2 ; 1/2) cm, or (0.50 ; 0.50) cm. Calculate Ap, then recover the factor using a quotient and check the second component. Does the factor change because the displacement command is shorter?

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The settings A stay the same. Each row contains the coefficients 1 and 2, in a different order.

Hint 2

Keep the fractions during the calculation. Divide an output component by the corresponding input component, then check the other by multiplication.

Compare with the solution

Each image component equals 1 × 1/2 + 2 × 1/2 = 1/2 + 1 = 3/2 cm. The second row gives the same sum in reverse order. Therefore Ap = (3/2 ; 3/2) cm, or (1.50 ; 1.50) cm.

The quotient (3/2)/(1/2) equals 3. Checking gives 3 × 1/2 = 3/2 cm for each component. The eigenvalue remains 3: shortening this arrow along its line has not changed the factor determined by the settings A.

Check your reasoning

  • Calculate the rows of A using fractions and give the image in centimetres.
  • Find the factor 3 with no units and check the whole equality.
  • Distinguish the length chosen for p from the factor imposed by A along this line.

Exercise 2 · Application · direction and sign

Follow a displacement command that gets reversed

The plotter receives q = (2 ; -2) cm. Calculate Aq and find the factor relating q to its image. Then describe what happens to the line, direction and length of the arrow.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The product 2 × (-2) is negative. Calculate the rows separately before proposing λ.

Hint 2

Multiply all components of q by the same candidate. Can a factor equal to -1 change the length?

Compare with the solution

Horizontal component: 1 × 2 + 2 × (-2) = 2 + (-4) = -2 cm. Vertical component: 2 × 2 + 1 × (-2) = 4 + (-2) = 2 cm.

The quotient -2/2 = -1 gives the candidate. It also works for the vertical component, because -1 × (-2) = 2 cm. Thus Aq = -1q: the line and length are preserved, and the direction is reversed. The same negative eigenvalue applies even though the displacement command is longer than w.

Check your reasoning

  • Obtain Aq = (-2 ; 2) cm and justify the signs.
  • Check the factor -1 for all components.
  • Describe the line, direction and length separately.

Exercise 3 · Diagnostic · responding to an objection

The right quotient is not enough

Someone commands u = (1 ; 0) cm and calculates Au = (1 ; 2) cm. They announce: “1/1 = 1, so u is an eigenvector. And the 0 vector would let me choose any λ.” Respond to the claims by writing the necessary equalities. Do not divide by 0.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

If λ = 1, what vertical component should the product λu have?

Hint 2

A nonzero difference is enough to reject an equality of vectors. Then reread the condition imposed on the vector in the definition.

Compare with the solution

The horizontal quotient gives only λ = 1 as a candidate. Its expected vertical component is 1 × 0 = 0 cm. However, the actual image equals 2 cm along this axis: the difference is 2 − 0 = 2 cm. Therefore Au ≠ λu and u is not an eigenvector.

No other factor can work for u: every multiple of u has a 0 vertical component. The 0 vector does satisfy A(0 ; 0) = λ(0 ; 0) = (0 ; 0) for any λ, but the definition requires a nonzero vector. This equality therefore proves no eigenvalue.

Check your reasoning

  • Treat the quotient as a candidate and show the component that refutes it.
  • Justify that no factor makes u an eigenvector, without dividing by a 0 component.
  • Explain the exclusion of the 0 vector, without concluding that 0 is forbidden as an eigenvalue of any matrix.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What equality and what condition define an eigenvalue?

λ is an eigenvalue of A if there is a nonzero vector v such that Av = λv. λ is the factor; v is an associated eigenvector. The equality must hold for the whole vector.

Recall 2What does a negative eigenvalue mean for the plotter’s arrow?

The arrow stays on its line and reverses direction. For λ = -1, it keeps its length. A negative factor does not mean a negative length.

Recall 3How can you check a factor without risking division by a 0 component?

Calculate Av, then multiply each component of v by the candidate λ. Compare all the resulting components. To propose λ using a quotient, use only a nonzero input component.

Recall 4Why exclude the 0 vector while sometimes allowing λ = 0?

The 0 vector satisfies the equality for any factor and therefore cannot select an eigenvalue. However, λ = 0 works if A sends a nonzero vector to the 0 vector.

Recall 5Why is showing arrows that represent eigenvectors not enough to declare the list complete?

Each arrow proves that its factor exists, without excluding other possibilities. Here, adding the equations forces λ = 3 if x + y is nonzero; otherwise y = −x forces λ = -1. The cases cover every nonzero vector.

Reconstruct the reasoning

Without looking at the diagrams, reconstruct this sequence: describe the transformation and the units; choose a nonzero displacement; calculate its image; propose a factor; check the whole vector; interpret the sign; distinguish the existence of the factors from the proof that the list is complete. Finish with the counterexample u and the explanation of the 0 vector.
