Level 2 · C066·M3

Indicator variables

Your goalEncode a category in a linear model, calculate a prediction and interpret a difference from the reference category while holding order size constant.

Before you start
c065-m5 : prediction interval · c050-m5 : conditioning · c061-m5 : identifiability and uncertainty · c066-m1 : OLS in matrix form · c066-m2 : collinearity

✿01 See the idea

In a print shop, an order can arrive at the counter, by phone or through a form. The person preparing the posters knows the number of posters and the order channel. They want to predict the preparation time, in minutes. Counting posters is natural; treating the phone channel as a quantity makes much less sense.

An indicator variable answers a specific question with 1 for yes and 0 for no. Ask “Did this order arrive by phone?”, then “Did it arrive through a form?”. A counter order answers no to these questions. The counter becomes our reference category: the other channels will be described by their differences from it.

The first diagram is a coding dictionary. The second holds order size constant and shows how the channel adds its offset to the base time. The categories serve as labels; their codes represent neither a rank nor an amount of channel.

The entire scene is fictional, including the coefficients of the prediction rule. They are supplied to practise coding, without fitting them to recorded observations or measuring any real improvement. We stay in this shop throughout the calculation and exercises.

The rule to remember

Choose a reference, encode the remaining categories separately, then read each coefficient as a difference from the reference at the same order size.

✿02 Follow an example

Worked example

Preparing a phone order for 4 posters

The fictional rule gives a constant a = 5 min, a slope b = 2 min per poster, a phone difference t = 3 min and a form difference f = -1 min. The counter is the reference. Let us calculate the predicted time for a phone order of x = 4 posters, then check the interpretation of the result.

  1. Define what the rule predicts

    x is the number of posters, in posters; c is the channel, with no unit. dT(c) equals 1 if c is phone, 0 otherwise; dF(c) equals 1 if c is form, 0 otherwise. These indicators have no unit. The letters T and F are channel labels. ŷ, read “y hat”, is the predicted time, in minutes. The time actually observed will be denoted by y, also in minutes.

    y^=a+bx+tdT(c)+fdF(c)

    a is the intercept for the reference category; b is the predicted extra time per poster; t and f are offsets in minutes relative to the counter. The constant a is expressed in minutes and b in minutes per poster: all the terms being added are in minutes.

    We assume a single known channel among counter, phone and form, and the same slope b for each channel. The rule therefore assumes constant offsets regardless of size. To interpret it as a conditional mean time, we write y = ŷ + ε, where ε is the error in minutes, and assume its mean is 0 for fixed x and c. ε is not necessarily 0 for a particular order. Calculating a prediction does not give its uncertainty interval.

  2. Build the row for the order

    The order arrives by phone: dT = 1 and dF = 0. With columns ordered as constant, size, phone, form, the row of the regression design matrix is as follows. The constant uses a column filled with 1; the size column keeps its unit of posters.

    [1;4;1;0]×[abtf]

    This row–column product multiplies each entry by its coefficient, then adds the results. It connects to the matrix formulation of least squares encountered earlier; here we use the supplied coefficients without estimating them again.

  3. Calculate the base, then activate the correct offset

    Start with size: 2 min per poster × 4 posters = 8 min. Add the constant: 5 + 8 = 13 min. This is the counter prediction for the same size.

    Next activate phone: 3 × 1 = 3 min. The form contributes nothing: (-1) × 0 = 0 min. The subtotal for base and phone is 13 + 3 = 16 min; adding the 0 form term leaves it unchanged.

    y^=5+2×4+3×1+(-1)×0=16 min

    Result: 16 min predicted. The indicator selects a contribution; it represents neither a minute nor a probability of success.

  4. Check using the rule for each channel

    At the counter, both indicators are 0: ŷ = a + bx. By phone, the rule becomes ŷ = (a + t) + bx. Through a form, it becomes ŷ = (a + f) + bx. This alternative expression lets us check the matrix product without mechanically repeating the same calculation.

    At x = 4 posters, we obtain 13 min at the counter, 16 min by phone and 12 min through a form. Phone–counter check: 16 − 13 = 3 min, exactly the coefficient t. Phone–form: 16 − 12 = 4 min, or t − f.

    “All else being equal” means keeping x the same here. A positive t describes a difference between the model’s conditional predictions. It does not show that changing channels would cause this difference in the real shop. Likewise, a describes the rule at x = 0; this point may be an extrapolation with no corresponding order.

  5. Why the channels are not a single quantity

    Suppose we use the arbitrary code counter = 0, phone = 1, form = 2. Multiplying it by a single coefficient g in the rule a + bx + gc would force the form offset to be double the phone offset. g denotes this single coefficient, in minutes per unit of code; c would then denote that numerical code.

    To reproduce the phone prediction, we would need g = 3. The form would therefore have an offset of 3 × 2 = 6 min and a prediction of 19 min, instead of the 12 min given by our rule. Nothing in the channel names justifies this constraint. Indicators allow separate offsets.

  6. Keep a reference to avoid redundancy

    With our 3 categories and a constant, we use 2 indicators. If we also added dC, the counter indicator, every row would satisfy the following equality:

    dC+dT+dF=1

    The sum of these columns would be exactly the constant column. This is perfect collinearity: the coefficients in this expression would not be separately identifiable. In an expression a + bx + hC dC + hT dT + hF dF, the h coefficients are the channel coefficients, in minutes. Adding the same quantity s to a and subtracting s from each h changes no prediction, because exactly one channel indicator equals 1. Here s is an arbitrary shift, in minutes.

    Leaving out the counter column fixes its offset at 0 and makes the others interpretable relative to this reference. It does not remove any counter orders. Estimating the coefficients still requires observations covering the categories and a size that is not entirely determined by the channel: removing a redundant column alone does not guarantee that there is no other collinearity.

✿03 Common mistakes

  • “I can number the channels and multiply that number by a coefficient.”

    A category number can serve as a storage label. Treating it directly as a quantity in regression forces differences proportional to those numbers. Revisit the incorrect form calculation: it gives 19 min instead of 12 min. Create an indicator for each category other than the reference.

    Review the arbitrary code and its constraint

  • “To keep all orders, I need all the indicators along with the constant.”

    Counter rows remain present with a pair of 0 indicators. Adding their column would create an exact dependence with the constant. Choose a reference and distinguish an omitted column from an omitted observation.

    Recover the equality between the columns

  • “The phone coefficient is the total time and proves the effect of ordering by phone.”

    The predicted time adds the constant, the size term and the offset. The coefficient gives only the difference from the counter at equal size. If sizes differ, separate their contributions; a causal interpretation requires additional arguments.

An order through a form

Compare with the solution

The row is [1 ; 6 ; 0 ; 1]. The size contribution is 2 × 6 = 12 min; the base is 5 + 12 = 17 min.

Add the form offset: 17 + (-1) = 16 min. Check: relative to the counter at the same size, the prediction is lower by 1 min, as f specifies. The pair [0 ; 0] encodes the counter in the stated dictionary. A missing or new channel requires explicit handling; it must not receive this pair by default.

Exercise 2 · Reasoned comparison

The sizes differ too

Compare a phone order for 6 posters with an order through a form for 4 posters. Calculate each prediction and their difference, then separate the contribution of size from that of the channel. Is this difference the coefficient t?

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Subtract the complete rules: the constants a cancel, but the size terms do not.

Hint 2

The channel difference between phone and form is t − f; the size difference contributes b times the difference in the numbers of posters.

Compare with the solution

Phone: 5 + 12 + 3 = 20 min. Form: 5 + 8 + (-1) = 12 min. The difference is 20 − 12 = 8 min.

The size difference is 6 − 4 = 2 posters, giving a contribution of 2 × 2 = 4 min. The channel contrast is 3 − (-1) = 4 min. Their sum gives 4 + 4 = 8 min: this is an independent check by decomposition.

This difference is not t: the sizes differ and the comparison uses the form as its reference. In our rule, t compares phone and counter at equal size. These calculations remain comparisons of predictions, without demonstrating causation.

Check your reasoning

  • The predictions are calculated before being subtracted.
  • The decomposition recovers the same difference, in minutes.
  • I explain why the difference cannot be read directly as t by examining the sizes and channels being compared.

Exercise 3 · Reconstructing the rule

Phone becomes the reference

Keep exactly the same predictions for the shop, but take phone as the reference. Now use counter and form indicators. Find the new constant and offsets; check each channel at x = 4 posters. Explain why a change in a coefficient does not indicate any change in predicted time here.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The new constant absorbs the old phone offset: it equals a + t. The size slope stays b.

Hint 2

The new offsets compare each channel with phone: counter minus phone, then form minus phone.

Compare with the solution

Let a′ denote the new constant, tC the counter offset and tF the form offset, all in minutes. dC and dF are their indicators. The rule becomes ŷ = a′ + bx + tC dC + tF dF, with phone coded [0 ; 0]. The prime in a′ signals the change of reference.

a′ = a + t = 5 + 3 = 8 min. tC = 0 − 3 = -3 min. tF = f − t = -1 − 3 = -4 min. The slope stays 2 min per poster.

For 4 posters, the phone base time is 8 + 8 = 16 min. Phone: 16 min; counter: 16 + (-3) = 13 min; form: 16 + (-4) = 12 min. We recover the previous predictions for each channel.

Algebraic check: a′ + tC = a and a′ + tF = a + f; for phone, a′ = a + t. These equalities preserve the rules for every size where they are applied. The coefficients change meaning because the reference changes; the predictions are preserved.

Check your reasoning

  • The new reference has 0 indicators and the constant absorbs its old offset.
  • I calculate signed differences relative to phone, with their units.
  • I check each channel and explain why the predictions remain unchanged.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1How does an indicator represent an order channel?

It equals 1 when the specified channel is the order’s channel, 0 otherwise. It has no unit and activates its coefficient in the sum.

Recall 2What does the phone coefficient represent when the counter is the reference?

A phone–counter difference in predicted time, in minutes and at the same size. The total time also includes the constant and the size term; this difference does not prove a causal effect.

Recall 3Why not add the counter indicator to the others while keeping the constant?

For mutually exclusive and exhaustive categories, the sum of all indicators equals 1: it reproduces the constant column. The coefficients are no longer separately identifiable. Omitting a reference column keeps all observations.

Recall 4What happens to the rule if phone replaces the counter as the reference?

The constant becomes a + t; the counter and form offsets become −t and f − t respectively. The slope b and all predictions remain the same after this consistent recoding.

Recall 5What hidden constraint is introduced by a channel code used as a single quantity?

A single coefficient forces offsets proportional to the chosen codes. Channel labels do not justify this relationship; separate indicators leave each difference free.
