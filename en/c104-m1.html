Level 3 · C104·M1

Sequences

Your goalDescribe a message as an ordered sequence, then build and check pairs of observed words to prepare to predict the next word.

Before you start
c103-m5 : regularization · c101-m5 : rolling-origin forecasting · c060-m5 : approximations and assumptions

✿01 See the idea

Read the fictional message “the cat follows the dog”. If you swap cat and dog, you get “the dog follows the cat”. The same words appear with the same counts, but the one doing the following has changed. A collection of words and their counts is therefore not enough to preserve this message.

A sequence is a succession of elements with an identified position for each. It preserves order and allows repetition: here, “the” appears 2 times, at different positions. A word is a value; its position is the address at which it is read. Different addresses can contain the same value.

To prepare to predict the next word, slide a small window over this message. The window groups a fragment of consecutive words, called the context. The target is the observed word immediately after this fragment. During prediction, this next word would be hidden; in our preparatory example, it is already known and is used to check how the pairs are built.

We deliberately split this message at spaces, with no punctuation and all letters in lowercase. An element here is therefore a whole word. This teaching choice does not describe how an actual model splits text, since it may use other units. The data are fictional; no model score or real record is presented.

The rule to remember

Keep the positions, order and repetitions. For each context, place the target immediately after its last position; stop forming pairs when this target falls outside the observed message.

✿02 Follow an example

Worked example

From the message to prediction pairs

Use only “the cat follows the dog” again, with 5 observed words. Set contexts of 2 consecutive words and move forward by 1 position. Build all pairs for which the next word actually appears in this message.

  1. Define a sequence and its index

    Let s be the message split into words and T its length. The index t is an integer that numbers a position; x with index t, written xt, is the word at that position. We count from 1: T = 5 words, x at position 1 is “the”, at position 2 “cat”, at position 3 “follows”, at position 4 “the” and at position 5 “dog”.

    s=(x1,…,xT);1≤t≤T

    A finite sequence can also be understood as a rule that assigns its element xt to each position t, for 1 ≤ t ≤ T. T is a word count; t is a position number with no physical unit; xt is a text symbol and has no numerical unit. Two sequences are equal if they have the same length and the same element at every position.

  2. Separate length, diversity and order

    The message has 5 positions, but only 4 distinct words: the, cat, follows, dog. Removing the second occurrence of “the” loses 5 − 4 = 1 position. The result preserves some words but no longer lets you read the complete message.

    Keeping the counts restores the number of occurrences: “the” appears 2 times. This does not restore the order: “the dog follows the cat” still has exactly the same counts. Before preparing inputs, you therefore need to state what the representation preserves.

  3. Define context and target precisely

    L is the chosen context length, in words; i is its starting position. X with index i, written Xᵢ, denotes the ordered fragment of L words. y with index i, written yᵢ, is the target word immediately after this fragment. The uppercase letter distinguishes the fragment Xᵢ from the single word xt. A pair (Xᵢ, yᵢ) therefore associates an input with its expected output; it does not contain a computed prediction.

    Xi=(xi,…,xi+L−1);yi=xi+L

    Assumptions: the text splitting is fixed, the words remain in their observed order and every window is contiguous. L is an integer with 1 ≤ L ≤ T; the start moves forward by 1 position. We add no missing word, end marker or continuation beyond the message. The target index must therefore satisfy i + L ≤ T. Choosing to limit the input to L words is a data construction choice; it does not prove that the rest of the history would be useless.

  4. Calculate and read the first pair

    Start with i = 1 and L = 2 words. The inclusive end of the context is i + L − 1 = 1 + 2 − 1 = 2. We subtract 1 because the starting position already counts as a word. Positions 1 to 2 give Xᵢ = (the, cat).

    The target comes immediately after: i + L = 1 + 2 = 3. At this position, the message contains “follows”. The pair is therefore (the, cat) → follows. The context does contain 2 words, and the target has not been added to it.

  5. Move forward and count all the pairs

    The next start is 1 + 1 = 2. Its context is (cat, follows), and its target is at position 2 + 2 = 4: “the”. Moving forward again, the last complete context with an observed target is (follows, the) → dog.

    To count without listing the pairs, let n be the number of pairs. The condition i + L ≤ T requires i ≤ T − L. Since i runs through the integers from 1, the number of allowed starts is n = T − L. If L = T, no start leaves a target word and n = 0.

    n=T−L=5−2=3 paires

    Our last start is therefore 3; its target is at position 3 + 2 = 5, exactly the last observed position. The diagram provides an independent check: it does contain 3 arrows, each attached to the word immediately after the context.

  6. Check the boundary and what the result establishes

    Why not also keep the fragment (the, dog)? It starts at position 4, but would need a target at position 4 + 2 = 6, beyond the 5 observed words. The fragment exists; its target is not provided. You can use it to request a future prediction, but not as a complete pair with an observed answer.

    We have prepared 3 pairs without training a model. The windows share words and positions: this count does not establish a collection of independent cases. Nor does it demonstrate good prediction on new messages. How to split data to evaluate a model is covered in the unit on temporal validation.

Explain it in your own words

Hide the pairs and reconstruct them from the message. Justify separately the last position of the context, the position of its target and where the list stops. Then explain what is lost in a list of distinct words and in a list of words with their counts.

✿03 Common mistakes

  • “The same words with the same counts give the same sequence.”

    Compare the cat follows the dog and the dog follows the cat. The length and counts match, but cat and dog occupy different positions. To check whether sequences are equal, compare the elements position by position.

    Compare the rows in the diagram

  • “The target is at the last position of the context.”

    The context ends at i + L − 1; its target is at i + L. In our first window, cat ends the context and follows is the target. Write down the positions before copying the words to avoid putting the answer in the input.

    Recalculate the boundaries of the first pair

  • “Every complete fragment must have an observed target.”

    The final fragment (the, dog) does have 2 words, but position 6 is outside the message. Keep this target unknown; inventing a word or returning to the start would change the data and assumptions.

    Check the message boundary

Compare with the solution

The length is 5 words and there are 4 distinct words. The word “the” appears at positions 1 and 4, giving 2 occurrences. Counting distinct values and counting positions answer different questions.

After the swap, position 2 contains dog instead of cat. The sequences therefore differ despite their identical counts. A single different position is enough to disprove their equality.

Lengthen the context of the same message

Hint 1

The last position of the context is i + L − 1 and the target is at position i + L.

Hint 2

Stop as soon as i + L would exceed the length 5. Then compare your count with T − L.

Compare with the solution

The number becomes n = 5 − 3 = 2 pairs. At start 1, the context (the, cat, follows) has the target “the”, at position 1 + 3 = 4.

At start 2, the context (cat, follows, the) has the target “dog”, at position 2 + 3 = 5. The next start would require a word beyond the message. The observed length stays fixed: reserving more words for the context removes possible starting positions.

The change from 3 to 2 pairs does not tell us which context would produce a better model. We have only checked the construction and its boundary.

Check your reasoning

  • You find 2 pairs by calculation and then by listing them.
  • You place the targets at positions 4 and 5.
  • You preserve the order, repetitions and stated shift.

Exercise 3 · Diagnosis and repair

An input that already contains its answer

Return to L = 2 words. A preparation procedure gives the following for start 2: input (cat, follows, the), target “the”. It also adds (the, dog) → the “to avoid losing any fragment”. Check these proposals against the positions in the message, then repair them without inventing a word. Can you infer predictive quality from this list?

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Calculate the boundaries of the expected input before looking at the target. The correct target value already appears at the end of the proposed input.

Hint 2

For the final fragment, check whether the target position exists in the observed data.

Compare with the solution

At start 2, a context of 2 words is (cat, follows). Its target, at position 4, is “the”. The proposed input has 3 words and contains the word at the target position: it therefore reveals what should be predicted. This position must be removed from the input, even though the word “the” may appear elsewhere in the message.

The fragment (the, dog) starts at position 4; its target should be at position 6, which exceeds 5. The repair is to exclude it from pairs with an observed target or to keep it separately as a context whose continuation is unknown. Returning to the first word would assume a circular message, an assumption that is absent here.

A target that already appears in the input is information leakage: it cannot be used to judge the ability to predict a word that is still hidden. Even after repair, a correct list of pairs establishes no score on new messages. An answer obtained after using the hints remains an assisted answer, to be distinguished from a later independent reconstruction.

Check your reasoning

  • You repair the pair to (cat, follows) → the and justify the positions.
  • You identify the leakage through the position of the word, without banning every repetition of its value.
  • You leave the last target unknown and infer no real gain from the list.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What information does a sequence preserve that a simple word count loses?

It preserves the word at each position, and therefore the order and repetitions. The same counts can correspond to different messages.

Recall 2What is the difference between t and xₜ?

t identifies an integer position in the sequence; xₜ is the element read at that position. Different positions can contain the same word.

Recall 3A context of L words starts at i: where does it end and where is its next target?

The context ends at i + L − 1, inclusive; the target is at position i + L. The target does not belong to this window.

Recall 4Why does a message of T words provide T − L complete pairs in our construction?

With starts from 1, a shift of 1 and a target immediately after each context of L words, the last allowed start is T − L. For 1 ≤ L ≤ T, this gives T − L pairs, with no additions or return to the start.

Recall 5The last context exists, but its target falls beyond the message. What can we say?

The context is available and the next word remains unknown. This fragment does not provide a pair with an observed target; we can only request a prediction, then check it if a later observation becomes available.

Reconstruct the reasoning

Reconstruct with the page hidden: define a sequence, then distinguish position, value and number of distinct values. Next, redraw the message and its windows; work out the context boundaries, the target position, the count T − L and the first impossible start. Finish by stating what remains unknown.
