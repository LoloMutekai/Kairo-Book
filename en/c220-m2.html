Vectorization

Your goalReplace a conversion loop with array operations while preserving the values, units and correspondence between samples.

Before you start

✿01 See the idea

A data logger records electrical readings A, B and C in this order: 1200 mV, 1500 mV and 1800 mV. For this fictional scene, we choose to subtract a common offset of 1000 mV, then express the corrected voltages in volts. The data and offset are invented for the calculation; they do not describe readings from an actual device.

With a pencil, you correct A, then B, then C. A program loop can follow the same steps. Since each output depends only on the reading at its position and the common offset, we can also tell the whole array: subtract this offset everywhere, then convert everywhere. The order A, B, C must remain identifiable in the result.

This is the vectorization studied here: expressing an operation on a typed numerical array, whose entries share a numerical data type, to let a computing library handle the iteration. Loops still exist inside. This notation can avoid the cost of repeated processing of individual elements in the interpreter; it guarantees neither simultaneous work on multiple cores nor a shorter running time.

Here, a data vector means an ordered sequence of numbers. No direction in space is needed. The rule applies entry by entry; it does not combine samples with one another. If each sample has its own offset, the positions must be paired, as in the second diagram and the exercises.

The rule to remember

First write the rule for an individual entry; apply it to the array while preserving positions and units; compare with the scalar reference before measuring the running time.

✿02 Follow an example

Worked example

Convert the batch without changing the calculation

Return to the common offset b = 1000 mV. The 3 readings form X = (1200, 1500, 1800) mV. We want the array U of corrected voltages in volts, in the same order.

  1. Define the contract for an individual entry

    n is the number of samples and has no unit. i identifies a position from 1 to n in the formulas. xᵢ is the reading at that position, in mV; uᵢ is the corresponding corrected voltage, in V. b is the common offset, in mV. s = 1000 mV/V is the conversion factor: 1 V corresponds to 1000 mV. The symbol X collects the xᵢ values and U collects the uᵢ values.

    ui=xi−bs, pour chaque position i

    We assume that the readings are numerical and finite, their order is fixed, the same known offset applies to the whole batch, and s is strictly positive. A missing value requires an additional rule; it does not become a voltage of 0. The calculation does not depend on any previous output. A correction that depended on the previous output would need a separate justification before vectorization.

  2. Build the scalar reference

    Here, scalar means “one number at a time”. For A, subtracting the offset gives 1200 − 1000 = 200 mV. Dividing by 1000 mV/V gives 1/5 V, or 0.20 V. The parentheses require subtraction before conversion.

    For B: 1500 − 1000 = 500 mV, then 500 ÷ 1000 = 1/2 V = 0.50 V. For C: 1800 − 1000 = 800 mV, then 800 ÷ 1000 = 4/5 V = 0.80 V. This ordered list will serve as the reference for the vectorized version.

  3. Move from individual entries to the array

    In a NumPy numerical array, the expression U = (X − b) / s applies subtraction and division to each entry. This convention differs from matrix multiplication: it involves no summation over positions. An ordinary Python list does not give subtraction this meaning; you first need a numerical array, for example one created with numpy.asarray and an explicit floating point type.

    U=(X−b)/s=(0.20;0.50;0.80) V

    A shape describes the length of each axis of an array. Here X and U have shape (3,), meaning a single axis with 3 entries; the comma indicates a shape with a single axis. b and s are scalars. Using them at every position is called broadcasting: the library interprets the same number at each entry, without requiring us to create an array of copies.

    The rule still requires 2 arithmetic operations per sample, or 6 for this batch. This count ignores conversions, memory reads and writes and library calls: it is not an execution time. Vectorization moves the iteration into array operations; it does not remove the work proportional to the number of entries.

  4. Check the values and their correspondence

    The inverse check reconstructs the reading: s × uᵢ + b must recover xᵢ. For A: 1000 × (1/5) + 1000 = 1200 mV; for B: 1000 × (1/2) + 1000 = 1500 mV; for C: 1000 × (4/5) + 1000 = 1800 mV. The fractions keep the calculation exact here.

    Another approach: the sum of the readings is 1200 + 1500 = 2700 mV, then 2700 + 1800 = 4500 mV. The offset was subtracted 3 times: 3 × 1000 = 3000 mV. The corrected sum is therefore (4500 − 3000) / 1000 = 1500 / 1000 = 1.50 V. This agrees with 0.20 + 0.50 + 0.80 = 1.50 V.

    An identical sum does not detect a swap of positions. You must also compare the shape, order and each output with the scalar reference. On a computer, the floating point type represents some numbers with rounding. The check then uses a tolerance justified by the units and the calculation; these exact fractions do not promise equality of every bit.

  5. Preserve the correct pairings

    If the offset varies, B now denotes its array, with bᵢ in mV at the same position as xᵢ. The rule becomes uᵢ = (xᵢ − bᵢ)/s. With X and B both of shape (3,), subtraction pairs the positions.

    By contrast, shape (3, 1) describes an array with 3 rows and 1 column. To understand broadcasting between arrays, compare the axis sizes from the right: they must be equal, or one must be 1; a missing axis is treated as having size 1. Thus a column of shape (3, 1) and an array of shape (3,) can combine into a grid (3, 3). The program may accept the calculation while answering a different question: all pairs instead of pairs at matching positions. The last exercise asks you to produce a counterexample.

  6. Connect this notation to profiling

    Keep the scalar reference and check the array version first. To compare running times afterwards, follow the profiling protocol: the same inputs, the same output type and the same timed scope. State whether conversion from a list and the creation of temporary arrays are included in the cost. This page produces no timing measurement.

    The expression may create a temporary array for X − b before division. For a small batch, preparation may dominate; for a large batch, reads, writes and temporary arrays may limit the benefit. A list comprehension keeps the calculation of individual elements in Python. Short notation therefore establishes neither the mechanism of a speedup nor a performance gain. Processes and specialized hardware belong to the following units.

✿03 Common mistakes

  • “I can no longer see a loop: the work has become instantaneous.”

    The iteration has been delegated to array operations. Each sample still requires subtraction and division. Compare the versions using the same measurement scope, after checking the results; program length is not a stopwatch.

    Review the transition from arrays to profiling

  • “The dimensions are accepted, so the samples must be paired correctly.”

    A column and an array with a single axis can form a grid of all pairs. State the expected shape, preserve the identities A, B, C and check a pairing by hand. The last exercise shows an accepted but unwanted entry that pairs a reading with another sample’s offset.

    Diagnose offsets paired with the wrong readings

  • “Dividing X and then subtracting b is equivalent to converting the corrected voltage.”

    X/s is already in volts, whereas b remains in millivolts. First subtract quantities with the same unit. To change the order, you would also have to convert the offset: X/s − b/s. The inverse check can detect an incorrect offset.

Exercise 1 · Scalar application

A reading below the offset

The same data logger adds a reading of 900 mV. With b = 1000 mV and s = 1000 mV/V, calculate the corrected voltage. Can it be replaced with 0 V to avoid a negative result? Justify your answer using the given rule.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Subtract the offset before dividing. Our contract allows a signed difference.

Hint 2

Reconstruct the reading from your voltage: multiply by s, then add b.

Compare with the solution

The difference is 900 − 1000 = -100 mV. The corrected voltage is -100 / 1000 = -1/10 V = -0.10 V. Its sign indicates that the reading is below the chosen offset.

Check: 1000 × (-1/10) + 1000 = 900 mV. Replacing it with 0 V would recover 1000 mV: that would be a different transformation, which discards the sign information. No clipping rule was requested.

Check your reasoning

  • You distinguish the difference in mV from the output in V.
  • You preserve the sign and recover the original reading.
  • You explain why forcing a 0 output would change the contract.

Exercise 2 · Vectorization explained

An offset at each position

The original batch X is kept, but the successive offsets form B = (1000, 1100, 1200) mV. X and B both have shape (3,). Write the array rule, calculate the outputs in order and give a check for each pair. s remains 1000 mV/V.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The letter B denotes an array of offsets; the letter b denoted the common scalar offset.

Hint 2

Pair reading B with offset 1100 mV, and reading C with offset 1200 mV.

Compare with the solution

The rule is U = (X − B)/s, with shape (3,). A keeps its output 0.20 V. For B: 1500 − 1100 = 400 mV, then 400 / 1000 = 2/5 V = 0.40 V. For C: 1800 − 1200 = 600 mV, then 600 / 1000 = 3/5 V = 0.60 V.

The result is (0.20 ; 0.40 ; 0.60) V. Reconstruction with the correct offset gives 1000 × (1/5) + 1000 = 1200 mV; 1000 × (2/5) + 1100 = 1500 mV; 1000 × (3/5) + 1200 = 1800 mV. Using b everywhere would have preserved the shape without implementing the rule for varying offsets.

Check your reasoning

  • You write the array subtraction, then the scalar division.
  • You preserve the expected shape and the positions A, B, C.
  • Each inverse check uses the offset belonging to its own sample.

Exercise 3 · Diagnosis and repair

The array grows without any new sample

In the previous variant, someone arranges X as a column of shape (3, 1) and leaves B with shape (3,). They calculate (X − B)/s using the broadcasting described in the example. Predict the shape and number of outputs. Calculate the entry that pairs reading A with the offset for B, then repair the shapes to recover an output for each sample.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Compare the axes from the right: the last axis of X can expand, and B gains a missing leading axis.

Hint 2

The entry with a mismatched pair uses 1200 mV and 1100 mV. It does not correspond to the offset for A.

Hint 3

Choose either arrays that both have a single axis or two columns. The same pairing must appear in both notations.

Compare with the solution

Array B is treated as a row for this operation with column X. The resulting shape is (3, 3), giving 9 outputs. Each row carries a reading and each column an offset: all possible pairs have been created.

The entry for the first reading and the second offset is (1200 − 1100) / 1000 = 100 / 1000 = 1/10 V = 0.10 V. The expected output for A was 0.20 V. A plausible numerical result does not prove correct correspondence.

Repair: giving X and B shape (3,) provides 3 paired outputs; giving both shape (3, 1) provides 3 rows and 1 column. In both cases, the values in order are 0.20 V, 0.40 V and 0.60 V. Check the sample identities before changing the shapes: flattening without examining their meaning does not repair an order that is already wrong.

Check your reasoning

  • You deduce the grid and its number of entries from the broadcasting rule.
  • You show a pairing of a reading with another sample’s offset, with its value and unit.
  • You propose shapes compatible with the requested pairing and recover the reference outputs.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What scalar rule must our array expression preserve?

For each position i: uᵢ = (xᵢ − b)/s, with xᵢ and b in mV, s in mV/V and uᵢ in V. Each output keeps the identity of its reading.

Recall 2What does vectorization move, and what must still be measured?

It delegates iteration and numerical operations to the array library. The work on individual elements remains. You must check the results, then measure running times using the same scope; the notation guarantees neither a performance gain nor hardware parallelism.

Recall 3Why can a column (3, 1) and an array (3,) produce too many outputs?

Broadcasting expands them into a grid (3, 3) of 9 pairs. For our conversion of individual samples, X and the offsets B must have paired positions and identical shapes, for example (3,).

Recall 4Which checks must you reconstruct before timing?

Check units, shape and order; compare each output with the scalar reference; reconstruct each reading with s × uᵢ + bᵢ. The sum check is useful but does not detect a permutation. With floating point numbers, also justify the comparison tolerance.

Reconstruct the reasoning

Reconstruct the sequence: the contract for an individual entry with units and assumptions; the scalar reference; array operations; checks of shapes and pairings; verification of results; comparison of running times using the same scope. Explain where a grid of pairs could accidentally replace the requested pairing.
