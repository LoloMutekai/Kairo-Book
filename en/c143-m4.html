Level 2 · C143·M4

Sequences of functions

Your goalRead a sequence of functions position by position, define its pointwise limit, and use the example xⁿ to see that the index at which the tolerance is met depends on the position and that continuity of each function does not pass to the limit.

Before you start
c142-m5 : convergence criteria · c045-m5 : introductory quadrature · c046-m5 : approximation error · c143-m1 : rigorous continuity · c143-m2 : compactness · c143-m3 : Riemann integration

✿01 See the idea

On a chalkboard, draw the curve y = xⁿ between x = 0 and x = 1, first for n = 1, then for n = 2, then for n = 5, and so on. For each value of n, the chalk draws a new function fn. A sequence of functions is this ordered list of curves, all defined on the same interval.

To read it, do not look at the whole curves. Place a vertical ruler at a fixed position x, for example x = 1/2, and record where each curve crosses it. This gives a sequence of ordinary numbers, fn(x), of the kind already studied with convergence criteria. Changing the position changes this sequence of numbers: each x has its own.

If the sequence of numbers fn(x) converges, its limit is written f(x). Repeating this at every point of the interval defines a function f, the pointwise limit. The word “pointwise” means point by point: each x is treated separately, without requiring a connection between the rates of convergence at two nearby positions.

In this scene, all the curves fn are continuous. Yet as n increases, they flatten against the horizontal axis and then rise almost vertically near x = 1. Two questions guide this unit: from which index onward does fn(x) stay within a given tolerance, and does the limit f remain continuous?

The numbers in the scene are fictional working values: the interval, the tolerance ε and the positions x are chosen for the exercise, have no physical units, and do not describe any measurements.

This unit introduces the pointwise limit and observes its behaviour in one example. The condition that controls all positions at once, uniform convergence, belongs to the next unit and is not defined here.

The rule to remember

Read a sequence of functions position by position: fix x, study the sequence of numbers fₙ(x), then assemble the limit f(x). The index N for a tolerance ε may depend on x.

✿02 Follow an example

Worked example

The curves xⁿ on the closed interval [0 ; 1]

On I = [0 ; 1], define fₙ(x) = xⁿ for every integer n greater than or equal to 1. The tolerance is ε = 1/4, or 0.25 in decimal notation; this is a fictional working value with no units. The positions studied are x = 1/2, x = 3/4 and x = 4/5. What is the pointwise limit f? From which index onward does each sequence fₙ(x) stay less than ε away from f(x)? Is the limit f continuous?

  1. Define the objects and assumptions

    I = [0 ; 1] is a closed and bounded interval, the setting of the unit on compactness. For every integer n greater than or equal to 1, fn is the function x ↦ xⁿ defined on I, and the list of these functions forms the sequence (fn). Here we take as given that each fn is continuous on I, since xⁿ is a product of functions equal to x. The numbers x, fn(x) and ε are real numbers with no units.

    The pointwise limit of (fn) is the function f, if it exists, satisfying the following condition, where the index N is an integer that may depend on x and ε.

    ∀x∈I,∀ε>0,∃N,∀n≥N⇒|fn(x)−f(x)|<ε

    The number |fn(x) − f(x)| is the approximation error of fn at x; ε is the tolerance fixed before the calculation. The inequality is strict and must hold for all indices n ≥ N, rather than for just one.

  2. Fix x and find the pointwise limit

    Take x = 1/2. For n = 1, the value is 1/2; for n = 2, 1/2 × 1/2 = 1/4; for n = 3, 1/4 × 1/2 = 1/8. Each term is obtained by multiplying the previous one by x.

    fn+1(x)=x·fn(x)

    For x between 0 inclusive and 1 exclusive, this multiplication cannot increase a positive term: the sequence of numbers fn(x) is non-increasing and bounded below by 0. The bounded monotone sequence criterion, covered with convergence criteria, ensures that it has a limit L. Taking limits in the previous relation gives:

    L=xL⇒(1−x)L=0

    Since x differs from 1, the factor 1 − x is nonzero, so L = 0. At x = 1, each term equals 1 × 1 = 1, so the limit is 1. The pointwise limit is therefore:

    f(x)=0si 0≤x<11si x=1

  3. Find the first index below the tolerance

    For x < 1, the limit is 0, so we seek the first index n such that xⁿ < ε. The terms are non-increasing, so a term below ε is followed by terms that are also below ε; the first index is enough for all subsequent indices.

    xn<ε=14

    Position x = 1/2. The term at index 2 is 1/4, equal to ε: the difference 1/4 − 1/4 is 0, so the strict inequality is not satisfied. At index 3, the term is 1/8 and the margin 1/4 − 1/8 is 1/8, which is positive. First index: 3.

    Position x = 3/4. The terms at indices 2 to 5 are 9/16, 27/64, 81/256 and then 243/1024, each obtained by multiplying the previous one by 3/4. At index 4, 81/256 (or 0.316) exceeds ε by 17/256. At index 5, 243/1024 (or 0.237) is below ε with a margin of 13/1024. First index: 5.

    Position x = 4/5. The terms at indices 2 to 7 are 16/25, 64/125, 256/625, 1024/3125, 4096/15625 and then 16384/78125. At index 6, 4096/15625 (or 0.262) still exceeds ε by 759/62500. At index 7, 16384/78125 (or 0.210) is below ε with a margin of 12589/312500. First index: 7.

  4. Compare indices from one position to another

    For the same tolerance ε = 1/4, the first indices are 3, 5 and 7 at x = 1/2, x = 3/4 and x = 4/5. Index 3 is not enough at x = 4/5, since even index 6 fails there. The observed indices increase as x approaches 1, whereas at x = 1 the sequence is constant.

    We have tested only three positions: these calculations show that the index changes with x, but they do not prove that no common index exists over the whole interval. Stating and proving such a property belongs to the unit on uniform convergence.

  5. Test continuity of the limit at the point one

    Recall continuity of f at the point 1, in the sense of the unit on rigorous continuity, on the interval I where x ≤ 1. For every tolerance η > 0, it requires a δ > 0 such that:

    |x−1|<δ⇒|f(x)−f(1)|<η

    Take η = 1/2 (a new working value) and suppose a reader proposes δ = 1/10. The left endpoint 1 − δ is 9/10. The number x = 19/20 is strictly between 9/10 and 1: it exceeds the endpoint by 1/20, so |x − 1| < δ. But f(x) = 0 and f(1) = 1: the difference is 1 − 0 = 1, which exceeds η by 1/2. This δ does not work.

    The same reasoning holds for every δ > 0: the interval (1 − δ ; 1) always contains positions where f is 0, at a distance 1 from f(1). The limit f is therefore not continuous at 1, although each fn is.

  6. Check the result

    Endpoints: at x = 0, all terms equal 0; at x = 1, all equal 1. The limit therefore goes from 0, just before 1, to 1 at the point 1, confirming the jump of 1.

    Signs: the margins 1/8, 13/1024 and 12589/312500 are positive, as are the excesses 17/256 and 759/62500, and the equality in the first case does give 0. At x = 1/2, the terms 1/2, 1/4 and 1/8 decrease as expected.

    Scope: a single counterexample is enough to refute the statement “the pointwise limit of continuous functions is continuous”, but it does not establish any general property of sequences of functions. The example also says nothing about what would restore continuity.

Explain it in your own words

Explain why a single example is enough to refute “the pointwise limit of continuous functions is continuous”, but is not enough to assert a property of all sequences of functions. Also say at which point the strictness of the inequality changed the result.

✿03 Common mistakes

  • “If each fₙ is continuous, the limit f is continuous too.”

    The pointwise limit does not guarantee this passage. With xⁿ, all the functions are continuous, but the limit is 0 before 1 and 1 at 1. Repeat the test with η = 1/2: every δ fails, because positions near 1 still have a limit of 0.

    Review the continuity test at the point one

  • “The index N found for one position works for all positions.”

    Prior to any additional proof, the index may depend on x and ε. For ε = 1/4, it is 3 at x = 1/2 but 7 at x = 4/5, where index 6 still fails. A statement about “all positions” requires a separate proof, beyond this unit.

    Review reading position by position

  • “As soon as a term is equal to ε or below ε, the job is done.”

    The definition requires a strict inequality that holds for all subsequent indices. At x = 1/2, the term at index 2 is 1/4, equal to ε: the difference is 0, so the criterion is not met. A single term below ε is enough only if the sequence stays there, which the non-increasing behaviour guarantees here.

    Redo the exercise on the first index

Exercise 1 · Explained application

First index at a new position

With fₙ(x) = xⁿ and the tolerance ε = 1/4 (a fictional working value), find the first index for the position x = 2/3. Write out each term, compare it with ε using a strict inequality, and give the margins.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

At each index, multiply by 2/3, as in the example, and compare the result with 1/4.

Hint 2

Compare the terms at index 3 and index 4 with ε, stating by how much each exceeds ε or lies below it.

Compare with the solution

Calculate 2/3 × 2/3 = 4/9, then 4/9 × 2/3 = 8/27, or 0.296: this term exceeds ε by 5/108, so index 3 does not work. Next, 8/27 × 2/3 = 16/81, or 0.198, which is less than ε with a margin of 17/324. The first index is 4.

The terms decrease, so all subsequent indices stay below ε. Check: 2/3 lies between 1/2 and 3/4, and index 4 is between 3 and 5, as the order of the indices in the example suggested.

Check your reasoning

  • Successive terms are calculated by repeated multiplication.
  • Each comparison is strict and states its margin or excess.
  • The index is justified for all subsequent indices by the decreasing behaviour.

Exercise 2 · Guided reasoning

Another δ for continuity

With the limit f from the example, the tolerance η = 1/2 and the proposed δ = 1/20, show that this δ does not work for continuity of f at 1. Choose a position x in the interval (1 − δ ; 1) and calculate the difference |f(x) − f(1)|.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

First calculate the left endpoint 1 − δ.

Hint 2

Choose x strictly between this endpoint and 1, for example at the midpoint, then read f(x) from the definition of the limit.

Compare with the solution

The left endpoint is 1 − 1/20 = 19/20. The number x = 39/40 is halfway between 19/20 and 1: it exceeds the endpoint by 1/40 and remains less than 1, so |x − 1| < δ.

Since x < 1, f(x) = 0, whereas f(1) = 1: the difference is 1 − 0 = 1, greater than η = 1/2. This δ does not work. For any δ, the same choice of a position between 1 − δ and 1 leads to the same conclusion.

Check your reasoning

  • The chosen position is strictly inside the interval and strictly less than one.
  • The value f(x) is read from the correct branch of the definition.
  • The conclusion compares the difference with η, rather than ε.

Exercise 3 · Transfer

Restrict the interval

Replace I with J = [0 ; 1/2], keeping fₙ(x) = xⁿ and ε = 1/4. Write on paper: a) the pointwise limit on J and whether it is continuous; b) an index that works simultaneously for all x in J, with justification; c) what this answer does not prove about I.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Every x in J is strictly less than 1, so the analysis in the example applies.

Hint 2

For x between 0 and 1/2, compare x cubed with 1/2 cubed by multiplying inequalities between positive numbers, then compare with ε.

Hint 3

Recall the result at x = 4/5: it is outside J, and it does not settle the case of the whole of I.

Compare with the solution

a) Every x in J lies in [0 ; 1), so the limit is 0 at every point: the 0 function on J, which is continuous.

b) For 0 ≤ x ≤ 1/2, we have x cubed ≤ 1/2 cubed = 1/8, by multiplying three inequalities between positive numbers, and 1/8 is less than ε with a margin of 1/8. For n ≥ 3, fn(x) ≤ x cubed since we multiply by numbers between 0 and 1. Index 3 therefore works for all x in J.

c) Index 3 fails at x = 4/5 on I, but this does not prove that no common index exists on I. The exercise does not define uniform convergence either: it only establishes a common index on a smaller interval.

Check your reasoning

  • The limit on J is justified by x < one, then its continuity is noted.
  • The common index is justified by an upper bound valid for every x in J.
  • The answer distinguishes what is proved on J from what remains open on I.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1What is a sequence of functions on an interval I, and how do you read it at a point?

It is a list of functions fₙ defined on I. At a fixed point x, it gives the sequence of numbers fₙ(x), studied as an ordinary sequence.

Recall 2How is the pointwise limit f of a sequence of functions defined?

For every x in I and every ε > 0, there is an index N, which may depend on x and ε, such that n ≥ N implies |fₙ(x) − f(x)| < ε.

Recall 3For xⁿ and ε = 1/4, is the index the same at x = 1/2 and at x = 4/5?

No: the first index is 3 at 1/2 and 7 at 4/5. The index depends on x; a common index would be an additional property, studied next.

Recall 4Is the pointwise limit of continuous functions always continuous?

No. With xⁿ on [0 ; 1], each fₙ is continuous, but the limit is 0 before 1 and 1 at 1: it is not continuous at 1.

Reconstruct the reasoning

A sequence of functions gives a sequence of numbers fₙ(x) at each x; its limit point by point defines the pointwise limit f. For a tolerance ε, the index N satisfies a strict inequality for all subsequent indices and may depend on x. With xⁿ on [0 ; 1], the first indices are 3, 5 and 7 at 1/2, 3/4 and 4/5, and the limit is 0 before 1 and then 1: continuity of each fₙ does not pass to the pointwise limit. The condition that controls all positions at once is the subject of the next unit.
