Level 4 · C230·M3

Weak derivatives

Your goalEstablish the weak derivative of a string profile with a corner, check its integral identity, and explain why a jump changes the conclusion.

Before you start
c165-m5 : duality · c166-m5 : spectral truncation · c167-m5 : initial and boundary value problem · c230-m1 : test functions · c230-m2 : distributions

✿01 See the idea

A string is held in a V shape. Its height decreases steadily toward a central knot, then rises. On the left, its slope is -2 cm/m; on the right, 2 cm/m. At the knot, no single tangent fits both slopes. Does this mean we must give up describing how the profile varies?

Here a test function is a smooth weighting function that is 0 outside a region in the interior of the string. Instead of requiring a slope at every point, we will compare weighted integrals. Integration by parts transfers differentiation from the profile with a corner to this smooth function. This is what weak means: the requirement takes a different form without becoming approximate.

The knot is an isolated point: changing only its value leaves all these integrals unchanged. Shifting the entire right branch, however, creates a jump that test functions detect. We will use the same string to explore the limits of the definition.

The string, its dimensions, and the chosen weighting functions are fictitious. This is a prescribed geometric profile, with no model of tension, force, or evolution over time. The drawings are schematic.

The rule to remember

A weak derivative is a locally integrable function that satisfies the integration by parts identity for every test function. A corner can be compatible with this identity; a single numerical check does not prove it.

✿02 Follow an example

Worked example

Check how the string varies without differentiating at its corner

On the open interval Ω = (−L, L), with L = 1 m, the vertical displacement is u(x) = a|x|, where a = 2 cm/m. The coordinate x is in metres and u is in centimetres. We seek a weak derivative with respect to x, then calculate the integrals for a test function constructed for this profile exactly.

  1. State the definition and the units

    We use C with superscript ∞ and subscript c for the set of infinitely differentiable functions whose support is compact and contained in Ω. Such a test function φ is 0 in a neighbourhood of each endpoint. Here φ is dimensionless; its classical derivative φ′ is in inverse metres. The prime denotes differentiation with respect to x.

    The space of locally integrable functions, denoted below, contains functions whose absolute value has a finite integral on every compact subinterval in the interior. If u and a function g belong to this space, we call g the weak derivative of u when the following identity holds for every test function. The symbol ∀ means for every.

    u,g∈Lloc1(Ω)
    ∫Ωuφ′ dx=−∫Ωgφ dx,∀φ∈Cc∞(Ω)

    The minus sign comes from integration by parts. The endpoint terms vanish because of the support of φ, without imposing a boundary condition on u. The length element dx is in metres. The function g is expressed in cm/m: the integrals on both sides are in cm. In the language of distributions, the derivative of u must therefore be representable by integration against a function g. Every locally integrable function has a distributional derivative; this derivative is not always a locally integrable function.

  2. Propose a function without inventing a slope at the knot

    On the left branch, u(x) = −ax, so its classical derivative is −a. On the right branch, u(x) = ax, so its derivative is a. We propose the following function g. It is bounded and therefore locally integrable; u is locally integrable too.

    g(x)={−asi −L<x<0asi 0<x<L

    We can set g(0) = 0 cm/m, or choose another finite value: a point has measure 0 and changes no integral. A weak derivative is unique almost everywhere, meaning up to a set of measure 0. Indeed, if two functions satisfied the definition, their difference would have 0 integral against every test function; the separation result for distributions induced by functions then forces them to be equal almost everywhere. This is not pointwise uniqueness.

  3. Prove the identity for an arbitrary test function

    Now take any test function φ. We split the integral at the knot so that we apply integration by parts only to smooth expressions. The brackets denote the value of the expression at the upper limit minus its value at the lower limit.

    ∫−L0(−ax)φ′ dx=[−axφ]−L0+a∫−L0φ dx
    ∫0Laxφ′ dx=[axφ]0L−a∫0Lφ dx

    At the endpoints, φ is 0. At the knot, u(0) = 0 cm: each junction term vanishes here. More generally, contributions at a continuous junction cancel because the left and right limits of u are equal. We must not assume φ(0) = 0: a test function can cross the knot.

    ∫Ωuφ′ dx=a∫−L0φ dx−a∫0Lφ dx=−∫Ωgφ dx

    We used no particular choice of φ: this establishes the weak derivative throughout Ω. Merely identifying the classical slopes almost everywhere would not suffice; the exercise on a jump will show the term that can be missing.

  4. Construct a valid test function for the calculation

    Choose a smooth, even bump function η that is positive at the centre and nonnegative elsewhere, with compact support in (−r, r), where r = L/4 = 0.25 m. Even means η(−x) = η(x). We normalize its total integral to B = L/2 = 0.50 m. This is possible: start with an even bump function b with the same support, positive at the centre and nonnegative elsewhere, then multiply it by B divided by the integral of b. The functions b and η are dimensionless; their integrals are in metres. The precise shape of b will not enter the calculations.

    Shift a copy of η to the right by c = L/2 = 0.50 m and multiply this copy by 2. The test function we use is:

    φ(x)=η(x)+2η(x−c)

    The shifted copy has its support in (0.25 m, 0.75 m), entirely on the right. By symmetry, the central bump contributes B/2 = 0.25 m to each side. The weighted copy contributes 2 × B = 1.00 m to the right side. Denote the integrals of φ over the left and right branches by A_g and A_d: A_g = 0.25 m and A_d = 0.25 + 1.00 = 1.25 m. The subscripts g and d label the left and right branches; they do not name another function.

  5. Integrate the candidate against the weighting function

    On each branch, g is constant: take it outside the integral, then multiply its value by the integral of φ over that branch. On the left: -2 cm/m × 0.25 m = -0.50 cm. On the right: 2 cm/m × 1.25 m = 2.50 cm. The signs account for the directions of the slopes.

    ∫Ωgφ dx=−aAg+aAd=-0.50+2.50=2.00 cm

    Check using another decomposition: the central bump is even and g changes sign, so its total contribution is 0. The shifted copy lies entirely on the positive slope; it contributes a × 2B = 2.00 cm. We recover the result without adding the left and right contributions.

  6. Calculate the other side and check the sign

    The integration by parts already proved gives, separately, aA_g = 0.50 cm for the integral of uφ′ on the left, and −aA_d = -2.50 cm on the right. Their sum is -2.00 cm. We still need to apply the minus sign in the definition: −(-2.00 cm) = 2.00 cm, as for the integral of gφ.

    The residual, defined as the sum of the integrals of uφ′ and gφ, is -2.00 + 2.00 = 0.00 cm. A 0 residual checks this calculation, while the proof with arbitrary φ justifies the general conclusion.

    Another check of the side containing φ′: the central bump has an odd derivative, so its product with |x|, which is even, integrates to 0. On the shifted copy, |x| = x, and integrating x times the derivative of the bump gives −B, because the boundary term is 0. Multiplying by a and 2 gives -2.00 cm again.

  7. Distinguish a quotient at a point from the weak definition

    Take a step h = r = 0.25 m on either side of the knot. The heights are equal: u(h) = u(−h) = 0.50 cm. The centred difference quotient is therefore (0.50 − 0.50) cm / 0.50 m = 0.00 cm/m.

    This number comes from symmetry. It does not create a classical derivative at the knot: the one-sided difference quotients remain -2 and 2 cm/m. Nor does it determine a required value of the weak derivative there. The weak criterion remains the integral identity for all test functions.

✿03 Common mistakes

  • “Without a tangent at the knot, no derivative is possible.”

    The classical derivative requires a limit at a point. For the weak derivative, propose a locally integrable function, then check the identity against every test function. The corner in our string satisfies this identity without fixing g at the knot.

    Review the candidate and the integral proof

  • “The test function must be 0 at the knot.”

    Its support must avoid the endpoints of Ω, not the interior knot. The junction terms vanish here because the profile is continuous. If you artificially impose φ(0) = 0, you risk making a jump invisible.

    Examine the jump in the last exercise

  • “The residual of this calculation is 0: the proof is complete.”

    A calculation uses a particular test function. The definition requires all test functions. Reread the proof before the choice of bumps: only that proof establishes the universal quantifier.

    Return to the arbitrary test function

Exercise 1 · Warm-up · distinguish representatives

Change only the value at the knot

Define a representative ũ equal to u at every point except at the knot, where ũ(0) = 7 cm. Does its weak derivative change? Can we claim it has a classical derivative at the knot? Justify the answers separately.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

What is the measure of the single modified point? Which integrals can change?

Hint 2

For the classical derivative, start again from the quotient using the value of ũ at the knot.

Compare with the solution

The change affects a set of measure 0. For every test function φ, the integrals of ũφ′ and uφ′ are equal. The same function g is therefore a weak derivative of ũ; it remains determined only almost everywhere.

The function ũ is no longer continuous at the knot: its limit there is 0 cm, different from 7 cm. It therefore cannot be classically differentiable there. This change to an integrable representative does not describe a new continuous physical string.

Check your reasoning

  • You invoke the equality of the integrals for every test function.
  • You keep the weak derivative unchanged almost everywhere and distinguish it from the classical derivative.
  • You do not equate changing a point with shifting an entire branch.

Exercise 2 · Application · recalculate the integrals

Give less weight to the right copy

Keep the same string and the same bump η, but replace the coefficient 2 of the shifted copy with 1. For ψ(x) = η(x) + η(x − c), calculate the integrals of gψ and uψ′. Check the units and the sign in their relationship. Explain whether this new check would suffice to prove that the definition is satisfied.

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

The central bump still contributes 0.25 m on each side. The shifted copy now contributes B on the right.

Hint 2

Also compare using symmetry: only the shifted copy contributes to the integral of gψ.

Compare with the solution

The function ψ is a valid test function: it is a sum of smooth functions with compact supports in the interior. Its left integral is 0.25 m. On the right: 0.25 + 0.50 = 0.75 m.

The integral of gψ is -0.50 + 2 × 0.75 = -0.50 + 1.50 = 1.00 cm. By symmetry, the central bump contributes 0; the copy gives aB = 1.00 cm, which checks the result.

The integral of uψ′ is -1.00 cm by integration by parts. This is indeed the negative of 1.00 cm. This additional check does not replace the proof for an arbitrary test function: even several chosen tests do not cover the quantifier for every.

Check your reasoning

  • You recalculate the right integral instead of reusing the one for φ.
  • You obtain results that are negatives of each other in cm and justify the sign.
  • You distinguish checking a case from proving the universal identity.

Exercise 3 · Transfer · identify the obstacle

Shift the entire right branch

The right branch of our profile is shifted vertically by J = 3 cm. The new profile v equals u to the left of the knot and u + J to the right; its value at the knot can be set arbitrarily. For any test function φ, calculate the integral of vφ′ and decide whether g is still its weak derivative. Can the additional term be represented by another locally integrable function?

Rate your confidence before comparing

Assisted answer: try this exercise without help later.

Hint 1

Add J times the integral of φ′ over the right branch. The function φ vanishes near L, but not necessarily at the knot.

Hint 2

The Dirac distribution at the knot, denoted by δ with subscript 0, acts by returning φ(0).

Hint 3

To rule out representation by an integrable function, take test functions bounded by 1, equal to 1 at the knot, with supports that shrink toward that point.

Compare with the solution

The added term is J times the integral of φ′ from 0 to L, giving J[φ(L) − φ(0)] = −Jφ(0). Thus the integral of vφ′ is −∫gφ − Jφ(0). Changing the sign gives:

−∫Ωvφ′ dx=∫Ωgφ dx+Jφ(0)

The sign of the jump term in the distributional derivative is positive. The distribution δ at the knot is defined by δ(φ) = φ(0). The derivative of v is the distribution induced by g, plus Jδ. For a test equal to 1 at the knot, this additional contribution is 3 cm. The fact that the classical slopes remain identical almost everywhere does not remove it.

Suppose a locally integrable function ĝ represents this derivative. Then w = ĝ − g would satisfy ∫wφ = Jφ(0) for every test. Choose a smooth bump θ with a dimensionless variable, compact support in (−1, 1), and values between 0 and 1, with θ(0) = 1. For a length ε strictly between 0 and L, define the following test, denoted by φ with subscript ε:

φε(x)=θ(xε)

As ε tends to 0, these tests remain equal to 1 at the knot and their supports shrink within (−ε, ε). The absolute value of the integral of w against each test is bounded above by the integral of |w| over (−ε, ε). This last quantity tends to 0, because w is integrable on a compact neighbourhood of the knot. Yet the identity would require the integral to equal J = 3 cm every time: a contradiction. The profile with a jump therefore has no weak derivative represented by a locally integrable function, although it has a distributional derivative.

Check your reasoning

  • You retain the junction term and find the positive sign of Jδ in the derivative.
  • You distinguish a distribution from a locally integrable function.
  • You explain why shrinking test functions rule out every candidate function, not just g.
  • You relate the difference from the first exercise to the change to an entire branch.

✿05 Recall from memory

Close the lesson, answer each question, then reveal the answer. Explain any missing steps in your own words.

Recall 1Which identity defines the weak derivative, and for which functions must it hold?

For locally integrable u and g, ∫uφ′ = −∫gφ must hold for every infinitely differentiable function φ with compact support in the interior. The minus sign comes from integration by parts. Checking a single test function is not enough.

Recall 2Why does the corner in the string not prevent its weak derivative from existing?

Apply integration by parts separately on each branch. The junction terms cancel because the profile is continuous, even though the slopes differ. The function equal to −a on the left and a on the right therefore satisfies the identity for every test.

Recall 3Does the weak derivative specify a required slope at the knot?

No. It is unique almost everywhere: changing its value on a set of measure 0 leaves every integral unchanged. Changing only the value of the profile at the knot also leaves its weak derivative unchanged.

Recall 4What does an upward vertical jump J add to the derivative of the profile?

A Dirac mass Jδ at the knot, with action Jφ(0). This addition cannot be represented by a locally integrable function: shrinking test functions preserve its value, whereas the integral of such a function would tend to 0.

Recall 5What does the 0 centred difference quotient at the knot of our string prove?

It establishes that the heights at opposite positions are equal. It proves neither the existence of a classical derivative at the knot nor the weak identity. That identity concerns all test functions and specifies no required value at a single point.

Reconstruct the reasoning

Without looking at the lesson, reconstruct the reasoning: continuous profile with a corner → candidate given by the slopes of the branches → integration by parts with an arbitrary test function → examination of the junction terms → weak identity and uniqueness almost everywhere. Then recover the numerical integrals using the bumps, and explain what the jump adds and why this addition is no longer an integrable function.
