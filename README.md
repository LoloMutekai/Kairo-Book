# Kairo Book

A course in mathematics, programming and neuroscience, in English.

Read it here: https://lolomutekai.github.io/Kairo-Book/

- 696 units across 139 chapters, from C004 to C269.
- Each unit has a lesson, a worked example, three exercises with their corrections, and recall questions.
- Chapters C001 to C003 are not part of this edition.
- Every page is static HTML and works offline once downloaded.
